# 05 — 卡片參數軸

**What to build:** 使用者能用「暗屬性、龍族、等級 8 以上、攻擊力 2500 以上、但不要融合」
這種條件找卡。這是條件最多的一軸,也是 ADR-0008 的「按鈕由[[值域正典]]生成」第一次真正
發揮作用的地方——HTML 只留空殼容器,種族有幾個、[[卡片子類型]]有幾種,全部由
`window.VOCAB` 決定。

分類類條件是**三態鈕**:點一下=包含,再點=排除,再點=取消。同一軸多選是 OR,不同軸之間
是 AND,同一軸同時被包含與排除時**排除優先**。

順帶把 MD 稀有度、Genesys 點數、OCG・TCG 三個欄位做成可搜條件——它們在 oldProject 只能
顯示不能搜。

**Blocked by:** 02 — 完整卡片呈現、03 — 搜尋骨架與卡名軸
