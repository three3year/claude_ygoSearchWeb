# 04 — 必發/選發規則層

**What to build:** 重跑建置後,發動型[[效果句]]帶上[[必發/選發]]。使用者能從報告看到這一層的準確率——用官方明示的那 1,160 條當獨立驗證集,規則判定與官方答案的一致率必須 ≥98%,達不到代表規則有洞。

**Blocked by:** 02 — 拆句骨架

**Status:** ready-for-agent

- [ ] 官方明示「必ず発動する効果です」判為「必發」,優先於任何規則(預期 1,160 筆)
- [ ] 日文效果句的發動子句以「できる/できます」結尾判為「選發」,否則判為「必發」
- [ ] 只有「誘發即時效果(2速)」與「誘發效果(1速)」兩類寫入 `optional`,其餘類型一律 `null`,需有測試
- [ ] 找不到發動子句時留 `null` 待判,不強行推定
- [ ] 獨立驗證:對官方明示的 1,160 條遮住答案跑規則判定,報告一致率,門檻 ≥98%
- [ ] 未達門檻時報告列出所有不一致的條目與其句型,供修規則
- [ ] 「…時,可以」這類完成式事件的發動子句掃描不得跨越效果句邊界誤咬合併行,需有測試
