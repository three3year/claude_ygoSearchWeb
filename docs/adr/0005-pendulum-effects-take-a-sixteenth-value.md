# 靈擺效果句判第十六值「靈擺魔法卡效果」

ADR-0004 的運作身分判準在靈擺欄有一個值域缺口:P 區的卡官方規則明文「魔法カード扱い」,靈擺效果句(section=pendulum)因此不該走六類怪獸側;但九個[[魔陷卡效果]]值以[[卡片種類]]命名,而卡片種類的十值裡沒有「靈擺」——靈擺效果句無值可填。全表現況(2026-08-10 掃描):靈擺欄 595 行,效果外文本 145(rule 136 + official 9)、llm 判過六類的 3 行(白翼的魔術師 11067666 ①、疾行機人 多米諾蝴蝶 28151978 ①②)、未判 447 行。

因此[[效果類型]]的值域從十五種擴為十六種:[[魔陷卡效果]]新增第十值**靈擺魔法卡效果**,靈擺欄的效果句(非效果外文本者)一律判它。與前九值不同,它**以運作身分而非卡片種類命名**——P 區的卡是魔法卡、但不屬於十種卡片種類的任何一種,官方詞彙裡也沒有「ペンデュラム魔法カード」這個種類名。速度照 ADR-0004 的框架可推導:P 區的靈擺效果 1 速。

證據狀態與裝備狀態族(票56)不同,要誠實記錄:官方對靈擺效果**零類型詞、零「〜カードの効果として」句式**(全表僅 EMクラシックリボー 55554175 一條擦邊引用,講的是被 P 效果破壞後觸發的怪獸效果)。本值的官方背書止於「P 區的卡是魔法卡」這條規則書明文——身分有背書,值名是本專案在官方沉默處自選的。因此這個值**不進官方明示的對應表**(`_SPELLTRAP_KIND_BY_WORD` 維持九項),值只來自判定;官方未來若開口,官方明示照舊是最高權威。

## Considered Options

- **維持六類怪獸側**(3 行舊值那套):與「P 區的卡是魔法卡」的官方規則正面矛盾,也違反 ADR-0004 自己的運作身分判準——等於為靈擺欄開例外。
- **泛稱值「魔法卡效果」**:命名跟官方語彙走(官方只說「魔法カード扱い」),但破壞「值=卡片種類全名」的既有命名規則,且票56 的句式家族明定「光寫大類的不產生判定」——泛稱值與那條裁定相衝。
- **靈擺欄整欄留 null 或另立獨立值域**:null 在管線裡是「還沒判」,447 行會永遠佔著待判池;獨立值域則一欄兩套語意——ADR-0004 曾以同樣理由否決這兩型做法。
- **第十六值「靈擺魔法卡效果」**(採用):運作身分判準的自然延伸,速度可讀、一欄一套語意;命名的人造成分照上文記錄在案。

## Consequences

- 既有 3 行 llm 舊值由改判票(票57 的 fix-57 批次)換值;447 行未判**歸還既有批次池**照常排票判定(kind=null 即入池,不另開特別排票)——步驟 0 的效果外文本邊界與必發/選發仍需逐行判,不機械填值。
- 判定流程(guide §1)步驟 2 的運作身分閘門新增靈擺分支:靈擺欄的效果句 → 靈擺魔法卡效果。§2.7 由九種改十種。
- [[必發/選發]]規則與其他魔陷卡效果值一致:有觸發事件的發動句照 §4 填值;P 區玩家主動的效果發動與持續適用段留空。
- [[規則層]]的管轄範圍照 ADR-0004 的閘門自動排除本值(判成魔陷卡效果的行不比對、不升級)。
- [[遮蔽測試]]不受影響:樣本只從官方明示的六類行抽,靈擺欄的 official 行全是效果外文本。
- [[官方明示]]抽取不變:靈擺欄的補足情報照舊掃六類類型詞與效果外句式(官方若在 pen_supplement 寫類型詞,照官方判——§2.7 三種保留形態的第三種)。
