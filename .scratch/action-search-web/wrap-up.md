# 動作搜尋 篩選欄位與玩家介面(action-search-web)收尾摘要

這一輪做了 16 張票:網址不帶參數、查詢存在瀏覽紀錄(票 01);Python 的查詢判斷改成「攤平成列、比對列」,舊讀法刪掉(票 02–05);建置期產出動作索引 `web/action-data.js` 並對回效果句(票 06、07);查卡網站側欄的「動作搜尋」區塊,含動作、從/到、段類別、極性、誰、受方、原因、被動作的卡三種指定法、經引用、無法確認的張數、同一效果與命中標示(票 08–16)。整合分支 `action-search-web`(e1f689d)。

動作索引 5,667,259 位元組(5.67 MB,gzip 1.65 MB),門檻 8 MB;列 45,302;卡片結構加動作索引建置約 64 秒,門檻 2 分鐘;43,316 段裡對不回效果句的 3 段(0.007%)。20 條常用查詢在 Python 與網站上逐張相同,只有一條是預期不同(見第二題)。全部測試全綠,兩次建置逐位元組相同,也與版控裡的產物相同。數字出處見[主要數字](#主要數字)與[重跑方法](#重跑方法)。

原型在本地分支 `prototype/action-player-ui`(commit `f571c51`),不併回 main;切到那個分支雙擊 `web/prototype-action.html` 可以開。

人工驗收的步驟另成一份:`.scratch/action-search-web/manual-acceptance.md`。

## 需要你決定的

### 區域的方要不要也照 Q17「寫得比查詢寬也算」?(票 09)

Q17 定的是誰與原因:寫的範圍比查詢寬(雙方各自、原因沒寫方)算命中。從、到的方沒講,現在照 Python 原本的判法逐字比:查「對手的墓地」只命中寫明對手的線,寫「任一方」(「自分または相手の墓地から」)、「雙方各自」的不算。票上沒有建議。

- (a)維持逐字比:全庫「從對手墓地特殊召喚」直接命中 29 張(網站清單含經引用 37 張)。代價是寫「任一方」的卡要選「不限哪一方」才查得到,和誰、原因的規則不一致。
- (b)照 Q17 涵蓋:「任一方」「雙方各自」查我方、查對手都命中;同一個查詢直接命中 39 張(多 10 張;雙方各自 0 張)。代價是 Python 與網站兩邊一起改,另開票;從與到都要改。

### 「卡名包含」要比哪些名字?(票 13)

網站的「給條件 → 卡名包含」比中文名、日文名、英文名與別名(大小寫不分,同指定卡的建議清單);Python 的「卡名包含」只比日文卡名(含卡片屬性表裡不設位置的「〜として扱う」卡名)。打日文時兩邊相同,打中文時只有網站查得到;網站只多不少。「兩邊答案一致」的測試只用日文。票上沒有建議。

- (a)維持現狀,網站多比中文、英文與別名:全庫「破壞 + 卡名包含 黑魔導」網站 1,259 張、Python 0 張;「特殊召喚 + 龍」網站 1,856 張、Python 948 張。代價是這一欄兩邊答案不一致,Python 驗不到中文的結果。
- (b)網站也只比日文名:兩邊永遠相同。代價是玩家打中文查不到東西。

### 效果對應要不要再補對法?(票 07)

43,316 段裡靠編號對回 34,061(78.6%)、靠原文位置 9,252(21.4%)、留空 3(0.007%);引用列 28 個全部對回。留空的 3 段全在 メンタルマスター 96782886:官方 DB 文本是舊式無編號,效果標記表的日文是新版,兩份卡文版本不同,官方 DB 文本更新後會自己對上。另有 2 段(7369217、69456283 的ユニオン括號說明)被效果標記表拆在兩個效果句之間,照段的起點算在前一句。

- (a)不補(建議,實作者的結論):兩種對法已經幾乎全部對回;對不回的段在同一效果的判斷裡當作符合,只是不標底色。
- (b)再補對法:要為 1 張卡的版本差異另寫規則,收益只有這 3 段。

### 開泛用引用時經引用的 `via` 樹要不要縮小?(票 04)

現有規則是經引用展開到底、只在走過的卡停,同一張卡經不同路徑會重複出現。Python 開泛用引用(`generic_reference`)時這棵樹很大:「儀式召喚」開泛用引用,15 張經引用卡的 `via` 合計約 58 萬個條目,查一次 4–7 秒,大部分是產出這棵樹。玩家介面的泛用引用固定關,不受影響;下一輪進階模式要開這個開關時才會碰到。票上沒有建議。

- (a)維持現有規則:張數與命中都正確,只是明細很長、慢。
- (b)改成每張經引用的卡只列一次:明細短、快。代價是改既有規則(里程碑二票 13),排進下一輪、和進階模式一起做。

### 實作:票 12 這張卡自己與指定卡

- 帶狀態的此卡(「この効果で特殊召喚したこのカード」「フィールドのこのカード」)算「這張卡自己」:它是母體為此卡的子集,不是「條件式剛好讓這張卡滿足」。

- 指定卡的建議清單比中文名、日文名、英文名與別名,最多 12 張;名字長度用對上的那個名字算。

### 實作:票 13 給條件

### 實作:票 14、15 經引用與無法確認
