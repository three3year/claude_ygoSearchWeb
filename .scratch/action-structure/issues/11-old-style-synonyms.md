# 11: 舊式用語同義表

**What to build:** 站主查詢時,舊式寫法的卡和新式寫法的卡一起被找到:「する事ができる」「フィールド上」「ゲームから除外」「生け贄」與新式同義;舊式「〜体を選択して」算取對象、不收成「選擇」;被動與主動收成同一動作詞。

- 動作詞:機制相同、寫法不同收成同一詞(被動也收);機制不同分開(捨てる ≠ 墓地へ送る、時 ≠ 場合、取對象 ≠ 選擇)。
- 同義表保留原述語字面,合併或拆開只改對照表、不重抽。
- 用官方 DB 文本重量各舊式用語的出現次數(先前的數字是在 ja-JP.cdb 上量的,不能沿用),附可重跑的統計工具。

**同義表抽成 `script/action_structure/synonyms.py`**(`PREDICATE_STEMS`、`TAILS`、`ACTION_PAST`、`TARGETING_PREFIXES`、`TARGET_REF`、`ACTIVATION_SUFFIXES`、`COST_GLUE`、`parse_predicate(s)`、`split_targeting`);`segment_extract` 再匯出同名,`action_query` 的匯入點不變。收進的舊式用語:

| 舊式 | 收法 |
|---|---|
| 生け贄に捧げる | 動作詞 解放(= リリース);「た」語尾、「なければならない」→ 極性 必須 |
| ゲームから除外する/される | 動作詞 除外,到 = 除外(述語寫明) |
| 墓地に送る | 動作詞 送墓(= 墓地へ送る) |
| 〜事はできない、戻す事ができる | 語尾(不能 / 可選) |
| 発動する事ができる | 發動句語尾(= 発動できる),反向檢查固定接著詞 |
| フィールド上 | 區域 場上(`ZONE_WORDS`,排在 フィールド 前) |
| (區域)に存在する(物件) | 從的助詞(= の),字面保留在 `from.text`,反向檢查照字面還原 |
| 〜を選択して(述語) / 〜を対象として(述語) | **取對象字面**:對象線 `targeting` True,字面留在原述語字面開頭(「選択して破壊する」);述語空的「〜を選択して発動できる」是發動句的取對象宣告(代價段、沒有動作詞) |
| 選択したモンスター/カード | 指回本區塊最近被取對象的同大類物件,線標取對象(= そのモンスター) |
| (代價)る事で、(效果) | 舊式代價句 = 「〜て発動できる。〜」,切成代價段 + 效果段(`_OLD_COST_RE`;「〜された事で」不切) |

「選択」「対象」不是動作詞;「以下の効果から１つを選択して」物件短語解析不出,不會被標成取對象(票 06 做分歧)。**新式「を対象として」一併收了**(同一機制、同一張表),票 08 的「取對象 墓地 → 特殊召喚」這類斷言可直接用;「対象として発動できる」後效果段的「そのモンスター」線已標取對象(`state.targeted` 由取對象字面填,`kind == 效果` 且指回被點名物件才標;延遲段不標留給票 08)。

**反向檢查模板**:簡單子句加 `[取對象字面]` 槽(在數量之後、原因之前);取對象線只有兩種寫得出——述語帶取對象字面(每條線都要標),或線指回本區塊先前被取對象字面點名的物件(`_targeted_earlier`);其餘標了 `targeting` 的線仍是「取對象線無模板」。`GLUE` 加 発動する事ができる(長的在前)與 事で。
