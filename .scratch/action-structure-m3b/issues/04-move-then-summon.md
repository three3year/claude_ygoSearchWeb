# 04: 移走 + 召喚切成兩段

**What to build:** 「XをリリースしてY召喚」的 X 只是被解放的卡,不再標成被召喚:

- て形串接的左半是把卡移走的動作詞(解放、除外、送墓、捨棄、返回、破壞)、右半是召喚系動作詞(召喚、上級召喚、通常召喚、反轉召喚、特殊召喚、P召喚、融合召喚、儀式召喚、S召喚、X召喚、L召喚)時,切成兩段:左半一段(線是左半的受詞),右半一段(線是主語;沒寫主語照既有的主語省略規則)。
- 左半的段類別照所在的句子(召喚條件區塊裡照既有規則是召喚手續,條件子句裡是條件段)。
- 右半沒寫主語、而且此卡的大類不是怪獸時,不退回此卡(站主裁定):右半的線指回同一區塊前面最近一個做同一種召喚(上下位詞也算)的段裡被召喚的物件,線標省略(找來源段的方式同里程碑三票 08:條件段與極性不能/不會的段不算,那一段要恰好一條被召喚的線)。找不到時右半標解析不出,原因「指回的物件找不到」;左半照常。此卡是怪獸時照既有規則,省略的主語是此卡。
- 左半是不移走卡的動作詞(無效、展示)時照舊一段共用一條線。
- 只管右半是召喚系的て形串接;右半是其他動作詞的(「無効にして破壊する」「リリースして発動できる」)不動。
- 反向檢查把切開的兩段接回一句,寫回原文相符。查詢判斷不改。

- 規格:需要你決定的「切開後的召喚段沒寫主語、此卡又不是怪獸時怎麼記?」「被解放的怪獸標成被召喚,修多寬?」「分開之後記成兩段嗎?」;實作決策「述語的串接」;使用者故事 17–22、44。

### 做了什麼

- `synonyms.move_then_summon_cut`:原述語字面是「移走的動作詞字幹 + て/で 收尾的語尾」而後面整串拆得回召喚系述語時,回左半字面長度;`simple_clause.move_summon_cut` 換成子句裡的位置。抽取與模板共用這一把尺。
- 效果子句(含召喚條件區塊的召喚手續、編號效果的「〜召喚する事もできる」)在 `_cost_and_effect` 切,右半排成下一截;條件子句在 `_condition_and_rest` 切,左半沒有觸發形、右半帶觸發形。兩種都是右半與左半連接「同時」,段類別照所在的句子。
- 右半照主語省略規則;此卡不是怪獸、而且主語退回此卡時,改指同一區塊前面最近一個做同一種召喚的段被召喚的物件(`cause_phrase.source_segment` 只給同區塊的段 + `summoned_by`),找不到標「指回的物件找不到」。
- 反向檢查:條件段沒有觸發形本來一律無模板,改成照 `simple_clause.is_move_half`(下一段緊接著它、兩段原述語字面接起來正好切在這一段結尾)放行;兩段各自寫回原文,接起來就是原句。

### 標「讀法」的決定(規格沒寫死、照既有做法或自己定的,請站主過目)

1. **寫在左半前面的主語怎麼放**。規格寫「右半一段(線是主語)」,但主語字面(「このカードは」「このカードが」「レベル７以上のモンスターは」)在原文裡寫在左半前面,段的範圍是連續的,放不進右半。做法:主語字面留在左半的範圍裡,照物件切點記成左半的施事線;右半沒有字面,線照主語省略規則指回同一個物件(「Xは」指 X,其餘是此卡)、標省略。查詢比對時施事線在段裡另有受詞時不比(`action_query._is_doer`),所以查「解放」指定此卡不會因為這條施事線命中。結果和規格要的一致(右半被召喚的是主語、左半命中的是被移走的卡),只是主語的字面記在左半。
2. **切開的兩段連接記「同時」**,同連用形串接。條件子句切出的兩個條件段也記「同時」(其他條件段之間沒有連接)。
