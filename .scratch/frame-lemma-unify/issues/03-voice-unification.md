# 03 — 態歸一

**What to build:** 同一動作的他動/自動/受身收成一個詞元、以他動形為名,差別記在態欄:戻る→戻す(自動);上げる→アップ(他動)、上がる→アップ(自動);下げる→ダウン(他動)、下がる→ダウン(自動);無効化(される)→無効にする(受身);全部折疊的 N になる→N にする(自動)、N となる→N とする(自動)——倍/半分/同じ/対象/攻撃対象/直接攻撃/素材/無効/効果… 與裸 になる→にする(站主 2026-10-27 裁定照同一條規則、不留例外)。アップ/ダウン 本身不分自他:對象欄有值(を)是他動,受事者在主語/主題(は/が)是自動,兩者都沒有時空。站主在拆解頁看到「このカードは墓地に戻る」是 戻す+自動、「攻撃力は倍になる」是 倍にする+自動、「効果は無効化される」是 無効にする+受身。類別樹做最小合併讓既有測試綠。來源:spec 實作決策「詞元對照表」態歸一段與「態欄」、ADR-0016。
