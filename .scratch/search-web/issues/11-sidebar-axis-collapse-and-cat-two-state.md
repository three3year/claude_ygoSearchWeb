# 11 — 側欄軸摺疊與大類兩態化

**What to build:** 側欄垂直太長——17 個參數軸兩百多顆按鈕全部展開,找一個條件要捲很久。
把每個參數軸改成**可摺疊區塊、預設收起**,側欄初見只剩三個文字輸入欄、搜尋/清除鈕與
一排軸標題列。同時把[[大類]]從三態鈕改成**兩態**(選取/未選):大類只有三值,排除某一類
等同勾選其餘兩類,排除態是冗餘的,而且點過頭誤入排除態會讓子類組整組收起,是這次
「行為不對」回報的實際來源。其他軸維持三態不變。

**摺疊與連動隱藏是兩個機制,語意不同**:

- **摺疊**是瀏覽狀態——收起只是視覺收納,裡面已選的條件**保留生效**,標題列顯示
  軸名＋已選數(如「種族 (2)」),避免看不見的條件造成零結果困惑。
- **連動隱藏**是條件語意——取消大類時對應子類組照舊**收起並清空**(現行
  `showAxis(false)` 的清空邏輯不變),[[必發/選發]]軸的承載連動同理。

兩者銜接:大類點選後,對應子類組**出現且自動展開**(點了怪獸通常就是要篩子類,
省一次點擊);必發/選發軸因效果類型選取而出現時同樣自動展開。

摺疊狀態**不記憶**——不進網址 hash、不進 localStorage。還原分享網址時,**有已選條件的軸
(含連動出現的軸)自動展開**,讓收到連結的人看得到條件。各軸獨立展開/收起,**可同時
多開**,非手風琴式。

舊網址相容不需處理(本版尚未公開,無既有分享連結)。
