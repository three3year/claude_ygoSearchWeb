# 01 — 效果類型判別規範文件

**What to build:** 一份 `docs/effect_kind_guide.md`,讓任何一個新開的 session 都能在沒有對話脈絡的情況下,對一條[[效果句]]判出唯一的[[效果類型]]與[[必發/選發]]。這是所有判定票與遮蔽測試的共同依據,也是遮蔽測試失敗時唯一的修正對象。

規範必須能獨立運作:讀者只有卡文(繁中與日文)、[[補足情報]]、與這份文件,沒有別的。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 六種[[效果類型]]各有一段定義,並附至少 3 個取自[[補足情報]]的官方例句(日文原文 + 卡名)
- [x] 有一條判別流程,對任一效果句走完後只會停在一個類型上,不會出現「兩者皆可」的終點
- [x] 「無種類效果」的定義明確對應官方用語「分類されない効果」,並說明它與「效果外文本」的差別(前者是效果但不屬四類,後者根本不是效果)
- [x] [[必發/選發]]的判別寫明三層:官方明示「必ず発動する効果です」→ 日文發動子句以「できる/できます」結尾為選發、否則必發 → 皆不適用時待判
- [x] 明文記載僅「誘發即時效果(2速)」「誘發效果(1速)」兩類具備必發/選發,其餘為空
- [x] 收錄歷史易錯區分,至少含:「只要OO在怪獸區域存在」判為永續;裝備方向「裝備此卡的怪獸」(此卡是裝備卡→無種類)vs「此卡裝備的OO」(此卡是怪獸→永續);「…時,可以」完成式事件的發動子句掃描邊界
- [x] 明文禁止把「効果ではありません」當作任何判定依據,並說明原因(多為「対象を取る効果ではありません」這類限定否定)
- [x] 說明[[官方明示]]的歸屬陷阱:補足情報會為解說而引用**其他卡**的效果文,判定歸屬時必須確認引用的是本卡
- [x] 說明無編號舊式卡文的拆句原則:依語意拆,每段必須是原文的連續子字串,換行為強分隔提示
- [x] 文件全程使用 `CONTEXT.md` 的詞彙,不使用實作名稱

## Comments

- 交付於 `docs/effect_kind_guide.md`。六類定義各附 3–4 條**實際存在於來源資料**的官方例句(卡片密碼 + 日文原文 + 明示句原文),不是編造的範例。
- 實作票 02 期間發現兩處必須寫進規範的官方事實:
  - 「〜として扱う」的規則處理(鳳凰 機亞弗里德 ①「フィールド・墓地に存在する限り、通常モンスターとして扱う」)官方判**無種類效果**,而非永續效果——雖然句型帶「存在する限り」。已寫成 §5.1 的唯一例外。
  - 裝備魔法的攻守變動,官方明示只寫到「チェーンブロックの作られない効果です」(團結之力 ①),**沒有指名類型**。這種寫法不構成[[官方明示]],不得當作類型依據;裝備方向的類型約定因此是寫死的規範(§5.2)而非官方裁定。
