# 02: 選值鈕的隱藏與灰色

**What to build:** 開一張標籤的抽屜,點選鈕只列這個動作在語料裡有的值;配合目前其他欄沒有命中的值灰掉、不能按。單詞標籤上按任何按得下去的鈕都有結果,否定形在極性不含否定時是灰的。見規格「判定」「條件模型的介面」「條件列與抽屜」段與前五題決定。區域三欄與中心詞兩欄在票 03、04,這張只做點選鈕的欄。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 引擎有一個純函式:給述詞與一欄,回傳其他欄成立的框上這一欄出現過的值;只掃詞元自己的框
- [ ] 條件模型有「抽屜選項」:標籤 → 分組 → 欄 → 值與狀態(亮、亮且鎖住、可按、灰);隱藏的值、沒有值的欄、沒有欄的組不列。票 01 的鎖住改由它給
- [ ] 隱藏只看詞元(三個位置、三種極性都算),整個標籤期間不變;灰色依其他欄目前的值,同欄已選一值時本身沒命中的另一值也是灰
- [ ] 亮著的值一律列出、可關,含詞元沒有的值(網址帶進來)
- [ ] 包含與排除標籤得到同一份選項
- [ ] 抽屜照抽屜選項畫:灰是不能按的鈕,提示「目前條件下沒有結果」;欄全空不畫、進階全空連小標不畫;點條件列的字仍捲到那一欄
- [ ] 條件模型測試(手寫小框表):規格 Testing Decisions 條件模型段除區域、中心詞以外的例子
- [ ] 全語料測試:75 張單詞標籤每顆可按的鈕加上去張數大於 0、每顆灰鈕加上去張數是 0、每個隱藏的值放開位置與極性後仍是 0
- [ ] 抽屜重畫一次的耗時(框數最多的 特殊召喚)記進 Comments
- [ ] 全套 node 測試通過
