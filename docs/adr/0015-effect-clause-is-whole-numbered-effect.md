# 效果句改指整段編號效果,效果類型標在標記句上

[[效果句]]原本同時是兩件事的單位:卡文的「一個效果」,以及[[效果類型]]、[[必發/選發]]、[[官方明示]]歸屬與[[遮蔽測試]]的標記單位。ADR-0012 與效果句詞條讓「●」子效果在官方認可時拆成獨立的列,所以 824 個 ● 子句(449 組、445 張卡)各自成為一句效果句。[[效果文分詞]]與[[動作框架]]直接沿用這個切分,母句和選項因此互相看不到:4079728 ② 的「以下のモンスターの内１体を選び」對不上後面的三個列舉項,43476205 ① 的「以下の効果を発動できる」整句抽不到框架。另有 430 句的 ● 從未被拆開,同一種結構在兩邊得到不同處理。

站主裁定(2026-10-09):它們本來就是一整段效果。我們決定**效果句改指一個編號效果的全文,連同它的「●」[[選項]]**;帶效果類型的那一列改稱[[標記句]],被拆開的效果句由一句[[領起句]]與數句[[子效果句]]組成。`data/tag_cards.json` 的拆法與內容不變,只是名稱換了;分詞與框架抽取改以效果句為單位。

## Considered Options

- **效果句不動,分詞線另立新詞「效果段」**:改動最小,只多一個詞條。但「一整段效果」這個概念會有兩個名字,而且站主心中的效果句本來就是整段。
- **效果句改指整段,標記單位另名**(採用):詞義回到站主的直覺,資料不動。代價是「效果句」在舊文件與程式註解裡的意思和新定義不同,要掃一次。
- **全面改,資料也併回**:把 824 列 ● 子句併回 449 個母句,推翻 ADR-0012 的 ● 拆分。184 組母句與選項的效果類型不同(例如 220414 ② 的賦予型領起句是效果外文本,●１つ 是誘發即時效果(2速)),一句會帶多個類型;搜尋的效果類型×必發/選發組合條件、官方明示歸屬、遮蔽測試的樣本 key 都要重做。這是另一條線的大工程,不值得為分詞而做。

## 分詞與框架的連帶決定

- **單位**:分詞與框架抽取以效果句為單位,被拆開的效果句把領起句與子效果句依序接回一段,每段仍保留自己的 index 與效果類型。
- **效果層**:分詞報告與框架覆蓋率分「效果/效果外文本」兩層統計;含子效果句的效果句一律算效果層。99 組領起句是效果外文本、子效果句是效果,依舊的切法會把真正的效果算進效果外。
- **● 成為選項邊界 token**:分詞器原本把 ● 當靜默字元丟掉;接回一段後若照舊丟,列舉項會連成一串。這條同樣套用到從未拆開的 430 句。
- **框架記選項**:出自選項的動作框架記它屬於哪個 ●,以及「●自分ターン：」這類標籤的值。標籤本身沒有述語,不另出框架。
- **列舉項不代入**:4079728 ② 是全語料唯一的純列舉項(3 句);為一張卡寫代入規則屬過擬合,框架的對象維持「以下のモンスターの内１体」,列入已知未修。
  - 更正(2026-10-14):「唯一」是錯的事實——重算後純列舉項(● 項全部沒有框架)是 27 張卡,幾乎都是「デッキから以下のモンスター/カード(の内N枚)を…」接清單的句型。「對象欄不代入」的決定不變;清單改記在框架的**列舉**欄(有序字串清單),規格見 `.scratch/frame-args-v2/spec.md`。

- CONTEXT.md:效果句詞條改寫;新增標記句、領起句、子效果句、選項;效果標記表到分類表一段的「效果句」改為標記句;效果文分詞、動作框架、發動句詞條改指新義。
- 2026-10-09 之前的文件與程式註解裡,「效果句」指標記句。`docs/effect_kind_guide.md`、`docs/effect_kind_rules.md`、`web/js/engine.js`、`script/tag_card/` 的註解與測試另開一張掃詞票;`.scratch` 舊票是歷史紀錄,不改。
