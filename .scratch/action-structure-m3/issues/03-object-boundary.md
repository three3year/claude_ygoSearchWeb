# 03: 物件切點

**What to build:** 物件範圍不再往前吞進不屬於它的字面。現況「物件修飾解析不出」的 9,678 個物件裡有 3,560 個是切點問題:時點「自分・相手ターンに、」「１度、」、標籤「：」、前提「〜限り、/場合、」、期間「発動後、ターン終了時まで」「エンドフェイズに」、「または、/さらに、」、「〜の中から、」、「〜になるように、」、主語「Xが/Xは」、物件內的「〜から」、開頭的助詞殘片。切出去的前文交給既有規則(前提、期間、時機、主語的對象線);既有規則認不得的,那一段照舊標解析不出,但物件本身不再帶吞進來的字面。「●２体以上：」「自分：」這類標籤記成依值分歧的標籤。

本票只修切點,不補修飾語規則(票 04、05、06)。
