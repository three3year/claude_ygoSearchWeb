# 01 — 改寫表來源檔與建置套用

**What to build:** 「文本改寫表」進站通道的地基:與[[卡文勘誤表]]並列的自持來源檔(一筆一卡:`id`/`old` 舊全文校驗/`new` 新全文/`refs` 依據條目/`reason`/`ticket`),建置卡片總表時整卡 desc 全文替換。放一筆合成改寫進來源檔、重跑建置,即可在卡片總表看到該卡 desc 換成新全文,回報列印套用筆數;`old` 對不上現行 desc、或同卡同時在勘誤表與改寫表,建置整批列舉後吵鬧失敗(ADR-0011 失敗哲學)。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] 來源檔落在 `data/` 直下與勘誤表並列,納入[[資料更新時間]]/建置回報慣例
- [x] 建置套用純函式與勘誤套用同層:全文相等校驗,不匹配整批列舉後 raise
- [x] 兩表互斥:同一 `id` 同在勘誤表與改寫表 → 建置失敗
- [x] build/update 兩個 CLI 都接改寫表(比照勘誤表參數與預設路徑),回報「文本改寫: 套用 N 筆」
