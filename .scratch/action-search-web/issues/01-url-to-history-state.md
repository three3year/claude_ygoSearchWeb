# 01: 網址不帶參數,查詢存在瀏覽紀錄

**What to build:** 搜尋後網址維持不變、不帶任何參數;上一頁、下一頁、重新整理照樣回到對應的查詢。範圍是整個查卡網站現有的條件,動作條件由票 08 接上。

- 查詢狀態(卡片條件、排序)不再寫進網址。每次搜尋在瀏覽紀錄新增一筆,狀態存在那一筆裡;上一頁、下一頁、重新整理時從那一筆還原條件並重查。
- 存在瀏覽紀錄裡的狀態可能是舊版網站寫的:認不得的欄位或值忽略,其餘照常還原。
- 網址帶著舊格式的參數時不解讀,顯示首頁,並把網址上的參數清掉。
- 把條件寫成網址、從網址讀回條件的程式與它的測試一併移除,包括修復被轉傳弄壞的連結那一段。
- 狀態的形狀要留得下之後的動作條件(票 08 會加),這張票不必先定它的內容。
- 雙擊開啟與經伺服器開啟行為相同。

- 規格:需要你決定的「Q27」;實作決策「網址與瀏覽紀錄」;使用者故事 42–46;測試決策「接縫三」與人工驗收。
- 背景:「不改網址、把狀態存在瀏覽紀錄裡」在雙擊開啟的頁面上實測可行(規格「補充說明」)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 搜尋後網址不變、不帶參數
- [ ] 每次搜尋新增一筆瀏覽紀錄;上一頁、下一頁還原條件、排序與結果
- [ ] 重新整理後條件、排序與結果還在
- [ ] 帶舊格式參數的網址打開是首頁,網址上的參數被清掉,不出錯
- [ ] 從瀏覽紀錄還原時,認不得的欄位或值被忽略、其餘照常還原(接縫三測試)
- [ ] 寫網址、讀網址的程式與測試已移除;沒有殘留只給它用的程式
- [ ] 其餘前端測試全綠;沒有條件時的畫面與現在相同
- [ ] README 裡提到分享網址或網址參數的段落已更新
- [ ] (站主)在真實瀏覽器驗上面四條行為,雙擊開啟與經伺服器開啟各一次;實作者把驗收步驟列在 Comments
