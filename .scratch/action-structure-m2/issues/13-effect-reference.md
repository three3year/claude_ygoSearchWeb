# 13: 引用他卡效果

**What to build:** 「この効果は、その罠カード発動時の効果と同じになる」「そのモンスターと同じ効果を得る」這類複製他卡效果的句子抽成內嵌效果節點 `{ref: {object: 被引用物件, effect: 引用的部分}, block: None}`;`effect` 值域:卡片發動、含某動作的區塊(「儀式召喚する効果」)、代價是某動作的區塊(「自身を手札から捨てて発動する効果」)、整張(判不出時)。建置時依被引用物件的條件式求出候選卡清單存進結構;展開到底,偵測到循環時停止,覆蓋報告加「引用循環」節(附卡號);被引用物件解析不出 → 節點標解析不出、原因「引用其他效果」,覆蓋報告加這一節;被引用物件是泛用物件 → 節點記 `any: true`。查詢:結果新組「經引用」,經引用命中的卡不進命中組,`hits` 項帶 `via`(經由的卡號與其命中段),只看 `effect` 指定的部分;新欄「泛用引用」開關(預設關),開時 `any` 節點也展開、命中標「經泛用引用」。查數值相同的「レベルは〜と同じになる」不在本票(票 08 的性質變更)。
