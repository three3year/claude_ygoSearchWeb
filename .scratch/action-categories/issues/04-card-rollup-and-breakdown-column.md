# 04 — 卡層彙總檔與拆解頁類別欄

**What to build:** 分詞鏈多出一份卡層彙總檔:每張卡的葉集合分效果組與代價組(各自去重、依樹序排)。拆解頁的框架表多一欄「類別」,顯示從大類到葉的路徑,多葉並列;不適用與未歸類各以淡色標示。站主翻任一張卡,逐框架看得到它歸哪裡;檢視 artifact 照原網址重新發布。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 卡層彙總檔:每卡一列,效果組與代價組的葉集合;由框架類別檔決定性彙總;不入版控;大類與詞元層不另存。
- [ ] 檢視資料腳本多讀框架類別檔與卡層彙總檔,把類別併進卡片拆解分片;拆解頁框架表加類別欄(路徑、多葉並列、不適用/未歸類淡色)。
- [ ] 卡層彙總經同一接縫餘多句組裝驗:一張卡的幾句原文 → 效果組與代價組的葉集合;回歸例子至少含代價位除外不進效果組一條。
- [ ] 檢視 artifact 照原網址重新發布;票 Comments 記網址與這一版的已歸/未歸/不適用數。
