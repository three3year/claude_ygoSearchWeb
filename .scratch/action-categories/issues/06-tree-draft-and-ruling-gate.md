# 06 — 類別樹草案與裁定關卡

**What to build:** agent 依 193 種動作詞元與來源/目的/極性/對象的分佈起草整棵類別樹:建議的大類名與成員、每個詞元的葉切法、每葉的條件、框架數、卡數與三條例句、預期未歸類的詞元清單(長尾 ≤3 次者預設不開葉)、與舊 21 類的一次性對照表(哪些舊類被合併、拆開、新增)。草案是審核關卡 md,走 review-mirror 發布鏡像;站主在鏡像上改大類名、搬詞元、拆合葉,封頂後 agent 把樹寫進來源檔、全語料重跑。站主裁定完成時,框架類別檔與拆解頁反映的是站主的樹。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 草案 md 的計數與例句由腳本從框架類別檔決定性產出(資料塊),不手抄。
- [ ] 草案含:樹、每葉條件/框架數/卡數/例句、未歸類詞元清單、舊 21 類對照表;同一動作兩個詞元的情形(已知未修第 8 項:宣言 vs 攻撃宣言)記在對照表,是否回框架線修由站主在關卡決定。
- [ ] 「需要你決定的」列大類命名與有爭議的葉切法,每項附選項與建議;鏡像記入 mirrors.json。
- [ ] 草案發布後本票標 ready-for-human;站主裁定後 agent 更新樹來源檔、補回歸例子、全語料重跑、拆解頁與總覽重新發布、決定行記回草案並重發鏡像,再標 resolved。
