# 效果 Tag 判定規範

體系定稿:2026-09-20 凍結(裁定紀錄 `.scratch/effect-tag/rulings.md`,票03–06);
2026-09-21 站主覆核裁定票15 增補 LP支付/LP失去 兩類(支付/失去/傷害三分)。
機器正本為 `script/web/vocab.py` 的 tag 值域(seal 對帳 `tag_digest`);本文件是
人讀正本,供判定票的批次檔引用。**追加類別、增刪槽位值、改邊界通則,一律需新
裁定票**;判定票只選 tag、不改體系。

判定基礎一律是**日文原文**(`text_ja`):tag 是對效果語意的結構化標注,繁中譯文
經過翻譯會失真(與效果類型判別規範 §0 同一條理由)。

## 0. 標的與範圍

- 標的是[[效果句]]:一句 0..N 個動作 tag(多動作句逐動作貼),外加誘發系句子
  的[[觸發時機]]單值。
- 第一期範圍:新式卡文效果句(index 帶①編號、kind 非效果外文本)。舊文卡效果
  句於體系穩定後另期補判。
- 條件與否定不貼:「〜できない/されない」歸行動限制/耐性;「〜した場合」「〜
  する場合」「〜する度に」是觸發或條件描述,不是動作;「●…する効果」這種
  **描述別的效果**的句段也不是動作。

## 1. 通用槽位

- **位置**(`pos`):`成本` / `效果`。**發動子句**(以「〜発動できる/発動する」
  收尾的第一句)裡的付出貼 `成本`;處理段的動作貼 `效果`。**無發動子句的句子
  (自我特召程序、永續/場地魔法的處理、●選項的領起句以外部分)一律貼 `效果`**
  ——位置只在有發動子句時區分。未拆的 ● 選項列舉裡各選項自帶「〜して発動
  できる」的,那個付出照樣是 `成本`。**代替處置**(「代わりに〜」)一律貼
  `效果`,不論替代的是代價還是破壞。**唯一不設位置槽位的類別是 LP支付**
  (裁定票15):支付本身就是代價,位置軸對它無意義,搜尋一律命中。
- **對象方**(`side`):`自身`(此卡自己)/ `我方` / `對手` / `雙方`。**判得準
  才填,不猜**;槽位缺值代表未標注,不代表「無」。

## 2. 動作類別(21 類)

### 區域移動(第1期已開貼)

卡片從一個區域到另一個區域。槽位:`from` / `to` ∈ {手牌, 牌組, 額外牌組, 墓地,
除外, 場上, 靈擺區} + `side` + `pos`。

- 慣用名對照(顯示層):蘇生=墓地→場上;檢索=牌組→手牌;回收=墓地→手牌;
  彈回=場上→手牌|牌組;送墓=任意→墓地;展開=手牌|牌組|額外→場上。
- 牌組頂/底不獨立(歸「牌組」);**牌組內位移**(「デッキの一番上に置く」而
  來源也是牌組)貼 `{to: 牌組}` 不填起點。
- 靈擺區放置(「Pゾーンに置く」)歸本類;起點/終點可為 `靈擺區`。
- 複合起點(「手札・墓地から」「デッキ・EXデッキから」)**逐起點各貼一個 tag**。
- 對象在發動子句、動作在處理段(「墓地の…を対象として発動できる。その
  モンスターを特殊召喚する」)照對象的區域填起點。
- 起點不明(「そのカードを手札に戻す」來源多可能)只填終點。
- 衍生物生成(トークン特殊召喚)貼 `{to: 場上}` 無起點。
- 場內身分/區位變動(罠モンスター「モンスターゾーンに特殊召喚する」、魔陷區
  ⇄怪獸區)貼 `{to: 場上}`、起點留空。
- **不貼**:通常召喚的解放手順(「リリースして召喚する事もできる」)、儀式/
  融合召喚的執行本身(歸召喚執行)、「魔法カード扱いで…セット/置く」(歸
  放置轉換)、X 素材的取除與重疊(不建模)、被動未來式(「〜された場合に除外
  される」的自我除外附註)。

### 抽牌/手牌交換

抽卡(不指定卡)。`side`、`extra` ∈ {捨棄, 回牌組}、`pos`。「抽1捨1」一個 tag
帶附帶槽位;「デッキから選んで加える」是檢索,歸區域移動。

### 無效

`what` ∈ {發動, 效果, 持續無效化};`extra` ∈ {破壞, 除外}。連鎖上的無效貼
發動/效果;「効果は無効化される」貼持續無效化。

### 破壞

效果破壞(戰鬥破壞是狀態,不貼;代替破壞歸耐性)。`what` ∈ {怪獸, 魔陷, 卡};
`scope` ∈ {單體, 複數, 全體};`side`、`pos`。

### 行動限制

禁止/限制行動。`what` ∈ {特殊召喚, 發動效果, 攻擊, 表示形式, 其他};`side`
(受限方,自限=我方);`term` ∈ {持續, 單回合}。

### 耐性/保護

`what` ∈ {戰鬥破壞, 效果破壞, 效果對象, 除外, 全效果, 代替破壞};`side`。
邊界:「攻撃できない」→行動限制;「攻撃対象にならない」→戰鬥規則;「効果の
対象にならない/受けない」→本類。

### 攻守調整

`item` ∈ {攻擊, 守備, 攻守};`dir` ∈ {上升, 下降, 變成}。「〜になる」句型
(倍化、減半、變 0、指定值)一律「變成」;「アップ/ダウン」歸上升/下降。

### 效果傷害/生命回復

`side`(承受方/回復方)、`form` ∈ {固定值, 參照值, 比例}。戰鬥傷害修飾歸
「其他」。LP 的四分:給傷害=效果傷害、回復=生命回復、付代價=LP支付、
失去=LP失去(裁定票15)。

### LP支付/LP失去(裁定票15,2026-09-21 增補)

- **LP支付**:玩家把 LP 當代價主動付出(「LPを払う」,含全形「ＬＰ」寫法;
  發動代價與維持代價都算)。槽位:`side`(支付方)、`form` ∈ {固定值, 參照值,
  比例}(「８００LPを払い」=固定值;「攻撃力分のLPを払う」=參照值;「LPを
  半分払って」=比例)。**不設「位置」槽位**(見 §1)。
- **LP失去**:效果使玩家失去 LP(「LPを失う」)。規則上**不是傷害**——不受
  傷害相關的防止/換算效果影響,故與效果傷害分立。槽位:`side`、`form`、`pos`。
- 邊界:
  - 「発動するために払うLPが必要なくなる」(支付免除)不是支付動作,不貼
    本類,歸「其他」。
  - 「LPが半分になる」等 LP 直接改寫句型量少,暫歸「其他」,累積後再裁。
  - 「ダメージを与える/受ける」歸效果傷害;「LPを回復する」歸生命回復。

### 表示形式變更

`to` ∈ {攻擊表示, 守備表示, 裡側表示};自由變更 `to` 留空。

### 控制權轉移/性質變更/計數器操作

`dir` ∈ {取得, 移交};`item` ∈ {卡名, 種族, 屬性, 等級, 階級, 刻度} +
`term`;`act` ∈ {放置, 去除}。

### 放置轉換

以改變後的身分被放置(當作裝備卡/永續魔法/永續陷阱/魔陷覆蓋)。`to` ∈
{裝備卡, 永續魔法, 永續陷阱, 魔陷覆蓋}。目的地是身分改變者歸此類——唯一
例外:靈擺區歸區域移動。

### 素材代用/召喚放寬/召喚執行/戰鬥規則/情報操作/其他

- 素材代用/召喚放寬:代替素材、無視召喚條件、追加召喚權。
- 召喚執行:魔陷卡上的召喚指令;`method` ∈ {儀式, 融合, 同步, 超量, 連結}。
- 戰鬥規則:`what` ∈ {貫通, 連續攻擊, 直接攻擊, 攻擊對象操作}(含許可與禁止)。
- 情報操作:`what` ∈ {確認, 展示, 隨機決定}。手牌妨害=區域移動+隨機決定兩個 tag。
- 其他:跳過階段、縱列操作、硬幣/骰子、戰鬥傷害修飾等,暫不細分。

## 3. 觸發時機(句層單值)

僅誘發系承載類型(誘發即時效果(2速)、誘發效果(1速)、魔陷卡效果十值)、且
發動子句帶觸發事件的句子。值域 17 值(見 vocab);「被破壞時」不分戰鬥/效果;
同句多個時機取**最先寫出的**;判不進 16 個具名值的貼「其他」。

## 4. 判定產出與來歷

- tag 物件:`{"cat": …, 槽位…, "pos": …, "src": "llm", "ticket": 票號}`。
- 判過某類別但**該句無該類動作**時,tag 給空、由收票程序把類別記進
  `tags_checked`(判空紀錄;seal 的零空缺讀它)。
- 規則直貼的 tag(`src: "rule"`)每次重跑重算;LLM/manual 的 tag 一經寫入
  照 ADR-0002 的保留規則,修正走 rejudge。
- 規則層的粗篩(候選圈選)與規則定義見 `script/tag_card/tag_rules.py` 與
  `docs/effect_tag_rules.md`;粗篩漏網是已接受的殘餘風險(ADR-0013)。

## 5. 逃生口

判不出、或句型落在本規範沒有涵蓋的形狀時:tag 留空、寫 `note`,不猜。累積的
懸案由裁定票收割——與效果類型線的規範演進同一條路。
