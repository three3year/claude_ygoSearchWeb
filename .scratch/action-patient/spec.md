# Spec: 動作對象——動作類別搜尋的「此卡/非此卡」條件

Status: ready-for-agent
Date: 2026-10-30

上游是動作類別搜尋線(`.scratch/category-search/`,票 01〜06 已交件):側欄「動作類別」軸能用類別樹的節點找卡,但最細只到「特殊召喚←手札」這種「動作+起訖區域」,分不出動到的是不是這張卡本身。本規格是 2026-10-30 /grill-with-docs 的定案,GLOSSARY.md 已新增「動作對象」詞條,並在「動作類別」詞條的搜尋段落補了一句指向它。

## 需要你決定的

### 「此卡」依什麼判?

決定(2026-10-30):(a)看受事者。

- (a)看受事者(建議):他動看對象,自動/受身看主語或主題。「解放此卡發動,從手牌特召另一隻」的特召不算此卡。
- (b)框架任一欄提到此卡都算:較寬,雜訊接近現在用效果文填「此卡」。

### 對象空著、主題是此卡的框架算不算?

決定(2026-10-30):(b)算,不分動作。

- (a)只限召喚/移動/素材類動作(建議):「此卡可以直接攻擊」不算,因為此卡是執行者。
- (b)算,所有動作都算:「此卡可以從手牌特殊召喚」「此卡可以直接攻擊」都是此卡。
- (c)不補:「此卡可以從手牌特殊召喚」這類 240 多張卡會漏。

### 適用範圍?

決定(2026-10-30):(a)全軸共用。

- (a)全軸共用(建議):一個條件管所有葉,「此卡回到手牌」「此卡攻擊力上升」都查得到。
- (b)只對召喚類。

### 介面形式?

決定(2026-10-30):(a)全域三選一切換,標題「動作對象」,選項「不限/此卡/非此卡」,放在「含代價」旁。

- (a)全域切換(建議):和「含代價」同一套模式,樹不變大;無法同時查「此卡特召」AND「其他卡除外」。
- (b)樹裡新增此卡葉(特殊召喚←手札:此卡):可混合查詢,但葉數大增。
- (c)每個節點三態外加此卡小切換:介面複雜。

### 第三個狀態是什麼意思?

決定(2026-10-30):(b)非此卡=確定不動到此卡。

- (a)動到別張卡:有動到此卡以外的卡就中,不管有沒有順便動到此卡;發動位置推論用不上。
- (b)排除此卡(建議):只有確定不動到此卡才中;字面指名此卡、或依發動位置推論會包含此卡,都不中。

### 「此卡和別張卡」(六花精 雪花蓮「此卡和1隻植物族怪獸從手牌特殊召喚」)怎麼算?

決定(2026-10-30):只在「此卡」中。原本裁定兩個模式都中;改採「非此卡=確定不動到此卡」後,「非此卡」不中。「このカードを含む〜」同樣處理。

### 此卡的屬性、裝備怪獸、X 素材怎麼算?

決定(2026-10-30):(a)屬性算此卡,裝備怪獸與 X 素材不算。

- (a)屬性算此卡,裝備怪獸/素材不算(建議):「此卡的攻擊力上升」查得到;裝備怪獸、X 素材是另一張實體卡。
- (b)屬性也不算:只有字面剛好是「此卡」才算。

### 泛稱群體怎麼算?

決定(2026-10-30):「此卡」模式下,泛稱群體不論全部類或選擇類一律不中。「非此卡」模式下,選擇類(帶數量)中;全部類(沒有數量)依發動位置推論,會包含此卡就不中。

- 只算非此卡:不推論。
- 兩種模式都中:「此卡+破壞」會混進大量全場破壞卡。
- 依發動位置推論(站主採用,細節如上)。

### 發動位置怎麼推?

決定(2026-10-30):依序取句中寫明的位置、觸發事件裡此卡去的地方、處理中此卡自己移動的起點;都沒有就是場上。

- 寫明的:「此卡在墓地存在的場合」「將墓地的此卡除外發動」「手牌的此卡」。
- 觸發事件:「此卡被送去墓地的場合」→ 墓地。
- 自己移動:「此卡從手牌特殊召喚」→ 手牌。

### 全部類要比對哪些條件?

決定(2026-10-30):比對區域、玩家、卡種、種族、屬性、字段、卡片子類型、數值條件;比不了的定語視為可能包含此卡。

- 區域、玩家、卡種都對(建議):比較少的版本。
- 也比種族、屬性、字段、子類型、數值(站主採用)。
- 只比區域:「對手場上全部破壞」也當成會動到此卡,明顯不對。

### 受事者寫成區域時怎麼算?

決定(2026-10-30):(a)當泛稱群體。

- (a)當泛稱群體(建議):「丟棄1張手牌」是選擇類,「手牌全部丟棄」照發動位置推論。
- (b)當作沒有受事者:「非此卡+捨てる」會漏掉最常見的寫法。

### 受事者是效果、發動、攻擊時怎麼算?

決定(2026-10-30):(a)跟著主人走。

- (a)跟著主人走(建議):「此卡的效果無效」是此卡;「那個發動無效」「對手的效果無效」當選擇類,非此卡中。
- (b)當作沒有受事者。

### 沒有卡片受事者的動作怎麼算?

決定(2026-10-30):(b)兩種模式都不中。

- (a)非此卡中:這些確實不動到此卡。
- (b)兩種模式都不中:只在「不限」時出現;「非此卡+抽卡」一定查無結果。

### 排除條件要不要套用模式?

決定(2026-10-30):(a)包含與排除都套用,和「含代價」一致。

- (a)兩邊都套(建議):勾「此卡」再排除「破壞」,只擋「會破壞此卡」的卡。
- (b)只套包含。

### 命中葉強調怎麼標?

決定(2026-10-30):(a)只標該模式下命中的葉。

- (a)只標該模式命中(建議):標示和過濾一致。
- (b)照舊標全部。

## Problem Statement

牌手想找「此卡從手牌特殊召喚」這類卡(手牌自己出場的怪獸),但動作類別樹最細只到「特殊召喚←手札」。這片葉不分動到的是此卡還是別張卡,1,593 張卡混在一起。

現在只能靠效果文近似:填「此卡從手牌特殊召喚」只抓到 532 張,漏掉「此卡可以從手牌特殊召喚」「此卡從手牌守備表示特殊召喚」等寫法;填「此卡%從手牌%特殊召喚」有 1,136 張,但會混進「此卡召喚時…從手牌將1隻…特殊召喚」這種「此卡」只是條件的句子。反過來想找「從手牌特召**別的**怪獸」更沒辦法。同樣的需求也出現在其他動作上:此卡回到手牌、此卡除外、此卡攻擊力上升,以及「不會動到此卡」的全場破壞。

## Solution

動作類別軸頂端、「含代價」旁加一個三選一切換「動作對象:不限/此卡/非此卡」,預設不限。

- **此卡**:選中的節點只算動到此卡本身的動作。卡文要直接指名此卡,包括此卡的屬性、此卡和別張、包含此卡的群體、此卡當作…使用。
- **非此卡**:選中的節點只算確定不動到此卡的動作。帶數量的選擇(場上1張卡)算;沒有數量的全部類(場上的卡全部)要依此卡發動時人在哪、群體的區域與條件能不能包含此卡來判斷。
- 包含與排除都套用;結果清單句尾只強調該模式下命中的葉;模式寫進網址。

資料面,分詞鏈匯出時逐框架判定動作對象,每句在原本的效果位/代價位葉之外,再記「此卡葉」與「非此卡葉」;網站索引帶這些欄位,查詢引擎依模式取葉。

## Implementation Decisions

**動作對象判定(分詞鏈匯出,擴充)**

- 判定在匯出步驟做,逐個帶葉的動作框架(效果位與代價位)給一個值:此卡/非此卡/皆非。框架抽取本身的受事者取法不改;判定在它的結果上加規則。
- 匯出多一個輸入:卡片總表裡此卡的卡面參數,包括卡種、子類型、種族、屬性、等級/階級/連結、攻守、日文卡名(比字段用)。
- **受事者**:依態,他動取對象,自動/受身取主語、沒有時取主題。對象空著而主題(含句內延續的主題)以此卡收尾時,主題就是受事者,不分動作。回填的值照常算。
- **此卡**:受事者字面指名此卡。包括:
  - 以 このカード 收尾,含帶定語或未切掉的區域/狀態(…したこのカード、リンク状態のこのカード)。
  - このカードの〈屬性〉,例如攻擊力、守備力、等級、Pスケール、效果。
  - 並列含此卡:このカードと〜、〜とこのカード、このカードを含む〜。
  - このカードは…として扱う。
  - 不算此卡的:このカード以外、このカードの装備モンスター、このカードのX素材、このカード名の。
- **非此卡**:受事者是卡,字面不指名此卡,而且不是「會包含此卡的全部類」。
  - 選擇類:受事者帶數量(數字+枚/体/つ…,或「〜まで」),一律算非此卡。
  - 全部類:沒有數量。依發動位置與條件比對判斷會不會包含此卡,會包含就是皆非,不會就是非此卡。
  - 受事者寫成區域(手札を１枚捨てる):以那個區域當群體,同樣依數量分選擇類或全部類。
  - 受事者是效果、發動、攻擊:主人是此卡 → 此卡;其他當選擇類 → 非此卡。
- **皆非**:沒有卡片受事者(ドロー、ダメージ、LP、數值)的框架,以及會包含此卡的全部類。哪些受事者不是卡,由匯出端一張封閉的名詞表決定,表外而且判不出來的列進報告。
- **發動位置**:一句效果句(整個編號效果,ADR-0015)內依序取:
  1. 條件或代價裡寫明此卡的區域(このカードが墓地に存在する場合、手札のこのカードを捨てて、墓地のこのカードを除外して)。
  2. 條件位觸發事件裡此卡的去處(このカードが墓地へ送られた場合 → 墓地;去處不明的「從場上離開」當不在場上)。
  3. 處理中此卡自己移動的起點(このカードを手札から特殊召喚 → 手札)。
  4. 都沒有就是場上(此卡在我方)。
- **全部類比對**:群體的區域(所在或來源)含發動位置,而且玩家、卡種、種族、屬性、字段、卡片子類型、數值條件全都對得上此卡的卡面參數,才算會包含此卡。
  - 字段比對:「X」以此卡日文卡名含 X 判斷。
  - 比不了的定語一律視為對得上,也就是可能包含。
  - 「このカード以外」直接判非此卡。

**匯出檔格式**

- 每句在既有的效果位葉、代價位葉之外,各再分兩組:此卡葉、非此卡葉。各自去重、依樹序,沒有就省略。
- 一個葉可同時在此卡葉與非此卡葉:同句兩個框架,一個動此卡、一個動別張。
- 皆非框架的葉只在原本的效果位/代價位葉裡。
- 匯出檔的 META 加此卡卡面參數的摘要(或逐卡雜湊),讓卡面參數變動時能判定匯出過時(同原文雜湊的精神)。

**索引管線(接縫 1)**

- 每句標記句在既有的效果位葉、代價位葉旁多四個對齊欄位:效果位此卡葉、效果位非此卡葉、代價位此卡葉、代價位非此卡葉。空值省略。
- 卡面參數摘要對不上時建置失敗,同原文雜湊的處理。
- 建置報告加:各模式的框架數、卡數,皆非裡「比不了視為可能包含」與「發動位置用預設場上」的數量。
- 兩次建置逐位元組相同。

**查詢引擎(接縫 3)**

- 查詢條件多一項動作對象,值是不限、此卡、非此卡。
- 每句的有效葉依模式取:不限時取原本的效果位葉(含代價時加代價位葉);此卡或非此卡時,改取該模式的效果位葉(含代價時加該模式的代價位葉)。包含、排除、命中句、AND 的既有語意都照舊,只是改讀有效葉。
- 沒選任何類別節點時,模式不影響結果。
- 舊式卡文的卡照舊不中。

**網址 hash**

- 動作對象以一個參數寫進 hash,不限時不寫。未知值安靜忽略,往返相等。

**呈現**

- 句尾仍列該句全部的葉,代價位另色照舊。
- 命中強調只標該句「有效葉 ∩ 包含節點葉集合」裡的葉,也就是該模式下真的命中的葉。

**側欄**

- 動作類別軸頂端、「含代價」旁放三選一切換,標題「動作對象」,選項「不限/此卡/非此卡」,預設不限。
- 已選數照舊只算節點;模式不是不限時,摺疊的標題上看得出模式在生效。
- 手機寬度可用。

## Testing Decisions

- 好的測試只斷言接縫的外部行為:日文例句與卡面參數進,匯出紀錄的模式葉出;查詢條件進,命中卡與命中句出;HTML 字面出。不斷言判定函式的內部、DOM 結構或 CSS class。
- **分詞鏈匯出接縫(擴充)**:沿用 `test_export.py` 的寫法(合成標記句經真的組裝、框架抽取與類別樹,再進匯出),多帶此卡卡面參數。每條裁定至少一個例句,斷言該句的此卡葉、非此卡葉:
  - 此卡:此卡從手牌特召;主題寫法「此卡可以從手牌特殊召喚」;主題延續;此卡的攻擊力;此卡當作…使用;此卡和1隻…。
  - 非此卡:選擇類;此卡以外;玩家、卡種、種族、數值對不上的全部類;區域受事者「丟棄1張手牌」;對手的效果無效。
  - 皆非:場上發動的全場破壞;比不了的定語;抽卡/傷害;裝備怪獸、X 素材的此卡模式結果。
  - 發動位置:寫明、觸發事件去處、自己移動起點、預設場上各一句。
  - 另加卡面參數變動讓匯出判為過時的測試,以及決定性重跑兩次逐位元組相同。
- **接縫 1(索引管線)**:沿用 `test_webindex.py` 的寫法,斷言四個新欄位對齊與空值省略;卡面參數摘要對不上時建置失敗(先例:既有的雜湊對不上建置失敗測試)。
- **接縫 3(查詢引擎)**:在 `engine.test.js` 的合成資料集加帶模式葉的卡,斷言:
  - 此卡與非此卡各自的單葉包含、上層節點。
  - 同句一葉同時在兩模式;雪花蓮型只中此卡;皆非框架只在不限中。
  - 含代價與模式並用;排除套用模式;AND 各節點都在該模式下成立。
  - 命中句索引;沒選節點時模式無效。
  - hash 往返三個值,未知值被忽略。
- **呈現縫**:沿用 `render.test.js` 的寫法,斷言同句兩框架時「此卡」模式只強調此卡帶來的葉。
- **人工驗收**:側欄切換的點選、摺疊時的模式提示、手機寬度;交件時站主在本機搜幾組:
  - 特殊召喚←手札+此卡/非此卡。
  - 破壊+非此卡。
  - 戻す→手札+此卡。
  - アップ:攻撃力+此卡。

## Out of Scope

- 樹裡新增此卡葉、或逐節點的模式選擇(混合查詢「此卡特召 AND 別張除外」)。
- 條件位框架(觸發事件)的此卡判定;觸發事件軸仍是另開線。
- 修正框架抽取本身的受事者或回填錯誤(例如回填漏掉、把此卡誤填成受事者的「戻す」)。判定照框架現況做,錯誤列進報告後另開票。
- 舊式卡文的卡。
- 繁中顯示名、節點卡數。
- push 到 GitHub Pages(等站主開口)。
