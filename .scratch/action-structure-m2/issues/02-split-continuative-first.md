# 02: 多子句先切再解析

**What to build:** 連用形語尾加讀點的子句不再要求左半先解析成簡單子句才切:看到已知的連用形語尾(ならず、されず、できず、なり、になり、し、り、え、い、き…補齊閉集)加「、」就切,兩截各自解析;左半解不出時只有它標解析不出,右半照常解析、照常命中;右半沒主語時依既有 `elided` 規則繼承左半的「は」主語。接續詞(ただし、しかし、もし)與以 の/は/を/に 收尾的左半不切。反向檢查兩截模板以「、」接回。

- 規格:需要你決定的「多子句串接怎麼切?」;實作決策「上游切分」;數據出處 C(述語字面含「、」4,161 段 / 3,705 張)。
- 實作先對全庫跑一次,把切法改變的段(切了之前沒切的、或切點不同的)列成清單交站主,附卡號與前後段字面。
