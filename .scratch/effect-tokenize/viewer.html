效果文分詞檢視

新格式新卡層・分詞詞典 — 詞・粒度原則最小可拆(ADR-0014,2026-10-08)。 「卡片拆解」分頁(票 04/05〜08、13/14;約束框架票 01〜06):每張卡的效果句(一個編號效果的全文,連同它的 ● 選項;ADR-0015)拆成兩種框架、依原文順序混排——動作框架:動作(詞元)、對象/來源/目的、位置(代價/效果/條件)、極性(肯定/否定/可能);約束框架:限制(次數/事件回合禁用/誓約/召喚條件)、時機、素材,專屬欄位併在「內容」欄;兩種都記選項(出自第幾個 ● 與標籤)。本頁供質性驗收:翻卡讀框架,判斷「讀不讀得出這張卡在做什麼、能怎麼用、什麼時候用、怎麼出場」。

句=效果句(含 ● 選項);框架覆蓋率=有抽到至少一個框架(動作或約束)的效果句比例(儀表板參考,不是通過門檻);OOV 佔比=未收錄段 token 數/內容 token 數(全語料已歸零)。

圖例: 代價 效果 條件 約束(限制·次數 等) 詞典詞 指示綁定(この/その+詞) 助詞 卡名/計數器名(〈名〉カウンター) 數字/數量約束/範圍(レベル〈n〉以下、2～5) 屬性字/召喚法/列舉前項(通常(魔法)) 量詞 OOV 未收錄 ●選項邊界
