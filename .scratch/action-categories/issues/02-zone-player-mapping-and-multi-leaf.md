# 02 — 區域與玩家映射、複合來源多葉

**What to build:** 來源/目的欄的原文字面(自分の墓地、相手フィールド、デッキ・EXデッキ、手札・墓地)在歸組時映成(玩家, 區域):區域沿用七值(手牌/牌組/額外牌組/墓地/除外/場上/靈擺區),玩家是 自分/相手/雙方/無。玩家不進葉、寫進框架類別檔的來源玩家/目的玩家欄;複合來源或目的拆成多個區域逐一匹配,一個框架因此帶多個葉、大類仍一個。站主在框架類別檔看到「手札・墓地から特殊召喚」帶 特殊召喚←手札 與 特殊召喚←墓地、「相手の墓地から」的葉與「自分の墓地から」相同但來源玩家欄不同。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 映射表住在歸組模組:字面 → (玩家, 區域);對不上任何區域的字面讓需要區域的葉不匹配(落預設葉或未歸類),不報錯。
- [ ] 「自分か相手の」「自分・相手の」記雙方;無前綴記無。
- [ ] 複合來源/目的逐區域各匹配一葉,葉清單有序(依字面順序);大類取共同祖先。
- [ ] 回歸例子:複合來源兩葉、玩家前綴不分葉但玩家欄有值、雙方、牌組頂/底歸牌組、對不上的區域字面。
- [ ] 全語料重跑:已歸數上升、未歸類依詞元聚合的計數記在票 Comments。
