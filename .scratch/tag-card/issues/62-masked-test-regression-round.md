# 62 — 遮蔽測試重判輪:定版前的回歸檢查

**What to build:** 33 張判定票替 `docs/effect_kind_guide.md` 補進了大量 §5.5 / §5.6 / §5.8 的邊界判準,而**沒有任何一次檢查回頭確認這些新判準有沒有打壞原本判對的行**。定版前跑一次[[遮蔽測試]]的**重判輪**:把第二期五輪的既有樣本用定版規範重判一次,對照當時的分數。

**Blocked by:** 17 — 行內 `『●』` 歸屬、55 — 繁中單側拆句與判定、60 — 標頭編號前綴、61 — 收緊 R17(全部會改到規範文件或標準答案,重判輪要用的是定版後的最終版本)

**Status:** ready-for-human

## 為什麼是重判輪而不是首判輪

票07 的結論是**不建議再加首判輪**:第二期五輪的首判曲線 98.6% → 99.7% → 99.2% → 99.2% → 99.7%,每輪都還會冒出 1~3 條沒見過的新形態,而每一條事後都能驗證出乾淨的規則、沒有一條能事前預見。再抽一次新樣本的期望值不變。

重判輪問的是**完全不同的問題**:規範是逐票長出來的,票50 加的判準從沒對票18 的樣本驗證過。這個問題目前無人回答,而它正是封版最該擔心的事——一條為了修 A 形態而寫寬的判準,可能安靜地把 B 形態判翻。

重判輪不計入首判輪的輪數上限(CONTEXT.md [[遮蔽測試]]詞條),樣本現成,成本低。

### 規範修正(全部先做全表驗證才寫)

驗證都跑在 `source: "official"` 且類型在六類值域內的 **17,316 條**效果句上。

1. **§5.6 閘門二:條件式跨回合許可的判準是「有沒有條件子句」,不是「在不在括號裡」。**
   全表含 `この効果は相手ターンでも発動できる` 的效果句 259 條:前面掛條件子句(`〜場合、`)的 **29/29 全是啟動效果**,獨立成句的 **230/230 全是誘發即時效果(2速)**。按括號切則切不乾淨(括號外 245 條裡有 15 條是啟動效果)。
2. **§5.6 新增:觸發事件是「對手做了某件事」不構成 2 速。**
   - 觸發事件**不是**效果的發動、且沒有明寫跨回合許可:`相手が〜した時／した場合に発動できる` 全表 **78/78 是誘發效果(1速)**。
   - 觸發事件**是**效果的發動:`相手が〜発動した時` **229/229 是 2速**;`相手が〜発動した場合` **16/16 是 1速**(官方補足寫「一連のチェーン処理後に発動できます」)。
   - 對照:`相手が〜する際に発動できる` 20/23 是 2速。
3. **§5.6 閘門二補替代線索:拿不到前言段時看補足。**
   卡文完全沒有時點線索的發動句,扣掉第 1 條那族(21 條)之後全表 1,536 條:補足對應區塊寫 `ダメージステップには発動できません` 的 **4/4 是 2速**(10678778 ②、83303851 ①、94997874 ①②),沒寫的 **1,529/1,532 是啟動效果**。三條具名例外:14124483 ①②、74294676 ①。道理是起動効果本來就不能在傷害步驟發動,官方寫這句等於承認它能在別的時點發動。
4. **§5.5 分界五收緊 + 補鄰族。** 全表:

   | 字面 | 條數 | 官方 |
   |---|---|---|
   | `〜召喚に成功したターン` | 24 | 無種類 22 / 永續 2(兩條例外同句另有 `〜存在する限り`) |
   | `このカードは〜召喚したターンには攻撃できない` | 27 | 永續 27/27 |
   | `この方法で特殊召喚したターン、自分は〜` | 12 | 無種類 12/12(依據是母句的自我特殊召喚程序) |
   | `〜効果を発動したターン` | 3 | 無種類 1 / 永續 2 → **不給規則,逐條照官方** |

5. **§8 判準9:票47 的家族推論刪除。**
   `以下の効果から１つを選択して発動` 全表 **126 條、效果外文本 0 條**(啟動 59 / 1速 51 / 2速 16),那是正常的發動句、照 §5.6 判速度。真正的聯合怪獸家族只認 `１ターンに１度、以下の効果を１つ発動できる。` 這個字面,全表 8 條 **8/8 效果外文本**。

### 誠實揭露

- **輪 3 有一條不是乾淨的判定**:`96300057` ① 與輪 2 的 `39299733` ① 結構完全相同,而輪 2 對答案時已經看到 39299733 的官方答案是啟動效果。輪 3 那一條因此帶著看過的資訊。若把它從輪 3 的分母剔掉,輪 3 是 358/358 = 100.0%,結論不變。

### 結論(供票09 的定版報告引用)

- 33 張判定票補進的判準**確實造成了回歸**:五輪 1,800 條裡有 5 條原本判對的行被新判準判翻,佔 0.28%。五條全部可歸因、全部已修、每一條的修法都在全表上驗證過(29/29、78/78 + 229/229 + 16/16、4/4 + 1529/1532、24 + 27/27 + 12/12、126 + 8/8)。
- 同一批判準同時**修好了原始 13 條錯判裡的 12 條**,淨效果是正的:五輪合計原始 1,783/1,796 = 99.28% → 重判 1,789/1,795 = 99.67%。
- 標準答案在票17/55/60/61 之後**一條都沒有變動**(rejudge 存證五輪全部 100%),所以沒有「重算即可」這一類的下降。
- 剩下的唯一系統性缺口是**遮蔽測試工具讀不到前言段**,已修。修完之後五輪的六條錯判裡有 6/6 都有可核對的判準可以判對。
