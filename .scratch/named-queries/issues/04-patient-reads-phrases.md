# 04: 動作對象改讀論元片語

**What to build:** 動作對象的判定值全語料不變,但判定讀的是片語與結構化值:選擇類 ← 受事者片語任一段有數量且數量類不是 全部(取自子句的已在片語裡),或回指欄的數量;中心詞類 ← 片語的中心詞類,加一張小表把 屬性 類裡跟主人走的事件類(効果/発動/攻撃/召喚)分出來;全部類的區域 ← 結構化所在/來源與段的玩家/區域;全部類比對的卡種 ← 中心詞字面尾,種族/屬性/字段/卡片子類型/數值 ← 修飾語類,其他類修飾語視為比不了;か/と 的替代項 ← 段;指示詞 ← 段的指示詞旗標;此卡/此卡以外/附屬卡/この効果 這幾條改成比段。受事者取法(依態)與判定規則不變。動作對象模組的正則式全部刪除。改讀後與票 01 的基準逐框比對,判定值差異 0;有差異時逐卡列出、每條判定更對才留下;理由碼可變但要給對照表。
