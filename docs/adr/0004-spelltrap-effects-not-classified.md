# 以魔陷卡身分運作的效果句不套六類效果類型,判「魔陷卡效果」

官方的四個類型詞(起動効果/誘発効果/誘発即時効果/永続効果)與「分類されない効果」是**怪獸效果**的分類。以魔法/陷阱卡身分運作的效果句只有咒語速度:魔法效果 1 速、陷阱效果 2 速;**卡片的發動**會提速(速攻魔法 2 速、反擊陷阱 3 速);墓地等處使用的效果回歸本體種類的速度。速度由[[卡片種類]]機械決定,不需要判定。

票53 的全表稽核把這件事量清楚了:魔陷卡上的官方類型明示 60 條,59 條是「變成怪獸時的效果」(33)或「賦予怪獸的 ● 子效果」(26)——兩者都是**怪獸效果**;剩下 1 條(聖遺物運動機構 29223325 ②)是行為偏離速度框架時官方特別說明的墓地發動特例。而 llm 判過六類的 375 條魔陷效果句,張張卡都有補足情報、官方**全部沉默**。反方向的證據同樣乾淨:怪獸卡「當作永續陷阱卡的場合」的效果(百夫長重騎士 普莉梅拉 15005145 ②③),官方連「永続効果」都不說,特地繞開寫「永続罠カードの効果として扱います」。

因此[[效果類型]]的值域從六種擴為十五種:新增九個以卡片種類命名的**[[魔陷卡效果]]**值(通常魔法卡效果/速攻魔法卡效果/儀式魔法卡效果/永續魔法卡效果/裝備魔法卡效果/場地魔法卡效果/通常陷阱卡效果/永續陷阱卡效果/反擊陷阱卡效果)。判準是**運作身分,不是印刷卡種**——普莉梅拉②③判永續陷阱卡效果。魔陷卡上仍判六類的只有三種形態:變成怪獸時的效果、「効果を得る」賦予怪獸的效果、[[官方明示]]的特例(官方明示永遠是最高權威)。

## Considered Options

- **維持票18/20 的擴充判法**(魔陷效果句照 §1 流程判六類):與官方不衝突(官方沉默),但也永無官方背書,而且是三票的必發/選發不一致(11/7/7 條)與票52 裝備卡爭議的共同根源——在官方永遠不給答案的地方硬選一邊,錯了也沒有裁判。
- **kind 清回 null**:null 在管線裡是「還沒判」,排票會把 375 條重新送判,而且「判過了:不適用」這個資訊就丟了。
- **kind 記咒語速度(1速/2速/3速)**:速度從卡片種類可完全推導,存進表違反「可推導的不入表」;同一欄混兩套值域也讓驗證分岔。
- **九個以卡片種類命名的值**(採用):對魔陷卡本身雖與卡片種類重複,但對「怪獸當作魔陷卡」的行,值承載了無法從 type 位元推導的判定資訊;速度直接可讀;一欄一套語意。

## Consequences

- 既有 375 條(`llm` 365 + `llm_then_rule` 10)由改判票(票54)整族換值;`official` 60 條與效果外文本不動。
- [[必發/選發]]的適用範圍改為「有觸發事件的發動型效果句」:魔陷卡效果中被動觸發的 42 條必發 + 13 條選發保留,卡本身發動的 150 條「選發」清掉(發不發動卡由玩家決定,無資訊量)。管線對魔陷卡效果值只吃官方明示與判定、不用 `_optional_by_rule()` 的句尾規則補值——§4 句尾規則在這一族的系統性誤判(票18/19/20 各 11/7/7 條)就此關閉。
- [[規則層]]的管轄範圍縮為六類:判成魔陷卡效果的行不參與影子預測比對、不升級 `llm_then_rule`(`rule_spelltrap_skipped` 計數)。
- `docs/effect_kind_guide.md` §1 流程加入運作身分閘門(步驟 2),§2.7 新增、§5.2/§5.6/§5.8/§5.9 改寫;§5.2 的裝備方向約定與票52 的破壞替代定案由本決定取代(那條爭議正是六類不適用的症狀)。
- [[遮蔽測試]]不受影響:樣本只從官方明示的六類行抽,而那些行全在三種保留形態裡。
