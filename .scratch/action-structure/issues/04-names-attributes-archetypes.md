# 04: 名稱、卡片屬性表與字段表

**What to build:** 站主能用卡名與字段查動作:查「ペンギン 怪獸 牌組 → 特殊召喚」命中大皇帝ペンギン;卡名帶位置條件、字段依 setcode、名稱排除與記載都判得對。

- 名稱表:「」引用的名稱與宣言名稱,條件比的是名稱;名稱比對前雙方做全半形折疊,結構保留原文字面。
- 卡片屬性表(物件0 的來源):每種屬性一張表、每列帶位置條件;「ルール上〜としても扱う」= 任何位置;「〜に存在する限り〜として扱う」= 只在該位置。
- 字段表(建置產物):以上游 mycard ygopro-database 的 ja-JP strings.conf `!setname` 為日文名 → setcode 起點;中文名從同 setcode 卡的繁中卡文「」引用配對,配不到的列報告;上游缺漏或錯誤由本站補丁來源檔覆蓋。
- 條件式:字段(名稱)依 setcode;「「X」と名のついた」= 字段;卡名包含(字串)比卡名子字串、不看 setcode;卡名 ∋ 名稱;「「X」以外」= 非(卡名∋X);記載(名稱)掃全卡文、含括號精確比對。
- 判斷卡能否當物件時,卡名與屬性帶位置條件者,取該對象線的「從」。
- 不認得的「」名稱:報告列出、該條件標解析不出,建置照常通過。
