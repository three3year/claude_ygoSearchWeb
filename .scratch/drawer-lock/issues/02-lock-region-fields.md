# 02: 鎖住的欄——區域欄打通,含網址讀回

**What to build:** 站主點 破壊@相手フィールド、特殊召喚←墓地、加える:デッキ→手札 這類條件葉加的標籤,打開抽屜:鎖住的區域欄只留一行、列出鎖住的項、按不掉、滑鼠停上去說「由 X 決定」;其他欄只列「詞元+鎖住的欄」出現過的值,被細分條件擋掉的灰鈕不再出現。重整或貼網址後照規格的規則仍鎖。見規格 Solution 2〜6 與 Implementation Decisions「條件模型」「抽屜畫面」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 條件模型定出標籤的鎖住的欄:來源那一列述詞中詞元、極性以外的欄;沒有來源或來源列沒有這種欄時沒有
- [ ] 對鎖住的欄 `addValue`、`removeValue`、`toggleValue` 回傳原標籤
- [ ] 抽屜選項:鎖住的區域欄只帶鎖住的項並標明鎖住、帶來源名字;不帶玩家、區域選單
- [ ] 隱藏名單用 詞元 + 鎖住的欄(三個位置、三種極性)問引擎;沒有鎖住欄的標籤和現在一樣;灰色判定不變
- [ ] 抽屜畫面:鎖住的區域欄畫一行(欄名 + 值,樣式同按不掉的鈕、不可按、項不帶 ×),說明「由 X 決定」
- [ ] 從詞元節點加、改成和條件葉一樣的標籤不鎖;還原、切換包含/排除不影響鎖
- [ ] 讀網址:欄位等於條件葉時鎖(只寫路徑與寫欄位對都一樣)、另加一欄時不鎖、只差位置時仍鎖;舊網址照樣讀得進來
- [ ] 條件模型接縫的測試(手寫小框表;先例:drawer-options、drawer-regions 測試檔)涵蓋上面各條;node 測試全過
