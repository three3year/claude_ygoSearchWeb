# 65 — 純換行前言拆分(引用跨界者安全退回)

**What to build:** 日文多行的前言段在建置期按**日文換行**拆成多個[[效果外文本]]效果句,各段自帶 role——但**只拆絕對安全的子集**:任何補足情報 `『…』` 引用會被拆點切開的段落,整段維持現狀不拆、列進退回清單(引用合併是票66 的事,本票寧可多退回也不出錯)。完工後中日行數一致的 1,253 段當場拆對、role 分布可見變化;70488851 這類引用跨行卡仍在退回清單裡,是預期狀態。規格見 spec-preamble-split.md,決策見 ADR-0009。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 拆句骨架的前言處理:日文按換行切段;任何 `『…』` 引用(含 `【『…』について】` 標頭引用,經既有正規化比對)橫跨拆點時,整段退回不拆
- [x] 中文對位:以「自身換行 + 句號」切成單位(無句號的行塊算一單位),日文每行單位數 = 句號數(無句號行算 1),兩側總數相等時依序分組;不相等整段退回。每段必須是中文原文的連續子字串,首尾空白照既有慣例剝除
- [x] 鍵與欄位:拆出的段 `0-1`、`0-2`…照日文行序,沒拆的維持 `"0"`;逐段 role 由既有前言 role 規則重算,kind 效果外文本、`source: rule`

- [x] 遮蔽樣本建構的 preamble 收集改為收齊該卡同 section 的**全部**前言列依序串接——拆過的卡不得拿到空前言
