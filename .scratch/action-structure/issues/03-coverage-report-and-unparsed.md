# 03: 全庫覆蓋報告與未解析組

**What to build:** 站主能看到全庫覆蓋報告,知道規則吃下多少、漏在哪;查詢結果不會靜默漏卡——字面含查詢動作詞、但結構不完整的段另列「未解析」組。
