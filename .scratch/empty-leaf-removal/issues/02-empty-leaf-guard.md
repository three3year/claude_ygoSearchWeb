# 02: 空葉防線

**What to build:** 日後卡文更新或規則調整讓某片葉變成 0 框時,真樹回歸測試失敗並列出葉名,由站主決定刪葉或改規則,不必等有人在搜尋頁搜不到才發現。見[規格](../spec.md)。

**Blocked by:** 01

**Status:** done

- [x] 類別模組新增空葉查詢:輸入類別樹與全語料框架,依樹序回傳沒有任何已歸框的葉名。不進建置流程、不擋匯出。
- [x] 小樹測試:有空葉時回報,包含預設葉空、只在條件位命中的葉算空;全部有框時回傳空清單。這些測試要能證明防線會紅。
- [x] 全語料測試:真樹對框架檔重新歸類(不讀舊的類別產物),回傳清單為空;失敗訊息列出葉名。
- [x] 框架檔不存在時,全語料測試略過並印原因,其他測試照跑。
- [x] 分詞鏈全套測試通過。
