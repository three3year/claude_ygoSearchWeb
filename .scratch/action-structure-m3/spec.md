## 問題陳述

里程碑二做完後,段解析出 59.5%,整張通過反向檢查的只有 1,057 張(全庫 14,207 張,有官方日文 14,187 張)。常用動作詞查下去,未解析組約是命中組的四成:查「特殊召喚」命中 4,567 張、未解析組 1,850 張。站主原本要接著做前端,看到卡片結構只填出一部分後,決定先再補一輪規則。

- 物件修飾解析不出 9,678 個物件 / 6,776 張;只差它就整張通過的有 1,271 張。其中 3,560 個不是修飾語本身的問題,而是物件範圍往前吞進了子句、標籤、期間或主語。
- 單獨的「召喚」沒有動作詞:含「に成功」且述語解析不出 1,048 段,另有 836 段不含「に成功」的句子也卡在它。

- 「離れた」520 段;兩張標準卡(使い捨て学習装置、竜姫神サフィラ)在里程碑二沒整張通過,卡在這類與另外三種寫法。

- 多子句切開後的非動作左半 177 處。

## 解決方案

先做一張零行為改變的重整票,再補一張小型寫法票,然後補六類寫法與對應的新動作詞(召喚、上級召喚、反轉召喚、P召喚、成為超量素材、離場)、新條件式原子與閉集。結構仍全由規則從官方日文重算,原文字面保留,反向檢查照樣是客觀驗收。

查詢層不加新欄;只有同義表的下位詞關係多一層(上級召喚 → 召喚 → 通常召喚)。前端不在範圍內。做完後出收尾摘要報新數字,由站主決定再補一輪還是做前端。

## 實作決策

沒在「需要你決定的」裡定讀法的子型,原則是:現有的格加上已定的讀法就能表達的,照著收;要新增格或新讀法的,這輪不收、留在解析不出,收尾摘要照實列出(見[不做的事](#不做的事))。

### 票的順序

- 第一張是零行為改變的重整票,第二張是小型寫法票(里程碑二摘要裁定)。
- 物件切點票排在物件修飾票之前:切點錯的物件要先切對,修飾語規則才量得準。
- 「離れた場合に除外される」的 241 段裡有 212 段主語帶「この効果で特殊召喚した」等狀態,排在帶狀態的此卡之後。
- 最後一張是收尾票:兩張標準卡整張通過反向檢查、前後對比、收尾摘要。
- 「召喚」動作詞排在「X素材」之前:「〜を素材として〜召喚に成功した」兩邊都要。

### 重整票

- 產物逐位元組不變,反向檢查與覆蓋報告數字不變。
- 內容(里程碑二摘要裁定):各動作的填格函式搬進各自模組;反向檢查的段模板分流改成表;填格函式共用的參數包成子句 context;以及 code review 標出的隱性契約——狀態原子代入規則、區塊狀態的主題三態、原述語字面串接後再拆、段模板的期間分流、傷害字幹黏著「を」。
- 摘要同一批的「置く/取り除く 改成字幹假朋友表」會改產物,不在這張票,移到小型寫法票(站主裁定)。

### 小型寫法票

- 句尾括號版次數限制(「（このカード名の以下の効果はそれぞれ１ターンに１度しか選択/使用できない）」「（１ターンに１度のみ）」等)照獨立一行的次數限制剝成略過文本。
- 支付的數量單位補「ライフポイント」。
- 變更表示形式補「〜表示に変更する」「〜表示にならない」。
- 觸發形閉集補「ダメージステップ時」「戦闘ダメージ計算時」。
- 抽牌沒寫「デッキから」、牌組由推得表補上時,牌組的方照抽牌者標(對手、雙方各自照記;抽牌者沒寫的記我方)。
- 放置、去除的字幹改成單字幹加字幹假朋友表(原本連語尾寫),並補被動語尾「置かれた」「取り除けない」;查「放置」「去除」的未解析組不能因此比中無關字面(「位置」等)。

### 物件切點

- 預設 1:物件範圍往前吞進前文的物件(時點「自分・相手ターンに、」、標籤「：」、前提「〜限り、/場合、」、期間、「または、/さらに、」、「〜の中から、」、「〜になるように、」、主語「Xが/Xは」、「〜から」、助詞殘片)在這輪修,單獨一張票。
- 「●２体以上：」「自分：」這類標籤記成依值分歧的標籤。
- 被切出去的前文交給既有的規則(前提、期間、時機、主語的對象線);既有規則認不得的,那一段照舊標解析不出,但物件本身不再帶吞進來的字面。

### 物件與條件式

- 「他の」:一律 非(同一張 此卡)(站主裁定)。「〜以外の」照既有規則不變(「このカード以外の」是此卡以外、「そのモンスター以外の」是指回的物件以外、「水属性以外の」是 非(屬性比較));既有規則認不得的「以外」寫法(「チューナー以外の」「「彼岸」モンスター以外の」)照同一套補:非(那個條件)。
- 「その+修飾+頭名詞」(その相手、その自分の、その融合、対象の、上記の):回指,修飾語留在回指字面,不建新物件、不加條件(站主裁定)。
- 預設 2:帶狀態的此卡(「この効果で特殊召喚したこのカード」「装備されているこのカード」「Pゾーンのこのカード」)建一個母體是此卡的子集物件,狀態寫在它的條件式裡。
- 預設 3:連體子句——「除外されている/除外状態の」→ 位置 除外;「セットされた」→ 表示形式 裏側;「特殊召喚された」→ 曾被特殊召喚(沒寫出發地就不帶區域);「X召喚した/された」→ 新建召喚方式原子。
- 預設 4:屬性比較的屬性加攻擊力、守備力、階級、連結值,比較詞照既有(以上、以下、等於)。
- 預設 5:卡片子類型閉集補 効果、デュアル、スピリット、トゥーン、ユニオン、リバース、永続、速攻、フィールド;「魔法・罠・モンスターの効果」這類頭名詞是「效果」的物件,記成物件種類 效果。
- 預設 6:區域字面補「Pゾーン」「EXデッキ」「魔法＆罠ゾーン」「メインモンスターゾーン」。
- 預設 7:新原子「與某物件的某屬性相同/不同」,帶屬性名(卡名、屬性、種族、等級、卡片種類…)與是否「元々の」;物件群內成員之間的「カード名が異なる」「同名」用同一個原子,比較對象是同群的其他成員。
- 列舉「AまたはB」(「魔法または罠カード」)用既有的 或。

### 動作詞與同義表

- 新增 召喚(單獨的「召喚」),上位詞 通常召喚;新增 上級召喚(アドバンス召喚、生け贄召喚),上位詞 召喚;新增 反轉召喚(反転召喚),沒有上位詞;新增 P召喚(P召喚、ペンデュラム召喚),上位詞 特殊召喚。下位詞關係要能傳兩層:查「通常召喚」命中 召喚 與 上級召喚 的段。
- リンク/シンクロ/エクシーズ召喚 同義到既有的 L/S/X召喚。
- 「召喚・特殊召喚」「召喚・反転召喚・特殊召喚」等列舉:一段多個動作詞。
- 預設 8:「このカードが召喚した時」與「召喚に成功した時」記同一個結構,此卡是被召喚的角色;原述語字面各自保留。
- 預設 9:「墓地からの特殊召喚に成功」的「からの」記成 從;「モンスターの特殊召喚に成功」的「の」是對象線助詞;「この効果で/この方法で特殊召喚に成功した」記原因 效果,指向本卡那一段;「「X」モンスターの効果によって」記原因 效果帶物件(既有)。
- 新增 成為超量素材:「XをYのX素材とする/にする」「Xを(Yの下に)重ねてX素材とする」;對象線的到是 Y 的超量素材。不移動到區域,不進推得表。
- 作為素材 的字幹補「〜素材とする」「〜素材とし」;「〜も融合素材とする事ができる」是 作為素材,「事ができる」照既有規則記可選、極性仍是 做。
- 新增 離場(フィールドから離れた、フィールド上から離れた);從 = 場上,沒有到;不進推得表;沒有上下位詞。

### 素材的各句型

- 「このカードをS素材とする場合」「XをYのL素材とする場合」:條件段,動作詞 作為素材,觸發形 場合(站主裁定)。召喚條件區塊裡照既有規則改成召喚手續或限制。
- 預設 10:「〜を融合素材とし、」左半併進右半的融合召喚段,左半的物件是那一段角色 素材 的對象線,不另成段;「〜を素材として(このカードが)〜召喚に成功した」同樣記成召喚段加角色 素材 的線。
- 預設 10:「Xが「Y」をX素材としている場合」是前提,用 存在 原子表達(物件種類 超量素材、所屬 X、條件 Y)。超量素材物件可以帶條件式(站主裁定,放寬里程碑二票 11 的規則);計數器照舊沒有。
- 預設 10:「「X」LモンスターのL素材として墓地へ送られた」的原因 作為素材 帶被召喚怪獸的物件。

### 多子句非動作左半

- 「Xを選択し、」「Xを対象とし、」認成取對象宣告,右半省略的物件指回它(里程碑二摘要裁定);數量照字面記。
- 預設 11:「デッキから/手札から/その中から 〜を選択し、」記 選擇,不記取對象;選者照主語(「相手はその中から」選者是對手)。
- 預設 11:「Xを対象とし、」後面接裝備段、分歧引導、宣言時,對象照常傳給後面的段:裝備段的裝備對象、分歧各支與宣言後的段裡的回指都指回它。
- 「〜とは〜が異なり、」認成右半物件的條件(用預設 7 的原子),不另成段(里程碑二摘要裁定);屬性名與「元々の」照字面。

### 離場與標準卡剩下的寫法

- 「(X)は、フィールドから離れた場合に除外される」「〜デッキの一番下に戻る」:照代替記,離場是被代替段、除外或返回是做代替的段(站主裁定);反向檢查為這個句型另寫模板。
- 「Xが(相手の効果で/相手によって)フィールドから離れた場合/時」:條件段 離場,原因照既有閉集;閉集補「相手によって」,記 戰鬥或效果、方 對手(站主裁定)。
- 預設 12:「Xがフィールドから離れた時に装備モンスター/そのモンスターは破壊される」在「時に」切成條件段(離場)加效果段。
- 「離れ、墓地へ送られた」照多子句串接的既有切法。
- 預設 13:「Xした/されたターンのエンドフェイズに」用現有的格,不加新觸發形:前提是 本回合發生過(指向那個動作)且 遊戲狀態 結束階段 兩個原子;舊式「〜ターンのエンドフェイズ時」是同一個讀法。
- 時點列舉「〜ターンのエンドフェイズ及び、〜ターンのエンドフェイズに」:兩個時點的或(站主裁定),寫成一般規則。
- 預設 14:「「X」により降臨」:召喚手續段,動作詞 儀式召喚,原因 效果帶物件 X,極性 做。

### 前提

- 列舉的且、或照[前提裡的列舉怎麼讀?](#前提裡的列舉怎麼讀?)的表。
- 連用形串接「Aが存在し、/存在せず、Bが存在しない場合」:前提形式補「し、」「せず、」,組成且。
- 「〜存在しない場合に特殊召喚できる」(「場合に」後面沒有讀點):前提形式補這個寫法。
- 預設 15:數量「２体以上/３枚以上」記在 存在 原子所指物件的數量格(值、比較、單位);「２種類以上」另記單位 種類。
- 預設 15:LP 比較(「LPが相手より少なく、」)新增遊戲狀態原子。
- 預設 15:沒寫區域的「Xが表側表示で存在する場合」預設場上。
- 區域的或(「墓地またはフィールド上に」)用區域集合表達;區域字面閉集同預設 6。

### 查詢判斷

- 不加新查詢欄。下位詞展開現行已是傳遞的,新詞只在下位詞表加列。
- 指定卡或物件條件代入時,判斷端跟著抽取端補,照既有的分法:
  - 卡片總表查得到的屬性照實比:屬性比較加 攻擊力、守備力、連結值;預設 5 補的子類型(效果、二重、靈魂、卡通、聯合、反轉,魔陷的永續、速攻、場地)要判得出。
  - 不是卡片屬性的狀態原子(預設 3 的召喚方式、預設 2 帶狀態的此卡的狀態)照既有的狀態原子規則,任何卡都代得進去。
  - 預設 7 的「與某物件的某屬性相同/不同」:比較對象是別的物件時,照既有的引用比較(先求被引用物件的候選卡);比較對象是同群其他成員時,單張卡代入一律符合。
  - `同一張` 的判法不變(指定卡代入永遠不符,所以「他の」的 非 永遠符合)。
  - 前提裡的新原子(數量、LP 比較)照舊不參與查詢。
- 新動作詞自動進未解析組的字面比對(動作詞經同義表換成述語字面)。「離場」「召喚」的字幹要避免比中無關字面(同里程碑二「置」的處理)。
- 代替開關的行為不變;「離れた場合に除外される」的被代替段照既有規則只在開關開時看。

### 反向檢查與報告

- 每個新句型補模板;新原子、新動作詞都要能寫回原文。
- 每張規則票回報全庫前後數字與「改前通過、改後不通過」張數,後者必須是 0;真有例外(改前是碰巧通過)時逐張列在票的 Comments,由站主核可。
- 覆蓋報告與反向檢查報告沿用;前後對比用統計腳本對兩份產物跑。
- 兩次建置逐位元組相同。

- 新動作詞、新原子、新閉集值寫進 GLOSSARY 對應條目;站主已裁定的讀法 2026-11-10 已先寫進 同義表、代替、物件、前提 四個條目(標「尚未實作」),實作時把標記拿掉並補上實作細節。

## 測試決策

- 好的測試只驗外部行為:輸入官方卡文與卡片參數,看查詢結果或反向檢查結果;不驗結構內部的格與形狀。

- **接縫二,反向檢查**:標準卡整張通過(票面註明例外的除外)。故事 21、31、33–35 從這個接縫驗:那一段或整張寫回原文相符。前提的且/或查詢與反向檢查都分不出來,讀法寫在票的 Comments「待站主核可」,收尾摘要標「讀法」列給站主。

## 不做的事

- 查詢篩選欄(受方、誰、原因)、前端、查詢輸入方式、結果介面:延到再下一個里程碑。
- LLM 補欄。
- 物件群體的合計與最高(「レベルの合計が〜になるように」「攻撃力が一番高い」)。
- 相對位置(リンク先、同じ縦列、正面、もう片方の自分のPゾーン)。
- 沒在這輪定讀法、要新增格或新讀法的子型,留在解析不出,收尾摘要照實列出:
  - 與此卡的關係(「このカードに装備」「このカードを素材として持っている」)。
  - 連體「融合素材としたモンスター」。
  - 「〜の降臨に必要」。
  - 「次のターンのエンドフェイズ」「〜エンドフェイズ時まで」這兩種時點寫法(物件切點票順帶解開的不算)。
  - 物件修飾與前提各自的「其他」長尾。
- 查詢比數值(次數、數量的算式、期間、範圍)照里程碑二,只記不比。
