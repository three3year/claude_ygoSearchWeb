# 05: 「装備」的讀法

**What to build:** 「装備魔法カード」「装備カード」不再讀成被此卡裝備的怪獸,指定卡代入時比得準:

- 「装備魔法カード」的「装備」:卡片子類型 裝備(與大類 魔法 並列)。字段、區域等其他修飾語照既有規則接在前面(「「聖剣」装備魔法カード」「このカードに装備されている装備魔法カード」的「装備」部分)。
- 「装備カード」的「装備」:既有的狀態原子 `裝備中`(正當成裝備卡裝在怪獸上的卡)。
- 緊接頭名詞的「装備」讀成 `被裝備者` 的只剩「装備モンスター」;`被裝備者` 其他既有字面(「このカードを装備した」「このカードの効果でこのカードを装備した」)不變。
- `裝備中` 指定卡代入的判法(狀態原子的判法表改一條):大類 怪獸一律符合;大類 魔法只有卡片子類型 裝備符合;大類 陷阱只有那張卡自己的官方日文含「装備」的符合。所有 `裝備中` 的字面(「装備されている」「装備状態の」「装備カード扱いの」與這次的「装備カード」)共用這一條。
- 「装備魔法カード扱いで」「装備カード扱いとして」是裝備段的方式字面,不是物件的修飾語,照既有規則(不要被新的物件讀法吃掉)。
- 修飾語裡與此卡的關係(「このカードに装備されている〜」當物件修飾語、「このカードが装備している〜」)照舊不收。

- 規格:需要你決定的「「装備カード」的「装備」怎麼讀?」「`裝備中` 指定卡代入時怎麼判?」;實作決策「裝備」「查詢判斷」;使用者故事 25–30。
- 統計:`m3b_scope.txt`「物件字面含「装備」」(「装備魔法カード」解析出 35、解析不出 28 個;「装備カード」解析出 21、解析不出 41 個;`裝備中` 原子 58 個;字面「装備」、物件字面不含「装備モンスター」的 `被裝備者` 原子 53 個)與「指定卡有沒有可能成為裝備卡」(陷阱 2,069 張,官方日文含「装備」的 93 張)。
