# 15 — 魔陷十值只收卡片種類不一致的卡+空值隱藏

**What to build:** [[效果類型]]軸的[[魔陷卡效果]]十值按鈕改語意(ADR-0010):成員 =
**帶該值效果句、且自身[[卡片種類]]與該值不一致**的卡。選「裝備魔法卡效果」不再回傳
裝備魔法卡本身(那是[[卡片子類型]]軸一顆鈕的事),只剩怪獸「當作裝備魔法卡」之類的
異類卡——這個軸從此答的是只有它答得出的問題。排除一致卡後全庫無卡的值,建置期直接
不生成按鈕。

**Status:** resolved

- [x] [[值域正典]]宣告魔陷十值 ↔ 一致[[卡片種類]]的對應:前九值 ↔ 同名魔法/陷阱
      子類型;**靈擺魔法卡效果 ↔ 靈擺怪獸**(靈擺怪獸的靈擺效果句視為一致)。
      正典自檢:對應兩側都必須是各自值域的成員(與 `_OPTIONAL` 承載關係同一個做法,
      不在前端手抄對照表)
- [x] 引擎:魔陷十值的包含態成員 = 有該值效果句且自身卡片種類不一致的卡;
      **排除態同此定義**——擋的是不一致卡的該類效果句,一致卡自身的效果句不在成員裡、
      不受這顆鈕影響
- [x] 句層耦合照舊:效果文關鍵字/[[必發/選發]]並用時仍須**同一效果句**滿足全部句層條件
      (票06),卡片種類不一致是卡層的附加閘,不動句層交集的形狀
- [x] 建置期全庫判定:排除一致卡後無卡的值不生成按鈕(census 計數,`filterable` 精神);
      前端不做動態卡數推導。預期「靈擺魔法卡效果」可能因此消失
- [x] 網址還原:被建置期拿掉的值出現在網址時視同未知碼忽略
- [x] 側欄群組標題(原「魔陷卡效果」)改名為**「跨類型魔陷效果」**(住[[值域正典]]的
      群組宣告,不是前端寫死)
- [x] 不變項驗證:怪獸側六類語意照舊;命中 badge 仍寫該行自己的 `k` 值名
      (異類卡命中「裝備魔法卡效果」badge 照寫);[[必發/選發]]的承載關係與
      `optionalAvailable` 規則不變
- [x] spec.md 搜尋語意段同步改寫
- [x] 測試:裝備魔法卡自身不命中「裝備魔法卡效果」;怪獸當作裝備卡(如 15005145

      不因效果文而受影響(比對的是卡片種類,不是效果內容);排除態不擋一致卡;
      空值不生按鈕

2026-08-17 實作完成。改動橫跨三層,每一層都沿既有的宣告管道走、沒有第二份表:

**一致對應住正典的 `own` 宣告**(`vocab.py`,與 `_OPTIONAL` 的 carriers 同構):
`(值碼, 大類碼, 子類型碼)` 十條,隨 `VOCAB.kind.own` 以 `{se: "s:equip"}` 形態出去;
正典自檢新增三種問題(對應掛在非成員上、大類/子類型解不動、對應重複)。

**引擎的形狀是「本類卡的該值效果句視同無值」**(`engine.js` 的 `kindAt`)——與
「不承載不是一個值」同一個形狀:包含態收不到、排除態也不擋。句層耦合原封不動,
跨類型判定只是把那一句的 kind 讀成空陣列。

**建置期只動 `groups` 不動 `items`**(`webindex.py` 的 `_cross_type_counts` +
`_drop_buttonless_kinds`):`items` 是顯示詞彙表——呈現層的逐行類型標籤
(`render.js` 的 `KIND_ZH`)對**每一行**查中文,本類卡的「儀式魔法卡效果」標籤
不能因為按鈕沒了而變成短碼。按鈕(分組)拿掉、詞彙表保留,`_unexported_codes`
那道「短碼不在按鈕清單」的檢查因此不需要開例外。

**網址的合法碼跟著按鈕走**(`hash.js` 的 `schema`):有分組的值域取分組聯集而不是
`items`——被拿掉的值視同未知碼,與兩態軸丟排除段同一條「UI 做不出來的狀態還原
不回來」。副作用:網址帶著被拿掉的值時 `Query.count` 也數不到它,零條件網址照舊
停在起始畫面而不是自動列出全部。

**全庫實測**(建置報告的「跨類型魔陷卡數」一行):sc=14、se=142、tc=11,
其餘七值(sn/sq/sr/sf/sp/tn/tk)0 張、按鈕拿掉——靈擺如預期消失,存活的三值
正是怪獸「當作裝備卡/永續陷阱/永續魔法」那三族。`web/data.js` 的 diff 只有
kind 值域一行 + built_at + digest。
