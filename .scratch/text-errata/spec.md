# 卡文勘誤表(text-errata)

2026-08-17 盤問定案(/grill-with-docs)。

## 問題

繁中卡文來源(salix5 cdb)偶有誤譯。第一例:`84488827` 侵入魔 巨角的
「上級召喚成功時，**可以**從以下效果選擇1個效果發動」——日文原文
「以下の効果から１つを選択して**発動する**」是必發,[[效果標記表]]也判必發
(official/high),「可以」是任意語氣的誤植。

直接手改 `data/cards.json` 不可行:總表每次 `update_cards.py` 都由 cdb 來源
整份重建,手改會被蓋回去;且該句的 `text_zh` 與雜湊同時存在拆句表與標記表,
不同步就觸發拆句紀錄失效與建置覆蓋檢查失敗。

## 決定(盤問答案)

1. **勘誤機制**:新增來源檔 `data/text_errata.json`,建置 `cards.json` 時套用;
   原文子字串比對不到(如上游自己修好)即建置失敗吵出來。
2. **原文語意**:「原文」= 勘誤前的來源卡文(salix5 原樣)。
3. **顯示範圍**:只有被勘誤的卡才帶原文欄位、才長「顯示原文」切換鈕
   (使用者自訂答案,收窄自「全卡都有鈕」)。
4. **切換行為**:逐卡切換、不記憶;翻頁或重搜後回到標註視圖。
5. **下游同步**:拆句表/標記表的 `text_zh` 與雜湊由同票一次性腳本更新,
   判定欄位原封不動;未來每筆新勘誤重跑同一支腳本。
6. **搜尋語意**:效果文只比對勘誤後文字;原文欄位不進搜尋。
7. **文件**:ADR-0011 + CONTEXT.md 詞條「卡文勘誤表」。
