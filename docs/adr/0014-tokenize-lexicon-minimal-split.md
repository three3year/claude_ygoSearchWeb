# 分詞詞典的粒度:最小可拆,封閉值域、語彙化詞、活用形例外

[[效果文分詞]]的詞典經多輪裁定逐條長出來,同一段字常有兩種切法——詞典同時收了整詞與它拆開後的每一段(特殊召喚 與 特殊/召喚、墓地へ送る 與 墓地/へ/送る),2026-10-08 盤點時 612 條裡有 175 條可以完全拆成其他詞條加助詞。我們定一條粒度原則:**能拆成其他詞條的複合詞一律拆開**,只留三種例外整詞——**封閉值域**(官方枚舉值的字面:種族、卡片子類型、階段名、區域名、表示形式、卡種+カード、玩家+區域、傷害種類)、**語彙化詞**(意思不是兩段相加:数値、いずれか、その後、一番上)、**活用形**(できる、送って 照舊一格,以 lemma 欄歸組)。拆開後「這幾格合起來是哪個術語」不在詞典記錄,交給[[動作類別]]的推導層。

這推翻了 2026-10-07 的 R1 裁定(墓地へ送る 家族整詞):詞典的工作是給出最小而一致的詞單位,術語辨識是推導的工作——兩件事混在詞典裡,就是重疊覆蓋的來源。

## Considered Options

- **術語整詞**:遊戲術語(特殊召喚、墓地へ送る)整詞、非術語拆。推導時術語直接是單位,但「是不是術語」得逐條判,重疊會隨新術語不斷長回來。
- **最小可拆+三種例外**(採用):詞典乾淨、切分形狀一致;代價是模板變長、術語身份要推導層重建。
- **只清零命中殘片**:工作量最小,重疊本身沒解。

## Consequences

- 封閉值域與語彙化詞是例外清單,判準是「官方枚舉值」與「意思不是兩段相加」;新詞入典時先問它屬不屬於這兩類,不屬於且拆得開就不收整詞。
- 列舉前項省略的補全詞若是封閉值,前項本身是詞時也補(魔法・罠カード 的 魔法 → 魔法(カード)),token 連到被補全詞的詞典 ID。
