# 01 — 驗證腳本走通管線(tracer bullet)

**What to build:** 站主能對任一組卡片執行驗證,拿到依條目分組的不一致報告。
以卡文詞彙表現有六條譯詞為線頭;另補一條已有庫內裁示的句式條目(如
「1回合可以使用最多〈n〉次」23 張型或「，隨後」267:0,出處註明審查檔,
擇一經站主同意入表)作佔位符試金石,讓譯詞、句式兩級檢查端對端都走通。

**Blocked by:** None — can start immediately。

**Status:** ready-for-human

**待站主驗收 1——句式試金石選型**:兩候選中選了
「この効果は１ターンに〈n〉度まで使用できる → 這個效果1回合可以使用最多
〈n〉次」入表(出處 review-41-monster-01「改寫依據」2026-08-24 裁示)。
理由:全句形帶 `〈n〉` 佔位,是比「，隨後」(純中文側標點裁示,無日文側
樣式可命中)更好的佔位符試金石。庫內計數以全句形重計=含①卡 10 句全數
照模板(審查檔的 23 張數的是寬鬆形「1回合可以使用最多2次」不限前綴,
兩個數字都對、量的不同)。不同意可換,條目獨立一列、退回即刪。

**待站主驗收 2——體例小修**:譯詞「〜の効果を受けない」的規範譯法欄
原寫「不受…效果影響」,`…` 不在體例佔位符之列(嚴格解析會吵),改為
「不受〜效果影響」並記於該條備註。另依 /code-review 發現補訂體例節兩句:
佔位符也可出現在譯詞條目(如「抽〈n〉張卡」,§3.19 收編時本就如此);
`〈n〉` 樣式以半形書寫、機器比對半形全形皆容許(日文側官方卡文用全形,
寬窄之辨歸《文本格式規範》§2)——消除 md 體例與腳本推導規則的分歧。
