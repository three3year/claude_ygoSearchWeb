# 10: 誰與不限定開關

**What to build:** 可以篩「誰做的」:我方或對手。Python 的查詢判斷和網站都能用;沒寫誰的段照規格分成算我方與不限定兩種,不限定的要打開開關才命中。

- 查詢判斷多兩個鍵:誰、不限定開關(鍵名英文、值用 `GLOSSARY.md` 的詞)。沒給時行為與現在相同。
- 段寫明了誰:寫的值和查詢相同,或寫的是同時含兩方的值(雙方各自),命中。
- 段沒寫誰:效果段、代價段、召喚手續段的主動句算我方;其餘(條件段、被動句、限制段、修飾段)是不限定,不限定開關開才命中。
- 不限定開關預設關;只管「整欄沒寫」,寫得比查詢寬的一律命中。
- 誰是段的欄,比的是段。對未解析組不生效。
- 攤平的列多「誰」一欄(寫明的值、算我方、不限定三種分得開),寫進動作索引。
- 網站:區塊多「誰」的選項與「含不限定的」勾選,預設關。

- 規格:需要你決定的「Q3」「Q16」「Q17」與前三題裡的「召喚手續、限制、修飾這三種段沒寫誰時怎麼算?」;實作決策「比對規則」的誰與不限定開關;使用者故事 15–19、27、47;測試決策「接縫一」與標準卡表。
- 候選標準卡:マグナム・ザ・リリーバー、ヴェルズ・ナイトメア(寫明);パラレル・テレポート(主動句沒寫);ホーリーナイツ・オルビタエル、EMスカイ・ピューピル(不限定);雙方各自由實作者從寫「お互いに」的段挑。
