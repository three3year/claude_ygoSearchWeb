# 08: 命中、張數與「不留」

**What to build:** 重跑鏈多一步「目錄」:每個動作框架 → 命中的具名查詢名清單(目錄序,三個位置都算;大類/中類是聯集、由樹推得),寫成中間產物給拆解頁與 LLM 抽驗讀;匯出檔的目錄欄補上每個節點一列(名、路徑、述詞或空、三個位置的張數、卡集合雜湊=卡片密碼排序後連寫的 sha1 前 16 碼),張數由票 06 的參考評估器對匯出框列算;「每個具名查詢在全語料三個位置合計至少命中一張」是建置期檢查,違反列清單、不產出。以編譯試跑的三張清單逐葉比對:101 葉張數相同、31 葉不同(不再互斥、並收取消、取自來源收回)、97 片預設葉取消、101 個詞元節點不變,新數字逐葉說明差異(尾綴比對預期 破壊:モンスター −4、にする:ドロー/数 −2)。目錄接縫:一句原文 → 每個動作框架命中的具名查詢名清單。
