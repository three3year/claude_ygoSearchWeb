# 頁尾資料來源改成連結

Status: ready-for-agent

2026-11-11 訪談定案，參照實作是 ark-keyword 的頁尾。與參照不同的每一處都逐項問過，見[與 ark-keyword 的對照](<#與 ark-keyword 的對照>)。

## Problem Statement

頁尾第二行的資料來源是純文字：`資料來源：查牌網（中文卡文・卡圖）・ygopro-database（日英卡名・日文卡文）・…`。訪客看得到站名，卻點不過去，想查原始資料只能自己搜尋。這一行先寫站名、再用括號寫資料，訪客真正在找的「某項資料從哪來」反而藏在括號裡。頁尾字級只有 10px，在手機上很難讀。

## Solution

頁尾維持兩行、置中、貼齊視窗底。第一行的資料更新時間不變。第二行改寫成：

`資料來源：中文卡文、卡圖 · 日英卡名、日文卡文 · MD 稀有度、MD 禁限 · Genesys 點數、OCG/TCG 禁限 · 效果類型`

- 五段各是一個連結，在新分頁開啟該來源的網站。
- 懸停時顯示「資料來源：<站名>」。
- 頁尾字級放大到 0.82rem。站上是深色主題，文字改用較亮的次要文字色以提高對比，連結用強調色。

外部站的網址集中到一個前端來源模組。頁尾的連結、卡名連到查牌網單卡頁的連結、卡圖網址都從這個模組產生。

## User Stories

1. As a 訪客, I want 頁尾的資料來源每一段都能點, so that 我能直接到來源網站查原始資料。
2. As a 訪客, I want 連結在新分頁開啟, so that 回來時已設的搜尋條件與捲動位置還在。
3. As a 訪客, I want 連結文字寫的是資料項目（例如「中文卡文、卡圖」）, so that 我一眼找到想查的那項資料從哪來。
4. As a 桌機訪客, I want 懸停連結時看到「資料來源：查牌網」這類提示, so that 點之前就知道會連到哪個站。
5. As a 手機訪客, I want 點一下連結就直接開啟, so that 不必先點出提示再點一次。
6. As a 訪客, I want 同一個來源的資料項目之間用「、」、不同來源之間用「 · 」, so that 看得出哪幾項來自同一站。
7. As a 訪客, I want 「中文卡文、卡圖」連到查牌網首頁, so that 我能用查牌網查中文卡文。
8. As a 訪客, I want 「日英卡名、日文卡文」連到 ygopro-database 的 GitHub 資料庫, so that 我看得到日英卡名的原始資料。
9. As a 訪客, I want 「MD 稀有度、MD 禁限」連到 Master Duel Meta 首頁, so that 我能查 MD 的稀有度與禁限。
10. As a 訪客, I want 「Genesys 點數、OCG/TCG 禁限」連到 YGOPRODeck 首頁, so that 我能查 Genesys 點數與 OCG/TCG 禁限。
11. As a 訪客, I want 「效果類型」連到 Yu-Gi-Oh! Neuron 的日文版, so that 我看得到效果類型依據的日文 Q&A 所在的官方資料庫。
12. As a 訪客, I want 頁尾字級比現在大, so that 在手機上讀得清楚。
13. As a 訪客, I want 頁尾連結用站上的強調色, so that 看得出哪些字可以點。
14. As a 訪客, I want 資料更新時間仍單獨成一行, so that 一眼看到資料多新，不必從一長串來源裡找。
15. As a 訪客, I want 資料更新時間的格式與顯示規則維持不變, so that 我熟悉的資訊不會換位置或換寫法。
16. As a 訪客, I want 頁尾仍然置中、內容不滿一屏時仍貼齊視窗底, so that 版面跟現在一樣。
17. As a 手機訪客, I want 來源行在窄螢幕上自動換行, so that 頁面不會出現水平捲動。
18. As a 訪客, I want 卡名連到查牌網單卡頁、卡圖照常顯示, so that 這次改動不影響卡片本身。
19. As a 維護者, I want 外部站的網址集中在同一個前端模組, so that 某站換網域時前端只改一處（建置腳本的下載網址另計，見 Out of Scope）。
20. As a 維護者, I want 頁尾的資料來源由來源清單組出來, so that 增減來源時只改清單、不必同時改 HTML。
21. As a 維護者, I want 改動後仍維持零建置協定, so that 不必多裝工具或多一道建置步驟。

## Implementation Decisions

- **來源模組（新增）**：一個新的前端模組，照零建置協定（ADR-0007）寫成掛在全域的 IIFE。它在呈現模組之前載入。script 標籤寫成 `<script src="…">`，`src` 是第一個屬性，因為前端測試沙箱只認這種寫法。模組公開三樣東西：
  - **頁尾來源清單**：五項，依現行頁尾的順序排列，每項有連結文字、站名、網址，內容見[來源清單](#來源清單)。
  - **單卡頁網址函式**：輸入卡片密碼，輸出查牌網單卡頁網址，與現行逐字相同，即查牌網首頁網址加 `?code=<卡片密碼>`。查牌網首頁網址在模組內只定義一次，清單與這個函式共用。
  - **卡圖網址函式**：輸入卡片密碼，輸出卡圖 CDN 網址，與現行逐字相同（salix5/query-data 的 jsDelivr CDN，檔名是不補零的卡片密碼加 `.jpg`）。
- **會過時的註解**：以下三段要一併更新。
  - index.html 說明載入順序的註解。
  - index.html 頁尾上方的註解，目前寫「靜態文案住 HTML、唯一動態的是第一行」，改完後第二行也是動態的。
  - 樣式表頁尾規則上方的註解，目前寫「兩行小字」。
- **呈現模組**：拿掉現有的卡圖與查牌網兩個網址常數，三處用到的地方（卡名連結、卡片縮圖、異圖輪播）改呼叫來源模組的函式。產出的網址字面不變。
- **主流程模組**：初始化時依來源清單組出第二行。
  - 第二行開頭是純文字「資料來源：」，後接五個連結，連結之間以「 · 」分隔。
  - 每個連結開新分頁，並阻擋開啟頁取得原頁面的控制權（`rel="noopener noreferrer"`）。
  - 懸停提示用瀏覽器原生的 `title`，內容為「資料來源：<站名>」，全形冒號。
  - 連結文字與站名以文字節點或 `textContent` 寫入，不拼接 HTML 字串。
- **頁面骨架**：第二行改成一個空段落，由主流程填入。第一行的資料更新時間維持現狀：META 沒有這個欄位時整行隱藏。
- **樣式**：
  - 頁尾字級改為 0.82rem，文字顏色改用 `--text-dim`。這是站上既有的次要文字色，介於 `--text` 與 `--muted` 之間，角色等同 ark 的 `--text-2`，不另加變數。
  - 頁尾連結顏色用 `--accent`，底線用瀏覽器預設。
  - 其餘維持現狀：置中、上下內距 4px、左右 20px、上框線、內容不滿一屏時貼齊視窗底。
- **舊規格的變更**：footer 規格（`.scratch/footer/spec.md`）有兩項裁示被這份取代。
  - 「footer 純文字、不加外部連結」改為五個連結。
  - 「字級 10px」改為 0.82rem。

## Testing Decisions

- 好的測試只驗外部行為，也就是訪客看得到的文字與點下去的去處，不驗 DOM 結構或模組內部。
- **不新增自動測試**（訪談 Q14、Q17 裁示）。來源清單是固定資料，組裝只是逐項產生連結並串起來，沒有條件分支。這跟 footer 規格「頁尾組裝是薄殼、不測」同一待遇。
- **既有測試照跑**：前端測試的沙箱依 index.html 的 `<script>` 順序載入模組，所以會自動載到新的來源模組。跑法：`node --test script/web/engine.test.js script/web/render.test.js`。
  - 呈現測試（prior art：卡片 HTML 字面斷言）必須照樣全過。它能抓到來源模組沒載入或函式名寫錯，這類錯誤會讓卡片 HTML 產不出來。
  - 呈現測試沒有斷言任何網址，異圖輪播也沒有測到。「網址字面不變」只靠下面的實看驗收確認。
- **實看驗收**：在 headless 瀏覽器實際開頁面看一次，逐項確認：
  - 第二行的字面與分隔符號。
  - 五個連結的網址與 `target`、`rel`。
  - 懸停提示的文字。
  - 卡名連結與卡圖網址跟改動前相同。
  - 手機寬度沒有水平捲動。
  - 字級與顏色已套用。

## Out of Scope

- 每個來源分開記錄下載時間（訪談 Q4：維持一次下載記一個時間）。
- 資料更新時間的格式或標籤改動（訪談 Q5：維持現狀）。
- 把兩行併成一行（訪談 Q1：維持兩行）。
- 頁尾改成靠左、改間距、取消貼底（訪談 Q7、Q8：維持現狀）。
- 自訂樣式的懸停提示框。
- 連到資料夾、單一檔案或特定 commit 層級的連結（只連各站首頁或資料庫首頁）。
- 建置腳本（Python）的下載網址併入來源模組：語言不同，無法共用，而且下載用的 API 或原始檔網址跟給訪客的首頁網址本來就不同。
- 頁尾以外位置的來源說明（README 不動）。

## 與 ark-keyword 的對照

參照實作是 ark-keyword 的 `App.vue` 頁尾、`core/query.ts` 的頁尾項目函式，以及 `core/sources.ts`。

| 細節 | ark-keyword | 本站 | 裁示 |
|---|---|---|---|
| 行數 | 一行 | 兩行（時間一行、來源一行） | 與 ark 不同（Q1） |
| 連結 | 有，開新分頁，`rel="noopener noreferrer"` | 同 | 同 ark（Q2） |
| 連結文字 | 資料名稱（陸服、頭像與圖示） | 資料項目（中文卡文、卡圖） | 同 ark（Q3） |
| 前綴 | 無，直接是連結 | 「資料來源：」純文字開頭 | 與 ark 不同（Q3 回答時使用者表示保留） |
| 時間 | 每個伺服器一個 | 全站一個 | 與 ark 不同（Q4） |
| 時間格式 | `2026-10-19 12:14(UTC+8)` | `資料更新時間：2026-08-17 19:41 (UTC+8)` | 與 ark 不同（Q5） |
| 字級與顏色 | 0.82rem、`--text-2`、連結 `--accent` | 0.82rem、`--text-dim`（本站對應的次要文字色）、連結 `--accent` | 同 ark（Q6） |
| 對齊 | 靠左 | 置中 | 與 ark 不同（Q7） |
| 間距與位置 | 上方留白 24px、上內距 12px，跟著內容走 | 上下內距 4px，貼齊視窗底 | 與 ark 不同（Q8） |
| 項目內的分隔 | 「與」（頭像與圖示） | 「、」 | 與 ark 不同（Q9） |
| 項目間的分隔 | 「 · 」 | 同 | 同 ark（Q10） |
| 懸停提示的冒號 | 半形「:」 | 全形「：」 | 與 ark 不同（Q11） |
| 懸停提示的名稱 | GitHub 的 `擁有者/資料庫`（Kengxxiao/ArknightsGameData） | 站名（查牌網） | 與 ark 不同（Q11、Q12 選項寫明，使用者選過） |
| 項目依條件出現 | 有（沒有台服資料就不列台服） | 無，固定五項 | 不適用：本站沒有會缺席的來源 |
| 連結目的地 | 資料所在的 GitHub 資料庫首頁 | 各站首頁（ygopro-database 本身就是 GitHub 資料庫） | 與 ark 不同（Q12） |
| 網址定義 | 集中在獨立的來源模組，建置的下載位置也從這裡衍生 | 集中在獨立的前端來源模組，建置不共用 | 同 ark，只差建置不共用（Q13、Q15） |
| 其他外部站網址 | 來源模組也收結果卡連到的外部站（PRTS） | 來源模組也收查牌網單卡頁與卡圖 CDN | 同 ark（Q16） |
| 自動測試 | 有（Vitest 驗項目、Playwright 驗連結） | 無，實看驗收 | 與 ark 不同（Q14、Q17） |

## Further Notes

- 名詞：「資料更新時間」依 GLOSSARY 詞條。頁尾上的「資料來源」只是一般用語，指資料所在的外部網站，這份規格沒有新增詞條。
- 本站的網站或資料庫目前都沒有版號，所以不像 ark 在連結後面接版號。
