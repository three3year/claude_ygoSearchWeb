# 15: 無法確認的張數

**What to build:** 清單下方多一行「另有 N 張無法確認」,讓玩家知道結果可能不完整。

- 前端引擎算出未解析組:來源照現有查詢判斷(無官方日文的卡、解析不出的段、物件判不了的段、解析不出的引用節點、區塊種類判不出的區塊),用動作索引裡對應的列與欄。任一段命中的卡只在命中的清單,不重複算。
- 段類別、極性的篩選對它照樣生效;誰、受方、原因的篩選對它不生效。
- N 只算同時滿足卡片條件的卡;句層條件對它不做同一效果的判斷。
- 這一行不能點;N 是 0 時不顯示。畫面上的用詞是「無法確認」。
- 被動作的卡判不了的線(票 12、13)要算進來;兩邊後做的那張把這個接上。

- 規格:需要你決定的「Q24」;實作決策「動作索引」的未解析組來源、「比對規則」最後一條、「前端查詢引擎」;使用者故事 35;測試決策「接縫三」「兩邊答案一致」。
