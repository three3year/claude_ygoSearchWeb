# 效果 Tag 體系裁定紀錄(票03–06)

**裁定主體聲明**:本紀錄由 agent 於 2026-09-20 依站主「/implement effect-tag all」
的全權委託作成,各【裁定點】一律採 `taxonomy-draft.md` 的草案立場;草案未表態的
細項由 agent 以「粒度最小可用、值域有語料支撐」為原則補裁,並逐條記理由。站主
回頭覆核時,任何一條裁決都可由新裁定票推翻——體系凍結凍的是「未經裁定不得改」,
不是「站主不能改」。證據基礎:當前 `data/tag_cards.json` 的新式子集 19,342 條
(與規格一致)之全文檢索計數(附錄),與既有分群素材(48 群 embedding、300 條
人工 30 群)。

## 批1(票03):通用槽位 + 區域移動 + 抽牌/手牌交換

### 通用槽位(約束全部類別)

- **位置**(`pos`):`成本` / `效果`,全類別皆有,預設 `效果`。發動的代價
  (「このカードをリリースし」「手札を１枚捨てて」)貼 `成本`,處理內容貼
  `效果`。**搜尋(第一期)只命中 `效果`**——草案通用槽位表明文「搜尋預設只
  命中效果」,Story 6(搜除外不撈自家代價)由此天然成立;`成本` tag 照貼進
  資料,未來要開位置開關時零遷移。
- **對象方**(`side`):`自身` / `我方` / `對手` / `雙方`,逐類別決定採不採用。
  `自身` 專指此卡自己;「持ち主(持有者)」句型按被移動的卡歸屬雙方時記 `雙方`,
  單方時記該方。

### 區域移動(`mv`)

- **定義定稿**:卡片從一個區域到另一個區域。蘇生/檢索/回收/展開/送墓/除外/
  彈回全是槽位組合,不另立類別。
- **槽位**:`from` / `to` ∈ {手牌, 牌組, 額外牌組, 墓地, 除外, 場上, 靈擺區},
  加 `side`、`pos`。
- 【裁定點】**牌組頂/底不獨立**,歸「牌組」。理由:語料牌組頂 148 條/底 123 條,
  獨立成值讓下拉膨脹兩格,而「檢索/回收到底放哪」不是牌手搜卡的主要條件;頂/底
  資訊由效果文關鍵字搜尋承接。
- 【裁定點】**靈擺區放置歸區域移動**(草案 from/to 值域已含靈擺區,採之)。
  「Pゾーンに置く」(340 條)語意上是「把卡弄到靈擺區」,身分改變是靈擺卡的
  規則內建,非效果特有;放置轉換不收目的地為靈擺區的句型(對放置轉換的
  「目的地是身分改變者歸該類」通則開此一條明文例外)。
- 【裁定點】**特殊召喚的表側/裡側、攻/守表示不當槽位**。第一期不建模;表示
  形式資訊歸「表示形式變更」類與關鍵字搜尋。理由:槽位每多一格,規則層與判定
  規範的組合數都翻倍,而「守備表示蘇生」的搜尋需求可由 蘇生+關鍵字 組合。
- **慣用名對照定稿**(UI 顯示層,非資料):蘇生=墓地→場上;檢索=牌組→手牌;
  回收=墓地→手牌;彈回=場上→手牌|牌組;送墓=任意→墓地;展開=手牌|牌組|額外
  →場上。
- **邊界**:「〜できない」「〜されない」的否定句**不貼**區域移動(歸行動限制
  或耐性);「特殊召喚する」寫在召喚條件/召喚程序(無種類效果)上時照貼
  (效果句自己描述的移動就是移動);セット自牌組/墓地(魔陷身分不變)是區域
  移動,終點=場上。

### 抽牌/手牌交換(`dw`)

- **定義定稿**:抽卡(不指定卡)與伴隨的捨棄/回牌組循環。與區域移動分界:
  抽牌不指定對象卡;「デッキから選んで手札に加える」是檢索(區域移動),
  「ドローする」是抽牌。
- **槽位**:`side`(對象方)、`extra`(附帶)∈ {捨棄, 回牌組, 無}、`pos`。
- 【裁定點】**「抽1捨1」採附帶槽位**(草案立場),不拆成抽牌+區域移動兩個
  tag。理由:附帶捨棄是同一個動作的參數;拆兩個 tag 會讓「搜手牌→墓地」撈進
  全部換手卡,而那不是搜棄卡代價的人要的。

## 批2(票04):妨害向四類

### 無效(`ng`)

- **槽位**:`what`(無效對象)∈ {發動, 效果, 持續無效化},`extra`(附帶處置)
  ∈ {破壞, 除外, 無}。
- 【裁定點】**持續性無效化與一次性無效同類、不同槽位值**(草案立場)。
  「装備モンスターの効果は無効化される」「そのモンスターの効果は無効化される」
  (382 條)貼 `what: 持續無效化`;連鎖上的「発動を無効にする/効果を無効に
  する」貼 `發動`/`效果`。

### 破壞(`ds`)

- **定義定稿**:效果把卡破壞;戰鬥破壞是狀態不是效果動作,不貼。「代わりに
  破壊する」的破壞替代歸耐性/保護(`代替破壞`),不貼破壞。
- **槽位**:`what` ∈ {怪獸, 魔陷, 卡},`scope` ∈ {單體, 複數, 全體},
  `side`、`pos`。「魔法・罠カードを破壊」= 魔陷;「カードを破壊」(不限種)
  = 卡;「モンスターを破壊」= 怪獸。`scope`:寫死 1 張=單體;「２枚まで」
  「全て」等=複數/全體;張數由選擇時決定者從寬記複數。

### 行動限制(`rs`)

- **槽位**:`what` ∈ {特殊召喚, 發動效果, 攻擊, 表示形式, 其他},`side`
  (受限方),`term` ∈ {持續, 單回合}。
- 【裁定點】**自我限制(demerit)與妨害對手同類**(草案立場),以 `side`
  區分——「この効果を発動するターン、自分は〜できない」貼 `side: 我方`,
  搜尋時排除自限即可。

### 耐性/保護(`pt`)

- **槽位**:`what` ∈ {戰鬥破壞, 效果破壞, 效果對象, 除外, 全效果, 代替破壞},
  `side`(保護對象)。
- 【裁定點】**邊界句型清單定稿**(行動限制 vs 耐性 vs 戰鬥規則):
  - 「攻撃できない」「攻撃宣言できない」→ 行動限制(`what: 攻擊`)——主語是
    行動者,禁的是「做」。
  - 「攻撃対象にならない/選択できない」→ 耐性(`what: 效果對象`?否——攻擊
    對象另計)→ **裁決**:「攻擊對象にならない」歸**戰鬥規則**(`what: 攻擊
    對象操作`)——它改的是攻擊對象的選擇規則,與「効果の対象にならない」
    (耐性)是兩件事。
  - 「効果の対象にならない」「効果を受けない」「戦闘では破壊されない」
    「効果では破壊されない」「除外されない」→ 耐性(對應 `what` 值)。
  - 「直接攻撃できる/できない」→ 戰鬥規則(`what: 直接攻擊`)——攻擊方式的
    許可與限制都是戰鬥規則(與 kind 線 R17 官方一律判永續效果同一族的觀察)。

## 批3(票05):數值與狀態七類

### 攻守調整(`st`)

- **槽位**:`item` ∈ {攻擊, 守備, 攻守},`dir` ∈ {上升, 下降, 變成},`pos`。
- 【裁定點】**「〜になる」句型一律歸「變成」**:倍化(倍になる)、減半(半分
  になる)、變 0、變指定值、變參照值全是 `變成`;「アップ/ダウン」增量句歸
  上升/下降。理由:日文句型本身二分乾淨(になる vs アップ/ダウン),規則層
  與判定規範不必逐卡拆算術;草案已把「變成一半」「變成 0」放進「變成」,
  倍化從其例。

### 效果傷害(`dm`)

- **槽位**:`side`(承受方)、`form` ∈ {固定值, 參照值, 比例}。含傷害轉嫁
  (「代わりに受ける」類)。戰鬥傷害的增減歸戰鬥規則?**裁決**:「戦闘
  ダメージは倍になる」等戰鬥傷害修飾歸**其他**(量少,第一期不細分;累積後
  再裁)。

### 生命回復(`hp`)

- **槽位**:`side`、`form`(同效果傷害)。「LPを払う」是代價不是回復也不是
  傷害,**不建模**(記錄:LP 支付第一期不設類別,搜尋需求低;未來要做時開
  新裁定票增類)。

### 表示形式變更(`ps`)

- **槽位**:`to` ∈ {攻擊表示, 守備表示, 裡側表示},`side`、`pos`。「攻守を
  変更する(自由選)」記 `to` 缺值(只貼類別)。

### 控制權轉移(`ct`)

- **槽位**:`dir` ∈ {取得, 移交}。「コントロールを得る」=取得;「相手に移す」
  =移交。

### 性質變更(`pp`)

- **槽位**:`item` ∈ {卡名, 種族, 屬性, 等級, 階級, 刻度},`term` ∈ {持續,
  單回合}。「〜として扱う」「〜になる」都算;攻守數值歸攻守調整不歸此類。

### 計數器操作(`cnt`)

- **槽位**:`act` ∈ {放置, 去除}。計數器種類不建模(草案立場)。

## 批4(票06):轉換與其他五類 + 觸發時機值域 + 體系凍結

### 放置轉換(`tf`)

- **定義定稿**:卡片以**改變後的身分**被放置(怪獸當作裝備卡/永續魔法、卡片
  當作魔陷覆蓋)。通則:目的地是身分改變者歸此類;**唯一例外**是靈擺區
  (批1 裁定,歸區域移動)。
- **槽位**:`to` ∈ {裝備卡, 永續魔法, 永續陷阱, 魔陷覆蓋}。

### 素材代用/召喚放寬(`su`)

- **定義定稿**:可代替素材、無視召喚條件、追加召喚權。無專屬槽位。

### 召喚執行(`se`)

- **定義定稿**:魔陷卡上的召喚指令(儀式/融合等召喚的執行效果)。
- **槽位**:`method` ∈ {儀式, 融合, 同步, 超量, 連結}。

### 戰鬥規則(`bt`)

- **槽位**:`what` ∈ {貫通, 連續攻擊, 直接攻擊, 攻擊對象操作}。邊界句型清單
  見批2 裁定。

### 情報操作(`in`)

- **槽位**:`what` ∈ {確認, 展示, 隨機決定}。
- 【裁定點】**「手牌妨害」不獨立成類**(草案立場):「相手の手札をランダムに
  １枚捨てる」= 區域移動(手牌→墓地, side: 對手)+ 情報操作(隨機決定)兩個
  tag 的組合。

### 其他(`misc`)

- 跳過階段/回合、縱列位置操作、硬幣/骰子(擲的動作本身)、戰鬥傷害修飾等
  量少句型,暫不細分;無槽位。累積後由新裁定票拆類。

### 觸發時機值域(獨立句層軸,`timing`)

- 【裁定點】**「被破壞時」不分戰鬥/效果**(草案傾向,採之):合寫句「戦闘・
  効果で破壊された場合」是常態,拆兩值會逼出複值軸;細分交給動作維與關鍵字。
- **值域定稿(17 值)**:召喚成功時 / 特殊召喚成功時 / 反轉時 / 被破壞時 /
  被送去墓地時 / 從場上離開時 / 被除外時 / 攻擊宣言時 / 傷害步驟時點 /
  給予戰鬥傷害時 / 受到傷害時 / 準備階段 / 主要階段 / 戰鬥階段 / 結束階段 /
  對手發動效果時 / 其他。
- **承載類型(carriers)**:與必發/選發完全同一組——誘發即時效果(2速)、
  誘發效果(1速)與魔陷卡效果十值。理由同 ADR-0004:有觸發事件的發動句才有
  時機可言;啟動效果/永續效果/無種類效果/效果外文本不承載,建置期照 carriers
  擋。一句多時機(「〜した場合、または〜した場合」)取**最先寫出的**時機,
  單值軸不擴複值(記錄於判定規範逃生口)。

### 規則敘用門檻(ADR-0013 的數字定案)

- 遮蔽測試:每類別固定種子抽 **200 句**候選(粗篩命中)為標準答案樣本;
  逐規則**錯標 0 筆**、**recall ≥ 90%**、樣本內命中不足 **8 句**的規則補抽至
  8 句。首批直貼**人工抽驗 50 條**。
- 粗篩(類別候選圈選)的定義與規則一起登記,漏網是已接受殘餘風險。

### 體系凍結宣告

以上 19 類動作類別(含槽位值域)、通用槽位、觸發時機 17 值,自本紀錄起
**凍結**。追加類別、增刪槽位值、改邊界通則,一律需新裁定票;貼標期(票07
起)只選 tag、不改體系。定稿的機器正本為 `script/web/vocab.py` 的 tag 值域

## 追記:貼標期實戰裁定(2026-09-20,票07/09/10/13 實作中補裁)

體系凍結後,遮蔽測試 679 句與首批判定暴露的邊界,逐條補裁如下(均為
規範細則,不動類別與槽位值域):

- **代替處置一律位置=效果**:「代わりに〜する」不論替代的是發動代價、召喚
  代價還是破壞,一律貼 `效果`——原裁「替代什麼繼承什麼」在無發動子句的句型
  上機器不可判,統一取消。
- **無發動子句的付出一律位置=效果**:自我特召程序(「〜を除外し、手札から
  特殊召喚できる」)、召喚手順的解放等,位置=成本只標**發動子句**內的代價。
- **牌組內位移貼 `{to: 牌組}`**:「デッキの一番上に置く/戻す」來源也是牌組時
  照樣貼終點、不填起點(整理動作視為到牌組的移動)。
- **衍生物生成貼 `{to: 場上}`** 無起點;**場內身分/區位變動**(罠モンスター
  特殊召喚、魔陷區⇄怪獸區)同樣貼 `{to: 場上}`、起點留空。
- **リリース=場上→墓地**(手牌解放另計 手牌→墓地);通常召喚的解放手順文
  (「リリースして召喚する事もできる」)不是效果動作,不貼、也不進粗篩。
- **「魔法カード扱いで(手札から)セット/置く」歸放置轉換**,區域移動不貼;
  魔陷以原身分從牌組/墓地/手牌被 セット 則照貼區域移動。
- **X 素材的取除與重疊不建模**(不屬任何類別)。
- **時機:反転召喚/A召喚(アドバンス召喚)歸「召喚成功時」**(通常召喚
  家族);召喚法特定形(S/X/リンク/融合/儀式/P召喚した)歸「特殊召喚成功時」;
  「捨てられた」歸「被送去墓地時」;「攻撃対象に選択された」歸「攻擊宣言時」;
  「リリースされた/装備された/取り除かれた/セットされた/宣言した/手札に
  加わった/ドローフェイズ」等不落具名值者一律「其他」(兜底規則 TM21,最低
  優先)。
- **遮蔽門檻的分母補充**:全表命中本來就不足 8 句的規則,以全量判定計
  (5/5 全對視同達標)——補抽補不出不存在的句子。
- **粗篩排除追加**:通常召喚解放手順(「リリースして(表側表示で)?召喚」)。

以上細則已同步寫入 `docs/effect_tag_guide.md`;遮蔽樣本 679 句 + 標準答案
1,277 個 tag 入版控(.scratch/effect-tag/masked/),tag seal 每輪現場重算。

## 追記:站主覆核裁定(2026-09-21,裁定票15)

站主逐條覆核本紀錄(代行裁定全清單),裁決如下:

- **批3「LP 支付不建模」推翻**(裁定票15):LP 要建模,且**支付/失去/傷害
  三分**——「LPを払う」(代價,290 條)、「LPを失う」(非傷害的失去,36 條)、
  「ダメージ」(既有類別「效果傷害」)是三件事,規則上互不換算。增兩類別:
  - **LP支付**(`lpp`):槽位 `side` + `form`。**不設「位置」槽位**——支付
    本身就是代價,位置軸對它無意義;搜尋一律命中(通用槽位「位置」的唯一
    明文例外,`vocab.TAG_POS_EXEMPT`;否則照 Story 6 整類搜不到)。前端由
    「槽位表無 pos」自行看出例外,不另立旗標(ADR-0008)。
  - **LP失去**(`lpl`):槽位 `side` + `form` + `pos`。
