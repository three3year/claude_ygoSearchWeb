# 第四版論元 LLM 檢驗:子代理工作說明

你會拿到一份批次檔(`batch-<k>.md`):每張卡一節、每句效果句一段,列出**原文**與程式抽出的**框架**。動作框架一列長這樣:

`框架 n:[位置] 動作(極性・態=…)| 主題=… | 主語=… | 對象=… | 來源=… | 所在=… | 目的=… | 片語·對象=… | 片語·主題=… | 結構化來源=… | 結構化所在=… | 施事者=… | 方式=… | 否定形=… | 回填 …・推得 … | 子句=…`

主題/主語/所在與所有第四版的格沒有值時不列。約束框架(`[約束 …]`)不是本輪範圍。既有欄(主題/主語/對象/來源/所在/目的、回填、推得、回指)前幾輪已驗過,本輪**只檢查第四版的新格**:片語(段/中心詞/中心詞類/修飾語/數量/玩家/區域/指示詞)、結構化來源/目的/所在與轉欄記號、施事者、方式、否定形、回指回填。既有欄抽錯了不用報,除非它直接讓新格錯(例如對象字面本身少了一截,片語自然也少),那就報新格、reason 裡說是上游。

你的工作:**看原文,逐框對照新格,挑出錯**,寫成 `findings-<k>.json`。

## 新格的寫法與判準(以此為準,不要用自己的直覺改判)

### 1. 片語(`片語·對象=`、`片語·主題=`、`片語·主語=`、`片語·目的=`)

每個有字面的欄一格;推得的目的(標「(推得)」)沒有片語,是對的。格裡以 ` | ` 分**段**,每段:`段 字面 中心詞 X(類) [指示詞] [玩家 P] [區域 Z] [修飾語 …] [數量 …]`。

- **切段**:依並列詞 と/か/や/及び/または 與「・」切。と同じ/と異なる 的 と 不切。前一格是屬性/非卡/其他類的詞(攻撃力か守備力が2100のモンスター、ドラゴン族か植物族のチューナー、融合・S・Xモンスター、光・闇属性、レベル4・5)是並列的**修飾語**,不切;夾在兩個區域/玩家詞之間的(自分か相手の、手札かフィールドの)也不切。魔法・罠カード、攻撃力・守備力、召喚・特殊召喚 切成兩段。
- **中心詞**:段去掉尾端的括號註記、助詞、數量尾後的**最後一個名詞格**(分詞的一格;特殊召喚、X素材、カード名 合記一格)。卡名「…」整段是中心詞。そのモンスター 的中心詞是 モンスター;魔法(カード) 是 魔法カード。只剩數量的段(その1枚、2体以上)中心詞就是那段數量。純數值的目的(０、１０００)中心詞是那個數。
- **中心詞類**(封閉表):卡——モンスター/カード/トークン/チューナー/素材/魔法/罠 與這些尾字的複合詞(罠カード、Sモンスター、X素材)、卡名「…」、區域詞(手札/デッキ/墓地/フィールド/自分フィールド/EXデッキ/モンスターゾーン…是「卡」,因為受事者本身是一疊卡);屬性——攻撃力/守備力/レベル/ランク/Pスケール/属性/種族/カード名/表示形式/コントロール/位置,與跟主人走的事件類 効果/発動/攻撃/召喚/特殊召喚/〜召喚;非卡——ダメージ/戦闘ダメージ/LP/カウンター/〈X〉カウンター/数/コイントス/戦闘/ゾーン、純數值;指示詞——それ/それら/いずれか/内/対象/残り/両方/どちらか、只剩數量的段;**其他**——表外。**落 其他 不是錯**(規格定表外落其他、進報告):相手/自分/お互い/プレイヤー/コントローラー/持ち主(玩家當受事者)、一番下/一番上/上/下(牌組位置)、裏側守備表示/守備表示 等表示形式值當目的、条件/先/数値/バトルフェイズ/サイコロ/ダメージ計算 都照規格落 其他。**只有「表內該中的卻落其他」「落錯類」「中心詞取錯格」才是錯。**
- **修飾語**(`修飾語 字面(類)、字面(類)…`):中心詞之前的各格依 の 與讀點切段,每段再依 ・/／/並列詞拆成並列項逐項定類。類:種族(〜族,含省略寫法 水(族))、屬性(光属性、光・闇属性 → 光(屬性)、闇属性(屬性))、字段(引號段直接接名詞:「DD」モンスター、「HERO」融合モンスター;**接 の 的引號段是卡名,落 其他**:「青眼の白龍」の攻撃力)、卡片子類型(融合/S/X/P/L/リンク/儀式、通常(モンスター)、効果/通常/リバース/デュアル/スピリット/ユニオン/トゥーン/チューナー/ペンデュラム 直接接名詞;**効果モンスター、装備魔法カード 這類分詞一格的複合詞是中心詞本身,不另出子類型修飾語——「闇属性・ドラゴン族の効果モンスター」只有兩個修飾語,是對的**)、玩家(自分/相手/お互い/持ち主/その自分/その相手;自身の 不算)、區域(墓地、自分フィールド、除外状態、自分(フィールド))、表示形式(表側表示/裏側守備表示/その表側表示…)、數值(`字面(數值:欄位 比較 數字)`:レベル4以下(數值:レベル 以下 4)、攻撃力1000／守備力1000 兩個、攻撃力か守備力が2100 一個共用一數、レベル4・5 一個列兩數、裸數接非卡 500ダメージ 欄位空數字 500);**其他**——定語子句(この効果で特殊召喚した)、以外/他の/元々の/残り、このカード/そのモンスター(所有格)、同じ種族、全ての/任意の(數量的前綴寫法,目前落 其他,不是錯)、罠・モンスター/魔法(カード)・罠カード(卡種並列,表沒有卡種,落 其他 不是錯)、カウンターが3つ以上(帶量詞的數不是數值)。**錯**:表內該中的落其他、類判錯、拆項拆錯、一段的修飾語整段漏掉(中心詞之前有字卻沒有任何修飾語)。
- **數量**(`數量 字面(類 數字)`、引用量 `(引用量)`、取自子句尾綴 `(取自子句)`):段尾的 數字+量詞(枚/体/つ/種類/個/組/回)→ 定數;+まで → 上限;N以上 → 下限(N以下 → 上限);全て → 全部;任意の数/任意の枚数/好きな数 → 任意;２～５体 只記字面類空;ずつ 併進字面(1体ずつ 定數 1)。**取自子句**:受事者字面沒數量、子句裡緊接受事者的 を+數量(手札を１枚捨てる、カードを全て破壊する、モンスターを任意の数、相手の手札をランダムに１枚)取進對象最後一段並標(取自子句);引用量(…の数まで/同じ数だけ/…の数の分だけ)只記字面、類空。**不是數量**:それぞれ、ターン終了時まで、５つ上がる、攻撃力を５００、修飾語裡的數值(カウンターが３つ以上の)、ヵ所/度(１ヵ所、１度)、合計３枚 的 合計(目前不放寬,42 框,不是錯)。**錯**:段尾有數量卻沒記、記錯類/數字、不是數量的被記了、取自子句接到別的子句的數。
- **玩家與區域**(`玩家 P`、`區域 Z`):段自己帶的;區域七值 手牌/牌組/額外牌組/墓地/除外/場上/靈擺區(批次檔用這些中文值),玩家 自分/相手/お互い/相對/無。墓地のモンスター → 玩家 無、區域 墓地;自分の墓地の → 自分、墓地;相手フィールド → 相手、場上;定語子句裡的區域(墓地のモンスターを対象とする効果)不算。來源/所在欄切走的區域片語裡仍留一份,是對的(對象=このカード 來源=手札・フィールド 時片語段是 手札・フィールドのこのカード、區域 手牌・場上)。段首是玩家詞、段裡沒有述語或 の 以外助詞時玩家是段首那個(相手モンスター → 玩家 相手;自分のLP → 自分)。
- **指示詞**:段以 その/それ/それら/対象の/この効果の対象 起頭時標;この 不算(このカード 不標)。

### 2. 結構化區域(`結構化來源=`、`結構化目的=`、`結構化所在=(玩家,區域)・…`)

來源/目的/所在三欄各自的字面過區域辨識成 (玩家,區域) 清單,依字面順序去重;推得的欄照字面算、玩家一律 無;認不出的(相手、見せたモンスター、０、以下の効果、その中)不放。**轉欄**(只在所在):非移動類動作(破壊/選ぶ/対象とする/めくる/確認…——不是 加える/ドロー/送る/捨てる/リリース/除外/戻す/置く/セット/装備/移動/各召喚)所在字面空、來源字面算得出區域 → 結構化所在抄來源的、尾綴 `(取自來源)`(手札・墓地から選ぶ 的 選ぶ:結構化所在=(無,手牌)・(無,墓地)(取自來源));で 接區域(Pゾーンで、フィールドで)→ 結構化所在取它、尾綴 `(取自で)`,那個 で 不記方式。**移動類不轉、所在已有字面不轉、來源字面不是區域(以下の効果から)不轉也不標**——這些都是對的。字面所在欄維持空是規格,不是錯。**錯**:區域值或玩家錯、該轉沒轉(非移動類、所在空、來源是區域)、移動類被轉、轉錯欄。

### 3. 施事者(`施事者=值(來源)`,預設補的尾綴 `(推得)`)

值 自分/相手/お互い/此卡/其他卡;來源 主題/主語/事件主語/によって/預設。規則依序:(1)框架自己帶對象(他動,或態空但有對象)時,主語(が)或主題(は;延續來的也算)是玩家 → 該玩家;是 このカード(含 墓地のこのカード、S召喚したこのカード)→ 此卡;是其他卡片片語 → 其他卡。受身、自動、沒對象的 このカード/卡片片語是受事者,不是施事者。(2)受身框架(或自動/態空且沒對象的)讀子句裡的 によって:相手の効果によって → 相手;このカードの効果によって → 此卡;「X」の効果によって → 其他卡;数によって/結果によって/目によって 不記。定語裡的 によって(融合モンスターカードによって決められた融合素材モンスター)不讀。(3)事件主語:全語料 0 框,不會看到。(4)代價位與效果位、他動、帶對象、以上都沒有 → 自分(預設)(推得)。**預設(推得)的不在本輪範圍,不用檢查**(是一條規則、靠回歸例子)。條件位、受身、自動、沒對象的留空是對的;受事者位有字面但規則認不出是誰的(このカードのコントローラー、ターンプレイヤー)留空也是規則。「この効果は」「このカードの効果は」註記主題不是施事者。使用者故事:「相手がモンスターを特殊召喚した時」條件框架的施事者 相手;「そのモンスターを破壊する」是 自分(預設)不是 相手;「このカードは破壊されない」沒有施事者;「相手の効果によって破壊された」→ 相手。**錯**(只看非推得的):值錯(讀錯主題/主語、受身的受事者被記成施事者、によって 讀到定語裡)、該有沒有(主題/主語明明是玩家或此卡、框架他動帶對象,卻空著或落成預設)。

### 4. 方式(`方式=字面 類`,表示形式另帶 `=值`,其他類尾綴 `(其他)`)

述語前、同一子句內離述語最近的 で 片語,字面只到 で(では/でも/でのみ/でしか 的後綴不帶,開頭的數量/全て/それぞれ/時間語不帶)。類:手段:效果(効果/この効果/その効果/…の効果 で)、手段:戰鬥(戦闘/その戦闘/攻撃/…の攻撃 で)、手段:方法(方法/この方法 で)、表示形式(守備表示/表側表示/裏側守備表示/攻撃表示/表側/裏側/裏側表示/表側攻撃表示/表側守備表示 整段相等;または/か 並列整段帶值)、視同(扱いで)、順序(好きな順番で/元の順番で)、**其他**(只記字面:リリースなしで、ままで、X以外で、同じ縦列で,**與 戦闘・効果で/戦闘または相手の効果で 這類戰鬥與效果的並列——封閉表沒有合值,落 其他 是規格決定,不是錯**)。**不收的 で**(沒有方式格是對的):定語子句裡的(この効果で特殊召喚したモンスター、その戦闘で発生する戦闘ダメージ)、定語裡的數值/封閉值並列(攻撃力2400以上で守備力1000の、戦士族・ドラゴン族で光属性の、同じ属性で…の)、繫詞(〜である、〜ではない、〜でなければならない、LPが2000以下で、)、で 接區域(進結構化所在 取自で)。一框至多一個,同子句兩個 で 取離述語最近的。**錯**:該收沒收(述語前同子句有 で 片語、不屬上述不收的)、不該收(定語裡的被收)、類錯、字面多了或少了(多帶 は、少了 の効果 前的主人)、表示形式值錯。

### 5. 否定形(`否定形=值`,只在極性=否定的框架上)

態 受身 → 受身(戦闘では破壊されない);否則看述語自己的否定形:にならない/受けない 系 → 不成不受(効果の対象にならない、効果を受けない);できない/行えない 系 → 不可能(攻撃できない、行えない);其餘 ず/ない/なく → 一般(墓地へ送らず除外する)。極性 肯定/可能 的框架不帶,是對的;〜しなければならない 是義務、不是否定,不帶;「〜でなければならない」上游判成否定、落 一般(13 框,已知,不用報)。**錯**:值與述語形式不符、否定框架沒有此欄、非否定框架帶了。

### 6. 回指回填(結構化來源/所在尾綴 `(回指)`;回指欄的 `目標移動類` 旗標)

條件:受事者是指示詞(その/それ/対象の…)、回指欄有目標且目標有區域、本框自己沒有來源(移動類)/所在(非移動類)字面(推得的不算有;回填來的字面與 取自來源 算有)、找法不是 事件、目標非移動類(対象とする/選ぶ/選択/破壊… 的所在;目標是 特殊召喚/加える/戻す/墓地へ送る 這類移動類,或回指鏈上經過移動類框架 → `目標移動類`、不填)。動作:目標的區域寫進本框的結構化來源(本框移動類:そのモンスターを特殊召喚する → 結構化來源=(無,墓地)(回指))或結構化所在(非移動類:そのモンスターを破壊する → 結構化所在=(相手,場上)(回指)),字面欄不動;蓋過推得的同欄結構化值。跨句號成立。目標區域認不出(自分及び相手の墓地)不填。**錯**:填錯欄、填的區域不是目標的區域、目標移動類卻填了、該填(條件全符合)卻沒填、本框有自己的字面卻被蓋。回指本身指錯(目標選錯)是回指線的事,只在它造成回填區域錯時以 回填錯 報並說明。

## 錯誤類型(type 欄只能填這些字)

本輪新增(請優先檢查):
- `中心詞錯/修飾語類錯`:切段錯、中心詞取錯格、中心詞類落錯(含表內該中的落其他)、修飾語類錯/漏/拆錯、玩家/區域/指示詞錯、結構化區域值或玩家錯、轉欄該轉沒轉/不該轉卻轉。
- `數量錯`:段尾數量漏記/錯類/錯數、不是數量的被記、取自子句接錯。
- `施事者錯`:非推得的施事者值錯或該有沒有(見第 3 節)。
- `方式錯`:該收沒收、不該收、類錯、字面範圍錯、表示形式值錯。
- `否定形錯`:值與述語形式不符、該有沒有、不該有卻有。
- `回填錯`:回指回填填錯欄/錯區域、目標移動類卻填、該填沒填、蓋過自己的字面。

既有類型(新格以外看到**明確**的錯也可回報,但不是重點):`漏抽動作`、`論元抽錯`、`位置判錯`、`極性判錯`、`多抽(不是動作)`。

## 回報格式

寫到批次檔同目錄的 `findings-<k>.json`(UTF-8,k 與批次檔相同):一個 JSON 陣列,每筆

```json
{"card": 12345678, "index": "①", "frame": 3, "type": "方式錯", "got": "方式=戦闘で 手段:戰鬥", "expected": "不記方式(定語子句裡的 で)", "reason": "一句話,引原文片段說明哪裡錯、應該是什麼"}
```

- `card` 卡號(整數);`index` 用「### 句」後的標籤(①/②/效果外文本 0/靈擺 ①…);`frame` 是「框架 n」的 n(整數),整句層級的問題填 null。
- `got` 是批次檔現在那一格的寫法(照抄),`expected` 是應該的寫法;沒有就寫空字串。
- 沒有錯就寫 `[]`。一個框架有多個問題各寫一筆。
- reason 用繁體中文,引原文照抄日文。
- 只回報有把握的錯;判準寫在上面,和判準不同的地方照判準,不要改判準。上面標明「不是錯」「是對的」的寫法不要報。拿不準的在 reason 開頭寫「(待確認)」。
- 不要改動批次檔或其他檔案;不要寫其他檔。

完成後用一兩句回覆:看了幾張卡、各型幾筆、最常見的錯是什麼。
