# 03: 句尾標籤

**What to build:** 搜尋結果的命中句,句尾只標這次查詢命中的述詞,讓使用者看得出是哪個條件中的;沒有條件時句尾沒有標籤。現行「每句列出全部葉」在這張拿掉。見規格「句尾標籤」段。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 命中句句尾列命中的述詞,每個述詞一個,文字是短句;述詞序號 → 短句的對照由條件模型依同一份查詢組出
- [ ] 位置前綴取命中框的位置:效果不寫,其餘寫 `代價:`、`條件:`;框的位置由引擎提供查詢函式,`render.js` 不讀框元組
- [ ] 框所在句不是這一句時,標籤加 `↑領起句` 與說明提示
- [ ] `pred` mark 不出徽章文字;沒有條件、或命中句沒有包含述詞時沒有句尾標籤
- [ ] `View.cardHtml` 接縫的例子涵蓋以上各條;舊的句尾標籤測試改寫或拿掉
- [ ] 真瀏覽器桌面走一次:一般命中、代價位、條件位、領起句繼承各看一例,console 無錯
- [ ] node 測試全過
