# Spec: 效果文分詞(Effect Text Tokenization)——動作類別重新推導的基底

Status: resolved(2026-10-01 站主確認共識;不另寫 ADR;拆除與分詞兩線並行)
Date: 2026-10-01

## Problem Statement

效果 Tag 線(21 動作類別、45,700 個規則 tag、六期收官)在三個層面都沒有兌現價值,站主裁定整體不信任:

1. **搜尋端**:用動作類別鈕實際查卡的結果與預期不符——規則照規格貼對了,但規格定義的命中與使用者直覺脫節。
2. **分析端**:21 類+槽位丟失太多句子結構(誰對誰、做什麼、順序),承載不了「這張卡在做什麼」的語意。
3. **品質信任**:遮蔽測試逐規則錯標 0、recall 近 100%,但量的是「規則有沒有照規格貼」,量不到「貼出來的東西對使用者有沒有用」——指標全綠與實際沒用並存,信任整體崩塌。

前導研究的句向量路線(e5-large 分群起草分類表)同樣被檢討:**句向量粒度太粗**(整句壓一個向量,丟失結構),且**向量近似路線本身可能就不適合受控語言**——效果文詞彙封閉、句型公式化,該用符號式方法精確處理。

## Solution(設計樹定案)

### 終點

以**效果文分詞**(日文側單詞編號)為基底,**重新推導動作類別**——分類表(2026-09-20 凍結)未來可能改版,需新裁定票解凍。

### 新線:效果文分詞

- **語言側**:日文(官方正本、句型最規範、與既有規則層/分群同基準;效果句日文文本已逐句存於 `data/tag_cards.json` 的 `text_ja`)。
- **範圍**:試點先行——三級分類的**新格式新卡**層(7,818 張/8,156 段,文字最規範雜訊最少);終局擴到新式全量(與效果 Tag 第一期同一把尺)。
- **分詞法**:領域詞典+最長匹配(純 Python 零依賴、結果決定性)。**分詞詞典**是來源檔:種子從既有 regex 字彙(`tag_rules.py`)與卡文詞彙表(`docs/text_glossary.md`)萃取,OOV 段統計出票補詞迭代(與長尾出票收票流程同構),切分慣例由站主裁定。
- **正規化(試點就定基本款)**:「卡名」→NAME token、數字→NUM token(帶原值屬性)、助詞(に/で/を/は等)獨立成 token。更細的正規化(區域變數化等)看報表再裁定。
- **產物**:詞典(來源檔)+每句詞 ID 序列(建置產物,卡文+詞典機械重算)。試點期產物都放 `.scratch/effect-tokenize/`,路線成熟後詞典升格 `data/` 來源檔。

### 第一步:統計報表(推導方法先不定)

三件套+互動檢視頁:

1. **詞頻表**
2. **OOV 率與高頻 OOV 段**(補詞迭代的輸入)
3. **正規化後句型模板分佈**(top-N+長尾形狀)

markdown 報表入 `.scratch/effect-tokenize/`,另發可翻閱的檢視 artifact(比照分群檢視頁,逐模板看例句)。**推導方法(模板聚合/特徵聚類/其他)看過報表數據再裁定**。

### 驗收標準:量化參考+質性為準

OOV 率、模板覆蓋率當儀表板參考(詞典收斂進度可追蹤),但收不收由站主翻檢視頁裁定——「模板能不能讀出這張卡在做什麼」由人判。明確避免舊線的教訓:指標全綠不等於有用,量化門檻不作為通過條件。

### 舊線處置:分類表兩維全拆、本體保留

- **搜尋介面立即拆除**:動作維(21 類鈕+分組、區域移動起點/終點、位置/對象方鈕——含 2026-10-01 tag-pos-side-search 剛上線的功能)+**觸發時機軸**,連同對應命中 badge 全部下架。
- **保留的軸**:效果類型(跨類型魔陷效果)、必發/選發(官方裁定值,信任度不受此次指控波及;必發/選發「怪獸側」組合依附效果類型軸,不受影響)。
- **索引資料也拆**:動作 tag 與觸發時機不寫進 `web/data.js`(索引瘦身、界面與資料一致);回頭時重建索引即可。
- **效果標記表本體(`data/tag_cards.json`)照留**:45,700 個 tag、遮蔽測試資產、tag seal 不刪除;舊線停工(不再投入新期數與修補),規則直貼照 ADR-0013 重跑時仍重算,只是產物不再出到前端。
- 拆除落地時同步改寫 CONTEXT.md 受影響詞條(效果標記表「網站進階查詢的核心依據」定位、效果 Tag、分類表、動作類別、槽位、觸發時機)與 ADR-0008 按鈕生成相關敘述。

## 裁定紀錄(訪談定案,2026-10-01)

| 決策點 | 定案 |
|---|---|
| 痛點 | 搜尋端沒用+分析端不足+品質不信,三層全中 |
| 向量檢討 | 句向量粒度太粗+向量路線本身可能錯,轉符號式 |
| 終點 | 重新推導動作類別(分類表可能改版) |
| 範圍 | 新格式新卡試點先行,終局新式全量 |
| 語言側 | 日文 |
| 舊線 | 分類表兩維搜尋鈕立即拆、索引資料拆、本體留 |
| 詞典 | 種子+OOV 迭代,慣例站主裁定 |
| 正規化 | 試點就定 NAME/NUM/助詞三款 |
| 推導方法 | 先出統計報表再定 |
| 報表 | 三件套+互動檢視頁 |
| 驗收 | 量化參考+質性為準 |
| 命名 | 效果文分詞;目錄 `.scratch/effect-tokenize/` |

## 待開票(建議切法)

1. **拆除票**:搜尋介面分類表兩維下架+索引剔除(建置期不產出、VOCAB 不生成對應鈕,ADR-0008 機制不變)+CONTEXT.md 受影響詞條改寫。
2. **詞典種子票**:從 regex 字彙與詞彙表萃取種子詞典,定切分慣例裁定點清單。
3. **分詞+報表票**:新格式新卡全量分詞、三件套報表+檢視 artifact、OOV 出票。
4. (報表裁定後)推導方法票。
