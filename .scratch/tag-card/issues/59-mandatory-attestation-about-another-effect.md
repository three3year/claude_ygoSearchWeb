# 59 — 必發明示的歸屬:標頭底下講「別的效果」的那一行被照字面吃了

**What to build:** [[必發/選發]]官方明示階梯的一道排除:`【…について】` 標頭底下、句子在解說**被複製/被參照的另一個效果**怎麼運作時,那一行的「必ず発動する効果」不指向本[[效果句]],不得產生必發明示。

**Blocked by:** 38 — 只判類型 kind-02(問題在那一票撞牆)

**Status:** ready-for-agent

## 為什麼

`docs/effect_kind_guide.md` §6 從票19 起就記著這件事,但只記在**判定者**那一側(「判到『這一行在解說別的卡/別的效果怎麼運作』時,不採用」)。抽取器的必發階梯沒有這道排除,照字面把它收成本效果句的必發明示。

救世星龍(7841112)的 `main/3`:

```
【『この効果で無効にしたモンスターに記された効果を、このターンこのカードの効果として１度だけ発動できる』について】
■…そのモンスターのテキストに記載されている効果を、このカードの効果として発動できます。
■これによって発動する効果の、効果の種類（起動効果・誘発効果・誘発即時効果）、発動の条件、…については、元となった効果と同じです。
■無効にしたモンスターのテキストに、"条件を満たした際に必ず発動する効果"が記されている場合でも、
  このカードがその効果を発動するかどうかは任意です。
```

第三行的「必ず発動する効果」講的是**被複製的那個效果**,而且整句的結論恰好相反(「このカードがその効果を発動するかどうかは任意です」)。抽取器仍把 `main/3` 標成有必發明示。

**後果是這一行判不進去**。它自己不發動(句尾的「発動できる」也是被複製效果的),走 §5.5 六條分界都不成立、回 §1 步驟 4 會落在永續效果——但 `tagcard._apply_optional` 對「有必發明示、類型卻不發動」的行會記進 `mandatory_other_kind`,而建置報告把它標成**必須為 0**。於是:

- 填永續效果(或任何不發動的類型)→ 報告的不變量從 0 變成 1;
- 留空 → 不變量保住,但這一行每一票都會再回到批次裡,再撞一次牆。

票38 選了留空(§9),並開這張票。這不是「判不出來」,是抽取器的歸屬有洞。

順帶:同一行也讓必發/選發的獨立驗證固定多一筆不一致(`規則=選發、官方=必發`,票31 起記在 §4 的次元壺旁邊)。修掉這道歸屬,那一筆也會一起消失。
