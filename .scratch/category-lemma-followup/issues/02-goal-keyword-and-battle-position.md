# 02 — 目的關鍵詞機制與表示形式六葉

**What to build:** 類別樹的葉可以宣告新條件「目的關鍵詞」(字面子字串清單,只比框架的目的欄),第一個真用途是表示形式:站主在類別總覽點 表示形式 › にする→裏側守備表示 就看到所有把怪獸變成裏側守備表示的效果,不必再翻 にする 預設葉的 377 框;蓋伏的效果同時也在 →守備表示(「變成任何守備表示」)。來源:spec 實作決策「規則表語意」目的關鍵詞各條、「類別樹來源檔」にする 節點表示形式六葉;CONTEXT.md「動作類別」詞條。

- [x] 匹配語意:目的關鍵詞只比目的欄(對象/主語/主題 有該字面也不算);子字串命中任一即命中;目的關鍵詞葉與關鍵詞葉同樣命中全收、依樹序去重、任一命中就不取預設葉;「關鍵詞葉命中時帶所在條件的葉也收」照舊適用;一葉同時宣告關鍵詞與目的關鍵詞時兩者都要命中。
- [x] 葉名:目的關鍵詞以「→」接字面、多個以 / 連寫(にする→裏側守備表示)。
- [x] 建置檢查:目的關鍵詞要是非空字串清單;一葉不能同時宣告目的(區域)與目的關鍵詞;目的區域葉與目的關鍵詞葉撞名由葉名唯一檢查擋下;覆蓋檢查把目的關鍵詞葉當關鍵詞類葉(不帶任何關鍵詞類條件的葉不能寫在它之前,關鍵詞類葉之間不互蓋)。
- [x] 測試小樹(機制,經 classify 的 tree 參數):只比目的欄;多目的關鍵詞多葉;與關鍵詞葉同時命中都收;命中後不取預設葉;與帶所在條件的葉兩軸並收;葉名組法;上述建置錯誤各一條。
- [x] 真樹:にする 節點在預設葉之前開 →裏側守備表示、→表側守備表示、→表側攻撃表示、→守備表示、→攻撃表示、→裏側表示,各宣告大類 表示形式;樹來源檔「說明」補目的關鍵詞語意。
