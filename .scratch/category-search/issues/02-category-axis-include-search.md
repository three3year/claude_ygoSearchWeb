# 02: 類別軸與包含搜尋

**What to build:** 牌手在側欄展開「動作類別」樹、點選節點,就能找出做那些動作的卡:選中的每個節點都要命中(AND),各自可在不同句,而每一句命中句都符合使用者選的效果類型、必發/選發與效果文;命中的葉在句尾被強調;條件寫進網址。來源:spec「查詢引擎(接縫 3)」「網址 hash」「側欄(query)」「呈現」;GLOSSARY「軸」「動作類別」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 側欄在效果類型、必發/選發旁多一個「動作類別」軸,由 VOCAB 的類別樹生成:大類 › (中類) › 詞元 › 葉,可展開/收合,每個節點三態鈕(未選 → 包含 → 排除;排除的語意在票 03);詞元的預設葉以同名、標「預設葉」列在子節點最後;不標卡數。
- [ ] 軸預設摺疊;標題列寫「涵蓋 N / 全部 張」與已選數;摺疊時已選條件保留生效。
- [ ] 包含語意:節點展開成葉集合(上層=底下所有葉,同詞元在不同大類下各自獨立);每個包含節點都要有一句可用的句(符合句層條件)的效果位葉與它交集;不同節點可由不同句滿足;沒有類別紀錄的卡一律不中;與其他軸 AND。
- [ ] 命中句=符合句層條件且帶任一包含節點的葉的句,照現有方式高亮;句尾命中的葉字面可辨(強調)。
- [ ] 網址:包含/排除節點以節點路徑寫進 hash,往返相等;樹裡找不到的路徑安靜忽略。
- [ ] 接縫 3 測試(合成資料):單葉、上層節點=任一葉、同詞元不同大類獨立、兩節點 AND 可不同句、AND 時每句都符合效果類型/必發選發/效果文、舊卡不中、命中句索引、與其他軸 AND;hash 往返含未知路徑。呈現縫測試:命中葉可辨。
- [ ] script/ Python 與 JS 測試通過;本機開網站搜一組(例:特殊召喚←墓地 + 誘發效果)確認樹與結果。
