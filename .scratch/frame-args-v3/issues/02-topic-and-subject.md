# 02 — 主題與主語(子句內)

**What to build:** 站主翻「相手フィールドの全ての表側表示モンスターは、守備力が０になり」時,になる 那列寫著 主題=相手フィールドの全ての表側表示モンスター、主語=守備力;「自分が受ける効果ダメージは０になる」的主題是 自分が受ける効果ダメージ;「このカードは戦闘では破壊されない」的 このカード 在主題、對象空著。動作框架多三個可選欄:主題(は 片語)、主語(が 片語)、被動(只在被動時帶)。同一子句有多個時取離述語最近的;後綴型(には/では/とは)照既有規則併入前一格;定語裡的 が(カード名が記されたモンスター)屬名詞片語,不出主語;「この効果は」這類速度/時機註記的主題沿用既有判斷,不當成動作的主題。本票只收子句內寫出來的,延續是票 03。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent
