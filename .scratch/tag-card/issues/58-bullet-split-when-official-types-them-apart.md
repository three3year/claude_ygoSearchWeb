# 58 — 官方把 `●` 判成不同類型時,拆句授權要開火

**What to build:** `_bullet_authorised` 第三種依據:[[補足情報]]對同一段的 `●` 給出**兩種以上**的[[效果類型]]時,把那些 `●` 拆成獨立[[效果句]]。

**Blocked by:** 37 — 只判類型 kind-01(問題在那一票浮出來)

**Status:** done

## 為什麼

票37 判到電子變形龍(3657444)①時撞牆:領起句是列舉型(`①：以下の効果から１つを選択して発動できる。`),管線因此不拆 `●`(官方沒開 `【…●について】` 標頭,行內也沒有 `『●…』` 原文引用),但官方用序數逐項給了類型——

```
■この効果を発動する際に『●』を１つ選択し、その『●』の効果として発動します。
■１つ目の『●』はフィールドで発動できる誘発効果です。…
■２つ目の『●』はフィールドで発動できる起動効果です。…
■３つ目の『●』はフィールドで発動できる起動効果です。…
```

一條效果句只有一個 `kind` 欄位,所以不拆就一定有一半是錯的:填啟動效果 → 這張卡在「誘發效果」查詢裡消失(spec 開頭要消滅的失效模式);填誘發效果 → 兩個啟動效果消失;留空 → 兩種查詢都找不到它,而且那一行每一票都會再進批次。

**手改資料補不出來**:標記表的效果句集合是管線算出來的,手加一行 `①-●1` 會對不到任何管線產出的行,被 `_report_orphans` 丟掉。`manual` 改得了值、改不了結構。所以只有管線這一條路。
