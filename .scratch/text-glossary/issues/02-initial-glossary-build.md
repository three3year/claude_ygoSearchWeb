# 02 — 初始建表:高頻萃取+散落裁示收編

**What to build:** 站主拿到一份約百餘條的審查檔(仿 text-rewrite 三欄體例,
逐條含日文/建議譯法/禁譯候選/計數/依據),逐行審查、退回迭代到放行後,
條目填入卡文詞彙表——讓 AI 翻譯與人工查閱從此有集中依據。

**Blocked by:** None — can start immediately(與 01 平行;不依賴驗證腳本)。

**Status:** ready-for-agent

- [ ] 語料=三級分類「新格式新卡」層(8,156 段)的中日句對照;高頻先行,門檻建議 ≥20 張(可依實際分布調整),目標約百餘條一次審得完
- [ ] 計數佐證母體=含①新式段(沿審查檔慣例)
- [ ] 收編歷批審查檔「改寫依據」節的散落裁示(「，隨後」267:0、「再次召喚」32:0、「1回合可以使用最多2次」23、額外牌組現代化等)
- [ ] 詞彙表既有六條(原 §3.19)補齊禁譯欄
- [ ] 譯詞與句式分節入表,句式用 `〈n〉`/`〜` 佔位符體例
- [ ] 站主逐行審查放行後才入表;審查檔留在 feature 目錄供回溯
