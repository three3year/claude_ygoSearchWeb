# 02: 此卡字面規則補齊

**What to build:** 「此卡」模式除了以 このカード 收尾的受事者,也涵蓋此卡的屬性、並列含此卡、身分改寫與效果跟著主人。字面上提到此卡、但動到的不是此卡本身的寫法則排除。做完時「アップ:攻撃力+此卡」查得到自我強化的卡,「取り除く:X素材+此卡」不會變成所有超量怪獸。

來源:spec「動作對象判定 › 此卡」「受事者是效果、發動、攻擊」;GLOSSARY「動作對象」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 此卡的屬性算此卡:このカードの攻撃力/守備力/レベル/Pスケール/効果 等。
- [ ] 並列含此卡算此卡:このカードと〜、〜とこのカード、このカードを含む〜。
- [ ] このカードは…として扱う 算此卡。
- [ ] 受事者是效果、發動、攻擊時跟著主人走:主人是此卡(このカードの効果)就算此卡。
- [ ] 不算此卡:このカード以外、このカードの装備モンスター、このカードのX素材、このカード名の。
- [ ] 建置報告的此卡框架數與卡數隨之更新,並列出各條規則各命中多少框架。
- [ ] 匯出接縫測試(日文例句):上面每條各至少一句,斷言該句的此卡葉。
- [ ] effect-tokenize 全套與 script/ 測試通過;本機搜「アップ:攻撃力+此卡」「戻す→手札+此卡」,記下張數與幾個抽樣觀察。
