# 16 — 必發/選發軸長出怪獸側組合鈕

**What to build:** 側欄的[[必發/選發]]軸從兩顆鈕變**同一軸兩組六顆**:「全部」組是既有的
必發/選發二值(語意原樣,含魔陷側承載句);「怪獸側」組是四顆**效果類型×必發/選發的
組合條件**——誘發即時(必發)/誘發即時(選發)/誘發(必發)/誘發(選發)。點「誘發(必發)」
一顆鈕,命中的是**同一[[效果句]]是誘發效果(1速)且必發**的卡,那一句被標亮、badge 照舊
寫該行自己的值。「怪獸的必發效果」從跨兩軸三顆鈕變成一顆(spec:`spec-optional-combo.md`)。

**Blocked by:** None — can start immediately(票06、票15 已 resolved)。

**Status:** resolved
