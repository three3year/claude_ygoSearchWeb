# 05: 卡名包含先換成卡片編號(中日英名、別名、`%`)

Status: ready-for-agent

**What to build:** 動作搜尋給條件的卡名包含,Python 的玩家查詢與網站都先把打的字換成一組卡片編號,被動作的卡在這組裡就命中(滿足條件的卡與這條線的候選卡有交集)。一張卡的名字是中文名、日文名、英文名、別名(中文卡文「※ 別名」,與前端索引同一個抽法)。比法:打的字先去頭尾空白,打的字與名字都做網站現在的折疊(全形英數與全形空白當半形、小寫),以 `%` 切段、去掉空段,各段依序出現在名字裡就算;沒有非空的段時等於沒給。效果:中文「黑魔導」Python 0 → 1,259 張,與網站相同。

- 卡文裡的「カード名に「X」を含む」(卡片結構條件式的卡名包含原子,判候選卡用)照舊只比日文、含位置條件;只有查詢側換。
- 介面不變(沒有語言切換鈕);網站多的是 `%`。
- 這張票不含「〜として扱う」當作的卡名(06)。
