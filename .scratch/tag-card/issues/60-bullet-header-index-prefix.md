## 為什麼

守星騎士 托勒密(18326736)① 的卡文是一個列舉型領起句 + 兩個 `●`:

```
①：このカードのX素材を以下の数だけ取り除き、その効果を発動できる。
●３つ：…X召喚扱いでEXデッキから特殊召喚する。
●７つ：自分メインフェイズに発動できる。次の相手ターンをスキップする。
```

官方逐項給了**兩種不同的類型**:

```
【①の『●３つ』の効果について】
■モンスターゾーンで発動できる誘発即時効果です。
【①の『●７つ』の効果について】
■モンスターゾーンで発動できる起動効果です。
```

兩條授權路徑都沒開火:

- `_BULLET_HEADER_RE` 只認 `〈Nつ目の〉(『●…』|●)〔のな〕?(効果|処理)?について`,標頭前面多的 `①の` 讓它整條不匹配(`_bullet_spec` 回 None)。
- `bullets_typed_apart`(票58)要求**主語是 `●` 的行**,而這裡的類型詞寫在標頭底下的行裡,行內看不到 `●`。

後果與票58 一模一樣:抽取器讀出兩個類型 → 拒判(進報告的「同一效果句被官方寫成兩種類型」),管線不拆 → 一條效果句只有一個 `kind` 欄位,填哪一個都會讓另一個從查詢層消失。票39 照 `docs/effect_kind_guide.md` §9 末段留空。
