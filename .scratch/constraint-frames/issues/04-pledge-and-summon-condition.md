# 04 — 誓約與召喚條件

**What to build:** 站主在拆解頁看到:誓約「このカードの効果を発動するターン、自分は機械族モンスターしか特殊召喚できない」(含寫在發動句括弧裡的)→ 限制·誓約(被約束動作=特殊召喚、形式=只能、範圍=機械族モンスター);「このカードは通常召喚できない」「…を除外した場合のみ特殊召喚できる」「融合召喚でのみＥＸデッキから特殊召喚できる」→ 限制·召喚條件,召喚手續(除外 墓地の「SPYRAL」カード３枚)與方式記在框架內;「「終焉龍 カオス・エンペラー」は１ターンに１度、…特殊召喚できる」與「「FA－ホープ・レイ・ランサー」は１ターンに１度、…X召喚する事もできる」出召喚條件與次數兩個框架。這些句子原本的特殊召喚、除外等動作框架不再出現。

**Blocked by:** 01、02

**Status:** resolved

- [x] 誓約框架記被約束的動作、形式(只能/不能)、範圍;括弧內誓約也認得出
- [x] 召喚條件框架記形式(不能通常召喚/不能特殊召喚/只能以某方式特殊召喚)、方式、手續(動作與對象)
- [x] 召喚條件帶次數時出兩個框架,次數框架的對象是那個召喚方式
