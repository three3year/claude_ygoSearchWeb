### 怎麼編

每葉的條件逐欄對到述詞欄位:來源/目的/所在(+玩家)→ 該欄任一 (玩家, 區域) 段相等(葉沒宣告玩家就不看玩家;推得的欄玩家 null、相對 是玩家值域的一值,照現行都不中宣告玩家的葉);關鍵詞 → 受事者中心詞(對象→主語→主題第一個有值的欄,現行 head_nouns 切、した/する/され 尾不算)任一段含;目的關鍵詞 → 目的欄中心詞任一段含;預設葉 {} 取消,詞元節點就是「詞元=X(極性類=Y)」。**233 葉全部編得出來**,沒有一葉缺欄位到編不出;但有兩處「欄位不夠」要規格 1 補(見下)。

### 三張清單(摘要;全文見 compile.md)

**一、可機械編譯且張數相同:105 葉。** 全部關鍵詞葉、目的關鍵詞葉、來源葉、來源+目的葉,與帶玩家的所在葉大多在此(特殊召喚←墓地、加える:デッキ→手札、破壊:モンスター、にする→守備表示、破壊@相手フィールド…)。

**二、可編譯但張數不同:31 葉。** 原因三種(卡·葉計):
- **不再互斥**(較具體的同詞元葉現在先到、寬葉收不到):2,710。最大的是 加える→手札 543 → 2,079(收進 デッキ/墓地/除外/EXデッキ→手札 四葉的卡)、破壊@フィールド 171 → 490(收進 自分/相手/お互いの 三葉)、選ぶ@フィールド 90 → 281、破壊@フィールド(耐性) 57 → 181、戻す→デッキ 510 → 620、戻す→手札 316 → 395、無効にする@フィールド 29 → 76、対象にする@フィールド(限制) 25 → 70。沒宣告玩家的所在葉在新模型下就是「不限玩家」,這是第三版要的語意,不是錯。
- **並收取消**(關鍵詞葉命中時來源/目的葉現在不收):13,只有 置く→フィールド 136 → 149(〜にカウンターを置く 的 16 框)。
- **非移動類 から 不當所在**:1,187,24 葉,全是 選ぶ/確認/見せる/めくる/取り除く/重ねる/X素材とする/破壊 的所在葉。現行歸葉有一條 2026-10-28 裁定:非移動類所在空著、來源有字面時「來源當所在比」(手札・墓地から選ぶ);述詞只讀所在欄時這些框就不中——選ぶ@自分墓地 436 → 38、選ぶ@デッキ 388 → 13、選ぶ@自分手札 310 → 145、めくる@自分デッキ 65 → 15、選ぶ@EXデッキ 56 → 11。沿用那條規則(所在空時讀來源)張數全部回到現在的數(選ぶ@墓地 因不再互斥還會到 472)。

**三、預設葉取消:97 葉**,改為詞元節點述詞。38 葉張數變(全是「其餘」變「全部」):特殊召喚 1,658 → 4,028、加える 11 → 2,123、戻す 14 → 1,101、選ぶ 186 → 1,328、アップ 37 → 1,112、無効にする 14 → 984、破壊 831 → 1,618、にする 35 → 713、送る 247 → 831、置く 7 → 404、除外 603 → 982…;59 葉是詞元節點唯一的葉,數字不變。**詞元節點**本身(現在 = 底下各葉聯集)101 個全部張數不變——含沒有預設葉的 得る、指定、無効にする(耐性),它們底下沒有未歸框。

**全語料沒有命中的具名查詢不留**:只算效果位,取り除く@お互いのフィールド 命中 0 卡(它只在代價位有 10 句);算三個位置就沒有空的。規格 2 的檢查要寫明算哪些位置。

### 欄位不夠的兩處(給規格 1)

1. **極性類(耐性/限制)述詞沒有欄可讀。** 框架只有 極性(肯定/否定/可能)與 態;できない 記 否定、不記 可能,耐性/限制 是 categories.polarity_class 讀子句字面(受身 → 耐性;にならない/受けない → 耐性;できない/行えない → 限制;送らず 這類一般否定沒有類)。效果位否定框架 2,634:受身耐性 786、非受身耐性 332(受けない 202、にならない 130)、限制 1,355、一般否定 161。只用 極性+態 近似(耐性=否定+受身、限制=否定+非受身):受ける(耐性) 197 → 0、対象にする(耐性) 123 → 0、攻撃対象にする(耐性) 16 → 9;対象にする(限制) 144 → 267、リリース(限制) 33 → 44、加える(限制) 5 → 14(吃進耐性與一般否定)。36 片否定節點的葉都要這一欄——框架線要把述語形記成封閉類(例:否定形 ∈ {被動否定, 不成/不受, 不可能, 一般}),或直接把極性類當框架欄位匯出。
2. **非移動類的 から。** 上面 1,187 卡·葉。規格 1 定一個:(a) 框架線把非移動類動作的 から 字面記進所在欄(來源欄留不留另定),述詞只讀所在;或 (b) 框架不動,編譯時非移動類詞元的所在葉編成「所在=X 或 來源=X」,使用者自建述詞也得知道這條。
