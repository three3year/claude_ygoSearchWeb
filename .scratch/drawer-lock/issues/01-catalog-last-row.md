# 01: 目錄樹:有子項的詞元節點只展開,節點本身排最後

**What to build:** 站主點目錄裡的 破壊 這類有子項的詞元節點只會展開,不加標籤;破壊 本身以同名列在它所有子的最後一列,點它加標籤、點 − 排除、加了標「已用」。大類 召喚 底下的詞元節點 召喚 也排到大類所有子的最後。父列照舊標張數。見規格 Solution 1 與 Implementation Decisions「目錄導覽樹」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 25 個帶子的詞元節點(清單見規格 Further Notes):父節點沒有葉路徑、點了只展開、沒有 −,張數與灰字規則照舊
- [ ] 每個這種節點最後一個子同名、帶原本那一列的葉路徑;點它加的標籤和改動前點父列加的一模一樣(網址路徑不變)
- [ ] 大類 召喚 的詞元節點 召喚 是大類的最後一個子;沒有子的詞元節點、大類、中類不變
- [ ] 「已用」只標在最後那一列
- [ ] 過濾框打父節點名字(含 破壊(耐性) 這類子名不含父名的)時父節點展開、最後一列看得到
- [ ] 目錄導覽樹接縫的測試(先例:conditions.test.js 的 Acat 例子)涵蓋上面各條;node 測試全過
