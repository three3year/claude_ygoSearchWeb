**後面各票怎麼用(「整張通過反向檢查」的驗收)**:

```python
from reverse_check import check_card
structure = next(c for c in self.structures if c["id"] == 卡號)   # build_structures 的輸出
self.assertEqual(check_card(structure), [])
```

`check_card(卡片結構) → 不通過清單`,空清單 = 整張通過。每筆是 `{"card", "name_ja", "block", "segment", "reason", "detail", "rendered", "original"}`,測試失敗時直接印出哪一段、什麼原因、產生的日文與原文。先例:`test_golden.py` 的 `test_whole_card_passes_reverse_check`。

**判法(嚴格)**:模板只從結構的格產生日文,不抄段的字面——物件由條件式+數量產生(「魔法カード１枚」= 大類 魔法 + 1枚)、指回的物件寫「その+頭名詞」、述語字面必須能拆回段的動作詞+態+極性。段裡有填值但模板不會寫的格,記「無模板」並指出格名(`格 duration 無模板`、`取對象線無模板`…),所以**每張票填新格時都要在 `reverse_check.render_segment` 補模板**,否則該票的標準卡過不了。正規化自己寫(`normalise`):去空白、全形 ASCII 折半形,①②③ 不動(不用 NFKC)。

**三種不通過**:無模板(含段未解析,detail 帶原因)、字面不符(附產生的日文與原文,全部列出)、段外殘留(區塊裡沒被任何段涵蓋、也不是固定接著詞 `①：`、`。`、`、`、`発動できる`、`発動する`、`その後`、條件段後的 `に` 的文字——每段各自全等還不夠,整個區塊的字都要有人認,漏掉一整句才看得出來)。

**全庫現況**(票 01 的抽取):段 56,070,通過 794、不通過 55,276(無模板 55,250、字面不符 26、段外殘留 0);特異点の悪魔 不在報告裡。
