# 03 — 官方明示:五階梯歸屬與類型抽取

**What to build:** 重跑建置後,約 62% 的[[效果句]]自動帶上正確的[[效果類型]]、`source: "official"`,而且每一條都能說出它是靠哪一種對位方式判定歸屬的。使用者打開報告就能看到各對位方式的覆蓋數,以及三份需要人工看的清單。

核心是**歸屬判定**——官方明示講的是哪一個效果句。原則是:證據唯一且明確才自動套用,任何歧義一律留白交給後續判定,絕不猜測。

**Blocked by:** 02 — 拆句骨架

**Status:** ready-for-agent

- [ ] 抽取「誘発即時効果」「誘発効果」「起動効果」「永続効果」「分類されない効果」並對應到六種中文值
- [ ] **否定句優先**:含「いずれにも分類されない」者判為「無種類效果」,不因該句列舉其他類型詞而多重命中(預期 956 筆)
- [ ] **「効果ではありません」不得產生任何判定**,需有回歸測試
- [ ] 「〜は効果として扱いません」視為[[效果外文本]]的官方明示;若指向的段落不在前言段,列進報告不自動處理
- [ ] 階梯一:`【①の効果について】` 系列標頭直接對位編號
- [ ] 階梯二:`『①』` 純序號引用對位。**短引號不得被字元長度過濾掉**,需有回歸測試(預期 775 張卡 / 1,591 行,序號對位失敗應為 0)
- [ ] 階梯三:`『效果原文』` 引用比對回日文卡文的編號區段,比對前正規化全形/半形數字,引號為截斷時取前綴比對
- [ ] 階梯三命中多個編號區段時視為歧義、不採用(實測 0 筆,仍須實作防護與測試)
- [ ] 階梯四:`「<本卡日文卡名>」の効果は…` 且該卡只有一個效果句時套用
- [ ] 階梯五:無任何歸屬標記且該卡只有一個效果句時整卡套用
- [ ] **明示句以「」提到的卡名只有別張卡、且無序號或原文引用時,不得產生任何判定**,以「深海の戦士」為回歸測試案例。此項與下方「卡名限定但多效果」的**筆數取決於計數約定**(一卡算一次 vs 一行算一次、是否跳過無引號行),不同寫法可差三倍以上——驗收看行為,筆數只進報告,不釘預期值
- [ ] 引號對不回本卡卡文者不猜測歸屬,列進報告(預期 22 筆)
- [ ] 卡名限定但卡文有多個效果者留待判定決定歸屬
- [ ] 官方以 `【●の効果について】` 系列標頭描述的子效果拆成獨立效果句,`index` 形如 `"①-●1"`,各自單一類型
- [ ] 覆蓋數達約 13,756 條 / 62.7%,報告分列各對位方式的覆蓋數(預期:標頭 8,193、`『①』`序號 1,584、`『原文』`引用 1,480、卡名限定單效果 1,498、一般單效果 1,004)
- [ ] 報告產出三份清單:歸屬由判定決定、引號對不上、明示句只提別卡名
- [ ] 這批行的 `source` 為 `official`,後續重跑永不覆蓋
