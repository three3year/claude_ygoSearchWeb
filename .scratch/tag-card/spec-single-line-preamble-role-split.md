# Spec: 單行前言以句號＋role 拆(含拆句表兜底三張)

Status: ready-for-agent
Parent: ADR-0012、票68、票69(本 spec 由 34695290 回報的 grilling 共識展開)

## Problem Statement

使用者回報 34695290:中文前言「此卡只能用「突變魔」卡片的效果特殊召喚。這個卡名的②③效果1回合各能使用1次。」是[[效果外文本]]沒錯,但它包含召喚條件與使用次數限制**兩種形態**,在[[效果標記表]]裡卻合成單一 `"0"` [[效果句]]、role 只記「召喚條件」——②③的使用次數限制從以 role 為條件的搜尋裡消失。

全表掃描確認不是個案:前言未拆、≥2 句、含 ≥2 種 role 的卡共 **105 張**。其中 **100 張**與 34695290 同型——官方日文卡文是**單行**,ADR-0009 的換行拆點沒有東西可拆,整段維持現狀(型態約半是召喚條件+使用次數限制、約半是儀式的素材指定+使用次數限制);3 張是機械規則救不了的特例(50604072 中日句數對不上退回、4168871/45286019 日文是一個複合句要句中拆);2 張(61901281/99234526)官方引用把整段括成一體,**維持不拆是正確結果**,不在修正範圍。

## Solution

前言拆分加**第二層拆點**:換行/引用合併分組之後,組內以「。」切句、以既有 role 正規式逐句判 role,**相鄰句 role 相異處**拆開、同 role 相鄰句合為一段;被[[補足情報]]引用括住的單位不進第二層,官方訊號照舊優先於 role 推論。實測全表跨句引用 16 張全是同 role 召喚條件,同 role 合併讓段界與引用天然一致,機械規則零例外。

三張特例以[[拆句表]]人工紀錄兜底,需兩個機制改動:拆句表對編號卡的前言生效,以及効果として扱いません型引用被拆點切開時的**涵蓋即歸屬**例外(引用完整包含的段照樣記 official)。決策取捨全文見 ADR-0012。

## User Stories

1. As a 使用者, I want 34695290 的前言拆成召喚條件與使用次數限制兩列、各自標效果外文本, so that 兩種形態在畫面上各自成行、以 role 為條件的搜尋兩邊都命中。
2. As a 網站查詢層, I want 單行多 role 的 100 張卡前言依句號＋role 二次拆開, so that 「哪些卡有使用次數限制」對這批卡不再給出錯資料。
3. As a 使用者, I want 同 role 相鄰句合為一段, so that 段的粒度就是搜尋的粒度,不製造官方沒有認可的多餘小段(8192327 的「召喚、召喚、次數」三句拆成兩段)。
4. As a 使用者, I want 被補足情報引用括住的單位不進第二層拆點, so that 官方逐項裁定視為一體的單位(61901281/99234526 等 24 段)維持不拆,官方訊號永遠優先於 role 推論。
5. As a 使用者, I want 跨句引用兩句同 role 的 16 張卡照同 role 合併成段, so that 段界與引用天然一致、引用不被切開,不需要任何例外規則。
6. As a 使用者, I want 儀式形態(藉由〜降臨。+ 次數句)拆成素材指定+使用次數限制, so that 約半數同病卡的素材指定 role 不再吃掉次數限制。
7. As a 使用者, I want 效果外文本的官方明示落到引用命中的那個細段(34695290 的引用只括第一句 → 落到召喚條件段), so that 歸屬因拆句變準,次數限制段不再連帶掛上它沒有的明示。
8. As a 使用者, I want 拆出的段沿用 `0-1`、`0-2`…照日文句序編鍵、沒拆的維持 `"0"`, so that 鍵的慣例與 ADR-0009 完全一致,歸屬模組不需改動。
9. As a 使用者, I want 每段都是中文原文的連續子字串、兩側串接可無遺漏蓋回原文, so that 拆句不可能悄悄改寫或漏掉卡文。
10. As a 使用者, I want 拆分是建置期機械規則、每次重跑現場重算, so that 新卡在差值更新時自動適用,不需要人工紀錄。
11. As a 判定執行者, I want 遮蔽測試樣本 key 因拆分變動時照 ADR-0009 前例以樣本過期處理, so that 不需要另做樣本遷移。
12. As a 使用者, I want 全表重跑後報告拆分段數與 role 分布變化(預期使用次數限制約 +100 列、素材指定/召喚條件為拆出而非改判), so that 驗收有數字可對。
13. As a 使用者, I want 退回清單、`substring_violations`、「效果外明示不在前言段」筆數都不因本次變動上升, so that 第二層拆點沒有讓既有保證變差。
14. As a 使用者, I want 前端索引隨拆分重建, so that 網站一列一行的呈現直接長出兩行、各帶 role 標籤,閱讀格式貼近新版卡片的書寫習慣。
15. As a 判定執行者, I want 拆句表對編號卡的前言生效(目前紀錄被回報為未使用), so that 機械規則救不了的編號卡(50604072)有人工兜底的路。
16. As a 使用者, I want 50604072 以拆句表紀錄拆成召喚條件(繁中兩句對日文一行)+使用次數限制, so that 票67 退回清單裡這筆多 role 錯資料被修正。
17. As a 使用者, I want 4168871/45286019 的日文複合句在頓號處句中拆、次數限制自成一段, so that 「此卡名的效果1回合只能使用1次」這型效果從合併句裡拆出來——這是本次修正的主要目標形態。
18. As a 判定執行者, I want 効果として扱いません型引用被拆句表拆點切開時,改驗「切出的每段都完整被引用包含且仍是效果外文本」, so that 官方說「這整團不是效果」時團裡每一段的歸屬照樣成立(涵蓋即歸屬),兩段都記 official/high 不降級。
19. As a 判定執行者, I want 涵蓋即歸屬例外只對拆句表人工紀錄開放、其他型引用被切開照舊整筆失效, so that 「引用不得被拆點切開」的底線只開一道有語義依據的窄門。
20. As a 判定執行者, I want 4168871 的紀錄帶 `ja_order`, so that 繁中語序相反(召喚限制在前、次數在後)的配對正確。
21. As a 使用者, I want 61901281/99234526 維持不拆、單一 role 的行為被回歸測試釘住, so that 將來的規則調整不會誤拆官方視為一體的單位。
22. As a 判定執行者, I want 35606858/40080312 列為同機制解鎖的順手候選(可選), so that 票67 退回清單的另外兩筆有路可走,但不強制本次處理。

## Implementation Decisions

- **拆點位階**(ADR-0012):官方換行 > 引用合併 > 句號＋role。role 推論只在官方訊號缺席(單行之內)處開火——這與 ADR-0009 否決「先判 role 再合併」不衝突而是接力:0009 拒絕的是拿推論**蓋過**官方換行訊號。
- **第二層拆點的實作位置**:既有前言拆分函式內、引用合併分組之後,組內逐句判 role(與既有前言 role 判定共用同一套正規式,抽出逐句版本)、role 相異處設拆點;組內有跨句引用時該組不進第二層。引用不得被切開的底線驗證照舊釘在最終 spans 上。
- **中日對位**:沿用既有 1:1 句對位(中文單位總數 = 日文句號數),對不上照舊整段退回。
- **判定欄位**:各段 kind 效果外文本、role 逐段重算、source 由規則與補足情報每次重跑重算(前言列零 manual、零 tags,拆開不丟失人工成果——ADR-0009 已查核的前提未變)。
- **拆句表編號卡前言支援**:適用範圍限前言段(編號句邊界仍歸編號),三道驗證照舊;編號卡的前言紀錄不再回報未使用。
- **涵蓋即歸屬**:効果として扱いません句式家族的引用被拆句表拆點切開時,驗證改為「切出的每段完整被引用包含且 kind 為效果外文本」,通過則各段 official/high;僅此句式家族適用,機械規則層碰不到此情境。
- **鍵與下游**:`0-1`、`0-2`…照日文句序;遮蔽測試樣本 key 變動以樣本過期處理;前端不改——一列一行與 role 標籤的呈現本來就是資料驅動。

## Testing Decisions

- 好測試只斷言**外部行為**:餵合成卡片與補足情報(或拆句表紀錄)進拆句骨架的頂層純函式,斷言輸出效果句列(index/兩側文字/kind/role/source)與報告鍵;不測內部輔助函式。
- **主接縫(既有,唯一)**:拆句骨架頂層純函式。先例:既有測試檔的 TestPreambleSplit(換行拆分、引用合併)與效果外明示歸屬測試類。新增場景:① 34695290 形態(單行兩句拆二、明示落第一段);② 8192327 形態(三句同 role 合併拆二);③ 儀式素材形態;④ 引用括住整段維持不拆;⑤ 跨句引用同 role 合為一段。
- **拆句表側(同一接縫)**:先例:既有以拆句表紀錄餵入的測試類(舊式卡拆分、"0-2" 尾碼)。新增:編號卡前言紀錄生效、涵蓋即歸屬正反例、`ja_order` 語序配對。
- **全表層級不寫單元測試**:拆分段數、role 分布、violations 0、明示歸屬報告不升,走建置報告數字對帳,與票66/67 驗收慣例相同。

## Out of Scope

- 61901281/99234526:官方引用括住整段,維持不拆是**定案**,只加回歸測試不改資料。
- 動[[卡片總表]]的中文卡文本體(不補換行,顯示分行由效果句列承載)。
- 前端改動:一列一行與 role 標籤既有,資料重建即生效。
- [[規則層]]與編號句(①②…)的邊界:本 spec 只動前言段。
- 35606858/40080312 的實際落表(僅列候選,處理與否由票69 執行時依對帳成本決定)。
