# 04: 字段對照表

**What to build:** 字段找得齊又不亂中。

- **草稿**:草稿工具機械產生對照表草稿,來源有兩個。一是三份 setcode 差集:卡名對到 0 張、誤中、漏中。二是卡文「このカード名はルール上「X」カードとしても扱う」。每個字段三欄:另比的卡名子字串、補進的卡片密碼、排除的卡片密碼,每筆附理由。setcode 是 EDOPro 社群資料,只當草稿來源,不進建置。
- **審核關卡**:草稿寫之前先用 `review-mirror`,發布鏡像給站主逐條核可。**發布後停手**,等站主核可再往下做。
- **入版控**:核可後成為入版控的手寫來源檔,建置期套用到字段的卡片密碼清單。下列三種失配時建置失敗:另比的子字串對到 0 張、密碼不存在、排除的卡其實不含該字串。

見規格「字段對照表」實作決策與「字段怎麼判?」的決定。
