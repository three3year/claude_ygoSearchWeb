# 05 — 素材框架

**What to build:** 站主在拆解頁看到素材行「「アマゾネス女王」＋「アマゾネス」モンスター」出一個素材框架:召喚法=融合(由卡片子類型帶入)、素材清單=[「アマゾネス女王」×1、「アマゾネス」モンスター×1];「「双天脚の鴻鵠」＋「双天」モンスター×２」記數量 2;「チューナー＋チューナー以外のモンスター１体以上」記下限;降臨句「「光の黄金櫃」により降臨。」→ 召喚法=儀式、清單=那張儀式魔法。效果外文本的覆蓋率明顯上升,抽不到框架的句子清單裡素材行消失。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 一行素材行或一句降臨句出一個素材框架,清單有序、每項保留原詞並記數量(定值或下限)
- [ ] 接縫的可選卡片子類型輸入生效:融合/同調/超量/連結/儀式各一條回歸例子;不帶子類型時召喚法留空、不報錯
- [ ] 框架主程式逐句從卡片總表帶入卡片子類型
- [ ] 全語料重跑,效果外覆蓋率前後比對寫進票追記,發布拆解頁
