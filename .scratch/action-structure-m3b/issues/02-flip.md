# 02: 反轉

**What to build:** 「リバース」有動作詞,新式與舊式的反轉效果都查得到:

- 同義表加動作詞 反轉,字幹「リバース」;沒有上位詞,也沒有下位詞,不進推得表。
- 反轉、反轉召喚(反転召喚)、反轉怪獸(卡片子類型 反轉)是三個不一樣的東西(站主裁定):查任一個都不因為另外兩個的字面命中;未解析組的字面比對也要分開(「リバースモンスター」不算反轉的字面)。
- 「Xがリバースした場合/時」:條件段,動作詞 反轉,X 是被反轉的卡。
- 「召喚・リバースした」等列舉:一段多個動作詞,同「召喚・特殊召喚に成功した」。
- 舊式標示「リバース：X」:條件段(動作詞 反轉,物件是此卡,原文沒寫所以標省略,觸發形 場合——站主裁定)加上 X 照效果句解析出的段。條件段的原述語字面記「リバース：」;反向檢查的模板看到這個字面就寫回「リバース：」,不寫「場合」。
- 「リバース：」後面的效果段不因為前面有條件段而標成延遲,取對象等標記照一般效果段。

- 規格:需要你決定的「「リバース」怎麼讀?」「「リバース：」的條件段,觸發形記什麼?」;實作決策「反轉」「查詢判斷」;使用者故事 7–13。
- 統計:`m3b_scope.txt`「段的寫法」(「リバース：」86 段、解析不出 85;「リバースした/する/し、」276 段、解析不出 263;「召喚・リバース」80 段、解析不出 74)。
