# 12 — 大類兩態化

**What to build:** 使用者點[[大類]]鈕(怪獸/魔法/陷阱)時是兩態切換:點一下選取、再點
取消,不再有排除態——點過頭誤入排除態、子類組突然消失的困惑源就此消滅。「不要某大類」
改以勾選其餘兩類表達,三值互斥之下查詢能力零損失。其他軸(含子類型)維持三態,
排除優先語意不變。

實作形狀:**態數(兩態/三態)是軸宣告的一部分**,由軸清單(`Query.axes()` 的形狀)攜帶,
點擊處理照宣告循環——不是在事件處理裡對大類寫特例。之後若有別的軸要兩態化,改宣告
就好。舊網址不需相容處理(本版尚未公開)。
