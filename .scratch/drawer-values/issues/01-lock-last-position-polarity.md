# 01: 位置與極性最後一顆鎖住

**What to build:** 抽屜裡位置、極性兩欄都是單純的開關:最後一顆亮著的按不掉,要全部就三顆都按亮,不再有「全關等於全部」。舊網址沒寫極性時照開,查到的卡不變。見規格「位置能不能全部關掉?」「極性能不能全部關掉?」兩題與「條件模型的介面」段。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 位置、極性只剩一顆亮著時,切換它標籤不變;兩顆以上亮著時都能關
- [ ] 抽屜裡鎖住的那顆是亮著但不能按,滑鼠停上去提示「至少要留一個」
- [ ] 只亮效果時按「效果」不再變成三顆全亮(規格 Further Notes 的 1,618 → 2,461 不再發生)
- [ ] 述詞沒寫極性時視同三種全亮:網址沒寫極性的動作標籤讀成三個值,查到的卡與現行相同
- [ ] 三種極性全亮時網址不寫極性,`canon` 冪等;肯定+可能、否定的寫法不變
- [ ] 三種極性全亮的短句寫「極性 不限」;肯定+可能照舊不寫
- [ ] 條件模型測試:鎖住、兩顆可關、還原後狀態;`Hash` 測試:沒寫極性往返、三個全亮不寫
- [ ] 全套 node 測試通過
