# 02: 反轉

**What to build:** 「リバース」有動作詞,新式與舊式的反轉效果都查得到:

- 同義表加動作詞 反轉,字幹「リバース」;沒有上位詞,也沒有下位詞,不進推得表。
- 反轉、反轉召喚(反転召喚)、反轉怪獸(卡片子類型 反轉)是三個不一樣的東西(站主裁定):查任一個都不因為另外兩個的字面命中;未解析組的字面比對也要分開(「リバースモンスター」不算反轉的字面)。
- 「Xがリバースした場合/時」:條件段,動作詞 反轉,X 是被反轉的卡。
- 「召喚・リバースした」等列舉:一段多個動作詞,同「召喚・特殊召喚に成功した」。
- 舊式標示「リバース：X」:條件段(動作詞 反轉,物件是此卡,原文沒寫所以標省略,觸發形 場合——站主裁定)加上 X 照效果句解析出的段。條件段的原述語字面記「リバース：」;反向檢查的模板看到這個字面就寫回「リバース：」,不寫「場合」。
- 「リバース：」後面的效果段不因為前面有條件段而標成延遲,取對象等標記照一般效果段。

- 規格:需要你決定的「「リバース」怎麼讀?」「「リバース：」的條件段,觸發形記什麼?」;實作決策「反轉」「查詢判斷」;使用者故事 7–13。

### 做了什麼

- 同義表:加字幹「リバース」→ 反轉(`synonyms.FLIP_STEM`、`FLIP_ACTION`),沒有上下位詞、不進推得表。「Xがリバースした場合/時」的 X 是被反轉的卡(對象線角色 受事)。
- 召喚的列舉可以列 反轉(`synonyms.is_enumerable`):「召喚・リバースした」「特殊召喚・リバースした」「召喚・特殊召喚・リバースした」「融合召喚・リバースした」都是一段多個動作詞;有召喚系時線的角色照舊是 被召喚。
- 未解析組比字面:「リバース」落在「リバースモンスター」「リバース効果」裡不算(`STEM_FALSE_FRIENDS`)。規格只點名「リバースモンスター」;「リバース効果(モンスター)」(王宮の号令「全てのリバース効果モンスターの発動及び効果は無効化される」、アマゾネスの弩弓隊「（リバース効果は発動しない）」)講的是反轉怪獸/反轉效果,不是翻面這個動作,所以一起扣掉。反轉召喚的字幹「反転召喚」本來就比不中「リバース」。
- 舊式標示「リバース：X」(新模組 `flip_label`):句子以「リバース：」開頭時(全庫 86 處都在卡文開頭),標示本身切成條件段——動作詞 反轉、對象線是此卡(角色 受事、標省略、助詞 None)、觸發形 場合、原述語字面「リバース：」、態 主動——X 從標示後面起照一般的句子解析。標示段在 `parse_sentence` 判延遲之前切走,X 的段不算延遲,取對象字面照一般效果段標(標示後有取對象線的段 13 段)。反向檢查加整段模板「反轉標示」:格正是上面那一組時寫回「リバース：」,否則無模板。
- GLOSSARY:同義表、觸發形兩條 m3b 段落拿掉「尚未實作」並補實作細節;同義表 m3 票 08 那段「還沒收的寫法」裡的「召喚・リバースした」註記為已收。
