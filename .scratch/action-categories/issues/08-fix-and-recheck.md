# 08 — 依檢驗修規則、同批複檢

**What to build:** 依 round1 的高頻錯誤類型修規則表或改樹:每類先補一條會失敗的回歸例子再修;改樹的部分(葉切法、條件)記回裁定關卡草案的決定行。用同一批樣本複檢到只剩個別長尾,未修的逐項記理由。站主看到錯誤數下降、沒有新的高頻類型。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 每類要修的錯誤先補回歸例子再修;改樹的改動重發裁定關卡鏡像。
- [ ] 同批複檢(round2):錯誤數下降、無新高頻類型;剩餘逐項附理由進已知未修。
- [ ] 全語料決定性重跑,前後的已歸/未歸/不適用數與差異落點記在票 Comments。
