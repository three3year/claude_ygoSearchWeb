# 03 — 關鍵詞讀三欄與多關鍵詞多葉

**What to build:** 葉的「對象」條件改名「關鍵詞」:比對時依 對象→主語→主題 找第一個有值的欄,只比那一欄(主題含回填延續的值);同時命中幾個關鍵詞葉就帶幾個葉,與複合區域同理。站主在框架類別檔看到「攻撃力・守備力が１０００アップする」帶 アップ:攻撃力 與 アップ:守備力 兩葉、「その発動した効果を無効にする」帶 無効にする:効果 與 :発動、「そのモンスターのレベルを４にする」歸 にする:レベル(對象)、「守備力が０になり」歸 になる:守備力(主語)、「攻撃力は１００００になる」歸 になる:攻撃力(主題);「このカードは…モンスターを破壊する」不因主題誤中。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 樹來源檔:葉條件鍵「對象」改名「關鍵詞」(既有樹同步改);完整性檢查:關鍵詞葉之間不互蓋(多葉),但前面一個沒有關鍵詞條件的葉涵蓋後面關鍵詞葉的區域/玩家條件時報錯(較具體者寫在前)。
- [ ] 規則表:匹配改成——對每個區域組合依樹序走葉,收集所有條件相符且帶關鍵詞條件的葉;沒有任何關鍵詞葉相符時取第一個條件相符、不帶關鍵詞條件的葉;葉清單依樹序去重。比對欄:對象有值比對象,否則主語,否則主題;三欄都空不中。
- [ ] 現有樹裡 アップ/ダウン/上げる/下げる/上がる/下がる、になる/にする 系暫不加關鍵詞葉(葉表在票 06 草案提議);無効にする 的 効果/発動 從先到先得改為多葉,全語料差異(「発動した効果」約 20 框)記在票 Comments;舊草案裁定項 10 的意義由此消失,交票 06 改寫。
