# 06: 結果卡片的鈕與目錄選擇窗

**What to build:** 結果卡片卡頭多一顆鈕,按了開目錄選擇窗,列出帶入這張卡後還有命中的目錄列與張數。

- **算法**:目標卡逐框表算一次,詞元索引掃各列的框,再由框反查卡算張數。
- **顯示**:只列張數 > 0 的列,預設「只看有寫條件的」,窗內可切模式。
- **挑一列**:產生那列的標籤、帶入這張卡、加到 AND 區;標籤仍鎖在原列。
- **元件**:全站還沒有彈窗元件,這張新做。鍵盤可關,手機寬可用。

見規格 Solution 5、「目錄選擇窗怎麼算張數?」的決定與 User Stories 16〜19。
