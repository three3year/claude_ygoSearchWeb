# 舊式卡文的拆句邊界是獨立的來源檔,且不由規則產生

3,805 張舊式無編號卡文的[[效果句]]邊界必須由判定者依語意決定——卡文沒有①②③,2,449 張連換行提示都沒有,[[官方明示]]只說類型不說邊界。這份邊界成果要放在哪裡、由誰產生,是兩個各自獨立的決定。

## 放在哪裡:獨立的[[拆句表]] `data/clause_splits.json`

考慮過三種:

- **活在判定結果檔裡**(`build_tag_cards` 的 `judgments` 參數):骨架每次重跑照樣生出整團再被替換掉。問題是判定結果檔同時扛兩種語意,而且「拆完之後重跑官方明示」這件事每次都得先重算一遍拆句才跑得動。
- **活在[[效果標記表]]裡**:依 ADR-0001 標記表是來源檔,重跑時以既有段落為準。但這會打破票05 立下的「文本欄位永遠取本次的值」——`text_zh` / `text_ja` / `text_hash` 是來源資料的投影而不是判定,卡文勘誤時必須跟著更新;若段落集合也由標記表決定,勘誤後拆點就對不上而且沒有東西會發現。
- **獨立的拆句表**(採用):只存拆點,骨架讀它把整團切開。

採用第三種的理由是**責任分離**:骨架永遠負責「卡文 → 效果句」,判定永遠負責「效果句 → 類型」。接縫因此是兩個參數而不是一個——`splits` 決定效果句的**集合**、`judgments` 決定效果句上的**值**,而且兩者有順序:拆句表要在官方明示抽取之前生效,判定結果在之後合併。塞成一個參數會把這個順序關係藏起來。

拆句表本身是判定者做出的、無法由卡文重算的一次性成果,因此 ADR-0001 對效果標記表的論證原封不動適用:入版控的**來源檔**,不是建置產物。

## 由誰產生:判定者,不是[[規則層]]

拆點**不由歸納出來的規則產生**。理由是拆句沒有現成的標準答案集——官方明示只寫類型,規則寫出來沒有東西可以對照,正是 ADR-0002 點名的失效模式。實測佐證:最直觀的「每個句號都是一段」這條規則,在 2,184 張有官方引用可驗的整團裡被打臉 **497 張(22.8%)**——官方引用橫跨句號,證明那兩句是同一個效果句。

補足情報裡的 `『原文』` 引用(2,150 張整團有,且引用是整團的真子字串)**只當提示與驗證器,不當拆點**。同一個理由已經寫在 `_split_bullets` 裡:沒有官方標頭的 `●` 只是同一個效果的選項列舉,拆了反而製造出官方沒有認可的效果句;`『原文』` 引用同樣可能只是一句話的片段,不是效果句邊界。

### 修訂(票16,2026-08-09):`『●…』` 引用不受這一條約束

上一段講的是**引用的邊界能不能當拆點**。`『●…』` 引用回答的是另一個問題:**拆點是 `●` 這個卡文自帶的記號**,不是從引用的邊界來的;引用只決定官方認不認這個 `●` 是獨立的子效果——與 `【●…について】` 標頭同一種依據,只是官方沒開標頭(實測 156 條賦予型領起句裡 150 條有這種引用)。因此加開一種拆句依據,判準三道:

1. 引用**從 `●` 起頭**。從句中截斷的引用仍然只是一句話的片段,照舊不算。
2. 只對**賦予型領起句**(`〜は以下の効果を得る。●…`)開火。領起句自己就寫了發動時 `●` 只是同一個發動的選項列舉,票14 實測那一族的官方類型是對的,拆了反而拆錯。
3. 拆之前跑本 ADR 的前兩道驗證(無遺漏覆蓋、官方引用不得被拆點切開)。第二道實測擋下 `45184165` ——官方的引用從領起句一路引到 `●`,自己就說了那兩段是同一個效果句。

**舊式無編號整團的拆點仍然完全由判定者決定**,這一條沒有鬆動。

## Consequences

- 三道驗證都是可機器檢查的,失敗即不寫入:
  - **無遺漏覆蓋** —— 段落按順序串接、忽略空白後必須等於原文。這是判定者「漏掉一句」這個沉默失效模式的唯一防線,也順帶成為卡文勘誤的偵測器(任何一個字元變動都會讓等式不成立)。
  - **引用交叉驗證** —— 官方 `『原文』` 引用被拆點切成兩半就是拆錯。涵蓋 2,150 張,不需要標準答案,進建置報告且必須為 0。
  - **卡文變動即失效** —— 整筆退回未拆狀態(整團、`index: "1"`),而不是保留舊拆點。保留失效的斷言會讓歸屬階梯在假前提上開火,那正是票11 的錯誤。
- 拆句表有紀錄本身就是「這張卡有幾個效果句」的斷言,`official.attest()` 的階梯四、五據此才敢對舊式卡開火(票11 之前是靠 index 猜,猜錯 1,146 條)。骨架把 `unsplit` 集合傳給抽取器,有拆句表紀錄的卡就不在裡面。這也意味著單句整團同樣要走判定——「句數」不是「效果數」的合法代理。
- 拆句判準寫在 `docs/effect_kind_guide.md` §8,但**不預先寫完**:先補最小必要的幾條,由試點票跑出來的打臉案例逐輪加上去,與票07 養規範文件的循環相同。
- 拆句表記下當時的卡文雜湊與判定票號。雜湊對「偵測變動」是冗餘的(無遺漏覆蓋已經涵蓋),留著是為了**診斷**:出事時能一眼看出這筆拆點是對著哪一版卡文切的。
