# Spec: 框架第四版論元——論元片語、施事者、方式、否定形與回指回填

Status: ready-for-agent
Date: 2026-10-31

框架述詞搜尋線(`.scratch/frame-predicate-search/map.md`)四份規格的第一份,對應地圖票「寫規格 1:框架線的論元片語與新欄」。形狀由 GLOSSARY.md 2026-10-31 定案段(動作框架第四版論元、論元片語、論元的方式與數量、框架述詞、動作對象)與 ADR-0018 裁定,本規格只抄,不重問;形狀底下的規則細節依地圖 Notes 在本規格的[需要你決定的](#需要你決定的)一次問完。地圖票「具名查詢編譯試跑」查出的兩處欄位不夠(否定形、非移動類的 から)在這裡裁。上游是第三版論元(`.scratch/frame-args-v3/`)、動作詞元統一與回指三線,全部已交件。

## 需要你決定的

### 否定形怎麼記?

效果位的否定框架 2,634 個,現行只靠類別線讀子句字面分耐性/限制;述詞沒有欄可讀,只用極性加態會讓 受ける(耐性) 197 → 0、対象にする(限制) 144 → 267(票 02)。全語料否定框架 3,088:受身否定 792、にならない/受けない 332、できない/行えない 1,364、一般否定(送らず、戻さず)600。

決定(2026-10-31):(a)框架加封閉類欄否定形,值 受身/不成不受/不可能/一般,只在極性=否定的框架上有值。

- (a)框架加封閉類欄**否定形**,值 受身/不成不受/不可能/一般,只在極性=否定的框架上有值(建議):具名查詢編譯時 耐性 寫成 否定形 ∈ {受身, 不成不受}、限制 寫成 否定形 = 不可能,就是述詞的同欄多值;一般否定也有值可搜。代價:使用者自建「耐性」述詞得知道它是兩個值(介面可以在規格 4 給一個快捷)。
- (b)直接把類別線的極性類(肯定/耐性/限制)匯成框架欄位:和現行葉名一致;但一般否定 600 框沒有值、可能與肯定合併後看不出,而且是類別線的歸組概念搬進框架,框架線以後還是得維護那張字面表。

### 非移動類的 から 怎麼進所在欄?

非移動類動作帶來源字面、所在空著的框架 1,866(選ぶ 895、離れる 417、選択 289、めくる 56、対象とする 42、見せる 37、発動 30…);沒有一框兩欄同時有值。現行類別線規則「所在空時讀來源」讓 選ぶ@自分墓地 這類葉有 1,187 卡·葉,述詞只讀所在時全部掉光(票 02)。

決定(2026-10-31):(a)結構化的所在欄取來源的區域與玩家、標「取自來源」,來源字面欄不動。

- (a)結構化的所在欄取來源的區域與玩家、標「取自來源」,來源字面欄不動(建議):字面欄逐位元組不變的驗收守得住,述詞只讀所在,使用者不用知道這條規則;記號和推得/回填一樣在拆解頁看得出。代價:所在欄的字面是空的、結構化值有東西,兩者不一一對應,匯出(規格 2)要照結構化值匯。
- (b)框架不動,編譯具名查詢時非移動類詞元的所在葉寫成「所在=X 或 來源=X」:框架乾淨,但述詞語意外露,使用者自建述詞也得照抄這條。
- (c)把 選ぶ/選択/めくる/見せる/確認 加進移動類:它們不移動卡,語意錯;而且會改既有框架的字面欄(受事者片語的區域從所在改記來源),違反驗收。

### 施事者的預設發動者補給哪些框架?

GLOSSARY 已定來源順序:主題 → 回指的事件主語 → 沒寫時預設發動者並標推得。沒寫主題也沒寫主語的動作框架:效果位帶對象 17,401、代價位帶對象 3,699、條件位帶對象 4,591;效果位不帶對象的 自動 2,075、受身 1,235。

決定(2026-10-31):(a)只補代價位與效果位、態不是受身/自動、自己帶對象(他動)的框架,值 自分、標推得。

- (a)只補代價位與效果位、態不是受身/自動、自己帶對象(他動)的框架,值 自分、標推得(建議):約 21,000 框;條件位不補(事件是誰做的原文沒寫就空)、受身與自動不補(主語/主題是承受方,不是施事者)、沒對象的不補(ドロー 的執行者由主題給,沒主題就空)。
- (b)代價位與效果位全部沒寫的都補:會把 攻撃力はアップする(自動)、破壊される(受身)也記成自分做的,語意錯。
- (c)不補,空就是空:卡文慣例省略 自分,「施事者=自分」的述詞會漏掉絕大多數效果。

### 被動句的 によって 記誰?

によって 出現 347 框,多數是 数によって以下の効果(不是施事者);相手の効果によって、カードの効果によって 這類才是被動句的施事者。

決定(2026-10-31):(a)玩家記玩家、卡片片語記其他卡、指名此卡記此卡,其他不記。

- (a)によって 片語是玩家或玩家起頭的(相手の効果によって)記那個玩家;是卡片片語(カードの効果によって、融合モンスターカードによって)記 其他卡;指名此卡的記 此卡;其他(数によって、表示形式によって)不記(建議)。
- (b)受身框架的施事者一律空:少寫一條規則,但「被對手的效果破壞」這個維度就沒有了。

### 此卡什麼時候是施事者?

主語是 このカード 的框架 5,014(條件位居多:このカードが…した場合)、主題是 このカード 的 1,744。

決定(2026-10-31):(a)主題或主語是 このカード 且框架自己帶對象(他動)時記此卡;受身、自動或沒對象的 このカード 是受事者。

- (a)主題或主語是 このカード,而且框架自己帶對象(他動)時記 此卡——このカードが相手モンスターを攻撃した場合、このカードは…を破壊する;受身、自動或沒對象的 このカード 是受事者,不是施事者(建議)。この効果で/このカードの効果で 是方式,不是施事者。
- (b)此卡從不當施事者,只記玩家:規則少一條,但「此卡攻擊」「此卡破壞」這一類就看不出主體是怪獸本身。

### 中心詞的邊界用哪一條?

現行關鍵詞規則(平假名邊界)把 表側表示モンスター、闇属性モンスター、アンデット族モンスター 整段當中心詞,靠子字串才中 モンスター;受事者中心詞現行 3,064 種。

決定(2026-10-31):(a)片語最後一個名詞格是中心詞,封閉值域複合詞一格就是中心詞,前面的格是修飾語;交件前重跑票 02 的編譯試跑。

- (a)片語最後一個名詞格(分詞的一格)是中心詞;分詞裡一格的封閉值域複合詞(罠カード、永続罠カード、戦闘ダメージ、自分フィールド)本身就是中心詞;前面的格是修飾語(建議):闇属性モンスター → 修飾語 闇属性(屬性)+中心詞 モンスター;表側表示モンスター → 表示形式 + モンスター;種族、屬性、表示形式才抽得成修飾語類。代價:中心詞和現行關鍵詞的中心詞不逐字同,交件前要重跑票 02 的編譯試跑確認 21 個關鍵詞、9 個目的關鍵詞的張數。
- (b)沿用平假名邊界:和現行完全一致,但修飾語類抽不出種族/屬性/表示形式——它們黏在中心詞上。

### 數量類要不要多「下限」?

N体以上 35、Nつ以上 10、N枚以上 2、N種類以上 1,共 48 框;GLOSSARY 的數量類值域目前是 定數/上限/任意/全部。

決定(2026-10-31):(a)加 下限,值域成 定數/上限/下限/任意/全部,下限另帶數字;GLOSSARY 同步。

- (a)加 下限,值域成 定數/上限/下限/任意/全部,GLOSSARY 同步(建議):述詞「數量=定數」不會誤收 2体以上。
- (b)不加,N以上 只記字面、類空:48 框搜不到數量類;「2体以上」在動作對象的選擇類/全部類判定要另寫規則。

### で 接區域算方式還是所在?

で 片語前的格是區域的約 60 框:フィールドで発動した効果 23、モンスターゾーンで 9、Pゾーンで破壊された 7、手札で発動した 6、相手フィールド/自分フィールドで 各 3、同じ縦列で 12。

決定(2026-10-31):(a)不是方式,區域與玩家記進結構化的所在欄、標轉欄,字面所在欄不動。

- (a)不是方式,區域與玩家記進結構化的所在欄、標轉欄,字面所在欄不動(建議):Pゾーンで破壊された 的所在就是 Pゾーン,和 Pゾーンのこのカードが破壊された 一樣可搜。
- (b)方式類 其他、只留字面:不改所在欄,但這 60 框的區域搜不到。

### LLM 抽驗怎麼分層?

慣例是 100 卡切 4 批交子代理挑錯、依類型修規則後同批複檢,存 `llm-check/`。新欄有七型。

決定(2026-10-31):(a)一輪合併,依新欄分層。

- (a)一輪合併,依新欄分層(建議):片語結構化(中心詞/修飾語類)、數量、施事者(非推得)、方式、否定形、回指回填、所在取自來源,一卡依序歸第一個符合的層(小層在前、全取),100 卡 4 批加同批複檢;錯誤類型在既有五類外加 中心詞錯/修飾語類錯、數量錯、施事者錯、方式錯、否定形錯、回填錯。推得的施事者是一條規則,靠回歸例子,不抽。
- (b)三輪(片語、施事者、方式各一輪):成本三倍,每輪抽到的卡大半重疊,而且三輪都得等前一輪修完。

## Problem Statement

站主要在網站上用[[框架述詞]]搜尋——「對手場上的怪獸被破壞」「從牌組把怪獸加到手牌、兩張以內」「此卡自己攻擊」——可是框架的受事者位(對象/主題/主語)與目的補語現在只是一段字面。動作對象、回指、區域、類別四支程式各自用正則式重拆同一段字面猜中心詞、數量、區域、玩家;類別線的關鍵詞只比子字串,表側表示モンスター 要靠「含 モンスター」才中;具名查詢編譯試跑發現耐性/限制沒有欄可讀、非移動類的 から 讀不到所在。誰做這個動作(自分/相手/此卡)與怎麼做(戦闘で、守備表示で)框架根本沒有記。沒有這些欄,述詞評估器(規格 3)沒有東西可評估,具名查詢(規格 2)編出來的張數也對不上現在。

## Solution

框架線在同一個接縫(一句效果句原文 → 框架清單)上把論元結構化,**加欄不換值**:

1. 受事者位與目的補語各多一個[[論元片語]]:依並列切段,每段有中心詞與中心詞類、修飾語(各段字面與類)、數量(字面與類)、玩家、區域、指示詞;整段字面照舊是原欄的值。
2. 來源/目的/所在三欄多結構化值:區域七值加玩家,字面不動;非移動類的 から 與 で 接的區域進結構化所在、標轉欄。
3. 新欄**施事者**(自分/相手/お互い/此卡/其他卡/空,推得的標推得)與**方式**(字面加方式類)。
4. 新欄**否定形**(受身/不成不受/不可能/一般),只在否定框架上。
5. **回指回填**:對象是指示詞、回指到的目標帶區域、框架自己沒有來源/所在字面時,把目標的所在放進來源(移動類)或所在(非移動類),只接非移動類目標,跨句,在回指之後跑。
6. 每個新封閉類有一張值表(框架線的封閉表,就是以後值域正典的來源),表外中心詞與修飾語落「其他」不擋建置、進報告;新欄填充率進報告;拆解頁與批次檔看得到新欄;一輪 LLM 抽驗加複檢。

驗收:舊欄全語料逐位元組不變(把新欄拿掉後的 frames.json 與修前相同)、新封閉類沒有表外值、填充率報告、編譯試跑用新中心詞重跑張數對得上。

## User Stories

1. 作為站主,我要「相手フィールドの表側表示モンスター１体を破壊する」的對象片語是 中心詞 モンスター(卡)、修飾語 表側表示(表示形式)、數量 １体(定數 1)、玩家 相手、區域 フィールド,這樣述詞可以逐欄寫、不用猜字面。
2. 作為站主,我要「闇属性・ドラゴン族の効果モンスター」的修飾語是 闇属性(屬性)、ドラゴン族(種族)、効果(卡片子類型),中心詞是 モンスター,這樣「破壞龍族怪獸」是一個欄位條件。
3. 作為站主,我要「「DD」モンスター」的修飾語 「DD」 記字段、「青眼の白龍」 整個是中心詞(卡),這樣字段與卡名分得開。
4. 作為站主,我要「レベル４以下のモンスター」的修飾語記 數值(欄位 レベル、比較 以下、數字 4),這樣數值條件不是一段死字串。
5. 作為站主,我要「そのモンスターの攻撃力」的對象片語中心詞是 攻撃力(屬性)、帶指示詞,這樣屬性類述詞與回指都有欄可讀。
6. 作為站主,我要「魔法・罠カード」切成兩段、各有中心詞(魔法、罠カード),這樣任一段命中的語意和現在的關鍵詞一樣。
7. 作為站主,我要「手札を２枚まで捨てる」的數量是 ２枚まで(上限 2),「全て破壊する」是 全て(全部),「任意の数」是 任意,這樣動作對象的選擇類/全部類以後讀數量類就好。
8. 作為站主,我要只寫在子句裡、緊接受事者的數量(手札を１枚捨てる、カードを３枚まで)也記進受事者片語的數量,這樣「丟一張手牌」和「手札を全て捨てる」分得開。
9. 作為站主,我要「数の分だけ」「同じ数」只記字面、數量類空,それぞれ 不是數量,這樣引用量不被誤判成定數。
10. 作為站主,我要「攻撃力を０にする」的目的片語中心詞是 ０、「裏側守備表示にする」是 裏側守備表示(表示形式),這樣目的關鍵詞葉編得出來。
11. 作為站主,我要「自分の墓地から」的來源同時有字面 自分の墓地 與結構化值(自分, 墓地),字面一個位元組都不變,這樣拆解頁、既有測試、動作對象與回指照舊能跑。
12. 作為站主,我要「手札・墓地から選ぶ」的結構化所在是 手札、墓地、標取自來源,這樣 選ぶ@自分墓地 這類述詞只讀所在就能中(見[需要你決定的](#需要你決定的))。
13. 作為站主,我要「Pゾーンで破壊された」的所在是 Pゾーン,這樣 で 接的區域不會被當成方式字面丟掉(見[需要你決定的](#需要你決定的))。
14. 作為站主,我要「自分はデッキから１枚ドローする」的施事者是 自分、「相手はカードを１枚捨てる」是 相手、「お互いは…」是 お互い,這樣「對手丟牌」是述詞的一個欄位。
15. 作為站主,我要「デッキからモンスター１体を手札に加える」沒寫誰做時施事者是 自分、標推得,這樣預設省略的主體看得出是規則補的。
16. 作為站主,我要「相手がモンスターを特殊召喚した時」這個條件框架的施事者是 相手,「そのモンスターを破壊する」的施事者不是 相手,這樣事件的執行者只記在事件自己身上。
17. 作為站主,我要「このカードが相手モンスターを攻撃した場合」的施事者是 此卡、「このカードは破壊されない」沒有施事者,這樣主語是此卡的受身句不被記成此卡做的。
18. 作為站主,我要「相手の効果によって破壊された」的施事者是 相手,「数によって以下の効果を適用する」的 によって 不記施事者,這樣被動句的執行者有欄可讀又不會誤抓。
19. 作為站主,我要「戦闘で破壊された」的方式是 手段:戰鬥、「この効果で特殊召喚した」是 手段:效果、「守備表示で特殊召喚する」是 表示形式(守備表示)、「扱いで」是 視同、「好きな順番で戻す」是 順序,這樣方式類述詞有封閉值可選。
20. 作為站主,我要「攻撃力2400以上で守備力1000のモンスター」定語裡的 で 不是方式,這樣並列修飾不會被誤記。
21. 作為站主,我要「このカードは戦闘では破壊されない」的否定形是 受身、「効果の対象にならない」「効果を受けない」是 不成不受、「攻撃できない」「行えない」是 不可能、「墓地へ送らず除外する」是 一般,這樣耐性/限制的具名查詢編得出來、一般否定也搜得到。
22. 作為站主,我要「…を対象として発動できる。そのモンスターを破壊する」的 破壊 所在是目標的區域、標回填,「そのモンスターを特殊召喚する」的 特殊召喚 來源是目標的區域,這樣回指到的目標在哪裡也能搜。
23. 作為站主,我要目標是移動類動作(手札に加える…その後、そのカードを…)時不回填,這樣目標已經搬走的區域不會被當成現在的所在。
24. 作為站主,我要框架自己有來源/所在字面時回指回填不蓋,這樣原文寫的字永遠優先。
25. 作為站主,我要每個新封閉類(中心詞類、修飾語類、數量類、方式類、施事者、否定形、轉欄記號)有一張值表,全語料出現表外值就建置失敗,這樣值域正典以後有單一來源。

## Implementation Decisions

**總則**

- 全部在框架抽取這一個接縫上做,輸出仍是「一句效果句原文 → 框架清單」;約束框架不動。
- 加欄不換值:既有的每個鍵與值逐位元組不變,新資訊一律是新的可選鍵;推得、回填、轉欄都只寫進新鍵或既有的記號欄。
- 處理順序:子句切分與既有論元收取 → 片語結構化(中心詞/修飾語/數量/玩家/區域/指示詞) → 來源/目的/所在的結構化與轉欄 → 施事者 → 方式 → 否定形 → 主題延續、既有回填、推得、詞元正規化(照舊) → 回指解析(照舊) → 回指回填。
- 每個新封閉類是框架線的一張封閉表(和移動類清單、推得值表同一種東西),表就是值域;全語料出現表外值的欄(數量類、方式類、施事者、否定形、修飾語類除「其他」、中心詞類除「其他」)建置失敗。「其他」只允許在中心詞類與修飾語類。

**論元片語(受事者位三欄與目的欄各一個)**

- 片語依受事者並列詞(と、か、や、及び、または;と同じ/と異なる 的 と 不算,沿用既有判準)切**段**;片語是一個有序段清單加整段字面。每段:字面、中心詞、中心詞類、修飾語清單、數量、玩家、區域、指示詞。
- **中心詞**:段的最後一個名詞格(見[需要你決定的](#需要你決定的));去掉段尾數量後取。中心詞是 卡名「…」 整個引號段時記卡名。
- **中心詞類**(封閉表,依中心詞比):卡——モンスター、カード、トークン、チューナー、卡名、X素材/素材、卡種+カード、子類型+モンスター 這類封閉值域複合詞、受事者本身是區域(手札、デッキ、墓地…);屬性——攻撃力/守備力/レベル/ランク/Pスケール/属性/種族/カード名/表示形式/コントロール/位置,與 効果/発動/攻撃/召喚/特殊召喚(跟主人走的事件類);非卡——ダメージ/戦闘ダメージ/効果ダメージ/LP/カウンター/数/コイントス/戦闘/ゾーン,與純數值(０、１０００);指示詞——それ/それら/いずれか/内/対象/残り 這類沒有名詞中心的段;其他——表外。
- **修飾語**:中心詞之前的各格依 の 與讀點切段,每段記字面與類。類的辨識:種族(分詞封閉值域 種族)、屬性(X属性)、字段(引號段後面還有中心詞)、卡片子類型(融合/儀式/S/X/L/P/効果/通常/チューナー/リバース/ユニオン/スピリット/トゥーン/デュアル/ペンデュラム 等封閉值域)、數值(屬性名+比較+數字,含 攻撃力N／守備力N 與 レベルN・N)、區域、玩家(沿用區域辨識)、表示形式(封閉值域)、其他(定語子句 特殊召喚した/効果で特殊召喚した、以外、他の、元々の、残り 等,只留字面)。
- **數量**:段尾的 數字+量詞(枚/体/つ/種類/個/組/回)+(まで/以上),或 任意の数/好きな数/全て/数まで;類是 定數(數字)/上限(數字)/下限(數字;N以上,規格決定 2026-10-31)/任意/全部;引用量(数の分だけ、同じ数)只記字面、類空;それぞれ 不是數量。受事者字面沒有數量、子句裡緊接受事者的 を+數量(手札を１枚捨てる)算該段的數量,記號標「取自子句」;子句裡別的數字(ターン終了時まで、５つ上がる)不算。
- **玩家與區域**:段自己帶的,沿用區域辨識;來源/所在欄切走的區域在這裡仍留一份(片語的值是切之前的)。
- **指示詞**:段以 その/それ/それら/対象の/この効果の対象 起頭時為真;目標照既有回指欄。
- 目的欄用同一結構;推得的目的沒有片語。

**來源/目的/所在的結構化**

- 三欄各多一個結構化值:[(玩家, 區域七值)…] 依字面順序去重,玩家值域 自分/相手/お互い/相對/無;算法就是現有的區域辨識,不另寫。字面認不出區域的(相手、見せたモンスター、0)結構化值空。
- 推得的來源/目的結構化值照字面算,玩家 無。
- **轉欄**(新記號欄,值域 取自來源/取自で):非移動類動作所在空、來源有字面時,所在的結構化值取來源的,標取自來源;で 接區域時所在的結構化值取它、標取自で(兩者都見[需要你決定的](#需要你決定的))。字面所在欄維持空。

**施事者**

- 值域 自分/相手/お互い/此卡/其他卡/空;另一欄記來源(主題/主語/事件主語/によって/預設)與推得旗標。
- 順序:(1)框架自己帶對象(他動,或態空但有對象)時,主題或主語是玩家 → 該玩家;是 このカード(含帶定語的此卡)→ 此卡;是其他卡片片語 → 其他卡。(2)受身框架:によって 片語依[需要你決定的](#需要你決定的)。(3)框架自己是效果類事件(その発動を無効にする 的 発動、その攻撃 的 攻撃)而回指欄記了事件主人時 → 主人的玩家或此卡;一般受事者的回指事件主語(相手がモンスターを特殊召喚した時…そのモンスターを破壊する)說的是目標的來歷,不是本框架的施事者,不用。(4)代價位與效果位、他動、帶對象、以上都沒有 → 自分、標推得;條件位、受身、自動、沒對象的留空。
- 主題延續來的主題(回填 topic)照用,不另標;「この効果は」「このカードの効果は」這類註記主題不是施事者(沿用既有判斷)。

**方式**

- 述語前、同一子句內的 で 片語(含 では/でも 後綴);定語裡的 で(數值或封閉值並列修飾:攻撃力2400以上で守備力1000の、種族で属性の)沿用既有判準不收;〜でなければならない 的 で 是繫詞不收;なしで、ままで 這類記 其他。
- 兩欄:字面與**方式類**(封閉表):手段:效果(効果/この効果/その効果/…の効果)、手段:戰鬥(戦闘/その戦闘/攻撃/…の攻撃)、手段:方法(方法/この方法/…の方法)、表示形式(守備表示/表側表示/裏側守備表示/攻撃表示/表側/裏側/裏側表示/表側攻撃表示/表側守備表示,另帶表示形式值)、視同(扱い)、順序(好きな順番/元の順番/順番)、其他(只記字面)。區域見[需要你決定的](#需要你決定的)。
- 一個框架至多一個方式;同一子句兩個 で 片語時取離述語最近的,另一個不記(子句字面照舊看得到)。

**否定形**

- 極性=否定的框架加封閉類欄(見[需要你決定的](#需要你決定的)):態是受身 → 受身;否則取子句裡述語自己的否定形——にならない/受けない 系 → 不成不受、できない/出来ない/行えない 系 → 不可能、其餘(ず/ない/なく)→ 一般;〜ければならない 不是否定(沿用類別線那張表的判準,搬到框架線後類別線在規格 2 改讀)。極性是肯定/可能的框架不帶此欄。

**回指回填**

- 條件:框架的對象(或受事者位)段是指示詞、回指欄有目標且目標的 place 有值、框架自己沒有來源(移動類)/所在(非移動類)字面、回指的 via 不是事件;目標是非移動類框架(対象とする/選ぶ/選択 這類所在類;回指欄要多記目標的動作詞元或移動類旗標)才接,目標是移動類(特殊召喚、加える、戻す…)不接。
- 動作:把目標的 place(字面)與結構化值寫進本框架的來源(移動類)或所在(非移動類)**結構化值**,字面欄不動;記號進既有的回填欄,值 來源(回指)/所在(回指);蓋過推得的同欄結構化值。跨句號成立;在回指解析之後、所有既有步驟之後跑。
- 全語料候選:對象是指示詞、目標帶區域、框架缺該欄字面的 3,640 框(移動類 2,025、非移動類 1,596;via 欄位 3,245、対象 360);其中目標是非移動類的才會填,實作時報數。

**驗收與報告**

- 字面不變:工具把新鍵剝掉後逐框比對修前的全語料框架檔,差異要 0;分詞鏈決定性重跑相同。
- 封閉類:全語料掃一次,表外值列清單;其他類的中心詞/修飾語列 top 100 進報告。
- 填充率:報告加一節——每個新欄 有值/推得/轉欄/取自子句/其他/空 的框數,分位置;回指回填填了幾框、拒絕幾框(目標是移動類)。
- 編譯試跑:票 02 的工具改讀新中心詞重跑,21 個關鍵詞葉與 9 個目的關鍵詞葉的張數與票 02 的結果比,差異逐葉說明。
- 拆解頁框架表多片語結構(展開式)、施事者、方式、否定形;推得、轉欄、取自子句的格淡色、滑過說明。批次檔同樣列出;照原網址重新發布。
- GLOSSARY:否定形新詞條;數量類值域若加下限同步;方式詞條補 で 接區域的去處;施事者的推導細節補進動作框架第四版論元段;回指回填那段從 session scratchpad 的 diff 併進 GLOSSARY 正文(目前只在地圖 Notes 提到的 diff 檔裡)。ADR-0018 不改。
- 下游四支程式與匯出在本規格**不改**(規格 2 的範圍);類別線那張否定形字面表交件時留著,規格 2 改讀再刪。

**給規格 2 的對照(交件時寫進 handoff)**

- 動作對象:數量字面/選擇類判定 → 數量類;中心詞封閉表 → 中心詞類;區域與玩家 → 結構化來源/所在;此卡/並列含此卡 → 段的中心詞與指示詞(字面規則仍在)。
- 回指:候選的限定語與中心詞比對 → 修飾語類與中心詞;數量 → 數量類。
- 類別線:head_nouns/keyword_in → 中心詞;polarity_class → 否定形;來源當所在 → 轉欄的所在。
- 匯出:每框的欄位就是上面這些結構化值。

## Testing Decisions

- 接縫一個,沿用現有:框架抽取「一句效果句原文(含 ● 項、帶同卡同段上文、可選效果外/卡片子類型)→ 框架清單」,本規格所有新欄位在這裡斷言。類別線、動作對象、回指、匯出的既有測試一條不改、全部照過——它們讀的字面欄沒變,這本身就是「加欄不換值」的測試。
- 好的測試只看輸出框架:動作、位置、極性加本規格的欄(片語各段的中心詞/中心詞類/修飾語類/數量類/玩家/區域/指示詞、來源/目的/所在的結構化值與轉欄記號、施事者與推得旗標、方式類、否定形、回填記號)。不斷言切段的中間狀態、不斷言封閉表的內容本身。
- 每個句型一條回歸例子,修規則前先補一條會失敗的例子;每條規則配反例:定語裡的 で 不是方式、受身的主題不是施事者、條件位不補預設施事者、自動不補、目標是移動類不回填、原文有來源時回指不蓋、それぞれ 不是數量、ターン終了時まで 不是數量、と同じ 不切段、卡名整段是中心詞、数によって 不記施事者。
- 全語料兩個檢查寫成測試:剝新鍵後逐位元組不變(讀修前的凍結檔;沒有檔時略過並印原因,沿用空葉移除票 02 的做法)、新封閉類沒有表外值。
- 先例:`test_frames.py`(283 條,TestInferredValues 的「推得的格當作沒寫」寫法)、`test_categories.py`(154 條)、`test_export.py`(120 條)、空葉移除票 02 的全語料測試。
- 全語料重跑後與修前比對:既有鍵差異 0;新欄只在報告裡看填充率。LLM 抽驗一輪加複檢,存 `llm-check/v4-round1`、`v4-round2`。
