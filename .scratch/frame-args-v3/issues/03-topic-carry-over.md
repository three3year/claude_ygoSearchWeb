# 03 — 主題延續

**What to build:** 站主翻「自分は手札を１枚捨て、デッキから１枚ドローする」時,ドロー 那列的主題是 自分、淡色標回填。子句沒有自己的主題時,沿用同一句內前一個主題,直到句號、新的主題、或一個自己帶 が/は 的條件子句(〜場合/〜時/〜限り 收尾)為止。延續的值記進回填欄(值域多「主題」)。主語不延續。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 回歸例子先補、後修:捨て、ドロー(延續)、句號停、新主題停、條件子句自己的 が 擋住延續(このカードは、相手モンスターが攻撃した場合…)、主語不延續(守備力が０になり、その効果は無効化される 的 無効化 不拿 守備力)、回填欄列出「主題」
- [ ] 全語料重跑:與修前比對,差異只落在主題欄與回填欄;抽查 20 句沒有延續錯;決定性重跑相同
- [ ] 拆解頁延續來的主題淡色、滑過說明是回填,照原網址重新發布;批次檔標出
