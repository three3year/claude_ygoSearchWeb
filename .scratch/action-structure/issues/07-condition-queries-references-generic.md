# 07: 條件查詢、引用與泛用分組

**What to build:** 站主不指定卡、只給條件也能查(「怪獸 牌組 → 特殊召喚」);條件含引用時判得對;只靠泛用物件命中的卡另成一組,可只查這組。

- 只給條件的查詢:卡片總表裡存在一張實卡同時滿足查詢條件與物件條件,化成指定卡的判法。
- 屬性 比較 引用(等級 = 物件1.階級);卡名 ∈ 範圍(No.101～No.107);引用時在被引用物件的候選卡裡找得到一組讓全部條件成立即可。
- S/X/L/融合召喚是特殊召喚的下位,查「特殊召喚」含它們。
- 泛用物件:條件式除大類、位置、控制方外沒有任何條件;結果分特定、泛用、全部三組。
