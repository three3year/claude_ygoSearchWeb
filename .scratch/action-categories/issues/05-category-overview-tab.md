# 05 — 類別總覽分頁

**What to build:** 檢視 artifact 新增「類別總覽」分頁:整棵樹可展開,每節點顯示框架數與卡數(大類與詞元層由葉彙總,多葉框架在大類只算一次);點一個葉列出它的框架(卡號、卡名、子句字面),點一條跳到那張卡的拆解;未歸類框架依詞元聚合另列;頁首儀表板顯示已歸/未歸/不適用三個數與已歸比例。站主能從類別走到卡,也能看到規則的盲區在哪些詞元。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 樹狀展開、節點計數、點葉列框架、點框架跳卡、未歸類依詞元聚合、儀表板。
