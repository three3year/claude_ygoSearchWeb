# 卡文詞彙表

卡片文本用語的日→中逐條對照,收**譯詞**與**句式模板**兩類條目。用途:
AI 翻譯新卡時的參照規範、人工翻譯與審查的查閱手冊、驗證腳本比對譯文
一致性的依據;未來供網站前端顯示。

與《文本格式規範》(`docs/text_format_guide.md`)的分工:**逐條對照歸本表,
結構規則(標點、語序、換行、圈號體例)歸格式規範**。審查中長出的新裁示
照此歸檔;本表條目變動以「審查批改」commit,慣例同格式規範。

## 體例

譯詞條目欄位:

| 欄 | 說明 |
|---|---|
| 日文 | 官方日文卡文的原詞 |
| 規範譯法 | 本站正式譯法,唯一 |
| 禁譯 | 不得使用的譯法(曾見或易誤之寫法),分號分隔;無則留 `—` |
| 庫內計數 | 佐證張數,母體為含①新式段(與歷批審查檔慣例一致);格式「規範 N / 禁譯 M」或單數字 |
| PSCT | TCG 對應詞,選填 |
| 例外 | 裁示「不用修」的卡片密碼清單,逗號分隔,各附一句理由於備註;無則 `—` |
| 備註 | 出處、來源層級、例外理由等 |

句式模板條目欄位同上,但「日文樣式」「中文樣式」兩欄寫**帶佔位符的樣式**;
譯詞條目的欄位在需要時也可帶佔位符(如「抽〈n〉張卡」):

- `〈n〉` = 半形數字(本表樣式一律以半形書寫;機器比對時半形全形皆容許
  ——日文側官方卡文用全形,寬窄之辨歸《文本格式規範》§2,不歸本表)
- `〜` = 任意內文(同句內,不跨句號)

驗證腳本(報告式,不阻擋建置)依本表比對譯文:日文側命中而中文側未照
規範(或用了禁譯)即列入報告;「例外」欄所列卡片自動跳過。樣式到機器
比對規則的推導由腳本定義,本表只維護人讀的樣式。
