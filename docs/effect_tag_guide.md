# 效果 Tag 判定規範

體系定稿:2026-09-20 凍結(裁定紀錄 `.scratch/effect-tag/rulings.md`,票03–06);
2026-09-21 站主覆核裁定票15 增補 LP支付/LP失去 兩類(支付/失去/傷害三分)。
機器正本為 `script/web/vocab.py` 的 tag 值域(seal 對帳 `tag_digest`);本文件是
人讀正本,供判定票的批次檔引用。**追加類別、增刪槽位值、改邊界通則,一律需新
裁定票**;判定票只選 tag、不改體系。

判定基礎一律是**日文原文**(`text_ja`):tag 是對效果語意的結構化標注,繁中譯文
經過翻譯會失真(與效果類型判別規範 §0 同一條理由)。

## 0. 標的與範圍

- 標的是[[效果句]]:一句 0..N 個動作 tag(多動作句逐動作貼),外加誘發系句子
  的[[觸發時機]]單值。
- 範圍:新式卡文效果句(index 帶①編號、kind 非效果外文本)。舊文卡效果句於
  體系穩定後另期補判。已開貼類別:區域移動+觸發時機(第1期)、破壞+無效
  (第2期,票16)、攻守調整+效果傷害+生命回復+LP支付+LP失去(第3期,
  票17)、行動限制+耐性/保護(第4期,票18)。
- 條件與否定不貼:「〜できない/されない」歸行動限制/耐性;「〜した場合」「〜
  する場合」「〜する度に」是觸發或條件描述,不是動作;「●…する効果」這種
  **描述別的效果**的句段也不是動作。

## 1. 通用槽位

- **位置**(`pos`):`成本` / `效果`。**發動子句**(以「〜発動できる/発動する」
  收尾的第一句)裡的付出貼 `成本`;處理段的動作貼 `效果`。**無發動子句的句子
  (自我特召程序、永續/場地魔法的處理、●選項的領起句以外部分)一律貼 `效果`**
  ——位置只在有發動子句時區分。未拆的 ● 選項列舉裡各選項自帶「〜して発動
  できる」的,那個付出照樣是 `成本`。**代替處置**(「代わりに〜」)一律貼
  `效果`,不論替代的是代價還是破壞。**唯一不設位置槽位的類別是 LP支付**
  (裁定票15):支付本身就是代價,位置軸對它無意義,搜尋一律命中。
- **對象方**(`side`):`自身`(此卡自己)/ `我方` / `對手` / `雙方`。**判得準
  才填,不猜**;槽位缺值代表未標注,不代表「無」。

## 2. 動作類別(21 類)

### 區域移動(第1期已開貼)

卡片從一個區域到另一個區域。槽位:`from` / `to` ∈ {手牌, 牌組, 額外牌組, 墓地,
除外, 場上, 靈擺區} + `side` + `pos`。

- 慣用名對照(顯示層):蘇生=墓地→場上;檢索=牌組→手牌;回收=墓地→手牌;
  彈回=場上→手牌|牌組;送墓=任意→墓地;展開=手牌|牌組|額外→場上。
- 牌組頂/底不獨立(歸「牌組」);**牌組內位移**(「デッキの一番上に置く」而
  來源也是牌組)貼 `{to: 牌組}` 不填起點。
- 靈擺區放置(「Pゾーンに置く」)歸本類;起點/終點可為 `靈擺區`。
- 複合起點(「手札・墓地から」「デッキ・EXデッキから」)**逐起點各貼一個 tag**。
- 對象在發動子句、動作在處理段(「墓地の…を対象として発動できる。その
  モンスターを特殊召喚する」)照對象的區域填起點。
- 起點不明(「そのカードを手札に戻す」來源多可能)只填終點。
- 衍生物生成(トークン特殊召喚)貼 `{to: 場上}` 無起點。
- 場內身分/區位變動(罠モンスター「モンスターゾーンに特殊召喚する」、魔陷區
  ⇄怪獸區)貼 `{to: 場上}`、起點留空。
- **不貼**:通常召喚的解放手順(「リリースして召喚する事もできる」)、儀式/
  融合召喚的執行本身(歸召喚執行)、「魔法カード扱いで…セット/置く」(歸
  放置轉換)、X 素材的取除與重疊(不建模)、被動未來式(「〜された場合に除外
  される」的自我除外附註)。

### 抽牌/手牌交換

抽卡(不指定卡)。`side`、`extra` ∈ {捨棄, 回牌組}、`pos`。「抽1捨1」一個 tag
帶附帶槽位;「デッキから選んで加える」是檢索,歸區域移動。

### 無效(第2期已開貼)

`what` ∈ {發動, 效果, 持續無效化};`extra` ∈ {破壞, 除外}。細則(票16):

- **三分照句形**:「発動を無効に」→發動;「効果を無効に」(を形)→效果——
  含對場上卡的「ターン終了時まで無効にする」一次性壓制;「効果は/が
  無効化される」(される形)→持續無效化;「効果を無効にして特殊召喚/
  セット」(召喚修飾形,被召喚者即被封效者)→持續無效化。
- **附帶處置**:「無効にし(、/て)破壊/除外」記 `extra`;**同句另貼破壞/
  區域移動 tag**——附帶處置也是動作(第1期 mv 對附帶除外的先例)。條件式
  追加處置(「さらに…破壊できる」)不記 `extra`,只另貼該類。
- 召喚・特殊召喚無效:值域無召喚值,`what` 缺值只貼類別;附帶破壞照記
  `extra`。攻擊無效(「攻撃を無効にする」)同樣貼本類、`what` 缺值。
- 「無効にした場合」是觸發條件不貼;「無効化されない/にされない」歸耐性。

### 破壞(第2期已開貼)

效果破壞。`what` ∈ {怪獸, 魔陷, 卡};`scope` ∈ {單體, 複數, 全體};`side`、
`pos`。細則(票16):

- 戰鬥破壞是狀態不貼;「(破壊される場合、)代わりに破壊」歸耐性(代替
  破壞)——**「リリースの代わりに破壊」是召喚代價的替代,是真破壞動作,
  照貼**。
- 「無効にし破壊」的破壞面照貼:`scope` 單體,`what` 依被無效者(魔法・罠
  →魔陷、怪獸效果→怪獸、混合列舉→卡)。
- 多對象指定**逐對象各貼**(「Aと B１枚を対象…破壊」→兩個 tag);單一指定
  涵蓋複數張(「２枚まで」「数だけ」)記 `複數`,「全て」記 `全體`;寫死
  1 張記 `單體`。
- 區帶定義的種類照語意:「魔法＆罠ゾーンのカード」「フィールドゾーンの
  カード」「宣言した種類(魔法・罠)のカード」=魔陷。手牌破壞照貼
  (「手札をランダムに１枚選んで破壊」= 卡)。
- 「(効果で)破壊するモンスター/カードを…選ぶ」是選擇範圍的修飾,不是
  破壞動作。

### 行動限制(第4期已開貼)

禁止/限制行動。`what` ∈ {特殊召喚, 發動效果, 攻擊, 表示形式, 其他};`side`
(受限方,自限=我方);`term` ∈ {持續, 單回合}。細則(票18):

- **召喚面三分**:P/S/X/リンク/融合/儀式召喚できない=特殊召喚(召喚法
  特定形,時機 TM2 同構);通常召喚/アドバンス召喚=其他;「召喚・特殊
  召喚できない」兩面各貼。值域無對應保護值的「リリース/素材に/セット
  できない」「〜召喚にしか使用できない」歸本類 `其他`。
- **強制攻擊**(「攻撃しなければならない」)= `攻擊`;「直接攻撃
  できない」「攻撃対象に選択できない」歸戰鬥規則(批2)。
- **通行費**「払わなければ〜できない」的 できない 面照貼本類(支付面歸
  LP支付,兩面各自成立)。
- **term 照句內錨形填**:このターン/そのターン/ターン終了時まで(前面非
  次の/相手/自分)/発動する・したターン=單回合;存在する限り=持續
  (「〜ない限り」是條件不填);「次の〜まで」「〜する間」等其餘寫法留空。
- **不貼**:修飾形(「通常召喚できないモンスター」,できない後接名詞或
  卡名引號)、效果自身的使用條件(「この効果は…にしか発動できない」
  「このカード名のこの効果は１ターンに１度しか使用できない」「ダメージ
  ステップでは発動できない」)、效果處理的選擇限制(「この効果で〜しか
  特殊召喚できない」)、存在限制(「1体しか表側表示で存在できない」歸
  「其他」類別)。
- 發動子句括弧內的誓約(「(この効果を発動するターン、〜できない)」)
  在規則層管轄外,由長尾判定照貼 `pos: 效果`。

### 耐性/保護(第4期已開貼)

`what` ∈ {戰鬥破壞, 效果破壞, 效果對象, 除外, 全效果, 代替破壞};`side`。
邊界:「攻撃できない」→行動限制;「攻撃対象にならない」→戰鬥規則;「効果の
対象にならない/受けない」→本類。細則(票18):

- **能動否定形同義照貼**:「(効果の)対象にできない」「除外できない」與
  「にならない/されない」同義,照對應 `what` 值貼本類(主語是行動者也
  一樣——批2 的行動者切分只適用攻擊家族)。
- 合記「戦闘・効果では破壊されない」戰鬥/效果**兩面各貼**;「効果を
  受けない」不論限定範圍一律 `全效果`;代替破壞=「破壊される場合、
  代わりに〜」(替代處置照貼其動作類別)。
- **無效化保護**(「無効化されない/無効にされない・できない」,含
  「召喚は無効化されない」)值域無對應值,`what` 缺值只貼類別。
- **不貼**:「(この効果でこのカードは破壊されない)」處理註記、「この
  カード名のこの効果で…除外できない」自我成本限制、發動子句裡的觸發
  敘述(「破壊されず…受けた場合に発動する」)。
- **side 錨**:このカード=自身;自分フィールド/墓地の〜=我方;「お互い」
  與無主語「フィールドの〜」明示兩面=雙方;相對指涉(その/対象の/装備
  モンスター)與無場所錨泛稱留空。

### 攻守調整(第3期已開貼)

`item` ∈ {攻擊, 守備, 攻守};`dir` ∈ {上升, 下降, 變成}。「〜になる」句型
(倍化、減半、變 0、指定值)一律「變成」;「アップ/ダウン」歸上升/下降。
細則(票17):

- 合記「攻撃力・守備力」貼 `攻守`,單獨各寫(「攻撃力は…アップし、守備力は
  …ダウン」)逐項各貼;或格(「アップ、またはダウン」)升降都貼。
- 「攻撃力・守備力を入れ替える」= `攻守`×`變成`。
- **修飾形不貼**:「攻撃力２０００アップの装備魔法カード扱いで装備」的數值
  增減是被賦予效果的描述,動作歸放置轉換(與破壞「選ぶ」修飾同理)。
- 「アップしている場合」「アップする効果」等條件/描述形不是動作。

### 效果傷害/生命回復(第3期已開貼)

`side`(承受方/回復方)、`form` ∈ {固定值, 參照值, 比例}(固定值=寫死數字;
參照值=由遊戲值導出,含「×N」「〜分」「〜の半分」;比例=LP 本身的比例)。
細則(票17):

- **戰鬥傷害一律不是效果傷害**:貫通句(「守備力を攻撃力が超えた分だけ戦闘
  ダメージを与える」)歸戰鬥規則;「戦闘ダメージは倍/０になる」修飾歸
  「其他」。傷害歸零/減半(「受けるダメージを０にする」)是傷害修飾,歸
  「其他」不貼本類。
- 承受方寫「そのコントローラー」「コントローラーから見て相手」等相對指涉
  時 `side` 留空;「自分か相手」二擇同樣留空。
- 適用他卡效果面(「ダメージを受ける方/LPを回復する方の効果を適用する」)
  貼本類、槽位留空。
- LP 的四分:給傷害=效果傷害、回復=生命回復、付代價=LP支付、失去=
  LP失去(裁定票15)。

### LP支付/LP失去(裁定票15 增補;第3期已開貼)

- **LP支付**:玩家把 LP 當代價主動付出(「LPを払う」,含全形「ＬＰ」寫法;
  發動代價與維持代價都算)。槽位:`side`(支付方)、`form` ∈ {固定值, 參照值,
  比例}(「８００LPを払い」=固定值;「攻撃力分のLPを払う」=參照值;「LPを
  半分払って」=比例)。**不設「位置」槽位**(見 §1)。細則(票17):
  - 發動代價的支付方恆為發動者(=我方);「任意の倍数のLPを払う」自選額度
    `form` 留空;「NLPになるようにLPを払う」= 參照值。
  - **通行費/維持形照貼**:「相手はNLPを払わなければ〜できない」(側=對手)、
    「〜毎にNLPを払う」、「払う事ができる」選擇性支付、自我特召程序的
    「NLPを払って特殊召喚できる」都算支付。支付方相對(「コントローラーは」)
    時 `side` 留空。
  - **觸發敘述判空**:「LPを払った場合に発動できる」「相手がLPを払って…
    発動する度に」「払う場合、代わりに〜」引用的是別的支付,不貼。
- **LP失去**:效果使玩家失去 LP(「LPを失う」)。規則上**不是傷害**——不受
  傷害相關的防止/換算效果影響,故與效果傷害分立。槽位:`side`、`form`、`pos`。
- 邊界:
  - 「発動するために払うLPが必要なくなる」(支付免除)不是支付動作,不貼
    本類,歸「其他」。
  - 「LPが半分になる」等 LP 直接改寫句型量少,暫歸「其他」,累積後再裁。
  - 「ダメージを与える/受ける」歸效果傷害;「LPを回復する」歸生命回復。

### 表示形式變更(第5期已開貼)

`to` ∈ {攻擊表示, 守備表示, 裡側表示};自由變更(「表示形式を変更する」)
`to` 留空;`side`。細則(票19):

- **to 映射照字面**:裏側守備表示/裏側表示=裡側表示;表側守備表示/守備
  表示=守備表示;表側攻撃表示/攻撃表示=攻擊表示。或格「表側攻撃表示か/
  または〜表示にする」兩面各貼;單獨「表側表示にする」結果未指明,to 留空。
- **に/で 粒子切分**:「守備表示で特殊召喚/セット」是召喚時表示指定,歸
  區域移動不貼本類;「表示形式が変更された」觸發、「守備表示になった」
  完成形非動作;「表示形式を変更できない」歸行動限制。

### 控制權轉移(第5期已開貼)

`dir` ∈ {取得, 移交}。細則(票19):「コントロールを得る」=取得(「得る事が
できる」選擇性動作照貼);「相手に移す」=移交;「入れ替える」互換=取得+
移交兩向各貼;「元々の持ち主に戻る」方向隨局面,`dir` 留空;「得た」完成/
修飾形與「移った」觸發形非動作。

### 性質變更(第5期已開貼)

`item` ∈ {卡名, 種族, 屬性, 等級, 階級, 刻度};`term` ∈ {持續, 單回合}
(錨形同行動限制:存在する限り=持續、このターン/ターン終了時まで=單回合、
跨回合形留空)。「〜として扱う」「〜になる」都算;攻守數值歸攻守調整。
細則(票19):

- 具名引號形(「「X」モンスター/カードとして扱う」)與被召喚者的卡名視同
  =卡名;「レベルを N として扱う」素材時等級視同=等級;值域外的扱う形
  (チューナー/通常モンスターとして扱う)`item` 缺值只貼類別。
- 合記兩面各貼:「種族・属性になる」、「レベル・/またはランクを上げる」。
- **不貼**:「(〜としては扱わない)」括弧註記、「として扱う効果を持つ〜」
  修飾、「元々の〜」「レベル・ランクの合計/によって/×N」參照形、否定形。

### 計數器操作(第5期已開貼)

`act` ∈ {放置, 去除};計數器種類不建模。細則(票19):「移す」=去除+放置
兩面各貼;程序費用(「取り除いて特殊召喚できる」)與代替破壞附帶去除照貼;
「X素材を取り除く」不是計數器;「置く事ができるカード」參照形與「置かれた
場合」觸發形非動作。

### 放置轉換

以改變後的身分被放置(當作裝備卡/永續魔法/永續陷阱/魔陷覆蓋)。`to` ∈
{裝備卡, 永續魔法, 永續陷阱, 魔陷覆蓋}。目的地是身分改變者歸此類——唯一
例外:靈擺區歸區域移動。

### 素材代用/召喚放寬/召喚執行/戰鬥規則/情報操作/其他

- 素材代用/召喚放寬:代替素材、無視召喚條件、追加召喚權。
- 召喚執行:魔陷卡上的召喚指令;`method` ∈ {儀式, 融合, 同步, 超量, 連結}。
- 戰鬥規則:`what` ∈ {貫通, 連續攻擊, 直接攻擊, 攻擊對象操作}(含許可與禁止)。
- 情報操作:`what` ∈ {確認, 展示, 隨機決定}。手牌妨害=區域移動+隨機決定兩個 tag。
- 其他:跳過階段、縱列操作、硬幣/骰子、戰鬥傷害修飾等,暫不細分。

## 3. 觸發時機(句層單值)

僅誘發系承載類型(誘發即時效果(2速)、誘發效果(1速)、魔陷卡效果十值)、且
發動子句帶觸發事件的句子。值域 17 值(見 vocab);「被破壞時」不分戰鬥/效果;
同句多個時機取**最先寫出的**;判不進 16 個具名值的貼「其他」。

## 4. 判定產出與來歷

- tag 物件:`{"cat": …, 槽位…, "pos": …, "src": "llm", "ticket": 票號}`。
- 判過某類別但**該句無該類動作**時,tag 給空、由收票程序把類別記進
  `tags_checked`(判空紀錄;seal 的零空缺讀它)。
- 規則直貼的 tag(`src: "rule"`)每次重跑重算;LLM/manual 的 tag 一經寫入
  照 ADR-0002 的保留規則,修正走 rejudge。
- 規則層的粗篩(候選圈選)與規則定義見 `script/tag_card/tag_rules.py` 與
  `docs/effect_tag_rules.md`;粗篩漏網是已接受的殘餘風險(ADR-0013)。

## 5. 逃生口

判不出、或句型落在本規範沒有涵蓋的形狀時:tag 留空、寫 `note`,不猜。累積的
懸案由裁定票收割——與效果類型線的規範演進同一條路。
