# 審查檔:卡文詞彙表初始建表(高頻萃取+散落裁示收編)

text-glossary 票02 產出。**此檔是審查檔,不入表**——站主逐條審查、放行的條目
才寫入 `docs/text_glossary.md`,依慣例只在站主明說 commit 才提交。

## 審查動線

- 逐條審:每條末行「**審查**」處標記 **放行** / **退回**(退回請加批註說明)。
- 退回條目修正後**同檔更新**再審;放行的條目入表,退回即刪、不入表。
- 條目格式:標題行「日文 → 建議譯法」(句式條目為帶佔位符樣式),下列
  **禁譯候選**(括號內為庫內計數,0 即庫內未見、屬「易誤」預防性候選)、
  **計數**(規範譯法命中張數)、**PSCT**(選填)、**備註**、**審查**。
- 已由歷批審查裁示過的條目標「**收編**」並註出處,審查時只確認入表形。

## 萃取方法與計數母體

- **萃取語料**:三級分類「新格式新卡」層 7,818 張/8,156 段的中日句對照
  24,601 句(效果標記表 `data/tag_cards.json`,2026-08-24 版控快照)。
  以片假名詞與 3〜8 字 n-gram 依張數排序初篩,人工歸併成詞條後逐條驗證。
- **計數母體**:**含①新式段**(全庫 text_zh 帶①編號的段,9,765 張/28,339
  句),沿歷批審查檔慣例(review-41-monster-01「規範未載句型以含①卡全庫
  計數定寫法」同一母體)。計數單位為**張**(一卡命中多句仍計 1)。
- **比對方式**:日文側子字串/樣式命中的卡,分別數中文側「規範譯法命中」
  「禁譯候選命中」「兩者皆未命中」;第三類逐卡人工抽看,確屬既有譯文
  不一致者記入文末附錄(勘誤候選,本票僅記錄不處理)。
- **門檻**:≥20 張(票02 建議值);計數低於門檻但屬歷批裁示收編者照收。
- 高頻但屬**卡名/系列名**的片假名詞(シャドール、オッドアイズ等)不入表
  ——卡名歸 §3.19 的「沿用庫內既有譯名」原則,非詞彙表對象。
