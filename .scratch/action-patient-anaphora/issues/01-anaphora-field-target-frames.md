# 01: 回指欄打通:対象の 與 対象とする 的目標

**What to build:** 站主打開拆解頁,就能看到最常見句型的指示詞指向哪個目標。「フィールドのモンスター１体を対象として発動できる。そのモンスターを破壊する」的 そのモンスター 帶回指:字面「モンスター１体」、區域 フィールド;「このカードを特殊召喚し、対象のモンスターをデッキに戻す」的 対象のモンスター 指 対象とする 那個框架,不是此卡。來源:spec「第一階段」。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 動作框架多一個可選的回指欄,值是目標的字面、區域、玩家,找不到就省略;框架欄位文件補上。
