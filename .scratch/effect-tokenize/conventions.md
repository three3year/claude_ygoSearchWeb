## 一、第一版切分慣例(已實作)

### 1. NAME:「」括住的卡名/字段引用

「…」整團收斂成一個 NAME token,帶原文(`NAME:青眼の白龍`);引號可巢狀
(「道化の一座『下稽古』」整團是一個 NAME)。模板統計時 NAME 收斂成佔位
——「サイバー・ドラゴン」と「ブラック・マジシャン」的同句型卡落同一模板。
『』在語料中只出現於卡名內部(隨 NAME 吸收),獨立出現時暫當句讀邊界處理
(見裁定點 R11)。

### 2. NUM:數字 → NUM token(帶正規化數值)

- 半形/全形數字串(１０００、3000)→ `NUM:1000`(全形→半形)
- 漢數字(一〜十)**僅在後接量詞時**轉 NUM(「一組」的 組 不在量詞集合,
  不轉——見裁定點 R10)
- NUM 後緊接的量詞(つ/体/枚/度/回)獨立成量詞 token(`c:体`)——
  「１体」=`NUM:1`+`c:体`,票面的「數字部分→NUM」照辦

### 3. 助詞:獨立 token(封閉類,不占詞典 ID)

票面清單:に/で/を/は/が/と/の/へ/も/から/まで/より/や/など。
實作追加四個(萃取與分詞兩端同套):

- **として**——不拆成 と+して(して 會變 OOV 殘渣);「〜を対象として」
  「〜として扱う」都切出完整助詞
- **または/及び**——並列接續詞,黏著兩個內容詞(手札または自分、
  デッキ及び相手),比照助詞切開
- **しか**——係助詞,「１枚しか発動できない」高頻句型的骨架

助詞匹配有 OOV 保護:OOV 段開著且尾字是平假名時不切助詞(活用殘尾
「〜し**て**」的 て 不可誤判成助詞)。

### 4. 句讀與圈號:邊界

- 。、：・（）『』／ **留在 token 序列裡但不編 ID**——句讀是句型模板的
  結構訊號(「発動できる。〜する。」的兩段結構靠 。 保住)
- 圈號(①②…)、●、空白:靜默剝除;段首「①：」的冒號一併剝(段落索引,
  不是句子內容)
- ・ 當並列邊界(魔法・罠カード → 魔法/・/罠カード),「攻撃力・守備力」
  同法

### 5. 詞典最長匹配+OOV 合併

- 每個位置依序嘗試:NAME → 邊界 → NUM → 詞典最長匹配(同長依碼位,
  決定性)→ 助詞 → OOV 累積
- 匹配不到的連續字元合併成一個 OOV token(`?:岩石族`),邊界與任何命中
  都會把 OOV 段收掉——OOV 段天然不跨句讀

### 6. 可能形:できる/できない 獨立 token(暫行)

詞典終篩把「〜できる」複合形剝掉(詞幹已獨立在表者),所以
「発動できる」=`発動`+`できる` 兩個 token。純平假名功能詞白名單:
する/した/され/される/されない/されず/できる/できない/できず/なる/ない。

### 7. 詞典萃取慣例(extract_seed.py)

- tag_rules regex:元字符當片段邊界;群組交替(`送(る|り|って)`)與字元類
  (`戻[すし]`)做前綴接合還原活用形;負向環視 `(?!…)` 不接合(排除語境
  不是詞彙);交替支內出現字面中斷(・、數字)時接合作廢
- glossary:只收表頭「日文/日文樣式」的兩張表第一欄,剝佔位符
  (〈n〉/〈時點〉/〜)與 ≠ 護欄
- 兩源片段統一過助詞切分+過濾:純平假名只留白名單、tag_rules 片段長度
  ≥2(glossary 放寬到站主親核的單漢字:払/戻/体/枚/度)、純 ASCII 只留
  LP、尾端單字助詞剝除、黑名單擋 regex 斷頭殘渣(う事/る場合/半分払…)

## 二、【裁定點】清單(附語料實例)

> 現狀=第一版實作的切法;量化數字出自 report.md(效果句 stratum)。

### R1 複合移動動詞:「墓地へ送る」切 墓地/へ/送る,還是整詞?

現狀照助詞獨立慣例切成三段(詞典有 送る/送り/送られた 等活用形)。
整詞派的理由:「墓地へ送る」是遊戲術語單元(PSCT 的 send),切開後
「送る」單獨出現沒有意義。切開派的理由:與「手札に戻す」「デッキに戻す」
共用 戻す,詞典省一半、模板對仗工整。

- `64865` デッキからサイバース族モンスター１体を**墓地へ送る**。
- `59080` 「マギストス」カード１枚を**墓地へ送るか**、魔力カウンターを…

### R2 サ変動詞+する:拆不拆?

現狀**不一致**(regex 萃出什麼就是什麼):詞典同時有「特殊召喚」與
「特殊召喚する」,最長匹配吞成一個 token;但「発動する」被終篩拆成
発動+する(只拆了 できる 家族的複合,する 家族沒拆)。建議裁定一律拆
(特殊召喚/する 兩 token,と できる 對稱)或一律合,拆比較利於模板收斂。

- `9113513` …１体をEXデッキから**融合召喚する**。(現為一個 token)
- `2519690` その相手モンスターの表示形式を**変更する**。(現為一個 token)

### R3 可能形 できる/できない:獨立 token(現狀),確認或推翻

現狀「発動できる」=発動+できる。對模板收斂有利(動作與可能性正交),
已依此終篩詞典。請確認。

- `4280258` 「召命の神弓－アポロウーサ」は自分フィールドに１枚しか表側表示で存在**できない**。

### R4 〜場合/〜時:併前詞還是獨立?

現狀混合粒度:詞典有 場合/した場合/された場合/た場合/した時/た時…,
「攻撃した場合」切成 攻撃+した場合、「行う場合」切成 行う+場合——同是
條件節,兩種形狀。裁定方向:(a) 一律 動詞+場合 兩 token(把 した場合 等
複合從詞典剝掉,した 另立);(b) 照現狀混合。

- `7171149` このカードが守備表示モンスターを**攻撃した場合**、…
- `1528054` このカードがモンスターと戦闘を**行う場合**、…

### R5 指示詞 この/その:複合詞條還是獨立 token?【已裁定,見文末追記】

現狀:このカード/このカード名/この効果/そのモンスター/そのターン 等高頻
複合是整詞;但裸「その+其他名詞」落 OOV(その 1,521 次=效果句第 3 高頻
OOV)。裁定方向:(a) 指示詞獨立成封閉類(この/その/それら/同じ?),詞典
剝掉複合;(b) 照現狀,把 その融合モンスター 這類缺口逐一補詞。(a) 模板
更齊整,但「このカード」(自指)與「そのカード」(回指)的語意差異會
退到助詞層之後才看得到。

- `9113513` …**その**融合モンスター１体をEXデッキから融合召喚する。
- `2405631` …**その一組**を特殊召喚できる。

### R6 種族/屬性/階級詞彙:封閉類入典

現狀 OOV 大宗:ドラゴン族 326/機械族 288/戦士族 218…、闇 380/光 340/
水 245…。且有**最長匹配誤切**:魔法使い族 被詞典的「魔法」搶頭,切成
魔法+使い族(OOV「使い族」198 次)。種族(25 種)/屬性(7 種)/
「レベル○/ランク○」是官方枚舉值,建議直接當封閉類補進詞典,魔法使い族
須整詞收錄壓過「魔法」。

- `59080` ●自分の手札・EXデッキ（表側）・墓地から**魔法使い族**モンスター１体を特殊召喚する。
- `42143067` ①:手札から**岩石族**モンスター１体を捨てて発動できる。

### R7 副助詞擴充:だけ/ずつ 比照 しか?

しか 已追加為助詞(高頻句型骨架);だけ(291 次)/ずつ(172 次)現落
OOV。同為副助詞,建議一併收進封閉類。

- `284224` …それぞれ１ターンに１度**だけ**戦闘では破壊されない。
- `86238081` このカードは１度のバトルフェイズ中に２回攻撃できる。(ずつ 同族例:１体**ずつ**)

### R8 では:拆 で+は(現狀)還是複合助詞?

現狀「戦闘では破壊されない」→ 戦闘/[で]/[は]/破壊されない(兩個助詞
token)。拆法資訊無損;合成 では 則模板短一格。輕量裁定。

- `2129638` このカードは戦闘**では**破壊されない。

### R9 縮寫並列:融合・S・X・リンク召喚 的 S/X

現狀 S/X 單字落 OOV(S 250 次/X 213 次)——詞典只有 S召喚/X召喚 複合,
「・」並列裡的縮寫接不上。裁定:S/X/P/L/A 等召喚縮寫(與 S素材 這類)
是否獨立入典(單字 ASCII 目前被過濾規則擋掉)。

- `6203182` ③:装備モンスターが融合・**S**・**X**・リンク召喚の素材になった事で…

### R10 漢數字與量詞集合

現狀漢數字只在後接 つ/体/枚/度/回 時轉 NUM;「一組」「一番上」不轉
(一番上 已是詞典整詞;一組 落 OOV)。裁定:量詞集合要不要擴
(組/種類/回分…),或漢數字一律轉 NUM。

- `2405631` …素材としたモンスター**一組**が自分の墓地に揃っていれば、…

### R11 『』引用

語料中『』只出現在卡名「」內部(隨 NAME 整團吸收),未見獨立使用;現狀
獨立出現時當句讀邊界、內文照常分詞。維持或另訂,無急迫性。

- `20448151` デッキから「道化の一座『下稽古』」以外の…(NAME 內部,已處理)

### R12 活用尾與輕動詞殘渣:た/て/し/ている/選んで

現狀效果句 OOV 前十名過半是活用尾:た 2,365/て 1,679/る 673/し 578/
して 512/ている 230——以及帶活用的常用動詞 選んで 1,129/選び 309。
裁定方向:(a) 比照 する/できる 白名單,把高頻活用尾收成功能詞封閉類;
(b) 高頻動詞(選ぶ/持つ/含む/除く…)以活用形窮舉補詞典(受控語言活用
形有限,窮舉可行);(c) 都做。這批佔 OOV token 的大頭,是 OOV 率從 7.4%
往下走的主要槓桿。

- `44818` …「ホーリーナイツ」魔法・罠カード１枚を**選んで**自分フィールドにセットする。
- `42143067` 手札から岩石族モンスター１体を**捨てて**発動できる。(捨て+OOV て)

## 三、裁定追記

### R5 定案(2026-10-01 站主裁定)

三段式規則,模板**不收斂**:

1. **この/その+已收入詞 → 指示綁定 token**(`d:この:W0123` 一個 token,
   顯示如 このカード)。模板統計保留詞身份——そのモンスター 與 そのカード
   是兩個模板(對照 NAME/NUM 的收斂:指示綁定不收斂,動作對象直接從模板
   讀得到)。指示詞屬封閉類,不占詞典 ID,無 ID 重編問題。
2. **その後 整詞保留**(「後」單字不在詞典的例外)。
3. **接不上詞典詞的裸指示詞照舊落 OOV**(そのまま 等整段 OOV),浮在
   OOV 表上供後續裁定。

詞典剝除的複合詞條(餘詞皆已在表):このカード/このカード名/このターン/
この効果/そのカード/そのターン/そのモンスター/その効果/その攻撃/その発動。
剝除條件帶保險:餘詞不在表內時保留複合,避免剝了反而製造 OOV。

### 比較詞定案(2026-10-01 站主裁定,源自 OOV 檢視)

以下/以上/未満 依前接環境二分,「レベル７以下」整團一格、「以下の効果」
另一格:

1. **屬性約束**(數字無量詞):前詞+數字+比較詞綁成一個 `q:` token——
   `レベル〈n〉以下`、`攻撃力〈n〉以上`。前詞須是緊鄰的詞典詞
   (語料實證:無量詞形的前詞就是 レベル/ランク/リンク/攻撃力/守備力
   這批屬性名)。
2. **個數約束**(數字帶量詞):數字+量詞+比較詞綁一格、名詞不綁——
   `モンスター|が|〈n〉体以上`(名詞隔著助詞,個數約束自成一格)。
3. **回指用法**(接不上數量):以下/以上/未満 獨立詞典詞(manual 來源)
   ——「以下の効果を得る」的 以下 另一格。

模板統計:數值收斂成 n(與 NUM 同),前詞/量詞/比較詞身份保留——
レベル〈n〉以下 與 ランク〈n〉以下 是兩個模板。

### 計數器名定案(2026-10-01 站主裁定,源自檢視)

計數器名是開放詞彙(魔力/捕食/糾罪/壊獣…213 種),比照〈卡名〉**收斂**:

1. **〈名〉+カウンター → 計數器名 token**(`k:魔力` 一格,顯示
   〈魔力〉カウンター);模板收斂成 〈名〉カウンター——名字收進 token
   屬性,例句層看得到。名的回折範圍:緊鄰的 OOV 段尾端非平假名連續段,
   或緊鄰的詞典詞(活用殘尾不綁進名字)。
2. **カウンター罠(反擊陷阱)整詞入典**(manual),同字異義不觸發綁定。
3. **裸 カウンター**(回指「そのカウンター」「カウンターが置かれている」
   等)照舊詞典詞/指示綁定。

### 屬性定案(2026-10-01 站主裁定,源自檢視)

屬性是七值封閉集合(闇/光/地/水/炎/風/神),**不收斂**(與指示綁定同,
各屬性各自成模板):

1. **屬性字+属性 → 屬性 token**(`a:闇` 一格,顯示 闇属性)。
2. **属性モンスター 複合詞條拆除**——闇属性モンスター → 闇属性|モンスター,
   裸 属性(「その属性」「属性を宣言」)照舊詞典詞。
3. **列舉前項的裸屬性字**(「光・闇属性」的 光)照舊落 OOV,浮在 OOV 表
   供後續裁定(列舉展開另議)。

### 屬性定案修訂(2026-10-01 站主裁定)

屬性字與 属性 **拆成兩詞**(取代前一條的 〇属性 綁定),解列舉複合:

1. **屬性字獨立 token**(七值封閉集合),成詞條件帶前瞻護欄:後面
   (可隔著・列舉)最終接到 属性 才成詞——闇属性 → 闇|属性、
   光・闇属性 → 光|・|闇|属性;墓地/水族 這類含同字的詞不受影響。
2. **属性 照舊詞典詞**(宣言/回指用法同前)。
3. 前一條的 属性モンスター 拆除維持不變。

### 種族定案(2026-10-01 站主裁定)

26 種族**整詞入典**(manual 來源),清單以值域正典為準(`script/web/vocab.py`
的 `_RACE`,26 值含幻想魔族),日文名對照 OCG 官方種族名。魔法使い族 整詞
以最長匹配壓過「魔法」,修 R6 記錄的誤切(使い族 198 次)。屬性字的前瞻
護欄(前一條)保證 水族/炎族 不會被屬性字誤切。

### 時機詞追加(2026-10-01 站主裁定)

**発動した時**(=發動時)整詞入典;**発動した場合** 同類型一併補齊——
對齊既有 召喚した時/召喚した場合/特殊召喚した時/特殊召喚した場合 家族。
修正前 発動した時 切成 発動した+OOV「時」(556 句),発動した場合 切成
発動した+場合;修正後兩形各自一格。R4(〜場合/〜時 粒度)的全面裁定
仍開放,本條是家族補齊不是定案。

### 時機詞追加撤回(2026-10-01 站主裁定)

前條「時機詞追加」整條撤回:発動した時/発動した場合 的 manual 詞條移除,
切法還原(発動した時 → 発動した+OOV 時;発動した場合 → 発動した+場合)。
〜時/〜場合 的粒度整題留給 R4 一次裁,不先零星入典。

### R4 定案+時/同時入典(2026-10-01 站主裁定)

**時/同時 整詞入典**(同時 15 次擋「〜と同時に」歧義,時点/時間 語料零出現
無需護欄);**R4 全拆**:所有以 場合/時 結尾的複合詞條剝除,場合/時 獨立成
時機標記——攻撃した場合→攻撃+した+場合、ターン終了時→ターン終了+時。
規則實義:時 可能錯過時點、場合 不會,差異落在單一 token 位。剝除殘幹:
非純平假名自動補進詞典(ターン終了/攻撃宣言/特殊召喚した等),純平假名
殘幹走白名單(した/され),漏網活用尾(た/なった)留給 R12。
前條「時機詞追加撤回」的保留態度由本條正式取代(R4 已一次裁)。

### 選んで進詞(2026-10-01 站主裁定)

選んで(選擇動作的連用形,原 OOV 第一高頻動詞形)整詞入典(manual)。
兄弟形 選び/選ぶ/選択できる 未入典,照舊浮於 OOV 表待裁(R12 範圍)。

### R2 定案(2026-10-01 站主裁定)

**サ変+する家族一律拆**:する/した/して/し/され系(されない/されず/された/
される/されて/され)結尾的複合詞條剝除,動作名詞與時態正交——
特殊召喚する→特殊召喚+する、発動した→発動+した、X召喚し→X召喚+し、
破壊される→破壊+される。與 R3(できる)、R4(場合/時)同一邏輯,
三條合起來:動作名詞|時態|時機標記 三位正交。連用形 し/して 補進功能詞
(して 原 OOV 512 次);殘幹非純平假名且 ≥2 字才拆,残して/超えた 這類
原生動詞活用不受影響(原生動詞歸 R12)。

**R2 實作追記**:剝除順序 R4 先 R2 後(R4 剝出的 破壊される/特殊召喚した
要再經 R2);される/された/されて/されない/されず 與 し/して 同列功能詞
入典;分詞器改**詞典與助詞跨類最長匹配**——し 入典後不可吃掉 しか
(度しか→c:度+p:しか 照舊),助詞較長時助詞優先。
