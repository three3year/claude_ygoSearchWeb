# 效果類型判別規範

這份文件是[[效果標記表]]所有判定票與遮蔽測試的共同依據。它必須能獨立運作:**讀者手上只有一張卡的繁中卡文、日文卡文、[[補足情報]]、與這份文件**,沒有對話脈絡、沒有前一票的記憶。

判定的輸出是每個[[效果句]]的兩個值:

- [[效果類型]] —— 十六種固定值之一,每個效果句只有一個:六種**怪獸側**類型(§2)加十種**[[魔陷卡效果]]**(§2.7,ADR-0004/ADR-0005)。
- [[必發/選發]] —— 「誘發即時效果(2速)」「誘發效果(1速)」兩類,以及魔陷卡效果中**有觸發事件的發動句**有值,其餘一律留空。

**判定以日文卡文與補足情報為準**,繁中卡文只用來對照與人工複查。效果類型是官方裁定概念,經過翻譯會失真。

詞彙一律使用 `CONTEXT.md` 的定義([[效果句]]、[[效果類型]]、[[必發/選發]]、[[效果外文本]]、[[官方明示]]、[[補足情報]]),不使用實作欄位名。

---

## 1. 判別流程

從上往下走,**第一個成立的分支就是終點**,不回頭、不併存。走完必然停在恰好一個類型上。

```
步驟 0:這一段是效果嗎?
  ├─ 補足情報寫「〜は効果として扱いません」 ─────────────────→ 效果外文本
  ├─ 這一段是素材指定 / 召喚條件 / 使用次數限制 / 卡名規則文字 ─→ 效果外文本
  ├─ 這一段是勝利條件(「自分はデュエルに勝利する」) ─────────→ 效果外文本
  └─ 否則 ↓

步驟 1:補足情報有指向這一句的官方明示嗎?
  ├─ 有(且歸屬確定,見 §6) ────────→ 直接採用官方寫的類型,流程結束
  └─ 沒有,或歸屬不確定 ↓

步驟 2:這一句以什麼身分運作?(§2.7 / §5.8,ADR-0004/ADR-0005)
  ├─ 以魔法/陷阱卡身分(魔陷卡自己的發動、在場上/墓地的效果、持續適用段;
  │  含怪獸卡「當作魔陷卡的場合」的效果) ──→ 〈卡片種類〉卡效果,流程結束
  ├─ 靈擺欄的效果句(P 區的卡是魔法卡) ──────→ 靈擺魔法卡效果,流程結束
  └─ 以怪獸身分(怪獸卡的效果;魔陷卡「變成怪獸時的效果」與
     「〜は以下の効果を得る」賦予怪獸的效果) ↓

步驟 3:這一句會形成連鎖嗎(有「發動」這個動作嗎)?
  ├─ 不會(常時適用、或只是一段處理程序) ──→ 步驟 4
  └─ 會 ─────────────────────────────────→ 步驟 5

步驟 4:不形成連鎖的效果(先過 §5.5 的六條分界,任一成立即為無種類效果)
  ├─ 效果在場上持續適用(數值變動、限制、不受影響、視為某種狀態且持續) → 永續效果
  └─ 是一次性的程序或規則處理(特殊召喚方法、代替素材、當作通常怪獸
     處理、把自己當裝備卡裝備) ──────────────────────────────→ 無種類效果

步驟 5:形成連鎖的效果
  ├─ 不是 2 速,但發動時點同時涵蓋主要階段與戰鬥階段 ───→ 無種類效果(§5.7)
  ├─ 可以在對手回合發動,或可以連鎖其他效果發動(2速) ──→ 誘發即時效果(2速)
  ├─ 有觸發事件(「〜した場合」「〜した時」「リバース：」),
  │  只在該時點形成連鎖,不能連鎖對手的效果 ─────────────→ 誘發效果(1速)
  └─ 沒有觸發事件,由自己在主要階段主動發動 ─────────────→ 啟動效果
```

判不出來時**不要猜**。把該效果句留空並在該票的結果檔記下理由,列進待審清單。留空是可以被後續處理的訊號,猜錯會變成沒人看見的錯誤資料。

**步驟 3 的「發動」不是只看卡文。** 卡文沒寫「発動」但[[補足情報]]寫了「〜に発動できます」時,那一句就是發動型效果,而且**補足情報寫的時點就是發動時點**,拿它去走步驟 5。全表有 13 條這種效果句(卡文不含「発動」卻判成發動型),漏看補足只能留空。

**但這條線索必須先過 §6 的歸屬。** 補足情報講的多半是**別的**效果句——樣本實測 87 行的補足裡出現過「発動できます」,其中絕大多數是在講同一張卡的其他編號效果。只有當那一行落在指向本效果句的 `【①の効果について】` 標頭底下、或它的第一個 `『』` 引用對得回本效果句的卡文時才算數。歸屬不確定就當作沒看到,回頭走步驟 4。

- 魔海城 埃該翁(10678778)①`①：相手のエクストラデッキから裏側表示のモンスターをランダムに１体除外する。このカードの攻撃力は除外したモンスターの攻撃力と同じになる。`
  卡文沒有發動子句,補足寫`■ダメージステップ開始時からダメージ計算前までの間であれば、ダメージステップでも発動できます。`——時點落在 §5.6 表的傷害步驟那一格、效果是改自己的攻擊力,判**誘發即時效果(2速)**。

## 2. 效果類型的值域

§2.1–§2.6 是六種**怪獸側**類型——官方的類型詞(起動効果/誘発効果/誘発即時効果/永続効果/分類されない効果)只用在**以怪獸身分運作**的效果上。§2.7 是十種**[[魔陷卡效果]]**——以魔法/陷阱卡身分運作的效果句不適用六類,只有由[[卡片種類]]決定的咒語速度(ADR-0004;靈擺欄見 ADR-0005)。走 §1 的流程自然會停在正確的一側,不用先背這條分界。

### 2.1 效果外文本

不構成任何效果的卡文段落。四種常見形態:**素材指定**(融合/同調/超量/連結素材與儀式的降臨指定)、**召喚條件**(此卡不能通常召喚、只能用某方法特殊召喚、上級召喚時的解放限制)、**使用次數限制**(這個卡名的①②效果1回合各能使用1次)、**裝備條件**(裝備魔法卡開頭的「〜のみ装備可能」)。另外「這個卡名在規則上也當作「〜」卡片」這類卡名規則文字也屬此類。

**裝備條件**是票18 補的一格。裝備魔法卡的第一句常寫「〈某族/某屬性/某卡名〉モンスターにのみ装備可能。」,官方對它的裁定 **24/24** 是效果外文本(`■効果として扱いません。このカードを装備可能なモンスターの条件です。`,八汰鏡 1200843、Ωメガネ 4857085 等),沒有一條判成別的類型。全表卡文含「装備可能」的 193 張裡只有 24 張有明示,其餘沒有明示的照這一條走。變體「〈…〉に装備する事ができる。」寫在卡文開頭時是同一件事(魂喰らいの魔刀 5371656),但全表只有 1 張,不寫成拆句判準(見 §8 判準16)。

**勝利條件**(`自分はデュエルに勝利する`)同樣是效果外文本:全表獨立成句的勝利條件 **6/6** 由官方寫明「効果として扱いません」(封印されしエクゾディア 33396948、死のメッセージ 94212438 等)。但寫在某個**發動型效果的處理裡**的不算——`②：…に発動する。次の自分ターン中、以下を適用する。●このカードが直接攻撃で相手に戦闘ダメージを与えた時、自分はデュエルに勝利する`(66765023)那一段的類型由發動子句決定,實測 3 條。

官方判別記號:**「〜は効果として扱いません」**。凡是官方這樣寫的段落,一律是效果外文本。

官方寫過八種等義變體,共通形狀是**「効果」後面直接接「扱い」**,看到任何一種都算數:`効果として扱いません` / `効果として扱われません` / `効果としては扱いません` / `効果としては扱われません` / `効果としての扱いではありません` / `効果としての扱いません` / `効果の扱いではありません` / `効果の扱いにはなりません`。「効果」與「扱い」之間夾了別的詞的(`効果で破壊された扱いにはなりません`、`効果ダメージの扱いではありません`)講的是別件事,**不算**。

官方例句:

- **被封印的艾克佐迪亞 / 封印されしエクゾディア**(33396948)
  卡文:`このカードと「封印されし者の右腕」…が手札に全て揃った時、自分はデュエルに勝利する。`
  明示:`■効果として扱いません。このカードによって定められた勝利条件です。`
- **黑暗武裝龍 / ダーク・アームド・ドラゴン**(65192027)
  卡文:`このカードは通常召喚できない。` / `自分の墓地の闇属性モンスターが３体の場合のみ特殊召喚できる。`
  明示:`【『このカードは通常召喚できない』について】■効果として扱いません。`
  明示:`【『自分の墓地の闇属性モンスターが３体の場合のみ特殊召喚できる』について】■効果として扱いません。手札のこのモンスターを特殊召喚する方法です。`
- **大飛蛾 / グレート・モス**(14141448)
  明示:`■『このカードは通常召喚できない。「進化の繭」が装備され…特殊召喚する事ができる』は効果として扱いません。`

### 2.2 無種類效果

**是效果,但不屬於其他四種發動/持續類型。** 對應官方用語「起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果」。

典型形態:不形成連鎖、也不是持續適用的**一次性程序或規則處理**——手牌/墓地的自我特殊召喚程序、代替融合素材、把自己當裝備卡裝備上去、在場上與墓地「當作通常怪獸處理」。

「不形成連鎖」是典型形態,不是定義。官方判過一條**自己就寫「発動できる」**的無種類效果,判別依據是發動時點四類都容不下——見 §5.7。

官方例句:

- **心眼的女神 / 心眼の女神**(53493204)
  卡文:`このカードを融合素材モンスター１体の代わりにする事ができる。その際、他の融合素材モンスターは正規のものでなければならない。`
  明示:`■「心眼の女神」の効果は、起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果です。`
- **守護者 艾爾朵絲 / ガーディアン・エアトス**(34022290)
  卡文:`①：自分の墓地にモンスターが存在しない場合、このカードは手札から特殊召喚できる。`
  明示:`■『①：…このカードは手札から特殊召喚できる』効果は、…いずれにも分類されない効果です。(この方法で特殊召喚を行う際にチェーンブロックは作られません。)`
- **鳳凰 機亞弗里德 / フェニックス・ギア・フリード**(69488544)
  卡文:`①：このカードはフィールド・墓地に存在する限り、通常モンスターとして扱う。`
  明示:`■『①：このカードはフィールド・墓地に存在する限り、通常モンスターとして扱う』モンスター効果は、…いずれにも分類されない効果です。`
- **龍盟-標槍龍 / ドラグニティ－ジャベリン**(80549379)
  卡文:`このカードがモンスターカードゾーン上で破壊された場合、墓地へ送らずに装備カード扱いとして…装備できる。`
  明示:`■起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果です。`

> **「把自己當裝備卡裝備上去」不是一律無種類效果**,標槍龍那一條的關鍵是**被動觸發**(`破壊された場合、墓地へ送らずに…装備できる`)。反過來,由玩家**主動指定對象**的那一款——`〜を対象とし、このカードを装備魔法カード扱いで装備する`(聯合飛行員 89357740 的 `●`、W-飛翼彈射器 96300057 的 `●`)——官方一律判**啟動效果**(22/22),即使卡文一個「発動」字都沒有。這是 §1 步驟 2 的「卡文沒寫発動不代表不發動」的另一種形態:句型本身(指定對象 + 主動裝備)就是發動。

> 注意 **フェニックス・ギア・フリード** 這個例子:句型帶「〜存在する限り」,看起來像永續效果,官方卻判為無種類效果——因為它做的是「規則上把自己當通常怪獸處理」,而不是在場上適用一個效果。**「〜として扱う」的規則處理歸無種類效果,但只在適用範圍伸出場外時成立**(這個例子是`フィールド・墓地`)。同一句話若限定在怪獸區域(`①：このカードはモンスターゾーンに存在する限り、通常モンスターとして扱う`,聖騎士 鮑斯 47120245)官方判**永續效果**。完整分界見 §5.5 分界一,那一節是本規範被實測打臉最多次的地方,判到不發動的效果時**逐條核對**。

另外五種常見形態,它們都長得很像永續效果,官方一律判無種類效果(判別依據見 §5.5):

- **同名卡在場上的唯一性限制** —— `「氷剣竜ミラジェイド」は自分フィールドに１枚しか表側表示で存在できない。`
- **離場時的自我除外** —— `表側表示のこのカードはフィールドから離れた場合に除外される。`
- **由召喚方法決定的原本數值** —— `召喚したこのカードの元々の攻撃力は１０００になる。`
- **破壞替代,而替代手段動用墓地的自己** —— `自分フィールドの「六武衆」モンスター１体のみが効果で破壊される場合、代わりに墓地のこのカードを除外できる。`
- **把效果賦予給「以此卡為素材召喚的怪獸」** —— `フィールドのこのカードを素材としてX召喚したモンスターは以下の効果を得る。`

**否定句優先**:含「いずれにも分類されない」的明示句,一律判為無種類效果。這句話會列舉其他四個類型詞,**不得因為看到那些詞而多重比對**。

### 2.3 永續效果

不形成連鎖、在場上(或指定的區域)**持續適用**的效果。判別關鍵是「持續」:攻守數值變動、對手不能做某事、此卡不受某類效果影響、只要某張卡存在就適用。

句型線索:`〜限り`、`〜する場合`(狀態條件而非事件)、`〜につき`、`〜できない`(施加於對手或雙方的持續限制)、`〜アップする`/`〜ダウンする`。

**這些線索無種類效果也照用**,只憑句型會整族誤標——判到不發動的效果一律先過 §5.5 的六條分界。

官方例句:

- **深海的戰士 / 深海の戦士**(24128274)
  卡文:`「海」がフィールド上に存在する限り、このカードは魔法の効果を受けない。`
  明示:`■「深海の戦士」の効果は永続効果です。`
- **野蠻人2號 / バーバリアン２号**(40453765)
  卡文:`①：自分フィールドの「バーバリアン１号」１体につき、このカードの攻撃力は５００アップする。`
  明示:`■『①』のモンスター効果は永続効果です。`
- **千眼納祭 / サウザンド・アイズ・サクリファイス**(63519819)
  卡文:`①：このカードがモンスターゾーンに存在する限り、このカード以外のフィールドのモンスターは攻撃できず、表示形式の変更もできない。`
  明示:`■モンスターゾーンで適用する永続効果です。`
- **森之住人 沃登 / 森の住人 ウダン**(42883273)
  卡文:`フィールド上の表側表示の植物族モンスター１体につき、このカードの攻撃力は１００ポイントアップする。`
  明示:`■「森の住人 ウダン」の効果は永続効果です。`

### 2.4 誘發即時效果(2速)

會形成連鎖、且**速度為 2**:可以在對手回合發動,也可以連鎖其他效果發動。

句型線索:`自分・相手ターンに`、`相手ターンでも発動できる`、`〜された時に発動できる`且該時點在對手回合(被攻擊的傷害計算時、被效果對象時)、手牌就能發動的怪獸效果。

官方例句:

- **栗子球 / クリボー**(40640057)
  卡文:`①：相手モンスターの攻撃で自分が戦闘ダメージを受けるダメージ計算時に、このカードを手札から捨てて発動できる。…`
  明示:`■手札で発動できる誘発即時効果です。`
- **雷魔神-桑卡 / 雷魔神－サンガ**(25955164)
  卡文:`①：…このカードが攻撃されたダメージ計算時に、攻撃モンスター１体を対象として発動できる。その攻撃モンスターの攻撃力を０にする。`
  明示:`■モンスターゾーンで発動できる誘発即時効果です。`
- **奧雷卡爾克斯的魔封劍 / オレイカルコスの魔封剣**(847217)
  明示:`■このカードの②の効果が適用されたモンスターがモンスターゾーンで発動できる誘発即時効果です。`

### 2.5 誘發效果(1速)

會形成連鎖、速度為 1、且**有觸發事件**:某件事發生「之後/當時」才能發動,不能拿來連鎖對手的效果。

句型線索:`〜した場合に発動`、`〜した時に発動`、`〜送られた場合`、`リバース：`、`自分エンドフェイズに発動する`(固定時點的強制發動)。

官方例句:

- **邪惡寄生蠕蟲 / 邪悪なるワーム・ビースト**(6285791)
  卡文:`①：自分エンドフェイズに発動する。フィールドの表側表示のこのカードを持ち主の手札に戻す。`
  明示:`■モンスターゾーンで発動する誘発効果です。(必ず発動する効果です。)`
- **三眼怪 / クリッター**(26202165)
  卡文:`①：このカードがフィールドから墓地へ送られた場合に発動する。デッキから攻撃力１５００以下のモンスター１体を手札に加える。…`
  明示:`■墓地で発動する誘発効果です。`
- **壺魔人 / 壺魔人**(55763552)
  卡文:`リバース：フィールド上に表側表示で存在する「ドラゴン族・封印の壺」を破壊する。…`
  明示:`■「壺魔人」のモンスター効果は、フィールドで発動する誘発効果です。`

### 2.6 啟動效果

會形成連鎖、速度為 1、**沒有觸發事件**:在自己的主要階段由自己主動發動。多半帶有代價(捨棄手牌、解放怪獸、除外墓地卡、取除超量素材)。

句型線索:`自分メインフェイズに発動できる`、`１ターンに１度、〜して発動できる`(前面沒有事件子句)、`〜を除外して発動できる`。

官方例句:

- **時間魔術師 / 時の魔術師**(71625222)
  卡文:`①：１ターンに１度、自分メインフェイズに発動できる。コイントスを１回行い…`
  明示:`■モンスターゾーンで発動できる起動効果です。`
- **飛箭龜 / カタパルト・タートル**(95727991)
  卡文:`１ターンに１度、自分フィールド上のモンスター１体をリリースして発動できる。…`
  明示:`■「カタパルト･タートル」のモンスター効果は、フィールドで発動する起動効果です。`
- **黑暗武裝龍 / ダーク・アームド・ドラゴン**(65192027)
  卡文:`①：自分の墓地から闇属性モンスター１体を除外し、フィールドのカード１枚を対象として発動できる。そのカードを破壊する。`
  明示:`【①の効果について】■モンスターゾーンで発動できる起動効果です。`

### 2.7 魔陷卡效果(十種)

**以魔法/陷阱卡身分運作**的效果句不適用六類——官方對它們**從不給類型詞**,它們只有咒語速度,而速度由[[卡片種類]]機械決定。前九種以卡片種類命名:**通常魔法卡效果、速攻魔法卡效果、儀式魔法卡效果、永續魔法卡效果、裝備魔法卡效果、場地魔法卡效果、通常陷阱卡效果、永續陷阱卡效果、反擊陷阱卡效果**;第十種是**靈擺魔法卡效果**(ADR-0005),以運作身分命名——P 區的卡官方規則是「魔法カード扱い」,但不屬於十種卡片種類的任何一種。

**靈擺魔法卡效果(第十值,ADR-0005)**:靈擺欄(【靈擺效果】段)的效果句以 P 區魔法卡身分運作,非效果外文本者一律判這個值——§1 步驟 0 照常先走,靈擺欄的使用次數限制句(「〜の②のP効果は１ターンに１度しか使用できない」)仍是效果外文本。速度:P 區的靈擺效果 1 速。官方對靈擺效果**零類型詞、零句式**(2026-08-10 全表掃描),這個值因此只來自判定、不在官方明示的對應表裡;官方若在靈擺補足寫出類型詞,照官方判(下方三種保留形態的第三種)。印在**怪獸效果欄**的句子照常走六類——靈擺怪獸在怪獸區是怪獸,身分以**欄位**分,不以卡分。例:白翼的魔術師(11067666)P①(チェーンブロックの作られない適用型)、疾行機人 多米諾蝴蝶(28151978)P①(持續適用)與 P②(主動發動)都是靈擺魔法卡效果。

**速度框架**(判定不需要填速度,它可以從值推導;「1速/2速」與「誘發效果(1速)/誘發即時效果(2速)」名稱裡的速度是同一套咒語速度,但這裡講的是魔陷卡的速度來源):

- 魔法效果 1 速,陷阱效果 2 速。
- **卡片的發動**會提速:速攻魔法的卡片發動 2 速、反擊陷阱的卡片發動 3 速。
- 墓地等處使用的效果回歸本體種類的速度(速攻魔法的墓地效果是 1 速)。

**判準是運作身分,不是印刷卡種**。兩個方向都成立:

- 魔陷卡的效果句幾乎全是魔陷卡效果——卡本身的發動、場上/墓地/被覆蓋時的效果、持續適用段、裝備卡施加在裝備怪獸身上的效果,全部照卡片種類填值。
- 怪獸卡「當作魔陷卡的場合」的效果句**同樣是魔陷卡效果**:百夫長重騎士 普莉梅拉(15005145)②③,官方寫 `■魔法＆罠ゾーンで永続罠カード扱いのこのカードが適用するチェーンブロックの作られない効果です。■永続罠カードの効果として扱います。`——連「永続効果」都不說,特地繞開類型詞。這兩句判**永續陷阱卡效果**。

**官方語彙(票56)**:官方不給六類的類型詞,但會以「**〜カードの効果として**+肯定述語(扱います/扱われます/適用されます/適用します/発動します/発動・処理を行います)」明示運作身分——這是[[魔陷卡效果]]側的[[官方明示]],抽取器已登錄(實測 89 行:装備魔法 73/永続罠 9/永続魔法 7),歸屬照 §6 的既有階梯。只認寫出[[卡片種類]]**全名**的;光寫大類的「魔法/罠カードの効果として」(實測 44 行)對不出前九值中的哪一個,不產生判定;靈擺魔法卡效果沒有對應句式,不在對應表裡(ADR-0005)。反方向的怪獸側語彙同樣乾淨:離開魔陷/裝備狀態後以怪獸身分觸發的效果,官方明寫「〜モンスター効果は誘発効果です」(見 §5.8 的裝備狀態邊界)。

**魔陷卡上仍然判六類的只有三種形態**(票53 全表稽核:官方在魔陷卡上的 60 條類型明示,33+26+1 恰好是這三種):

1. **變成怪獸時的效果**——陷阱怪獸等「此卡發動後變成怪獸」的卡,在怪獸區域運作的效果是怪獸效果(影依的原核 4904633、詛咒的雕像 3129635 ②)。
2. **賦予怪獸的效果**——`〜は以下の効果を得る。●…` 的 ● 子效果成為**怪獸自己的效果**(轉生揭幕鎧甲 68663427)。注意「効果を得る」(怪獸獲得)才算;`装備モンスターに適用される効果`(裝備卡自己的效果作用在怪獸身上)**不算**,那仍是裝備魔法卡效果(官方語彙把兩者分得很開,見 §5.2)。
3. **官方明示的特例**——行為偏離速度框架時官方才開口:聖遺物運動機構(29223325)②在墓地/除外狀態發動,魔法效果本體 1 速照理不能在對手回合發動,官方因此明寫 `墓地または除外された状態で発動する誘発効果です`。§1 步驟 1 的官方明示優先權涵蓋這種行,照官方判。

**[[必發/選發]]**:魔陷卡效果中**有觸發事件的發動句**照 §4 填值(墓地/場上被動觸發那族,強制與否是真資訊、官方會背書);**卡本身的發動不填**——發不發動一張卡永遠是玩家的選擇,寫「選發」沒有資訊量。靈擺魔法卡效果同一套:P 區玩家主動的效果發動(「自分メインフェイズにのみ発動する事ができます」那族)與持續適用段(「チェーンブロックの作られない効果」)留空,有觸發事件的發動句才填。

兩者都不形成連鎖,很容易混。差別在**它到底是不是效果**:

| | 是效果嗎 | 官方用語 | 例 |
|---|---|---|---|
| **無種類效果** | 是,只是不屬於其他四類 | `いずれにも分類されない効果です` | `①：自分の墓地にモンスターが存在しない場合、このカードは手札から特殊召喚できる`(守護者 艾爾朵絲) |
| **效果外文本** | 不是,連效果都不算 | `効果として扱いません` | `このカードは通常召喚できない`(黑暗武裝龍) |

實務上會撞在一起的是**特殊召喚程序**:同樣是「怎麼把這張卡叫出來」,官方兩種都判過。判別依據只有一條——**看官方怎麼寫**:

- 寫在召喚條件那一段、官方說「効果として扱いません」(黑暗武裝龍、大飛蛾)→ 效果外文本。
- 寫成一個編號效果、官方說「いずれにも分類されない効果です」(守護者 艾爾朵絲 ①)→ 無種類效果。

沒有官方明示時,以位置為準:**第一個效果編號之前的段落是效果外文本**;寫成編號效果的特殊召喚程序是無種類效果。

**位置這條線不只管特殊召喚程序,代替素材也照走。** §2.2 把「代替融合素材」列為無種類效果的典型形態,但那說的是**寫成編號效果**的那一種;同樣一件事寫在前言段就是效果外文本:

| 位置 | 卡文 | 官方 |
|---|---|---|
| 前言段 | `このカードは「シンクロン」チューナーの代わりとしてS素材にできる。`(極星天 凡娜迪絲 61777313 等 7 張) | **效果外文本**(8/8,含 82697428 的解放替代) |
| 編號效果 | `①：このカードは、融合モンスターカードにカード名が記された融合素材モンスター１体の代わりにできる。`(6205579、52101615、88696724) | **無種類效果**(3/3) |
| 編號效果 + 限定場上 | `②：このカードはモンスターゾーンに存在する限り、「デストーイ」融合モンスターカードに…代わりにできる。`(81481818) | **永續效果**(§5.5 分界一) |

## 4. 必發/選發

**「誘發即時效果(2速)」「誘發效果(1速)」兩類,加上[[魔陷卡效果]]中有觸發事件的發動句寫值。** 啟動效果本就由玩家主動開啟,永續效果、無種類效果、效果外文本則不發動——這四類一律留空,不要填「必發」。魔陷卡效果的行(ADR-0004):**有觸發事件的發動句**(墓地/場上被動觸發,如「覆蓋的此卡被破壞送去墓地時…」)照本節判必發/選發;**卡本身的發動**與不發動的段落留空——發不發動一張卡永遠是玩家的選擇,填「選發」沒有資訊量。

三層,由高到低:

1. **官方明示** —— 補足情報寫「必ず発動」→ **必發**(官方寫過「必ず発動する効果です」「必ず発動します」「必ず発動し、〜」三種,都算)。
   - 邪惡寄生蠕蟲(6285791):`■モンスターゾーンで発動する誘発効果です。(必ず発動する効果です。)`
   - 壺魔人(55763552):`■「壺魔人」自身がリバースした場合に必ず発動する効果です。`
   - 闇晦之城(62121):`■このカードがリバースした場合に必ず発動する効果です。`
2. **日文句型規則** —— 找出這個效果句的**發動子句**,看它的結尾:
   - 以「できる/できます」結尾 → **選發**(`〜に発動できる。`)
   - 否則 → **必發**(`〜に発動する。`、`リバース：`)

   **「否則 → 必發」有一個成族的例外**:魔法・陷阱卡「這張卡本身的發動」那一段(§5.8)。舊式卡文把它寫成 `〜して発動する。`,句尾規則會推定必發,但要不要發動這張卡是玩家的選擇。~~一律選發~~ **ADR-0004 之後這一族連值都不填**(卡本身的發動判魔陷卡效果、必發/選發留空),句型規則在魔陷卡效果的行上也不再補值,這個歷史錯誤來源就此關閉(票18/19/20 三票各實測 11/7/7 條都在這一族)。
3. **找不到發動子句** → 留空待判,不強行推定。舊式無編號卡文在依語意拆開之前也算這一類——那一團的第一句常是素材指定或召喚條件,不是發動子句。

拆開之後仍然判不出來的,實務上幾乎都是同一種:**舊式的代價句型 `〜する事で、…する。`**。它不以「できる」結尾,句尾規則因此要嘛認不出發動子句、要嘛推定必發,但那個「事で」正是「付這個代價就可以」的意思——繁中一律譯作「可以藉由…」,判**選發**。票13 實測 5 條(剣闘獣ムルミロ 5975022 ②、コアキメイル・ルークロード 10060427、牙城のガーディアン 23535429、真六武衆－エニシ 75116619、魔轟神獣ルビィラーダ 94845226),票18 再 2 條(マテリアルファルコ 1287123、ライトレイ ギア・フリード 4722253),票19 再 2 條(セイヴァー・スター・ドラゴン 7841112 ①、ホルスの黒炎竜 LV６ 11224103 ②)。

**票19 起它由 `tagcard._optional_by_rule()` 自動判**(那是 §4 第二層的句型規則,不是[[規則層]]——後者只寫[[影子預測]]、只管[[效果類型]])。判別條件:發動子句含 `〈辭書形〉事で` → 選發,結算順序在句尾「できる」之後、「否則必發」之前。三件事是量出來才這樣寫的:

- **不要求逗號**——`〜墓地に送る事で「ホルスの黒炎竜 LV８」１体を…`(11224103)後面直接接引號。
- **不要求發動子句沒有「発動」**——`相手が…効果を発動した時、このカードをリリースする事で…`(7841112)的「発動」是**觸發事件**裡的,不是這一句自己的可否;只看有沒有「発動」會把它推定成必發。
- **但「た事で」不算**——那是「因為發生了這件事」而不是「付這個代價」,官方判必發(`装備モンスターがフィールドから離れた事でこのカードが墓地へ送られた場合に発動する`,51686645 / 90673413)。少了這道排除,官方明示的必發獨立驗證會從 847/848 掉到 845/848。

登記後全表命中發動子句 **111 條**,其中已經有必發/選發答案的 18 條**全部**是選發,反例 0 條;官方明示的必發獨立驗證維持 847/848。上面那 9 張全部命中。

### 發動子句怎麼抓(掃描邊界)

發動子句是效果句裡描述「什麼時候、付什麼代價、能不能發動」的那一段,**到第一個句號為止**:

- `①：このカードが墓地へ送られた場合に発動できる。デッキから…手札に加える。`
  → 發動子句 = `①：このカードが墓地へ送られた場合に発動できる。` → 以できる結尾 → **選發**
- `①：自分エンドフェイズに発動する。フィールドの…手札に戻す。`
  → 發動子句 = 第一句 → 不以できる結尾 → **必發**

**「…時,可以」完成式事件的邊界**是最容易咬錯的地方。舊式卡文常把發動時點與處理寫在同一句,或把「できる」放在處理的動詞上:

- `１ターンに１度、手札を１枚捨てる事ができる。その後カードを１枚ドローする。`
  ——「できる」在第一句、屬於發動子句 → 選發。
- `〜した時、相手に１０００ダメージを与える事ができる。`
  ——只有一句,「できる」屬於這一句 → 選發。

四條硬性邊界:

- **不得跨越效果句邊界**。日文官方卡文常整段不換行(`①：…。②：…。`),掃描時必須停在下一個編號之前;咬到下一個效果的「発動できる」會整族誤標。
- **不得把處理段的「できない」當成發動子句的結尾**。`〜は攻撃できない` 是處理內容,不是發動的可否。
- **句尾的括號補述要剝掉再看結尾**。官方把限制寫在發動子句句尾的括號裡,而括號內常自帶句號:`①：通常魔法カードが発動した時に発動できる（同一チェーン上では１度まで）。` 的發動子句是括號之前的部分,結尾是「発動できる」→ **選發**。不剝括號會把它讀成不以できる結尾而誤判必發(實測 130 條)。
- **領起句不是發動子句**。`②：…「天気」効果モンスターは以下の効果を得る。●…` 這種句子既沒有「できる」也沒提到発動,真正的發動寫在後面的 `●` 分項裡;此時**留空待判**,不得推定必發(實測 11 條)。

## 5. 歷史易錯區分

這一節是前一世代實際誤標過的地方。判定時**逐條核對**。

### 5.1 「只要OO在怪獸區域存在」= 永續效果

`このカードがモンスターゾーンに存在する限り〜`、`「海」がフィールドに存在する限り〜` 這種「只要…存在就…」的句型是**持續適用**,判**永續效果**,不要因為它描述了一個條件就當成有觸發事件的誘發效果。

- 千眼納祭(63519819)`①：このカードがモンスターゾーンに存在する限り…` → `■モンスターゾーンで適用する永続効果です。`
- 深海的戰士(24128274)`「海」がフィールド上に存在する限り…` → `■「深海の戦士」の効果は永続効果です。`

**唯一的例外**是「〜として扱う」的規則處理(見 §2.2 的 鳳凰 機亞弗里德):同樣帶「存在する限り」,官方判無種類效果。判別依據是這句話做的事情是**規則上的視為**,而不是在場上適用一個效果。

### 5.2 裝備方向:先確定主語是誰

繁中譯文的兩個方向長得很像,讀反會連「這是誰的效果」都標錯:

| 繁中 | 日文 | 此卡是什麼 |
|---|---|---|
| 裝備**此卡的**怪獸 | `装備モンスター` | 此卡是**裝備卡**,那隻怪獸被它裝備 |
| **此卡裝備的**OO | `このカードが装備している〜` | 此卡是**怪獸**(聯合怪獸等),它去裝備別的東西 |

判定約定(ADR-0004 改定):

- 此卡是**裝備卡**(魔陷卡)→ 它的效果句以魔陷卡身分運作,判**裝備魔法卡效果**(§2.7)——不論主語是「装備モンスター」還是對手,也不論是加攻守、限制攻擊還是破壞替代。~~票52 之前這裡按主語分判無種類/永續~~,那套區分是在官方永遠不給答案的地方硬選一邊,已由 ADR-0004 整族取代。
- 此卡是**怪獸**(聯合怪獸等)、效果寫「このカードが装備している〜」→ 怪獸效果,判**永續效果**(不變)。

官方在裝備卡這一側**從不給類型**。團結之力(56747793)`①：装備モンスターの攻撃力・守備力は…アップする。` 的官方明示只寫到:

```
■装備されているこのカードが適用するチェーンブロックの作られない効果です。(装備モンスターに適用される効果です。)
```

「チェーンブロックの作られない効果」同時涵蓋永續效果與無種類效果,**不構成官方明示**,不得當作類型依據。「装備モンスターに適用される効果です」是在講效果作用在誰身上,也不是類型詞。**「不給類型」是量出來的,不是印象**:全表魔法・陷阱卡上、日文原文含「装備モンスター」的效果句,官方類型明示 **0 條**——這正是 ADR-0004 的證據之一:官方不給類型,因為它們是裝備魔法卡的效果,類型詞本來就不適用。

> **歷史**:票52 之前這一族按主語判無種類效果(施加在裝備怪獸身上)或永續效果(主語是對手、破壞替代),票52 為破壞替代定過案。那整套區分連同 §5.5 的六條分界在裝備卡上的適用,已由 ADR-0004 取代——裝備卡的這些效果句一律**裝備魔法卡效果**。ファイティング・スピリッツ(6178850)官方逐句區分「装備モンスターに適用される/されない」的那兩行,講的仍是效果作用在誰身上,兩句現在都是裝備魔法卡效果。

**「効果を得る」是另一回事**,官方確實指名類型時照官方:轉生揭幕鎧甲(68663427)`①：このカードを装備したXモンスターは以下の効果を得る。` 的 ● 子效果,官方寫 `■このカードを装備したエクシーズモンスターがモンスターゾーンで適用する永続効果です。`——**怪獸獲得**的效果是怪獸自己的效果(§2.7 保留六類的第二種形態),與「裝備卡的效果作用在怪獸身上」是官方語彙裡分得很開的兩件事。

### 5.3 誘發即時(2速)與誘發(1速)只差速度

兩個詞在繁中字面幾乎一樣,務必看清「(2速)」「(1速)」的標註。判別只問一件事:**能不能在對手回合、或連鎖其他效果發動?**

- 能 → 誘發即時效果(2速)
- 不能 → 誘發效果(1速)

問題是「在對手回合會觸發」不等於「能在對手回合發動」——`〜が戦闘で破壊された場合` 這種事件在雙方回合都會發生,它仍然是 1 速。**光看「這件事會不會發生在對手回合」判不出速度**,要看發動時點落在戰鬥流程的哪一格,見 §5.6。

「手牌就能發動的怪獸效果一律 2 速」也**不成立**:`②：自分が戦闘ダメージを受けた時に発動できる。このカードを手札から特殊召喚し〜`(源數之壁 42352091)是從手牌發動,官方判誘發效果(1速)。手牌只決定發動的**場所**,不決定速度。

### 5.4 「…時,可以」完成式事件的發動子句邊界

第三個歷史誤標區在[[必發/選發]]:舊式卡文把發動時點與處理寫在同一句,掃描發動子句時很容易咬過頭——尤其日文官方卡文整段不換行時會咬進**下一個效果句**。判別方式與兩條硬性邊界見 §4「發動子句怎麼抓」。

### 5.5 永續效果與無種類效果的六條分界

不發動的效果落在這兩類之間,而 §1 的步驟 4(「持續適用」vs「一次性程序」)不足以判掉全部——**「〜する限り」「〜できない」這些永續效果的句型線索,無種類效果也照用**。以下六條分界取自官方明示,判到不發動的效果時逐條核對,**任何一條成立就是無種類效果**(分界六兩個方向都給答案),六條都不成立才回步驟 4。

**分界一:適用場所超出場上 → 無種類效果。**
永續效果只在場上(或官方指名的區域)適用。同一個「規則上視為」的句子,適用範圍限於怪獸區域是永續效果,範圍及於墓地或手牌就是無種類效果。**視為的是卡名還是種類都一樣,只看範圍**:

| 卡文 | 官方 |
|---|---|
| `このカードはモンスターゾーンに存在する限り、カード名を「海」として扱う。`(亞特蘭提斯的戰將 90098000) | 永續效果 |
| `このカードはモンスターゾーンに存在する限り、通常モンスターとして扱う。`(聖騎士 鮑斯 47120245) | 永續效果 |
| `このカードのカード名は、フィールド・墓地に存在する限り「ブラック・マジシャン」として扱う。`(混沌的魔術師 47963370) | 無種類效果 |
| `このカードのカード名は、墓地に存在する限り「ワイト」として扱う。`(白骨皇子 57473560) | 無種類效果 |
| `このカードはフィールド・墓地に存在する限り、通常モンスターとして扱う。`(巨型植物 53257892) | 無種類效果 |

**分界二:原本數值由召喚方法決定 → 無種類效果。**
`〈召喚方法〉したこのカードの元々の攻撃力は〜になる` 這種以召喚方法修飾主語的原本數值改寫是規則層級的處理,不是場上適用:

- `①：召喚したこのカードの元々の攻撃力は１０００になる。`(惡之魔娘 莉莉絲 23898021)→ **無種類效果**
- `①：このカードの元々の攻撃力・守備力は、このカードのレベル×３００になる。`(貪婪類星體 50263751)→ **永續效果**(沒有召喚方法修飾)

  **這一條只管「元々の」。** 少了那三個字就不成立——改的是場上的現值,那是持續適用,即使主語同樣被召喚方法修飾也一樣:`①：この方法で特殊召喚したこのカードの攻撃力・守備力は１００００になる。`(萬物創世龍 10000)官方判**永續效果**。實測:帶「元々の」的 12/13 是無種類效果(唯一例外那行自己含發動子句,類型由發動子句決定);不帶「元々の」且不含發動子句的 13/13 是永續效果。另有 2 條不帶「元々の」卻判無種類效果的,句子主體是**自我特殊召喚程序**(`このカードは…手札から特殊召喚できる。この方法で特殊召喚したこのカードの攻撃力は…`,地葬星 魁札 25449584),類型由前半決定,不是這一條的反例。

**分界二之二:以召喚方法修飾主語的「〜として扱う」 → 無種類效果。**
分界二講的是**數值**,同一個道理也管**視為**:`〈召喚方法〉したこのカードは〜として扱う` 官方一律判無種類效果(11/11)。

- `①：「BF」モンスターを素材としてS召喚したこのカードはチューナーとして扱う。`(ABF-五月雨之騷速刀 53389254)→ **無種類效果**
- `①：〜この方法で特殊召喚したこのカードはチューナーとして扱う。`(第一企鵝 12975671)→ **無種類效果**
- 對照:沒有召喚方法修飾、只講場上狀態的 `①：このカードはモンスターゾーンに存在する限り、通常モンスターとして扱う。`(聖騎士 鮑斯)是**永續效果**(分界一)。

  注意這一條**只管「として扱う」**。「〈召喚方法〉したこのカード〜」的句型整體是 127 條、永續 85 / 無種類 42,不能一律判無種類:`③：融合召喚したこのカードは１度のバトルフェイズ中に３回攻撃できる。`(V.HERO 三重人 46759931)是永續效果。

  同一族裡有一組覆蓋不足、只能記成具名例外的:主語是「〈指定的卡〉**をリリースして**アドバンス召喚したこのカード」時官方判**無種類效果**——`②：「ガジェット」モンスターをリリースしてアドバンス召喚したこのカードは１度のバトルフェイズ中に２回攻撃できる。`(古代機械齒輪 熱核反應機龍 44874522 ①②、超弩級砲塔列車 古斯塔夫・馬克斯 81269231 ②,3/3)。對照:沒有指定解放對象的「アドバンス召喚したこのカード〜」是**永續效果**(4/4,`①：アドバンス召喚したこのカードは相手の魔法・罠カードの効果の対象にならない。` 95192919)。**3 條全部集中在 2 張同系列卡,寫成判別條件就是過擬合**——遇到這個句型照分界一到六走,判成永續效果,只有這兩張卡照官方。

  另有一條覆蓋不足、只能記在這裡的例外:`①：このカードは、このカードのアドバンス召喚のためにリリースしたカードと元々の種類（モンスター・魔法・罠）が同じカードの効果を受けない。`(真龍機兵 十二鍊機巧 57761191)官方判**無種類效果**,雖然它長得就是永續效果的「不受影響」。

**分界三:破壞替代的代替手段動用場外(墓地・手牌)的自己 → 無種類效果。**
`〜が破壊される場合、代わりに〜` 的替代效果預設是永續效果(在場上適用),但代替手段若動用**不在場上的**這張卡(墓地或手牌),它就不是在場上適用:

- `②：自分フィールドの「機塊」モンスターが効果で破壊される場合、代わりにフィールド・墓地のこのカードを除外できる。`(斷路機塊 5846183)→ **無種類效果**
- `②：自分フィールドのレベル３以下のアンデット族モンスターが戦闘・効果で破壊される場合、代わりに手札のこのカードを捨てる事ができる。`(6128460)→ **無種類效果**(手牌同理,分界一的道理)
- `③：フィールドのこのカードが戦闘・効果で破壊される場合、代わりにこのカードのX素材を１つ取り除く事ができる。`(剎帝利怒威 香格里拉 73542331)→ **永續效果**

  這一條是整族的分界,不只管怪獸:官方明示的 139 條全在怪獸卡上(永續 100 / 無種類 28 / 啟動 11),而 28 條無種類 **28/28** 都是「代替手段動用墓地(24)或手牌(4)的自己」。**裝備卡(與裝備卡扱い的聯合怪獸)上的破壞替代也走這一條**,判永續效果——它不是 §5.2 那條「施加在裝備怪獸身上」的約定管得到的形態,官方對同族寫過 `は装備モンスターに適用される効果ではありません`(票52,依據見 §5.2 第三列)。

**分界四:效果是賦予給別的怪獸而不是自己適用 → 無種類效果。**
`このカードを素材として召喚したモンスターは以下の効果を得る` 這種句子,賦予的當下此卡已經是素材、不在場上適用任何東西:

- `③：フィールドのこのカードを素材としてX召喚したモンスターは以下の効果を得る。`(古神 克圖格亞 12948099)→ **無種類效果**
- `②：このカードをS素材としてドラゴン族SモンスターをS召喚した場合、そのSモンスターは戦闘では破壊されない。`(輝煌的星之龍 75874514)→ **無種類效果**
- `このカードを儀式召喚に使用した儀式モンスターは罠カードの効果を受けない。`(儀式魔人ディザーズ 30492798)→ **無種類效果**——儀式素材同族。這一族的「不受影響」句型長得像永續效果,[[規則層]] R8 曾在這裡預測錯,票23 起整族排除(素材とした/使用した)。
- 但**被賦予的 `●` 子效果本身照常判**——那是被賦予的怪獸在場上適用的,多為永續效果(見 §5.2 的轉生揭幕鎧甲)。
- 官方對其中一批寫得更絕:`■『②：…以下の効果を得る』は効果の扱いではありません`——領起句連效果都不算,那一段是[[效果外文本]]而不是無種類效果。這種句子**只在補足情報寫了才算**,判定時先翻補足情報有沒有這一句(票16 全表實測 118 條領起句因此由官方直接定案)。
- **「只在補足情報寫了才算」有一族票22 量出了家族答案:自己得到型的純領起句。** 單一句子、主語是**このカード自己**(不是被賦予的別張卡)、以「以下の効果を得る」收尾、又沒有發動子句的領起句(`②：このカードは、このカードのカウンターの数によって以下の効果を得る。` 220414、`また、このカードが持っているエクシーズ素材の数によって、このカードは以下の効果を得る。` 23776077),官方給過答案的 **41/41** 全是「効果の扱いではありません」——本卡補足沒寫時照家族判**效果外文本**,已登記為規則層 R13。**多句的不算**:發動子句在前、「得る」收尾的效果句(13857930)類型由發動子句決定,單句限定就是為了排除它們。賦予**別的怪獸**的領起句仍照本分界(預設無種類效果)。
- 對照:`①：このカードがモンスターゾーンに存在する限り、ターンプレイヤーは以下の効果を適用する。`(剛鬼 雷霆食人魔 30010480)是**永續效果**——此卡人在場上,分界四不成立。

**分界五:適用期間由「〜召喚に成功したターン」限定 → 無種類效果。**
永續效果的適用期間是「只要條件成立」,沒有回合邊界。不發動的效果若把適用期間綁在**某一次召喚的那個回合**,官方判無種類效果(實測 14/18,其餘為含發動子句的誤判):

- `②：フィールドのP召喚されたモンスターを素材としてこのカードが融合召喚に成功したターン、このカードは相手の効果を受けない。`(符文眼靈擺龍 1516510)→ **無種類效果**
- `①：このカードがX召喚に成功したターン、このカード以外のフィールドのカードの効果は発動できず、無効化される。`(DDD雙曉王 伽梨玉迦 15939229)→ **無種類效果**
- 對照:`②：このカードがモンスターゾーンに存在する限り、〜`沒有回合邊界,是**永續效果**。

**分界六:素材相關的規則處理,看效果作用的對象是不是只有此卡自己。**
`〜を素材とする場合、〜` 這種在「把某張卡當素材使用」時開的特例,兩種都判過,分界是**這句話改變了誰**(實測 42/43):

- 只改變**此卡自己**成為素材時的視為(等級、是不是調整、卡名)→ **無種類效果**(35/36)。此卡當下正要離場成為素材,不是在場上適用一個效果:`②：自分フィールドのこのカードをS素材とする場合、このカードをチューナー以外のモンスターとして扱う事ができる。`(斬機系列)、`②：このカードを「No.」モンスターのX召喚に使用する場合、このカードのレベルを３か４として扱う事ができる。`(邃淵鯊 61496006)
- 讓**別的卡**也能當素材、或及於**其他素材怪獸** → **永續效果**(7/7)。此卡人在場上,賦予的是一個場上適用的許可:`①：自分フィールドのこのカードをサイバース族モンスターのリンク素材とする場合、手札のサイバース族モンスターも１体までリンク素材にできる。`(代理馬 16684346)、`②：フィールドのこのカードをS素材とする場合、このカードを含む全てのS素材モンスターをレベル２モンスターとして扱う事ができる。`(33541430 等 3 張)
- 反過來,**手牌的此卡**能當素材(`〜を素材とする場合、手札のこのカードもL素材にできる`,代碼生成員 30114823)是**無種類效果**(11/11)——此卡不在場上,分界一的道理。

  唯一的例外是 `③：フィールドの表側表示のこのカードを融合素材とする場合、カード名を「召喚師アレイスター」として扱う事ができる。`(875572),官方判永續效果,形態上與上面第一條無異,原因不明。

還有一族只出現在同名卡限制上,直接記下來:`「〈本卡卡名〉」は自分フィールドに１体(１枚)しか表側表示で存在できない` 官方一律判**無種類效果**(氷剣竜ミラジェイド 44146295、王の影 ロプトル 94183877、星風狼ウォルフライエ 3322931 皆是),不要因為它是一條持續限制就判永續效果。同理 `表側表示のこのカードはフィールドから離れた場合に除外される`(混沌核 3806388)也是無種類效果。

**這兩族與「召喚は無効化されない」三族票19 起進了[[規則層]]**(R10 / R12 / R11),因為量出來的覆蓋與一致率都夠。判別條件的權威版本在 `script/tag_card/rules.py`,覆蓋條數由建置流程算進 `docs/effect_kind_rules.md`;下表只給要點:

| 規則 | 命中 | 排除 | 覆蓋 | 官方 | 一致率 |
|---|---|---|---|---|---|
| R10 | `しか表側表示で存在できない` | 発動、觸發事件 | 135 | 83 | 100% |
| R11 | `召喚は無効化されない` | 発動、`存在する限り`、觸發事件 | 16 | 11 | 100% |
| R12 | `フィールドから離れた場合に除外される` | 発動、`存在する限り` | 13 | 10 | 100% |

R11 的 `存在する限り` 排除條件是必要的:`①：このカードがモンスターゾーンに存在する限り、自分のモンスターのP召喚は無効化されない`(77384395)講的是**在場上賦予別人**的許可,官方判永續效果;`①：このカードの特殊召喚は無効化されない`(17469113 等 8 張)講的是自己被召喚那一瞬間的規則處理,才是無種類效果。R12 同理(S-Force 21368442)。

**R12 沒有觸發事件的排除條件,那是刻意的**:它自己的命中樣式 `離れた場合` 就落在觸發事件的字面上(`た場合`),加了排除等於整條失效。它的安全來源是命中樣式本身夠窄——全表 13 條,官方 10 條全部一致。

### 5.6 戰鬥流程中的發動時點決定速度

沒有寫「自分・相手ターンに」「相手ターンでも発動できる」的戰鬥相關效果,速度看發動時點落在戰鬥流程的哪一格。這是 §5.3 的細則:

先過四道前置閘門,四道都不成立才查表:

- **這一句以魔陷卡身分運作嗎?** 是 → **〈卡片種類〉卡效果**(§2.7),不進本節——§1 步驟 2 就該攔下它,速度由卡片種類決定,不用查表。`①：相手モンスターの攻撃宣言時に発動できる。その攻撃を無効にする。` 寫在陷阱卡上(魅影騎士團 失常磁環 62645025 的卡發動)是通常陷阱卡效果,同一句話寫在怪獸上(拖曳山嫗 21187631)才進本節、判誘發效果(1速)。魔陷卡在墓地等處由事件觸發的效果**同樣是魔陷卡效果**,除非官方明示給了類型(聖遺物運動機構 29223325 ②,§2.7 第三種形態)。
- **卡文寫了跨回合許可嗎?** 分三種,前者與第三者成立:
  - 獨立的一句 `この効果は相手ターンでも発動できる。` → **誘發即時效果(2速)**(實測 218/218)。
  - 寫在括號裡且**附帶條件**(`（自分の墓地の「テラナイト」モンスターが７種類以上の場合、この効果は相手ターンでも発動できる）`,煉星騎士 多祿某 64414267)→ **不算**,照沒有那句話時的形態判,實測 14/14 全是**啟動效果**。
  - **寫在前言段、並點名編號**的那一種算數:`このカード名の①②の効果は１ターンに１度、いずれか１つしか使用できず、相手ターンでも発動できる。`(聖占術姬 塔羅蕾 94997874)——被點名的 ①② **都是誘發即時效果(2速)**(實測 6/6)。**編號效果本身可以一個時點字都沒有**:`②：フィールドの表側表示モンスター１体を対象として発動できる。そのモンスターを裏側守備表示にする。` 單看這一句像啟動效果,跨回合許可在前言段裡。**判到看起來是啟動效果的行,先回頭看 `index` 為 `0` 的前言段**。
- **發動時點的「回合」被寫死成對手回合嗎?** 指的是 `相手ターンの〜に発動できる` 這種把回合寫進時點的寫法(不是 `自分・相手ターンに`)。看那個時點是不是固定階段:
  - **不是**固定階段(`相手ターンの直接攻撃宣言時に`、`相手ターンのメインフェイズに`)→ **誘發即時效果(2速)**(實測 3/3)。`①：相手ターンの直接攻撃宣言時に、このカードを手札から捨てて発動できる。その攻撃を無効にする。`(速攻稻草人 18964575)官方明示`■手札で発動できる誘発即時効果です。`
  - **是**固定階段(`相手ターンのエンドフェイズに`)→ 照下表,是**誘發效果(1速)**(實測 5/5)。階段到來是觸發事件,寫成對手回合只是限定哪一邊的階段。
- **發動時點是一段期間,而事件只是那段期間的修飾語嗎?** `〜した<ターン|バトルフェイズ>に発動できる` → **誘發即時效果(2速)**(實測 12/12)。事件已經過去,能發動的是整段期間而不是事件那一瞬間,所以連鎖得動:`①：自分の「超重武者」モンスターが戦闘で相手モンスターを破壊した自分バトルフェイズに発動できる。`(超重武者 拳-C 71386411)、`①：このカードが「エクソシスター」モンスターを素材としてX召喚した自分・相手ターンに、〜発動できる。`(42741437)。**只寫自己的回合/戰鬥階段也算**——期間的歸屬不改變速度。
  - 反過來,期間若是修飾**事件**而發動仍綁在事件上(`リンク召喚したこのカードが相手ターンに破壊された場合に発動できる`,7480763),那是誘發效果(1速),照下表判。分辨方式:句尾是「〜した期間に発動できる」還是「〜した場合／時に発動できる」。

| 發動時點 | 類型 | 例 |
|---|---|---|
| `攻撃宣言時`,且時點的主語是**怪獸**(`相手モンスターの〜攻撃宣言時`) | **誘發效果(1速)**(實測 76/81) | `①：特殊召喚された相手モンスターの攻撃宣言時に、〜発動できる。その攻撃を無効にする。`(幻變騷靈 拖曳山嫗 21187631) |
| `ダメージステップ開始時〜ダメージ計算時`,**選發**,且效果**改變這一次戰鬥的數值或傷害**(攻守變動、戰鬥傷害處理、破壞替代) | **誘發即時效果(2速)** | `②：攻撃表示のこのカードが攻撃表示モンスターと戦闘を行うダメージ計算時に１度、発動できる。その戦闘では〜`(龍狸燈 42596828) |
| 同上但效果是**把怪獸破壞掉**而不是改數值 | **誘發效果(1速)** | `②：このカード以外の自分のモンスターが相手モンスターに攻撃されたダメージ計算前に発動できる。攻撃モンスターとこのカードを破壊する。`(魔鏡導士 念力限界者 65471349,實測 3/3) |
| 同上但**必發**(`〜発動する`) | **誘發效果(1速)** | `②：このカードが相手モンスターと戦闘を行うダメージ計算時に発動する。`(CNo.104 42396591) |
| 同上但效果**與這次戰鬥的數值無關**(例如把自己特殊召喚) | **誘發效果(1速)** | `①：自分の「剣闘獣」モンスターがモンスターと戦闘を行うダメージステップ開始時に発動できる。このカードを手札から特殊召喚する。`(劍鬥獸 維斯帕西亞努斯 88996322,實測 3/3) |
| `ダメージ計算後` / `ダメージステップ終了時` / `戦闘ダメージを受けた時` / `戦闘で破壊された場合` | **誘發效果(1速)** | `②：自分が戦闘ダメージを受けた時に発動できる。`(源數之壁 42352091) |

表的第一列有**兩條已知的官方例外**,它們形態一致但覆蓋只有 2 條,不足以成為判別條件,只記在這裡供比對:`①：このカードが相手（の表側表示）モンスターと戦闘を行う攻撃宣言時に１度、このカードのX素材を１つ取り除いて発動できる。その相手モンスターの攻撃力を半分にし／０にし、（その数値分）このカードの攻撃力をアップする。`(No.96 黑霧 55727845、77205367 ②-●1)官方判**誘發即時效果(2速)**。同族的「攻撃宣言時 + 改攻守數值」共 21 條,其餘 19 條都是誘發效果(1速)——**遇到攻撃宣言時仍然照表判 1 速**,不要因為這兩條就整族改判。

還有一條也不足以成規則、只記下來:`①：自分・相手のメインフェイズに、フィールドのモンスターがリバースした場合に発動できる。`(時間倒回者 86346363)官方判**誘發效果(1速)**。「自分・相手の〈階段〉に」在這裡是發動時點的限定,不是 §5.3 的跨回合許可——同一句還有獨立的觸發事件(`〜した場合に発動できる`)時,速度由觸發事件決定。實測只有 1 條,不當判別條件用。

兩條要點:

- **誘發即時效果幾乎都是選發,但「幾乎」不是「一律」。** 官方明示的 1,382 條誘發即時效果裡,1,366 條(98.8%)是選發、**10 條是必發**。所以看到 `〜発動する` **不可以**直接把誘發即時排除掉——那 10 條全部是同一種形態:**觸發事件是某個效果或卡的「發動」**(`モンスターの効果・魔法・罠カードが発動した時に発動する`、`裏側表示のこのモンスター１体のみを対象とする魔法カードが発動した時に発動する`,大盾守衛者 65240384)。這種效果依規則必須連鎖得上,速度只能是 2。
  - 反過來看更好用:全表「必發 + `〜が発動した時`」共 9 條,**全部**是誘發即時效果(9/9)。**觸發事件是「效果的發動」時,連鎖能力壓過必發/選發**,照下一條要點判。
  - 必發仍然是**排除依據**的場合:觸發事件不是「效果的發動」時(戰鬥、召喚、送墓、固定階段),必發就照表判 1 速。
- **「能不能連鎖對手」才是本質**,上表只是它在戰鬥流程上的投影。連鎖對手發動的效果(`相手が〜を発動した時に発動できる`)一律回 §5.3 判。固定階段的發動(`自分エンドフェイズに発動する`、`相手スタンバイフェイズに発動できる`、`相手バトルフェイズ開始時に発動できる`)是**誘發效果(1速)**——階段到來是觸發事件,不是連鎖能力。

> 「從手牌捨棄發動」不是速度的線索。`②：自分が戦闘ダメージを受けた時に発動できる。このカードを手札から特殊召喚し〜`(源數之壁 42352091)官方明示寫的是`■『②』のモンスター効果は、手札で発動する誘発効果です。`——手牌只決定發動的**場所**,速度看的是上面那三道閘門與這張表。

### 5.7 會發動、卻仍是無種類效果:發動時點橫跨主要階段與戰鬥階段

§2.2 的典型形態是「不形成連鎖」,但那是形態不是定義。官方判過一條**效果自己寫「発動できる」**的無種類效果,理由官方寫在括弧裡:它能在自己的主要階段**與**自己的戰鬥階段發動,四種發動類型沒有一種容得下這個時點——啟動效果只在自己的主要階段,誘發即時效果是 2 速,誘發效果要有觸發事件。

- **栗子巴比倫 / クリバビロン**(70914287)③
  卡文:`③：自分のメインフェイズ及びバトルフェイズに発動できる。このカードを持ち主の手札に戻し、自分の手札・墓地から「クリバー」「クリビー」「クリブー」「クリベー」「クリボー」を１体ずつ選んで攻撃表示で特殊召喚する。`
  明示:`■『③』はフィールドで発動できる効果です。（起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果です。自分のメインフェイズまたは自分のバトルフェイズに発動できます。対象を取る効果ではありません。ダメージステップには発動できません。）`

閘門(在 §1 步驟 5 的最前面):效果自己寫「発動できる」、**不**具 §5.6 的 2 速特徵、但發動時點同時涵蓋主要階段與戰鬥階段 → **無種類效果**。

順序不能顛倒:誘發即時效果本來就能在戰鬥階段發動,先判 2 速會把這條閘門變成整族誤標的來源。

**實測只有 1 條,而且不進[[規則層]]。** 官方判無種類效果的效果句裡,卡文出現「発動」的共 9 條,其餘 8 條的「発動」講的都是**別的**效果——拿別的效果的發動當條件(`〜モンスターが効果を発動するために手札を除外する場合、代わりに墓地のこのカードを除外できる`,S-Force 追溯者 53782828)——只有這一條是效果自己說「発動できる」。覆蓋 1 條遠低於規則層的 8 條門檻,所以它只寫在本文件,不登記為規則。

### 5.8 以魔陷卡身分運作的效果句 → 魔陷卡效果

官方那四個類型詞是講**怪獸效果**的,以魔法/陷阱卡身分運作的效果句官方**從不標類型**。全表 14,118 條官方明示裡,落在魔法卡上的類型明示只有 22 條、陷阱卡 38 條,而且 60 條裡 59 條是「變成怪獸時的效果」或「賦予怪獸的 `●` 子效果」、1 條是官方特別說明的墓地發動特例(票53 逐條稽核)——**沒有一條**在講以魔陷卡身分運作的效果句。這些效果句判**〈卡片種類〉卡效果**(§2.7,ADR-0004),不走六類。

**[[卡片種類]]從哪裡來**:批次檔每張卡帶一個,值域見 `CONTEXT.md`。**卡文分不出來**——通常魔法與速攻魔法的寫法完全一樣,靠卡文猜這一格等於擲骰子。票18 的 200 張裡有 80 張是魔法或陷阱卡,其中通常魔法 13 張、速攻魔法 4 張。怪獸卡「當作魔陷卡的場合」的效果句(普莉梅拉 15005145 ②③)照**它運作時的身分**填值(永續陷阱卡效果),不照印刷卡種。

**怪獸的裝備狀態邊界(票56):判準是運作時的身分**,兩方向的官方語彙都乾淨:

- **裝備狀態中運作**(持續適用段與裝備狀態中的發動句)→ **裝備魔法卡效果**。官方寫「装備魔法カードの効果として扱います」:暴風龍的防人(14235211)②③、DZW-魔裝鵺妖衣(6330307)②③、支援武器(29071332)②③——支援武器解除裝備的發動,官方還寫明「スペルスピード１の装備魔法カードの効果」。印刷卡種不是裝備魔法也一樣:通常魔法 遺言的假面(22610082)②被「假面魔獸 帝斯卡帝斯」的效果當作裝備卡裝備時的效果,官方同樣寫這一句。
- **離開裝備狀態後**在墓地/怪獸區以怪獸身分觸發的效果 → 怪獸側六類。官方明寫「モンスター効果は誘発効果です」:鐵鍊蛇(80769747)③、寄生蟲帕拉諾伊德(14457896)②、聖遺物②群。
- **把此卡當作裝備卡裝備上去的那個發動**是在怪獸區/手札發動的怪獸側效果(啟動/誘發),不因裝備後的身分而改判(暴風龍的防人 卡1、DZW ①)。同一個效果句**同時含**裝備動作與裝備狀態子效果時,官方對兩個子部分各給一句明示,抽取器對不出唯一標的、不猜(kind_conflicts 6 張:彩虹栗子球 2830693、真紅眼黑龍劍 19747827、支援武器 29071332 卡1、法典之愛華斯 35877582、古神哈斯塔 70913714、裝留破壞鎧 77679716),該行保留發動側的既有判定。

常見形態全部同一個值,不再需要區分:

- **卡本身的發動**:`自分フィールド上の「ジェムナイト」…１体をリリースし、…選択して発動できる。`(ジェム・エンハンス 41777,通常陷阱)→ 通常陷阱卡效果。
- **持續適用段**:`表側表示になったモンスターの表示形式は変更できない。`(砂漠の裁き 4869446,永續陷阱)→ 永續陷阱卡效果。
- 一張卡兩段都有時照樣拆成兩段(炎舞－「玉衝」 19059929 ①②),兩段都是永續魔法卡效果——拆句的意義在[[效果句]]是分群與貼 tag 的單位,不因類型相同而免拆。
- **場上/墓地的效果發動**:永續陷阱在場上的效果發動(明與宵の逆転 3160805)、裝備卡墓地自回收(31423101)→ 照卡片種類填值。速度不用判,由 §2.7 的速度框架推導。

**例外只有 §2.7 的三種形態**:變成怪獸時的效果、`効果を得る` 賦予怪獸的 ● 子效果、官方明示的特例——那些照六類判(§1 步驟 1 與步驟 2 的怪獸身分分支)。

**必發/選發**:照 §4——有觸發事件的發動句填值,卡本身的發動與不發動的段落留空。

> **歷史**:ADR-0004 之前這一節把卡本身的發動判成誘發即時效果(2速)/啟動效果(按卡片種類二分)、持續適用段判永續效果、必發/選發在卡發動上填「選發」。票18/19/20 三票在這一族與 `_optional_by_rule()` 的句尾規則各撞出 11/7/7 條不一致,票53 的全表稽核則量到:llm 判過的 375 條魔陷效果句官方全部沉默(卡卡都有補足情報、條條有機會講而全部不講)。這兩件事指向同一個結論——六類在這裡本來就不適用——才有 ADR-0004 的整族改判(票54)。

### 5.9 「発動後Ｎ回目の〜」的延後處理

魔法・陷阱卡把「發動後第 N 次的某階段做某事」寫進卡文的,只剩一條真正的分界(ADR-0004 之後):

- **寫成前言段的被動態壽命句** `このカードは発動後、Ｎ回目の〜に破壊される／墓地へ送られる。` → **效果外文本**。官方明示 **10/10** 全是 `効果として扱いません`(デプス・アミュレット 8279188、サイバー・ネットワーク 12670770 等)。
- **其餘一律〈卡片種類〉卡效果**(§2.7)。~~票20 曾按補足的連鎖敘述分判誘發效果(1速)/無種類效果~~——那條分界要回答的「形不形成連鎖」現在只影響[[必發/選發]]:補足寫 `チェーンブロックの作られる効果` 的(Ｄ・パワーユニット 7817703、武神隠 11221418、倍返し 5914184)是有觸發事件的發動句,照 §4 填**必發**;寫 `チェーンブロックは作られません` 的(タイムカプセル 11961740、極星宝グングニル 15286412)不發動,留空。補足沒講連鎖的(神の威光 16308000)**類型照樣填得出來**(永續陷阱卡效果),只有必發/選發留空——ADR-0004 之前這種行只能整個留空,現在不用了。

## 6. 官方明示的歸屬陷阱

補足情報會**為了解說而引用其他卡的效果文**。判定歸屬時必須確認引用的是**本卡**。

深海的戰士(24128274)是標準案例。它的補足情報三行:

```
■「深海の戦士」の効果は永続効果です。          ← 指向本卡,本卡只有一個效果句,採用
■「海」がフィールドに存在する間のみ適用される効果です。
■「海」がフィールドゾーンに存在する場合だけでなく、「海神の巫女」の『このカードが
  フィールド上に表側表示で存在する限り、フィールドは「海」になる』効果が適用されて
  いる場合でも、…                              ← 『』裡是「海神の巫女」的卡文,與本卡的
                                                 效果句無關,必須忽略
```

規則:

- 明示句用「」提到的卡名**只有別張卡**時,這一行不產生任何判定。
- 『』引用的效果原文**對不回本卡卡文**時,不猜歸屬。
- 『』引用同時命中**多個**效果段時,視為歧義,不採用。
- 卡名限定(「〈本卡卡名〉」の効果は…)但本卡有**多個**效果句時,由判定者決定歸屬,不整卡套用。
- `【…について】` 標頭**一律是新段的開始,黏在行尾的也算**。官方偶爾把下一段的標頭接在前一行的尾巴(`■…必ず発動する効果です。【③の効果について】`,實測 15 行),那一行之後的明示講的是**新**標頭的效果,不是上一個編號的。行中間的 `【…】` 則是強調而不是標頭(實測 1 行:`効果の発動を伴わない【カードの発動】だけであれば〜`)。
- **標頭底下的句子講的不一定是標頭那個效果。** `【…について】` 只保證「這一段在講這個效果」,句子本身仍可能在講**別的**效果——票19 實測 1 行:救世星龍(7841112)的 `【『この効果で無効にしたモンスターに記された効果を…発動できる』について】` 底下寫著`■無効にしたモンスターのテキストに、"条件を満たした際に必ず発動する効果"が記されている場合でも、このカードがその効果を発動するかどうかは任意です。`——那個「必ず発動する効果」講的是**被複製的那個效果**,不是這一段。[[必發/選發]]的官方明示階梯照字面吃它會把這一段標成必發(而它其實連類型都判不出來)。判到「這一行在解說別的卡/別的效果怎麼運作」時,不採用。
- 一行**只由第一個『』引用決定歸屬**。日文的寫作慣例是主語在前,後面的引用是解說時提到的另一個效果:`■『②』はフィールドで発動する誘発効果です。（『①』の効果を発動したこのカードが…必ず発動する効果です。）` 講的是②,①只是條件。逐一套用會把②的判定複製到①(實測 92 行,無一例外)。

歸屬確定不了時:類型值仍然是官方的,但**歸屬由判定者決定**,並在該票的結果檔記下判斷依據。歸屬與類型是兩件事,不要因為歸屬不確定就丟掉官方的類型。

## 7. 禁用句型

### 「効果ではありません」絕對不可作為判定依據

補足情報有 4,433 處出現「効果ではありません」,**絕大多數是限定否定**,與效果分類無關:

- `(対象を取る効果ではありません。)` —— 說的是不以卡為對象
- `チェーンブロックの作られる効果ではありません。` —— 說的是不形成連鎖,但沒說是永續還是無種類

把它當成「不是效果」會整族誤標數千行。**看到這個句型直接跳過**,回到 §1 的流程自己判。

會形成連鎖與否的資訊仍可作為**輔助線索**(不形成連鎖 → 走步驟 4),但它**不能**單獨決定六類中的哪一類。

### 「効果として扱いません」則可以採用

這是效果外文本的官方明示(見 §2.1,含八種變體)。但若它指向的段落**不在卡文開頭的前言段**,不要自動拆分卡文——列進報告請人工判讀。

**但括弧裡的那一種不算。** 官方會把「不算哪一種效果」的補述寫在句尾括弧,那和「対象を取る効果ではありません」同一類的限定否定:

```
■モンスターゾーンで適用する永続効果です。（モンスター効果として扱われます。罠カードの効果としては扱われません。）
```

這一行講的是永續效果,括弧只是說它不算陷阱卡的效果。**判別方式:明示句要出現在括弧之外才算數。**

## 8. 無編號舊式卡文的拆句原則

沒有①②③編號的舊式卡文,由判定者依語意拆成多個效果句。**繁中與日文兩側都要拆**——實測 489 張兩側句數不一致,不能只拆一側再推另一側。

這一節**還在長**,而且是故意的:拆句沒有現成的標準答案集(官方只寫類型不寫邊界),所以判準只能被實測一輪一輪打出來,與 §5.5 / §5.6 的長法相同。判準 10–15 是票13(第一批 200 張)打出來的,判準 16–18 是票18(第二批),判準 19–20 是票19(第三批)。

### 硬性規則(違反即不寫入)

1. **每一段必須是原文的連續子字串。** 不改寫、不補字、不調整標點。
2. **無遺漏覆蓋。** 拆出來的段落按順序串接、忽略空白與換行後,必須等於原文忽略空白後的字串。**不准有缺口**——缺口是「漏看一句」的唯一沉默失效模式,而這一批有 2,449 張連換行提示都沒有。
3. **官方 `『原文』` 引用不得被拆點切開。** 補足情報若引用了整團裡的一段原文,那一段一定完整落在**同一個**效果句之內;被切成兩半就是拆錯。3,805 張整團裡有 2,150 張適用,系統會自動檢查。

拆句對的原文是**管線的未拆整團**(批次檔 `split_targets` 的 `text_zh` / `text_ja`)。繁中卡文尾端的別名譯註(`※〜`)已被管線剝除(票21 時點 117 張,現值看建置報告的「別名註記(※)已從卡文尾端剝除」)——票21 曾因批次檔頂層 `card_text_zh` 未剝譯註而在驗證一的覆蓋檢查上失敗(20349913),審查後 `make_batches.py` 已同步剝除,兩處文字現在一致;其他方括號附註(`[按照判例修正]`,20436034)則保留在原文裡,拆句時附在相鄰段落即可。

### 判準

4. **一句一類型。** 拆出來的每一段必須能被判成單一效果類型;如果一段裡明顯有兩種類型(例如前半是誘發效果、後半是持續適用),那就是還該再拆。
5. **前言段照樣先抽出來。** 素材指定/召喚條件/使用次數限制在拆句時就分離為[[效果外文本]],不要混進效果句。它們的 `index` 是 `"0"`(第二段以上為 `"0-2"`、`"0-3"`),效果句才從 `"1"` 開始。
6. **換行是強分隔提示,但只對 1,356 張有效。** 另外 2,449 張整團完全沒有換行,這條用不上。
7. **句號不是切點。** 「每個句號都是一段」這條直覺在有官方引用可驗的 2,184 張裡被打臉 **497 張(22.8%)**——官方引用橫跨句號的情形很常見(條件句 + 處理句、發動子句 + 效果處理)。看語意,不看標點。
8. **補足情報的「■」條目可作參考。** 官方逐項解說時常常一項對一個效果,但這只是提示——官方也會為同一個效果寫多條解說。
9. 官方在一個效果內用「●」分項描述的子效果,拆成獨立效果句,各自單一類型。**領起句寫明 `●` 是同一次發動的選項列舉時不拆**(`以下の効果から１つを選択して発動する`、`次の効果から１つを選択して発動する`);領起句是**賦予型**的(`以下の効果を得る`)才拆,而且**領起句自己是效果外文本**——官方對這一族寫的是「『…以下の効果を得る』は効果の扱いではありません」(エレメント・ザウルス 92755808)。

### 判準(票13:第一批 200 張打出來的)

10. **一段一類型優先於兩側句數對齊。** 繁中與日文句數不一致時(3,805 張裡有 489 張),把日文相鄰的句子**併成一段**去對回繁中的一句——但只有它們**同類型**時才可以併。不同類型不能併(併了就違反判準四)。實例:ガーディアン・ケースト 9633505 日文三句、繁中兩句,後兩句官方都判永続効果,併起來就對得上。

11. **兩側語序不一致時,段落照繁中順序列,另記日文的閱讀順序。** 繁中譯者習慣把「使用次數限制」「維持代價」這類**框架句**提到最前面,日文則放句尾;同一批句子兩側排法不同,逐段對位就不成立。

    做法(票51 把拆句表放寬成「配對」之後才有):

    - 結果檔的 `clauses` **照繁中順序**列(它們進拆句表後叫 `segments`)。網站給人看的是繁中卡文,段落順序照繁中排,讀起來才對得上卡面。
    - 同一卡多給一個 `ja_order`:段落**位置**的排列,說明**日文**怎麼讀。日文那一側照它串接後同樣要無遺漏覆蓋。
    - `index` **照日文的序號**給。官方用①②③稱呼舊式卡文,對的是日文那一側,所以 index 跟著日文走——這與判準15 是同一條規矩(`index` 與段落在卡文裡的位置無關)。

    **`index` 與 `ja_order` 是兩件事,不要互相推導。** `ja_order` 講的是**位置**(繁中第幾段對到日文第幾段),`index` 講的是**這一段是日文的第幾個效果句**;而判準5、15 又規定[[效果外文本]]段一律 `"0"`、與日文序號無關。三者疊起來的樣子:

    ```
    一族の掟 296499  日文 ①宣言 → ②不能攻擊宣言 → ③維持代價(效果外文本)
                    繁中 ③ → ① → ②

    clauses[0]  維持代價(日文③)    index "0"   ← 效果外文本,判準5:一律 "0"
    clauses[1]  宣言(日文①)       index "1"
    clauses[2]  不能攻擊宣言(日文②) index "2"
    ja_order    [1, 2, 0]                  ← 日文從 clauses[1] 讀起
    ```

    三段全是效果句時就沒有這個交錯,index 直接是日文的 ①②③(カース・オブ・スタチュー 3129635 拆出來是 `"1"`、`"3"`、`"2"`,照繁中順序列)。

    已知 7 張:カース・オブ・スタチュー 3129635、爆弾ウニ 52140003、一族の掟 296499(以上票51 補判完成)、激流蘇生 7092142、魔導アーマー エグゼ 7180418、デプス・アミュレット 8279188(以上票19)、ヒロイック・ギフト 95920682(還沒判到)。實判率 6/600 = 1.0%。

    票19 那三張的形狀一模一樣,可以當樣板:**繁中把「1回合1張」「維持代價」「發動後第N回合自毀」這種框架句提到最前面,日文放句尾**。三張的 `ja_order` 都是 `[1, 0]`(日文從 `clauses[1]` 讀起),效果外文本段的 `index` 都是 `"0"`。

    **兩側真的配不起來才留空**——句子在一側被拆併、或譯文多出/少掉一個意思單位,那不是重排,`ja_order` 也救不了。留空並記理由,下一票會原封不動再出現一次;**留空的卡每一票都會再出現,不要因為看過就跳過**。

12. **連續數句都是效果外文本時併成一段。** 官方就是整段給裁定的——召喚條件 + 勝利條件寫在一起的 6 張,官方都是對整段寫「効果として扱いません」。

13. **尾端的限制句看它指誰。** 舊式卡文常把限制寫在最後,而它是不是獨立的效果外文本段,看它指的是「這一個效果」還是「這張卡的效果」:
    - 句子裡出現 `この効果` 或 `この方法` → 講的是這一個效果,**留在該效果句內**。編號卡文就是這樣寫的,官方把它算進那個編號的類型裡(實測 16 條)。**冠了卡名也一樣**——`「聖騎士ガラハド」のこの効果は１ターンに１度しか使用できない`(13391185)講的仍是那一個 `●`。
    - 以卡名或 `このカード名` 指稱**全卡效果**(`「曙光の騎士」の効果は１ターンに１度しか使用できない`、`「魔導書の奇跡」は１ターンに１枚しか発動できない`)→ 抽成[[效果外文本]]段。這與編號卡文把它寫在前言段是同一件事(`「セイクリッド・テンペスト」の①の効果はデュエル中に１度しか使用できない` 4820694 就在前言段)。
    - 這是票13 唯一**製造新拆點**的判準,已拿官方引用交叉驗證掃過全部未拆整團:開火 58 段(其中 23 段有 `『原文』` 引用可驗),**引用被切開 0 段**。重跑:

      ```
      python script/tag_card/check_split_rule.py \
        "(?=(?:「[^」]+」|このカード名)[^。]*?(?:効果|発動)[^。]*?しか(?:使用|発動)できない。\s*$)" \
        --not-matching "この効果|この方法"
      ```

    - **正向寫法的次數限制同屬本判準**(票24):`「フォトン・パイレーツ」の効果は１ターンに２度まで使用できる。`(36834155)以卡名指稱全卡效果,照第二點抽成[[效果外文本]]段。`まで(?:使用|発動)できる` 變體的掃描在未拆整團上開火 2 段、引用被切開 0 段(票24 時點),但覆蓋只有 2,不併入上面的掃描正則,由判定者逐張看。
    - **與發動限制連寫成一句的也同屬本判準**(票25):`「魔導書庫クレッセン」は１ターンに１枚しか発動できず、このカードを発動するターン、自分は「魔導書」と名のついたカード以外の魔法カードを発動できない。`(40230018)——「しか発動できず、」接續後半的發動回合限制,整句都是以卡名指稱全卡的框架限制,整句抽成一段。`「〜」は１ターンに１枚しか発動できず、` 變體的掃描在未拆整團上開火 1 段、引用被切開 0 段(票25 時點),覆蓋不足以併入掃描正則,由判定者逐張看。

**新判準要先過這一關才寫進這一節。** `script/tag_card/check_split_rule.py` 拿一條**還沒用**的判準在全部未拆整團上假設照它切,回報有沒有官方引用被切開——[[拆句表]]的驗證二只驗已經寫進表裡的拆點,擋不住一條寫太寬的判準。判準七的反例可以拿它重現:`"(?<=。)(?=.)"`(每個句號都是一段)在目前的未拆整團上開火 2,516 段、**切開 479 段**的官方引用。

14. **`この効果で〜` 開頭的後續限制不是獨立效果句。** `この効果で特殊召喚したモンスターは、フィールドから離れた場合に除外される`、`この効果で特殊召喚したモンスターの効果は無効化される` 這類殘留限制,在編號卡文裡一律寫在**同一個編號效果之內**,官方也只給那個編號一個類型(實測 449 條)。舊式卡文把它斷成獨立一句,**不要因此拆開**——那是效果處理的一部分,不是另一個效果。同理,`その時の攻撃モンスターは攻撃しなければならない`(一角獣の使い魔 22318971)這種發動之後的處理描述也不拆。

15. **效果外文本段的 `index` 是 `"0"`,與它在卡文裡的位置無關。** 段落順序照原文(判準二要求無遺漏覆蓋),所以尾端抽出來的效果外文本段會排在效果句後面,`index` 序列長成 `"1"`、`"0"`。`"0"` 標的是「這一段不是效果」,不是「這一段在最前面」。

### 判準(票18:第二批 200 張打出來的)

16. **裝備魔法卡開頭的「〜のみ装備可能。」抽成[[效果外文本]]段。** 那一句是裝備條件而不是效果(§2.1,官方 24/24),它後面才是效果本體。票18 的 200 張裡 9 張適用(八汰鏡 1200843、ドラゴンの秘宝 1435851、銀の弓矢 1557499、ヴァイロン・セグメント 1644289、はがねの甲羅 2370081、Ωメガネ 4857085、下克上の首飾り 5183693、サイクロンレーザー 5494820,以及變體寫法的魂喰らいの魔刀 5371656)。
    - 這是票18 唯一**製造新拆點**的判準,寫進本節之前已拿官方引用交叉驗證掃過全部未拆整團:開火 82 段(其中 58 段有 `『原文』` 引用可驗),**引用被切開 0 段**。重跑:

      ```
      python script/tag_card/check_split_rule.py "(?<=装備可能。)(?=.)"
      ```

      掃描範圍是**當下**的未拆整團,所以本票的 9 張拆完之後重跑會少掉那 9 段(82 → 74)。數字對不上不是判準壞了;要重現原始數字得先把[[拆句表]]退回本票之前的版本。同一件事也適用於判準13 記的 58 段。

    - 變體「〈…〉に装備する事ができる。」寫在卡文開頭時同樣是裝備條件,但全表只有 1 張(5371656),另外 2 張同句型的是效果本體(`自分の墓地の装備魔法カード１枚をこのカードに装備する事ができる`,40884383、90407382)——覆蓋不足且會誤傷,**不寫成掃描判準**,由判定者逐張看。

17. **判準14 的例外:官方把 `この効果で〜` 那一句單獨拿出來給了不同類型時,照官方拆。** 判準14 說殘留限制不拆,前提是官方只給前一段一個類型;官方若用 `【『この効果で…』効果について】` 標頭或逐項 `『…』` 引用替它另外標了一個類型,那它就是獨立的效果句。票18 實測 3 條:ドリル・ウォリアー 3429238(前段起動効果、`次の自分のスタンバイフェイズ時、この効果で除外したこのカードを…` 誘発効果)、スーパービークロイド－ステルス・ユニオン 3897065(前段起動効果、`この効果によってモンスターを装備している場合…` 永続効果)、吠え猛る大地 4587638(前段永続効果、`この効果が適用された事によって…` 誘発効果)。
    - 拆點落在官方引用的邊界上,所以結構上不可能切開引用(管線的驗證二照樣會擋)。**沒有官方另標類型就照判準14 不拆**——シャクトパス 2584136 的 `この効果によってこのカードを装備したモンスターは攻撃力が０になり〜` 官方只說了它何時適用、沒給類型,不拆。

18. **`●` 分項裡有兩種類型時再往下拆。** 判準9 只說 `●` 拆成獨立效果句,但一個 `●` 底下可以寫兩個效果。判準4(一句一類型)照樣管到 `●` 之內:Ｄ・ステープラン 2250266 的 `●攻撃表示：` 底下前半是永續效果、後半是誘発効果(官方一行裡就分開講了),`●守備表示：` 也一樣,整團因此拆成 5 段而不是 3 段。`●` 記號本身留在它後面那一段的開頭。

### 判準(票19:第三批 200 張打出來的)

19. **官方用 `【…『●』について】` 標頭逐項給裁定時,拆句表只寫一段,`●` 交給管線拆。** 管線本來就會拆這一族(`_split_bullets`,票03),而它是**在拆句表套用之後**才跑的,所以判定者自己把 `●` 切成獨立段落會被再切一次:段落 `"2"` 的內容以 `●` 起首、前面沒有領起句時,管線把它變成 `"2-●1"`,判定的 `index` 就對不回任何一行,關卡三當場擋下整批。實測:剣闘調教 9780364 寫 `1/2/3` → 管線給回 `1`、`2-●1`、`3-●1`。
    - **判別方式**:補足情報有 `【１つ目の『●』について】`/`【●…について】` 這種標頭 → 只寫一段,`●` 的類型留給後續的判類型票。沒有標頭(官方只是行內引用 `『●…』`,或根本沒提 `●`)→ 照判準9 自己拆,管線不會插手,因為授權還要求領起句是**賦予型**(`以下の効果を得る`),而拆出來的 `●` 段自己不帶領起句。
    - 本票 3 張帶 `●` 的整團:剣闘調教 9780364(有標頭 → 寫 1 段)、アルカナフォースⅠ 8396952 與 Ｄ・スコープン 10591919(無標頭 → 自己拆成 3 段,兩張的 `●` 段都由官方接手了類型)。

20. **判準13 只管尾端的限制句;夾在句子中間的不抽。** 卡名限制句寫在**領起句與 `●` 之間**時,把它抽成獨立段落會把同一個效果切成前後兩截(領起句一段、`●` 區塊一段),違反判準4——那兩截是同一次發動。實測 1 張:魔導冥士 ラモール 9560338 的 `このカードが召喚に成功した時に発動できる。…以下の効果を適用する。「魔導冥士 ラモール」の効果は１ターンに１度しか使用できない。●…` 整團就是 1 段誘発効果(官方也只給了一個類型、一個連鎖區塊)。

**判準19、20 沒有掃描紀錄,理由與判準17、18 相同**:判準19 的拆點條件是「補足情報有沒有 `【…『●』について】` 標頭」、判準20 是「這個限制句後面還有沒有同一個效果的後半」,兩個都不是「拆點落在什麼字串旁邊」,寫不成 `check_split_rule.py` 吃的正則。判準19 反而是**不製造**拆點的判準(它要求少拆),判準20 也是,所以連安全性都不必另外論證。

**判準17、18 沒有掃描紀錄,那是工具的限制而不是漏做。** `check_split_rule.py` 吃的是**一條正則**,它只認得出「拆點落在什麼字串旁邊」;判準17、18 的拆點條件是語意的(「官方另外給了這一句一個不同的類型」),寫不成正則,掃了也只會掃到別的東西。這兩條的安全性另有來源:**拆點一律落在官方 `『…』` 引用的邊界上**,所以結構上不可能把引用切成兩半,而[[拆句表]]的驗證二在每次套用時照樣會擋。**製造新拆點又寫得出正則的判準,一律要先掃過才寫進本節**(判準13、16 就是這樣過關的)。

### 只有一句的整團也要拆

1,113 張整團只有一句,看起來不用拆。**還是要走完流程**,輸出「這團就是 1 段」。那一筆紀錄本身就是「這張卡只有一個效果句」的斷言,[[官方明示]]的歸屬階梯四、五要的就是這個——沒有它,這張卡拿不到官方權威的類型。

反過來說也成立:**句數不是效果數的代理**。單句也可能整句都是效果外文本(純召喚條件),不要因為只有一句就直接當成效果句。
