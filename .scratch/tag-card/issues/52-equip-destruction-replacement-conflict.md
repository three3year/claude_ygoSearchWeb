### 定案:永續效果。而且不必只靠「挑一個」

官方不給這一族的**類型**沒錯,但官方給了判別這一族該走哪一條規範的**語彙**——這一票就是靠它定案的,不是靠喜好:

- **ファイティング・スピリッツ(6178850)** 一張卡上兩句話,官方逐句寫:

  ```
  ■『装備モンスターの攻撃力は…アップする』は装備モンスターに適用される効果です。
  ■『装備モンスターが戦闘によって破壊される場合、代わりにこのカードを破壊する事ができる』は装備モンスターに適用される効果ではありません。
  ```

  §5.2 的約定條件就是「效果施加在裝備怪獸身上」,而官方自己說破壞替代**不是**。約定不開火。

- **八汰鏡(1200843)** 的同一句,官方寫 `■魔法＆罠ゾーンで表側表示のこのカードが適用するチェーンブロックの作られない効果です。`——適用場所是場上的魔法＆罠區域。對照 §5.5 分界一(超出場上才是無種類效果),它在場上適用,所以走分界三的預設判**永續效果**。

- **整族的官方基線**:全表 `〜破壊される場合、代わりに〜` 且不含発動的效果句,官方明示 139 條**全部在怪獸卡上**(永續 100 / 無種類 28 / 啟動 11),魔法・陷阱卡 0 條;那 28 條無種類 **28/28** 都是分界三講的「代替手段動用墓地或手牌的自己」(`墓地のこのカードを除外`、`手札のこのカードを捨てる`)。裝備卡沒有自己的裁定,照這一族判。

規範改了兩處:§5.2 第三列的待修註記改成定案(附上上面兩段官方原文),§5.5 分界三加一句「裝備卡上的破壞替代也走這一條」。

### 改判怎麼走:管線本來沒有這條路

`_merge_clause()` 對 `llm` / `llm_then_rule` 的行一律沿用既有值,再判一次只會進 `judgment_overridden` 清單——所以票面說的「走 `merge_judgments.py` 的路徑」在動工當下是做不到的:剩下的路只有手改 `data/tag_cards.json` 標 `manual`,那正是票面禁止的。

ADR-0002 的「判定一次就算數」講的是**重跑不覆蓋**(建置管線不得洗掉人的成果),不是「判錯了也不能改」。規範是逐票長出來的,先判的票用的是還沒補上那一條的規範,同族兩個答案是必然會再發生的事,所以這一票把改判做成管線的一條正式路徑而不是一次性的手術:

- `make_batches.py --rejudge <密碼>:<section>:<index> --name fix-52` —— 逐條指名標的產生改判批次(標的必須是**已經判過**的行,還沒判的走正常排票)。批次帶上那一行現在的判定與來源,改判票才知道自己要動什麼。
- 結果檔那一行寫 `"rejudge": true` 才換得掉。批次標了改判、結果檔沒寫旗標的**整批不寫入**——否則既有那一行會照舊擋下來,改判等於沒做而且看起來成功了。
- 改判只碰得到 `llm` / `llm_then_rule`。[[官方明示]]與 `manual` 碰到即整批不寫入(`judgment_rejudge_refused`):前者是權威資料,後者是使用者看過這一行的證據。
- **冪等**:值已經相同時什麼都不做也不報告,改判票因此與其他票一樣能單獨重跑(Story 39)。

ADR-0002 補了一段修訂記這個決定。

### code-review 之後補的四件事

- **旗標的反方向也要把關。** 原本只擋「批次標了改判、結果檔沒寫旗標」,反過來結果檔自己多寫一個旗標則無人擋——那等於一般判定票能偷偷覆寫既有判定,正是 ADR-0002 修訂裡「要一張自己的票」要防的事。反向檢查掃結果檔的**每一個**段落(拆句標的也算,那種段落的 `clauses` 同樣帶類型)。
- **改判不吃掉 `tags`。** 改判整行換成本次的值會連[[效果 Tag]]一起丟掉,而那是另一條軸。目前 tags 全空,是潛在缺陷不是現行 bug,補了測試釘住。
- **碰不到的來源、值又相同時不算失敗。** refused 那條路原本不比對值,`manual` 行本來就寫著同一個答案時也會讓整批不寫入,與 rejudged 那條路的冪等不對稱。順帶讓 refused 的行不必再進 `judgment_overridden` 說一次同一件事。
- **文件對齊。** `CONTEXT.md` 補[[改判]]詞條(spec 的「新增詞彙進 CONTEXT.md」);spec 的「四種來源永不被重跑覆蓋」補上改判這個出口、「批次檔產生沒有值得測試的邏輯」註明旗標檢查是薄殼裡唯一帶判斷的地方;§5.5 分界三從「墓地」改寫成「墓地・手牌」(28 條無種類是墓地 24 + 手牌 4);§5.2 把推導寫成兩步(約定先結算,約定不開火才輪到六條分界),免得被讀成「場上適用所以永續」——第一列同樣場上適用卻判無種類,靠的正是約定。
