# 05: 物件修飾:回指與此卡

**What to build:** 補和「指誰」有關的修飾語:

- 「他の」:一律 非(同一張 此卡)(站主裁定);`同一張` 在查詢判斷的判法不變。
- 「その+修飾+頭名詞」(その相手、その自分の、その融合、対象の、上記の):回指,修飾語留在回指字面,不建新物件、不加條件(站主裁定)。
- 帶狀態的此卡(「この効果で特殊召喚したこのカード」「装備されているこのカード」「Pゾーンのこのカード」):建一個母體是此卡的子集物件,狀態寫在它的條件式裡。
- 連體子句「X召喚した/された」:新建召喚方式原子。
- 查詢判斷端:狀態原子(召喚方式、帶狀態的此卡的狀態)照既有的狀態原子規則,任何卡都代得進去。

- 規格:需要你決定的「「他の」一律讀成此卡以外嗎?」「「その相手モンスター」是回指還是新物件?」;實作決策「物件與條件式」(預設 2、預設 3 的召喚方式)、「查詢判斷」;使用者故事 26、27、28。
- 統計:`m3_categories.md` 第 1 節 C(回指前綴 1,224)、B(修飾此卡 657)、E 的「他の」部分、F 的「X召喚した」部分。
