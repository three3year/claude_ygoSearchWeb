# 派子代理的模型

主會話派子代理(Agent 工具)時,`model` 參數依這條判準選;implement-spec 本身沒有模型選項,每次派工都要選。

| 工作 | model |
|---|---|
| 票面有全語料守門(基準差異 0、md5 不變、digest ok)且只搬東西、照規格寫死的形狀做:探索筆記、基準/驗收工具、步驟重排、匯出序列化、評估器、目錄機械改寫、張數統計、拆解頁/報告、交件文件與鏡像重發、合併、Standards 審查 | `opus` |
| 改判定規則、逐卡判「改讀後更對」、刪正則式改讀結構化欄且要零行為改變、讀日文原文挑錯(LLM 抽驗的審閱者)、Spec 審查、code review 修正、裁定落地 | `fable`(預設,不傳) |

依據:2026-11-01 named-queries 共 17 個子代理約 5M token,前一類約 2.5M 用 Fable 沒有必要。
