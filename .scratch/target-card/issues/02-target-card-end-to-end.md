# 02: 針對卡片一路查得到(受事者片語直接比)

**What to build:** 給一張卡,查得出受事者片語寫的條件那張卡都滿足的框,從匯出檔一路到網址。

- **匯出**:段多帶段的條件。卡種、子類型、種族、屬性用與網站卡面同一套碼。數值存 [欄位, 比較, 數字或區間]。字段與卡名展開成卡片密碼清單,清單匯成一張表,段只帶索引。另帶此卡旗標與比不了的原因。格式版本 3 → 4,網站建置的版本檢查跟著改;目錄、統計不變。字段這張先只用卡名包含,對照表在票 04。
- **評估器**:參考評估器加 針對卡片(卡片密碼)、針對模式(不違反/只看有寫條件)兩欄,回傳命中與「部分條件未比對」旗標。JS 評估器對上它;卡面的屬性與種族在載入時編成位元。
- **條件模型**:新欄種類「卡片」,值必須是存在的卡片密碼。網址欄 `針對卡片`、`針對模式` 排在欄序最後,預設模式不寫。認具名查詢時跳過這兩欄(同 位置),帶了卡片的標籤寫欄位對。
- **抽屜**:先給一個填密碼的純文字欄,自動完成在票 05。

這張只讀受事者片語(含屬性受事者取主人的段),目的片語與回指目標在票 03。四個位置與排除述詞都能帶。見規格 Solution 1〜3、「匯出檔」「參考評估器」「網站建置與前端」實作決策,與「段的條件在哪裡解析」「網址與鎖」「効果モンスター」「部分條件未比對」的決定。
