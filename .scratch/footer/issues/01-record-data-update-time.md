# 01 — 下載殼記下資料更新時間

**What to build:** 維護者跑一次更新流程、五個來源(中/日/英 cdb、MD 稀有度、
Genesys)全部下載成功後,建置機上自動留下一筆[[資料更新時間]]記錄(本機檔、
不入版控),供後續建置讀取。下載失敗或 `--offline` 時既有記錄原封不動——
時間誠實反映「下載」,不反映「重跑」。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 任一來源下載失敗 → 不寫、既有記錄不被覆蓋(下載失敗即 raise,記錄程式碼不會執行)
- [x] `--offline` → 不呼叫網路、不動既有記錄
