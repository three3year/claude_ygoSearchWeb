# 01 — 中類機制與 數值 四個中類

**What to build:** 類別樹可以在大類與葉之間設中類:大類底下列中類清單、葉以名字宣告,宣告了的葉路徑是「大類 › 中類 › 葉」(詞元層省掉),沒宣告的照舊「大類 › 詞元 › 葉」。類別紀錄每個葉附路徑;拆解頁類別欄照路徑顯示,類別總覽的大類底下中類排在詞元節點之前。真樹的 數值 開 攻撃力、守備力、レベル、Pスケール 四個中類(レベルになる、同じレベルになる 也歸 レベル)。站主在類別總覽點開 數值 › 攻撃力 就看到 アップ:攻撃力、ダウン:攻撃力、になる:攻撃力… 所有攻擊力的變動。規格:`.scratch/category-middle-class/spec.md`。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 樹來源檔:頂層大類可帶中類清單(順序即總覽順序),葉可宣告中類(值在所掛大類的清單裡;借到別大類的葉用那個大類的清單);葉名不變。
- [ ] 完整性檢查四條,各有小樹例子:葉宣告的中類不在所掛大類的清單、清單裡的中類沒有葉、中類與同大類的詞元節點同名、葉引用的中類屬於別的大類。
- [ ] 類別歸組接縫的紀錄多「路徑」欄(每個葉一條,與葉清單同序);既有回歸例子補上預期路徑(直接寫出,不用依葉名查樹的輔助函式)。
- [ ] 回歸例子:攻撃力・守備力 アップ 兩條路徑、無屬性 アップ 仍是 數值 › アップ › アップ、レベルになる 歸 數值 › レベル、沒中類的大類路徑不變;另以小樹驗「同一詞元的葉一半在中類、一半在詞元節點」。
- [ ] 拆解頁類別欄與類別總覽照路徑;總覽的中類層與詞元層同一計數口徑(多葉框架在該節點只算一次),詞元節點只彙總留在它底下的葉。
- [ ] 全語料重跑:框架類別檔與卡層彙總檔與改動前逐位元組相同;分詞鏈重跑兩次相同;拆解頁照原網址重新發布。
