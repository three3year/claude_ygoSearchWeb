# 03 — 時機與事件回合禁用

**What to build:** 站主在拆解頁看到每個效果「什麼時候能發動」:發動句內的「自分メインフェイズに発動できる」→ 時機(自分·メインフェイズ·限定);「自分・相手のメインフェイズに」→ 雙方;「相手ターンに発動できる」→ 相手·ターン·限定;「この効果は相手ターンでも発動できる」→ 相手·ターン·追加;「自分・相手のバトルフェイズ開始時に」「自分スタンバイフェイズに発動する」這類階段時點也是時機。「この効果はこのカードが特殊召喚したターンには発動できない」→ 限制·事件回合禁用(事件=特殊召喚したターン)。原本這些「この効果は…」整句不出框架,現在改出約束框架。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 時機框架記誰的回合(自分/相手/雙方)、窗口(ターン、階段名、階段時點)、型態(限定/追加)、極性
- [ ] 時機只來自發動句內窗口與「この効果は」註記;只記原文寫出的,不依效果類型補;選項標籤「●相手ターン：」不出時機框架
- [ ] 「〜した場合に発動できる」照舊是條件位置的動作框架,不是時機
- [ ] 事件回合禁用框架記界定回合的事件與被禁止的動作
- [ ] 「①：１ターンに１度、自分メインフェイズに発動できる」同句出次數與時機兩個框架
- [ ] 每個句型一條回歸例子;受影響的既有例子改期望值
- [ ] 全語料重跑,發布拆解頁
