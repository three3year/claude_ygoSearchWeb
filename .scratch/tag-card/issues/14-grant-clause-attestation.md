# 14 — 「以下の効果を得る」的領起句吃掉了 `●` 的官方類型

**What to build:** 領起句 `〜は以下の効果を得る。` 與它底下的 `●` 子效果目前併在**同一個**[[效果句]]裡([[拆句表]]還沒把 `●` 拆開)。[[官方明示]]寫的是 `●` 的類型,但因為只有一行,那個類型被套在領起句上——而領起句本身根本不發動。

發現經過:票07 第二期輪 3 的遮蔽測試判錯 `89355716` 晴之天氣模樣 ②。

```
②：このカードと同じ縦列の…「天気」効果モンスターは以下の効果を得る。   ← 領起句,不形成連鎖
●このカードを除外し、…発動できる。…この効果は相手ターンでも発動できる。 ← 這個才是誘發即時效果(2速)
```

標記表給整團的類型是**誘發即時效果(2速)**,但同一張卡的[[補足情報]]自己寫著:

```
■『②：…「天気」効果モンスターは以下の効果を得る』効果はチェーンブロックの作られない効果です。
```

官方明說領起句**不形成連鎖**,所以 2 速不可能是它的類型——那是 `●` 的。這與票10 挖出的 `1516510` 符文眼靈擺龍是同一種病:官方講的是子效果,但拆句還沒把子效果分出來,類型就落到領起句頭上。
