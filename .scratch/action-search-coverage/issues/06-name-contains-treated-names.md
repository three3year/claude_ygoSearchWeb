# 06: 卡名包含:「〜として扱う」當作的卡名

Status: ready-for-agent

**What to build:** 卡名包含換卡號時,也算卡「〜として扱う」當作的卡名:當作的卡名先換成它指的那張卡,用那張卡的四種名字(中日英名與別名)比;對不到卡的用日文字面。不看位置條件。效果:打中文「救世龍」查得到「想い集いし竜」(它在場上、墓地當作「救世竜 セイヴァー・ドラゴン」)。

- 當作的卡名取卡片屬性表 `name` 的第二列起;對卡先比日文卡名原字,再比全半形折疊、去空白後的字(全庫 123 個全部對得到,見規格〔數據出處〕)。
- 動作索引加一節「當作的卡名」:每張有當作卡名的卡 → 對到的卡號清單與對不到卡的日文字面清單;Python 的 `decode_action_index` 與網站解碼一起加。網站用它加上前端索引的四種名字算同一組卡號;Python 從卡片結構與卡片總表算。
- 規格:需要你決定的「Q5」「Q11」;實作決策「卡名包含換成卡片編號」;使用者故事 26、27;測試決策「Python 的 `run_query`」「兩邊答案一致」。
