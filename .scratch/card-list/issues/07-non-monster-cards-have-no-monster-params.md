# 07 — 非怪獸卡不得帶怪獸參數

**What to build:** `_make_card` 對 `race` / `attribute` / `level` / `atk` / `def` 加上大類閘門——
`type` 沒有 `TYPE_MONSTER` 位元的卡,這五個欄位一律清空(數值欄 0、`atk`/`def` 為 `None`),
與既有的 `def: None if is_link` 、`scale` 只在靈擺卡填、`link_marker` 只在連結卡填同一條原則。
`setcode` **不動**(系列碼是卡面上真的有的東西,2,172 張非怪獸卡有值)。重生 `data/cards.json`。

**Status:** resolved

## 為什麼

cdb 為 79 張魔陷卡存了完整的怪獸參數(50 張永續陷阱、25 張通常陷阱、4 張永續魔法),
但那**不是卡片的參數,是它變成怪獸之後的參數**,而且**寫在效果文的括號裡而不是印在卡面上**:

> ②：陷阱卡發動時,連鎖那個發動可以在墓地發動此效果。此卡變成通常怪獸
> (**水族、水、等級2、攻1200/守0**)在怪獸區域特殊召喚(不當作陷阱卡)。
> —— 伯吉斯異獸 林喬利蟲 `1154611`,cdb 記 `race: 64, attribute: 2, level: 2, atk: 1200`

cdb 存這些欄位是給遊戲引擎用的:引擎得知道這張卡特召之後有什麼數值。

**決定性證據**是這兩張:

| 卡 | race | attribute | level / atk / def |
|---|---|---|---|
| 鏡像的沼澤人 `50277973` | **0** | **0** | 4 / 1800 / 1000 |
| 量子貓 `87772572` | **0** | **0** | 4 / 0 / 2200 |

卡文是「①：**宣言種族和屬性各1個**可以發動此卡。此卡變成持有宣言的種族、屬性的通常怪獸
(等級4、攻1800/守1000)」——種族與屬性在結算時才決定,所以 cdb 那兩欄空著。
**cdb 的 `race` 欄描述的確實是「特召後的形態」,形態不固定時它就空著。** 這不是解讀,
是 cdb 自己講明了。

留著這些值的實際後果:每一個消費者都得各自記得過濾一次,漏掉就是無聲的錯誤結果——
查卡網站的 spec 撰寫過程中就真的把 `race: 256` 當成卡片的種族判斷過一輪(見
`.scratch/search-web/spec.md` 與 ADR-0008)。修在來源層,下游就沒有機會犯這個錯。

「拿掉會不可逆」不成立:`cards.json` 是建置產物,要用時改回來重跑即可;而且那個資訊
本來就在效果文裡。

## Comments

2026-08-13 由查卡網站的 spec 撰寫過程發現。原本的設計是把過濾放在
`script/web/build_index.py` 的消費層,經使用者指出後改為修在來源層——理由是
`cardlist.py` 早就有同樣的閘門(`def: None if is_link`、`scale` 只在靈擺卡填),
魔陷卡這一類只是漏了。

依賴關係:`.scratch/search-web/` 的建置票應排在本票之後,或在本票完成前於
`build_index` 保留過渡用的大類閘門。

2026-08-13 實作完成。閘門在 `_make_card`,與 `def: None if is_link` 並排;
`MONSTER_PARAMS` 常數同時是閘門的欄位清單與不變式檢查的依據,兩處不會走鐘。

**驗收第 6 條「`git diff` 只動到那 79 張卡」與第 1 條互相矛盾,本票依第 1 條實作。**
第 1 條要求非怪獸的 `atk`/`def` 為 `None`,而 4,927 張非怪獸卡裡只有 48/47 張的
`atk`/`def` 原本非 0,其餘 4,848 張原本是 `0`——`0` → `null` 同樣是變動,所以
diff 必然是 4,927 行而不是 79 行。第 6 條是寫票時照著殘值統計表推出來的預期,
漏算了這一段。取第 1 條的理由:本票的原則是「欄位只在卡片真的有那個參數時才填」,
連結怪獸的 `def` 就是 `null` 而不是 `0`,非怪獸的 `atk`/`def` 沒有道理反過來留 `0`;
而且 `0` 對消費端來說是個看起來合法的攻擊力,正是本票要消滅的無聲錯誤來源。

逐欄核對 HEAD 版與新版(14,207 張全比):
變動 4,927 張,全部是大類非怪獸;怪獸卡 **0 張**變動;`setcode`、`scale`、
`link_marker`、`desc` 等欄位 **0 筆**變動。變動欄位分佈 `atk` 4,927、`def` 4,927、
`race` 76、`attribute` 76、`level` 75——後三者的筆數與票內的殘值統計表逐格吻合。
建置報告:「非怪獸清空怪獸參數: 79 張」、「不變式『大類是怪獸 ⟺ 有種族與屬性』: 成立
(怪獸 9280 張、缺種族或屬性 0 張、非怪獸殘留參數 0 張)」。冪等:再跑一次 sha256 相同。
