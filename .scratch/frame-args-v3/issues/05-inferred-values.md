# 05 — 推得值

**What to build:** 站主翻「墓地のこのカードを除外する」時,目的格是 除外、淡色標推得;「手札を１枚捨てる」的目的是 墓地、來源是 手札(都是推得);「デッキから１枚ドローする」的目的 手札 標推得、來源 デッキ 是原文不標。一張「動作 → 推得的目的/來源」對照表(規格決定):除外→目的 除外;捨てる→目的 墓地、來源 手札;ドロー→目的 手札、來源 デッキ;特殊召喚與各召喚法→目的 フィールド;セット→目的 フィールド;加える→目的 手札;装備、リリース、破壊 不補。只補原文沒寫的格,原文有字面時用原文;否定框架也補。動作框架多一個可選欄「推得」(值域 目的/來源)。
