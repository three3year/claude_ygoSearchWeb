# 03: 非此卡曳光彈——「特殊召喚←手札+非此卡」查得到

**What to build:** 「動作對象」切換多一個「非此卡」,選中的節點只算確定不動到此卡的動作。做完時「特殊召喚←手札+非此卡」查得到「從手牌特召別隻怪獸」的卡,查不到「此卡從手牌特召」或「此卡和1隻植物族從手牌特召」。

本票先做不需要發動位置推論的部分。沒有數量的全部類一律保守當皆非,也就是兩種模式都不中;推論在票 04、05。

來源:spec「動作對象判定 › 非此卡、皆非」「匯出檔格式」「索引管線」「查詢引擎」;GLOSSARY「動作對象」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 匯出判定非此卡:受事者是卡、字面不指名此卡,而且屬於下列之一:
  - 選擇類:帶數量,如數字+枚/体/つ,或「〜まで」。
  - 「このカード以外」。
  - 受事者寫成區域且帶數量:手札を１枚捨てる。
  - 受事者是效果、發動、攻擊,主人不是此卡:その発動、相手の効果。
- [ ] 皆非:沒有卡片受事者(ドロー、ダメージ、LP、數值),由一張封閉的名詞表決定;表外而且判不出的受事者列進報告。本票的全部類也暫時當皆非。
- [ ] 並列含此卡(このカードと〜、このカードを含む〜)只在此卡,不在非此卡。
- [ ] 匯出檔每句多記效果位非此卡葉、代價位非此卡葉;同一個葉可同時在此卡葉與非此卡葉。
- [ ] 索引每句再多兩個對齊欄位;引擎的非此卡模式改讀非此卡葉,包含、排除、含代價、AND、命中句照 01 的語意。
- [ ] 側欄切換多「非此卡」選項;網址參數多這個值,往返相等。
- [ ] 建置報告列非此卡與皆非的框架數、卡數,以及表外受事者數。
- [ ] 匯出接縫測試(日文例句):選擇類、此卡以外、丟棄1張手牌、對手的效果無效都是非此卡;抽卡、傷害是皆非;此卡和1隻…只在此卡;全場破壞暫為皆非。
- [ ] 引擎接縫測試:非此卡單葉包含;同句一葉同時在兩模式;雪花蓮型只中此卡;皆非框架只在不限中;排除套用非此卡模式;hash 往返三個值。
- [ ] effect-tokenize 全套與 script/ 測試通過;本機搜「特殊召喚←手札+非此卡」,記下張數與抽樣觀察。
