# 03: 排除與含代價

**What to build:** 牌手把節點點成排除時,卡上任何一句帶它的卡整張不出現;勾「含代價」時代價位的動作也算(包含與排除都算),條件寫進網址。來源:spec「查詢引擎(接縫 3)」「網址 hash」「側欄(query)」;GLOSSARY「動作類別」。

**Blocked by:** 02

**Status:** resolved

- [x] 排除(卡層):卡上任何一句(不受句層條件限制)的有效葉與任一排除節點交集,整張卡不中;同軸包含與排除衝突時排除優先。
- [x] 只有排除、沒有包含時:沒有類別紀錄的卡也不中;命中句照既有句層條件規則。
