# 04: 中心詞只能挑清單

**What to build:** 抽屜的受事者中心詞、目的中心詞兩欄,打字只是縮小清單,只能從清單挑;清單是目前條件下有命中的全部中心詞,打了清單外的字不收。見規格「判定」段中心詞一條、「中心詞框怎麼收字?」與「條件列與抽屜」段。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 抽屜選項的中心詞欄回候選清單:其他欄成立的框上這一欄出現過的中心詞,依中心詞表順序,不含已加入的,沒有 300 個上限
- [ ] 詞元在這一欄沒有任何中心詞、也沒有已加入的詞時不畫這一欄
- [ ] Enter、離開框、點抽屜別的鈕時,字等於清單裡某一項才加入;否則清空框、不改標籤
- [ ] 票 09 的「框裡有字時按下不搶焦點」保留:框裡是清單內的字時按抽屜別的鈕,字照樣收進去、按到的鈕照樣生效
- [ ] 網址帶進來的清單外的詞照列為已加入的項、可刪
- [ ] 條件模型測試:候選只含命中的、順序、不含已加入的;條件列事件測試(先例 typed_commit):清單內收、清單外不送 `onEdit` 且框被清空
