# 69 — 三張人工卡:拆句表兜底前言拆分

**What to build:** 票68 的機械規則救不了的三張,以拆句表人工紀錄拆開。需要兩個機制改動:**拆句表對編號卡的前言生效**(目前編號卡的紀錄被回報為未使用),與**效果外文本型引用的涵蓋即歸屬例外**(ADR-0012 第三決定)。

**Blocked by:** 68 — 單行前言以句號＋role 拆

**Status:** done

三張卡的實況與預期拆法:

- **50604072(/爆裂模式)**:日文兩行,但第一行是複合句對繁中兩句(「通常召喚できず、…でのみ特殊召喚できる。」↔「此卡不能通常召喚。只能用「爆裂模式」的效果特殊召喚。」),單位數 3≠2 退回(票67 退回清單)。紀錄:繁中前兩句合段 ↔ 日文第一行(召喚條件,官方【…について】引用整行括住,official),第三句 ↔ 第二行(使用次數限制)
- **4168871(黑羽的寶牌)**:日文一個複合句「「黒羽の宝札」は１ターンに１枚しか発動できず、このカードを発動するターン、自分はモンスターを特殊召喚できない。」,拆點在頓號(句中拆);繁中語序相反(召喚限制在前、次數在後),需 `ja_order`。官方引用整句括住裁定効果の扱いではありません → 涵蓋即歸屬,兩段都 official/high
- **45286019(齒輪齒輪人 Mk-III)**:同 4168871 形態(「…使用できず、…特殊召喚できない。」句中拆),舊式無編號卡、拆句表已有紀錄,改既有紀錄把 "0" 再拆成兩段;引用涵蓋即歸屬,兩段 official/high

檢核:
