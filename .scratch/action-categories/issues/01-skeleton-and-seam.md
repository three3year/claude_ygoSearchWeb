# 01 — 骨架與接縫:類別樹來源檔、歸組模組、框架類別檔

**What to build:** 分詞鏈重跑後多出一份框架類別檔:每個動作框架一列,記狀態(已歸/未歸/不適用)、葉清單與大類。類別樹是一份入版控的來源檔,這張票先只放幾個葉(區域移動 底下 特殊召喚←墓地、加える:デッキ→手札;破壊 自成一葉),用來打通整條路:樹 → 規則匹配 → 框架類別檔 → 測試接縫。站主能跑一次分詞鏈,看到「墓地から特殊召喚する」的框架已歸到 特殊召喚←墓地、條件位的框架記不適用、沒葉的詞元記未歸類。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 類別樹來源檔格式定案並入版控:節點三種(大類/詞元節點/葉),葉帶條件欄(詞元必填;來源區域、目的區域、極性、對象關鍵詞可選),葉名由條件機械組出(詞元←區域、詞元→區域、詞元:來源→目的、詞元:關鍵詞、詞元(否定))。
- [ ] 歸組模組讀框架抽取的輸出、寫框架類別檔(卡號/段落/句序/框架序、狀態、葉清單、大類、來源玩家、目的玩家;玩家欄本票可留空);決定性、不入版控,與 frames.json 同待遇;接在分詞鏈框架抽取之後。
- [ ] 匹配語意:只看框架欄位;位置是條件 → 不適用;詞元沒節點或條件全不符且無預設葉 → 未歸類;沒有「其他」。
- [ ] 建置期樹完整性檢查:葉名全樹唯一、每葉至少有詞元條件、每大類至少一葉、同詞元條件不重疊;違反時報錯不產出。
- [ ] 唯一接縫:一句效果句原文(帶上文)→ 每個動作框架的類別紀錄;測試檔放模組旁、用真的分詞器/詞典/樹,只斷言(動作、狀態、葉清單、大類、來源玩家、目的玩家)。第一批例子:蘇生、檢索、破壊 預設葉、條件位不適用、未歸類詞元、選項內的框架照貼。
- [ ] 全套既有測試照常通過;分詞鏈決定性重跑逐位元組相同。
