# 10: 離場

**What to build:** 「離れた」有動作詞,自我限制的「離れた場合に除外される」照代替記:

- 新增 離場(フィールドから離れた、フィールド上から離れた);從 = 場上,沒有到;不進推得表;沒有上下位詞,只比字面。字幹不能讓未解析組比中無關字面。
- 「Xが(相手の効果で/相手によって)フィールドから離れた場合/時」:條件段 離場,原因照既有閉集;閉集補「相手によって」,記 戰鬥或效果、方 對手(站主裁定)。
- 「Xがフィールドから離れた時に装備モンスター/そのモンスターは破壊される」:在「時に」切成條件段(離場)加效果段。
- 「(X)は、フィールドから離れた場合に除外される」「〜デッキの一番下に戻る」:照代替記,離場是被代替段、除外或返回是做代替的段(站主裁定);文面沒有「代わりに」,反向檢查為這個句型另寫模板。代替開關的行為不變。
- 「離れ、墓地へ送られた」照多子句串接的既有切法。
