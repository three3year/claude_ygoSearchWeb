# 01: 此卡曳光彈——「特殊召喚←手札+此卡」查得到

**What to build:** 牌手在動作類別軸頂端把「動作對象」切到「此卡」,選中的節點就只算動到此卡本身的動作。做完時「特殊召喚←手札+此卡」查得到「此卡從手牌特殊召喚」與「此卡可以從手牌特殊召喚」的卡,查不到「解放此卡發動,從手牌特召另一隻」。

這張先接通全鏈:匯出、索引、引擎、側欄、網址、強調。判定只做最核心的兩條:受事者以 このカード 收尾,以及主題規則。其餘字面規則在票 02。

來源:spec「動作對象判定」「匯出檔格式」「索引管線」「查詢引擎」「網址 hash」「呈現」「側欄」;GLOSSARY「動作對象」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 匯出時逐個帶葉的動作框架判定此卡:受事者依態取(他動取對象,自動/受身取主語、沒有時取主題),字面以 このカード 收尾就是此卡,含帶定語、未切掉區域或狀態的寫法。對象空著而主題(含句內延續的主題)以 このカード 收尾時,主題就是受事者,不分動作。
- [ ] 匯出檔每句在效果位葉、代價位葉之外,多記效果位此卡葉、代價位此卡葉;去重、依樹序,空的省略。決定性重跑兩次逐位元組相同。
- [ ] 索引每句多兩個對齊欄位(效果位此卡葉、代價位此卡葉),空值省略;兩次建置逐位元組相同。
- [ ] 查詢條件多「動作對象」,本票的值是不限與此卡。此卡時,每句的有效葉改取此卡葉;含代價時再加代價位此卡葉。包含、排除、AND、命中句都改讀有效葉;沒選節點時模式不影響結果;舊式卡文的卡照舊不中。
- [ ] 側欄:類別軸頂端、「含代價」旁放「動作對象」切換,本票先有「不限/此卡」,預設不限。模式不是不限時,摺疊的標題看得出模式在生效;手機寬度可點。
- [ ] 網址:模式以一個參數寫進 hash,不限時不寫;未知值安靜忽略,往返相等。
- [ ] 呈現:命中強調只標該句有效葉與包含節點葉集合的交集;同句「此卡從手牌特召」與「從手牌特召別隻」並存時,只強調前者帶來的葉。
- [ ] 建置報告列此卡框架數與卡數。
- [ ] 匯出接縫測試(日文例句經真的分詞鏈):此卡從手牌特召、主題寫法「このカードは手札から特殊召喚できる」、主題延續,三者都是此卡;代價解放此卡、處理特召別隻的句子,特召不是此卡。
- [ ] 索引接縫測試:新欄位對齊與空值省略。
- [ ] 引擎接縫測試:此卡單葉包含、上層節點、含代價、排除套用模式、AND 兩節點都在此卡模式成立、沒選節點時模式無效、命中句索引、hash 往返含未知值。
- [ ] 呈現縫測試:同句兩框架時只強調此卡的葉。
- [ ] effect-tokenize 全套與 script/ 的 Python、JS 測試通過;本機開網站搜「特殊召喚←手札+此卡」,記下命中張數(調查值:含主題規則約 861 張)。
