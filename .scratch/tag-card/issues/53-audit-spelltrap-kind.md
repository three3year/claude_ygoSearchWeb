# 53 — 稽核:魔法・陷阱卡的效果類型與官方敘述的一致性

**What to build:** 純讀稽核(不改 `data/tag_cards.json` 任何一行)。使用者發現官方的效果類型分類(起動/誘発/誘発即時/永続)在規則書上只適用於怪獸效果,假說是魔陷卡上官方只會在「變成怪獸時的效果」與「賦予怪獸的效果」兩種形態標類型。稽核全部魔陷卡帶 `kind` 的效果句(共 2,585 條),量化現有分類與官方敘述的一致程度,產出報告供決定要不要動 §5.8 的擴充判法。

**Blocked by:** 無

**Status:** done

## 範圍與方法(開工前與使用者議定)

三圈全稽:

1. **`official` 來源 60 條**(魔法 22 / 陷阱 38,非效果外文本):逐條回對[[補足情報]]原文,驗證抽取與歸屬正確(抓管線缺陷)。
2. **`llm`/`rule` 來源、非效果外文本 ~375 條**:按形態分桶普查(卡本身發動/持續適用段/賦予型●/變成怪獸/非場上狀態發動/裝備怪獸效果/其他),每條記三分法結論——**確認**(官方有話且一致)/**無證據**(官方沉默)/**衝突**(官方有話且不一致)。
3. **效果外文本 ~2,150 條**:掃補足情報有無「其實是效果/給了類型」的反向敘述,命中的逐條人工讀。

掃法:重用 `script/tag_card/official.py` 的 `attest()`(含 §6 的括弧外才算數、否定句優先、歸屬階梯),對全部魔陷卡重算官方明示,與表中紀錄雙向比對;對不上的與歸屬不出的逐條人工讀。

**預先議定的處置**:發現的衝突只列清單,留待改判票;**不預設基準線定語**——「官方只在哪幾類上標類型」的正式定語看完普查結果再定(實測 60 條裡有 1 條落在兩類假說之外:聖遺物運動機構 29223325 ②,墓地/除外狀態發動,官方明寫誘発効果)。CONTEXT.md 與 guide 這次都不改。

## 結果

實際條數:魔陷卡帶 `kind` 的效果句 2,585 條 = `official` 255(類型明示 60 + 效果外文本明示 195)+ `llm`/`rule` 非效果外文本 375 + 效果外文本(`rule`/`llm`)1,955。

### Part A:官方列 255 條——零缺陷

- 以 `official.attest()` 對全部魔陷卡重算官方明示,與表中紀錄**雙向比對:255 條全數一致,反向漂移 0 條**(重算得出、表上卻沒記 official 的:0)。
- 歸屬階梯分佈(類型明示 60 條):header 42 / quote 15 / seq 3。**沒有一條走弱階梯**(single / name_single),歸屬證據都是官方指名的。
- 獨立於 attest 的關鍵詞全掃(魔陷卡補足情報中括弧外含類型詞的行,共 75 行):62 行成為判定、8 行進註記(歸屬待拆/待判,見 Part D)、5 行是純解說他卡效果的句子(形勢反轉、王宮的號令、克己挑戰、無垢奧藝、鬼計驚嚇)——**無一遺漏**。
- 60 條類型明示的形態,逐條人工讀過:**變成怪獸時的效果 33 / 賦予怪獸的效果(●)26 / 非場上狀態發動 1**。唯一的第三形態是聖遺物運動機構(29223325)②:「墓地または除外された状態で発動する誘発効果です」。

### Part B:llm/rule 375 條——官方全部沉默

三分法:**確認 0 / 衝突 0 / 無證據 375**。而且 375 條**全部**落在有補足情報的卡上(無補足情報的 0 條)——官方對每一條都有機會講而沒講。與使用者的前提相符:官方的類型詞不用在「以魔陷卡身分」運作的效果句上。

內部一致性(§5.8 固定表:卡本身發動的類型應由卡片種類唯一決定):

- **違規 1 條**:寶石強化(41777,通常陷阱)index 1 判**啟動效果**,§5.8 應為誘發即時效果(2速)。`llm` 來源,候選改判標的。
- **需覆核 2 條(規範空白,不是違規)**:明與宵的逆轉(3160805)與深淵的護身符(8279188),兩張都是**永續陷阱在場上的效果發動**(補足情報明說卡的發動本身另外隨時可做),分別判了啟動效果/誘發效果(1速)。陷阱卡的效果發動規則上是 2 速,但 guide §5.6 的第一道閘門只寫了「卡本身的發動」,這一族目前無明文——要不要補規則、這兩行要不要改,留給下一張票。

### Part C:效果外文本 1,955 條——零衝突

官方對效果外文本行的反向敘述(「其實是效果/給了類型」):**0 條**。另有 7 行官方的「効果として扱いません」明示自動歸屬不出(quote 涵蓋不到整句等),逐行人工讀:4 行印證了 `rule` 判的行(牌組封鎖 0、墨瓦臘尼加 0、大進化藥 0、Ω眼鏡的段內子句),3 行的標的效果句還沒判(潔淨世界①、終刻起動②、超升階魔法究極之力②領起句)——無資料錯誤。

### Part D:附帶發現(留給後續判定票)

純愛妖精三張速攻魔法(21347668 瞌睡回憶、55584558 美味回憶、82105704 快樂回憶)的補足情報,對「此卡作為超量素材時賦予怪獸的 ② ● 效果」有**直接類型明示**(誘発効果/永続効果),但標頭歸屬自動對不出,標的 ● 效果句目前都還沒判(kind=null)。將來排到這幾張時判定者要看補足情報。

### 假說評估(定語留待使用者決定)

官方在魔陷卡上標類型的形態,實測就是三種:**變成怪獸時的效果**(33)、**賦予怪獸的效果**(26)、**非場上狀態發動的效果**(1)。共通點可收斂為一句:官方標類型的都是「不在以魔陷卡身分發動/適用中」的效果句。魔陷卡以自己身分在場上的效果句(發動、觸發、持續適用),官方明示 **0 條**——現行 §5.8 的擴充判法是專案自己的延伸,與官方**不衝突**(官方沉默),但也**無官方背書**。要維持現狀、還是把這些行改為不分類/新值,是模型層決定,本票不動。
