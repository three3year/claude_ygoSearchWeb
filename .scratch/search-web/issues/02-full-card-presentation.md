## Comments

2026-08-13 實作完成。`script/web/webindex.py` 補齊欄位(+ 17 條測試,共 65 條);
前端 `web/js/{util,render}.js` 與 `style.css` 改寫。索引從 6.03 MB / gzip 1.54 MB
長到 **7.15 MB / gzip 1.82 MB**(spec 用中文字串估的是 7.82 / 1.75 MB)。

**索引欄位的有無由大類與[[卡片子類型]]決定,不由值決定。** 這是本票最容易寫錯的一行:
「空值省略」照字面做的話,攻擊力 0 的怪獸會變成攻擊力未知、刻度 0 的 28 張靈擺卡會變成
沒有靈擺欄。真正的規則是**這張卡有沒有那個參數**——連結怪獸沒有守備欄,非怪獸沒有種族
屬性等級攻守(罠モンスター那 79 張的數值是它變成怪獸之後的形態),靈擺卡有刻度。
攻守的 `?`(攻 83、守 54)沿用 cdb 的哨兵值 `-2`,前端以「負值即 `?`」讀它,兩邊不必
對同一個數字。

**`s`(子類型)不在本票的欄位清單裡但一起帶進來了**:素材指定行要依召喚法上色、超量的
階級要畫成 `☆` 而不是 `★`,兩件事都得知道子類型。票01 的 Comments 也記著「短碼不在
按鈕清單」那個方向要等 `s` 進來才有真的觸發路徑——[[衍生物]]就是它,現在有測試餵一張帶
`0x4000` 位元的卡進去,建置會倒。`o`(必發/選發)留給票06,本票沒有用到它的顯示。

**多加了一道檢查:`※` 別名的缺口與抽取結果對不上即建置失敗。** 覆蓋檢查的缺口分類器
(看到 `※` 開頭就放行)與抽取器(要求換行 + `※` + 一行到底)是兩份對「別名長什麼樣」
的定義,漂開的時候那一段文字會 `tx`、`ax`、`d` 三處都沒有——放它過去等於在覆蓋檢查上
開一個吃掉真文字的洞,與票01 把故事文抽進 `d` 是同一個理由。實測 117 張兩邊一致。

**行首的標籤改成寫 `role` 而不是「效果外文本」**(票01 掛的 `.eff-kind`):8,180 行都
寫同一個詞等於沒寫,而素材指定/召喚條件/使用次數限制才是使用者一眼要分出來的東西。
沒有 `role` 的效果句照舊顯示[[效果類型]]。票04/06 的命中 badge 掛在同一個位置。

2026-08-14 訂正(使用者裁示):**標籤改成常態不顯示,點一下該行才展開在整段效果文的
下方**,再點收起。讀卡文的人多數時候要讀的是卡文,32,637 行各掛一顆類型標籤是雜訊;
而「這一句是誘發即時還是啟動」是一次刻意的提問,值得一次點擊。位置從行首移到文字**下方
自成一行**——接在文字後面的話它會擠進最後一行的行尾,看起來像卡文的一部分。展開狀態
不進呈現狀態,全量重繪就散掉:那個問題問完了。沒有標籤的行(故事文、空的靈擺欄)不反應。
票04/06 的命中 badge 因此不再與它同位置——badge 要說明「為什麼這張卡被選中」,那是
常駐資訊,不能藏在點擊後面。

**多顯示了 OCG・TCG 限定**(驗收清單沒列):`ot` 為了票05 的搜尋條件本來就要進索引,而
「兩者」是 13,822 張的常態、不寫出來,只有 385 張限定卡會多出一個標記——這是卡面上讀不到
但玩家會想知道的事,而且不佔版面。

**靈擺通常怪獸的下半段標頭是 `【怪獸敘述】` 而不是 `【怪獸效果】`**(37 張):那一段是
故事文而不是效果,票01 已經把它抽進 `d`,呈現層照它的身分給標頭。

**分區與否看的是子類型而不是 `pz` 有沒有內容**(審查抓到的):16 張靈擺卡的靈擺欄是空的
——卡文就寫著 `【靈擺效果】【怪獸效果】` 中間什麼都沒有(例:645794 威風妖怪 蛤蟆),
其中 5 張連效果句都沒有。照 `pz` 非空判分區的話這 16 張連一個標頭都不長,讀的人分不出
剩下那幾行是靈擺欄還是怪獸欄的效果——而那正是分區要解決的問題。空的那一欄寫
`（無）`:標頭底下真的沒有東西時,寫出來才不會看起來像漏掉。

**卡圖載不到時用 `visibility: hidden` 而不是 `display: none`**:位置留著,某幾張缺圖時
右側的卡文才不會左右跳動。異圖切換時要把它清掉,否則前一張缺圖會讓後面每一張都不顯示。

**沒有加自動化的渲染測試**(spec 的 Testing Decisions:DOM 渲染結果、CSS、卡圖載入走
人工驗收)。實作過程以 `node:vm` + DOM stub 載入真實前端檔跑過一次冒煙:黑魔導 17 版異圖
的前後環繞、連結怪獸的九宮格、靈擺兩種分區、素材指定的五種上色、`攻?／守?`、`※` 別名
副標各驗一次。永久的接縫 3 測試 harness 是票03 的事。
