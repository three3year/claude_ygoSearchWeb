# 57 — 定案+落地:值域擴第十六值「靈擺魔法卡效果」(ADR-0005)

**What to build:** 值域決定票。P 區的卡官方規則上是「魔法カード扱い」,依 ADR-0004 的運作身分判準,靈擺效果句不該走六類怪獸側;但九個[[魔陷卡效果]]值以[[卡片種類]]命名,而卡片種類值域裡沒有「靈擺」——靈擺效果句在十五值制下無值可填。

現況(2026-08-10 掃描):靈擺欄(section=pendulum)共 595 行,rule 判效果外文本 136、official 判效果外文本 9(無形噬菌體家族等)、**llm 判過六類的只有 3 行**(白翼的魔術師 11067666 ①永續效果、疾行機人 多米諾蝴蝶 28151978 ①永續效果②啟動效果)、未判 447 行。官方對靈擺效果**零類型詞**(全表僅 EMクラシックリボー 55554175 一條擦邊引用,講的是被 P 效果破壞後觸發的怪獸效果,不是在分類 P 效果),也從沒寫過「〜カードの効果として扱います」——證據強度遠低於裝備狀態族(票56)。

**候選方案**(2026-08-10 使用者定案:採 1):

1. **值域擴第十六值「靈擺魔法卡效果」(採用)**——運作身分判準的自然延伸;身分本身(P 區=魔法卡)有規則書背書,值名是官方沉默處的自選,ADR-0005 記錄在案。
2. 靈擺效果維持六類怪獸側——與「P 區的卡是魔法卡」的官方規則矛盾,否決。
3. 泛稱值「魔法卡效果」/整欄留 null/另立值域——分別與票56「光寫大類不產生判定」相衝、佔死待判池、一欄兩套語意,否決。
