# 效果 Tag 分期貼標規劃表(票12 首版)

第1期(區域移動+觸發時機)已收官(seal 14/14,見 `seal-phase1.txt`);
後續期次按分群大小由大到小,每期複製本表一列開期次票,重複首期路徑:
規則直貼(遮蔽門檻)→ LLM 長尾 → seal → UI 補該類按鈕(按鈕由值域正典
自動長出,實際只需把類別加進 `tag_rules.PHASES` 與粗篩)。

## 首期實測基準(供估算)

- 母體:新式效果句 19,342 條;區域移動粗篩命中 ~11,000 條。
- 規則層:直貼 24,171 個 tag(93 條規則),LLM 長尾僅 144 條(判空 83)
  ——規則覆蓋率遠高於預期,長尾成本主要花在遮蔽樣本(679 句判定)。
- 觸發時機:規則 7,862 條、LLM 4 條。
- 錯標率:遮蔽 679 句/1,277 tag 錯標 0;規則收斂歷經 6 輪修正
  (誓約尾句、する場合條件形、●選項內嵌發動子句、多源列舉是主要陷阱,
  見 rulings.md 追記——後續期次直接沿用這些通則)。
