# 07 — LLM 檢驗第一輪

**What to build:** 依約束框架分層、固定種子抽 300 張卡(有限制·次數、時機、誓約/召喚條件、素材與事件回合禁用的卡各有配額,並保留一層「有動作框架被取代」的卡),切成 6–8 份交 LLM 子代理,每份讀原文與框架「挑錯」。產出依錯誤類型歸納的報告,作為 08 修規則的輸入。沿用動作框架那套抽樣、切批、彙整工具,加約束框架的分層與錯誤類型。

**Blocked by:** 02、03、04、05、06

**Status:** ready-for-agent

- [ ] 分層規則與種子固定,300 張樣本清單存檔(同批複檢沿用)
- [ ] 錯誤類型固定:漏認約束、誤認約束、類別/子類判錯、欄位抽錯、取代錯誤(不該消失的動作框架消失,或該消失的還在)、次數歸屬判錯(句首/句中)
- [ ] 子代理回報格式統一(卡號、句標籤、框架序、錯誤類型、理由)
- [ ] 錯誤依類型歸納成報告,列各類次數與代表例
- [ ] 子代理數量維持 6–8 個;若改用多代理工作流程編排,先取得站主同意
