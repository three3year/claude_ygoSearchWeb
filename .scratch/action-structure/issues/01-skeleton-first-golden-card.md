# 01: 骨架:第一張標準卡跑通(特異点の悪魔)

**What to build:** 站主對特異点の悪魔(32484853)下動作查詢,得到正確的命中與不命中。這張票把整條路線打通:官方 DB 日文文本 → 區塊 → 段 → 卡片結構產物 → Python 查詢判斷 → 標準卡斷言。只實作這張卡用到的句型,其他句型留空或標「解析不出」。

範圍(依 spec「實作決策」):

- 來源:以卡片密碼對官方 DB 文本;次數限制前言不記。
- 區塊:新式卡依①切;本卡只有一個編號效果區塊。
- 段:條件段(相手がモンスターを特殊召喚した時,觸發形=時)、代價段(手札からこのカードと魔法カード１枚を捨てて)、效果段(そのモンスターを破壊する)。
- 物件:物件0、條件段的被召喚怪獸、代價的魔法卡;初始位置、數量。
- 自動規則:位置照順序更新、「從」繼承後查推得表(破壊 → 場上→墓地、捨てる → 手牌→墓地);從條件段指回來的(そのモンスター)不標取對象。
- 結構格先全部開好,值可留空、每格允許「解析不出」,保留原文範圍與原述語字面,段與物件用穩定 id。
- 產物:一卡一行 JSON、入版控;同一份輸入兩次建置逐位元組相同(時間與雜湊由 CLI 薄殼給進純函式)。
- 查詢判斷(純函式,輸入全庫結構與查詢,輸出命中卡與命中段):動作詞、從/到逐條對象線比、指定卡代入對象物件、段類別範圍、取對象、條件段與推得終點兩個開關(預設關)、極性預設只算「做」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 特異点の悪魔的查詢斷言寫成測試,站主核可斷言內容;至少涵蓋:命中「破壞 怪獸 場上(推得開)」、不命中「取對象 破壞」、命中「捨棄 手牌 → 墓地(推得開)」且對象含此卡、條件段開關關時不命中「特殊召喚」、開時命中
- [ ] 推得開關關時,沒寫明終點的段不以推得值命中
- [ ] 結構產物對全庫可產出(抽不出的格標解析不出,不中斷建置),同一輸入建兩次逐位元組相同
- [ ] 只用 Python 標準庫;測試用標準庫 unittest,與既有各組測試一起全綠
