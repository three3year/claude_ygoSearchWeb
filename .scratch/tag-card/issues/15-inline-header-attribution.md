# 15 — 黏在行尾的 `【…】` 標頭讓官方明示掛到上一個編號

**What to build:** [[補足情報]]的歸屬靠 `【①の効果について】` 這種標頭分段,而抽取器只認**行首**的標頭。官方偶爾把下一個標頭黏在前一行的尾巴,那一行之後的所有 `■` 明示就會繼續算在**上一個**編號底下,類型因此掛錯效果句。

發現經過:票07 第二期輪 4 的遮蔽測試判錯 `49456901` CNo.104 假面魔蹈士 黑影 ②。

```
【②の効果について】
■『このカードが「No.104 仮面魔踏士シャイニング」をX素材としている場合、以下の効果を得る』そのものは効果として扱いません。【『●』の効果について】
■モンスターゾーンで発動できる誘発即時効果です。      ← 這是『●』的,卻算成了②的
```

官方在同一行裡先說「② 的領起句根本不是效果」,再用黏在行尾的標頭切到 `●`。抽取器看不到那個標頭,於是把 `●` 的**誘發即時效果(2速)**填給了 ②——而官方對 ② 的明示其實是**效果外文本**。
