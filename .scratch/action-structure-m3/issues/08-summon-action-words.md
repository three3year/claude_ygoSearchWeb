# 08: 召喚動作詞

**What to build:** 單獨的「召喚」有動作詞,「〜に成功した」的條件段解析得出:

- 新增 召喚(上位詞 通常召喚)、上級召喚(アドバンス召喚、生け贄召喚;上位詞 召喚)、反轉召喚(反転召喚;沒有上位詞)、P召喚(P召喚、ペンデュラム召喚;上位詞 特殊召喚)。下位詞展開現行已是傳遞的,只在下位詞表加列。
- リンク/シンクロ/エクシーズ召喚 同義到既有的 L/S/X召喚。
- 「召喚・特殊召喚」「召喚・反転召喚・特殊召喚」等列舉:一段多個動作詞。
- 「このカードが召喚した時」與「召喚に成功した時」記同一個結構,此卡是被召喚的角色;原述語字面各自保留。
- 「墓地からの特殊召喚に成功」的「からの」記成 從;「モンスターの特殊召喚に成功」的「の」是對象線助詞。
- 「この効果で/この方法で特殊召喚に成功した」記原因 效果,指向本卡那一段;「「X」モンスターの効果によって」記原因 效果帶物件(既有)。
- 「召喚」字幹不能讓未解析組比中無關字面。

「〜を素材として〜召喚に成功した」在票 09;「により降臨」在票 11。

- 規格:需要你決定的「單獨的「召喚」記成什麼?」;實作決策「動作詞與同義表」(預設 8、9);使用者故事 1–10。「上級召喚」這個中文名是寫規格時取的,站主核可時可以改。
