# 效果類型判別規範

這份文件是[[效果標記表]]所有判定票與遮蔽測試的共同依據。它必須能獨立運作:**讀者手上只有一張卡的繁中卡文、日文卡文、[[補足情報]]、與這份文件**,沒有對話脈絡、沒有前一票的記憶。

判定的輸出是每個[[效果句]]的兩個值:

- [[效果類型]] —— 六種固定值之一,每個效果句只有一個。
- [[必發/選發]] —— 只有「誘發即時效果(2速)」「誘發效果(1速)」兩類有值,其餘一律留空。

**判定以日文卡文與補足情報為準**,繁中卡文只用來對照與人工複查。效果類型是官方裁定概念,經過翻譯會失真。

詞彙一律使用 `CONTEXT.md` 的定義([[效果句]]、[[效果類型]]、[[必發/選發]]、[[效果外文本]]、[[官方明示]]、[[補足情報]]),不使用實作欄位名。

---

## 1. 判別流程

從上往下走,**第一個成立的分支就是終點**,不回頭、不併存。走完必然停在恰好一個類型上。

```
步驟 0:這一段是效果嗎?
  ├─ 補足情報寫「〜は効果として扱いません」 ─────────────────→ 效果外文本
  ├─ 這一段是素材指定 / 召喚條件 / 使用次數限制 / 卡名規則文字 ─→ 效果外文本
  └─ 否則 ↓

步驟 1:補足情報有指向這一句的官方明示嗎?
  ├─ 有(且歸屬確定,見 §6) ────────→ 直接採用官方寫的類型,流程結束
  └─ 沒有,或歸屬不確定 ↓

步驟 2:這一句會形成連鎖嗎(有「發動」這個動作嗎)?
  ├─ 不會(常時適用、或只是一段處理程序) ──→ 步驟 3
  └─ 會 ─────────────────────────────────→ 步驟 4

步驟 3:不形成連鎖的效果(先過 §5.5 的四條分界,任一成立即為無種類效果)
  ├─ 效果在場上持續適用(數值變動、限制、不受影響、視為某種狀態且持續) → 永續效果
  └─ 是一次性的程序或規則處理(特殊召喚方法、代替素材、當作通常怪獸
     處理、勝利條件、把自己當裝備卡裝備) ──────────────────────→ 無種類效果

步驟 4:形成連鎖的效果
  ├─ 不是 2 速,但發動時點同時涵蓋主要階段與戰鬥階段 ───→ 無種類效果(§5.7)
  ├─ 可以在對手回合發動,或可以連鎖其他效果發動(2速) ──→ 誘發即時效果(2速)
  ├─ 有觸發事件(「〜した場合」「〜した時」「リバース：」),
  │  只在該時點形成連鎖,不能連鎖對手的效果 ─────────────→ 誘發效果(1速)
  └─ 沒有觸發事件,由自己在主要階段主動發動 ─────────────→ 啟動效果
```

判不出來時**不要猜**。把該效果句留空並在該票的結果檔記下理由,列進待審清單。留空是可以被後續處理的訊號,猜錯會變成沒人看見的錯誤資料。

## 2. 六種效果類型

### 2.1 效果外文本

不構成任何效果的卡文段落。三種常見形態:**素材指定**(融合/同調/超量/連結素材與儀式的降臨指定)、**召喚條件**(此卡不能通常召喚、只能用某方法特殊召喚、上級召喚時的解放限制)、**使用次數限制**(這個卡名的①②效果1回合各能使用1次)。另外「這個卡名在規則上也當作「〜」卡片」這類卡名規則文字也屬此類。

官方判別記號:**「〜は効果として扱いません」**。凡是官方這樣寫的段落,一律是效果外文本。

官方寫過八種等義變體,共通形狀是**「効果」後面直接接「扱い」**,看到任何一種都算數:`効果として扱いません` / `効果として扱われません` / `効果としては扱いません` / `効果としては扱われません` / `効果としての扱いではありません` / `効果としての扱いません` / `効果の扱いではありません` / `効果の扱いにはなりません`。「効果」與「扱い」之間夾了別的詞的(`効果で破壊された扱いにはなりません`、`効果ダメージの扱いではありません`)講的是別件事,**不算**。

官方例句:

- **被封印的艾克佐迪亞 / 封印されしエクゾディア**(33396948)
  卡文:`このカードと「封印されし者の右腕」…が手札に全て揃った時、自分はデュエルに勝利する。`
  明示:`■効果として扱いません。このカードによって定められた勝利条件です。`
- **黑暗武裝龍 / ダーク・アームド・ドラゴン**(65192027)
  卡文:`このカードは通常召喚できない。` / `自分の墓地の闇属性モンスターが３体の場合のみ特殊召喚できる。`
  明示:`【『このカードは通常召喚できない』について】■効果として扱いません。`
  明示:`【『自分の墓地の闇属性モンスターが３体の場合のみ特殊召喚できる』について】■効果として扱いません。手札のこのモンスターを特殊召喚する方法です。`
- **大飛蛾 / グレート・モス**(14141448)
  明示:`■『このカードは通常召喚できない。「進化の繭」が装備され…特殊召喚する事ができる』は効果として扱いません。`

### 2.2 無種類效果

**是效果,但不屬於其他四種發動/持續類型。** 對應官方用語「起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果」。

典型形態:不形成連鎖、也不是持續適用的**一次性程序或規則處理**——手牌/墓地的自我特殊召喚程序、代替融合素材、把自己當裝備卡裝備上去、在場上與墓地「當作通常怪獸處理」。

「不形成連鎖」是典型形態,不是定義。官方判過一條**自己就寫「発動できる」**的無種類效果,判別依據是發動時點四類都容不下——見 §5.7。

官方例句:

- **心眼的女神 / 心眼の女神**(53493204)
  卡文:`このカードを融合素材モンスター１体の代わりにする事ができる。その際、他の融合素材モンスターは正規のものでなければならない。`
  明示:`■「心眼の女神」の効果は、起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果です。`
- **守護者 艾爾朵絲 / ガーディアン・エアトス**(34022290)
  卡文:`①：自分の墓地にモンスターが存在しない場合、このカードは手札から特殊召喚できる。`
  明示:`■『①：…このカードは手札から特殊召喚できる』効果は、…いずれにも分類されない効果です。(この方法で特殊召喚を行う際にチェーンブロックは作られません。)`
- **鳳凰 機亞弗里德 / フェニックス・ギア・フリード**(69488544)
  卡文:`①：このカードはフィールド・墓地に存在する限り、通常モンスターとして扱う。`
  明示:`■『①：このカードはフィールド・墓地に存在する限り、通常モンスターとして扱う』モンスター効果は、…いずれにも分類されない効果です。`
- **龍盟-標槍龍 / ドラグニティ－ジャベリン**(80549379)
  卡文:`このカードがモンスターカードゾーン上で破壊された場合、墓地へ送らずに装備カード扱いとして…装備できる。`
  明示:`■起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果です。`

> 注意 **フェニックス・ギア・フリード** 這個例子:句型帶「〜存在する限り」,看起來像永續效果,官方卻判為無種類效果——因為它做的是「規則上把自己當通常怪獸處理」,而不是在場上適用一個效果。**「〜として扱う」的規則處理歸無種類效果,但只在適用範圍伸出場外時成立**(這個例子是`フィールド・墓地`)。同一句話若限定在怪獸區域(`①：このカードはモンスターゾーンに存在する限り、通常モンスターとして扱う`,聖騎士 鮑斯 47120245)官方判**永續效果**。完整分界見 §5.5 分界一,那一節是本規範被實測打臉最多次的地方,判到不發動的效果時**逐條核對**。

另外五種常見形態,它們都長得很像永續效果,官方一律判無種類效果(判別依據見 §5.5):

- **同名卡在場上的唯一性限制** —— `「氷剣竜ミラジェイド」は自分フィールドに１枚しか表側表示で存在できない。`
- **離場時的自我除外** —— `表側表示のこのカードはフィールドから離れた場合に除外される。`
- **由召喚方法決定的原本數值** —— `召喚したこのカードの元々の攻撃力は１０００になる。`
- **破壞替代,而替代手段動用墓地的自己** —— `自分フィールドの「六武衆」モンスター１体のみが効果で破壊される場合、代わりに墓地のこのカードを除外できる。`
- **把效果賦予給「以此卡為素材召喚的怪獸」** —— `フィールドのこのカードを素材としてX召喚したモンスターは以下の効果を得る。`

**否定句優先**:含「いずれにも分類されない」的明示句,一律判為無種類效果。這句話會列舉其他四個類型詞,**不得因為看到那些詞而多重比對**。

### 2.3 永續效果

不形成連鎖、在場上(或指定的區域)**持續適用**的效果。判別關鍵是「持續」:攻守數值變動、對手不能做某事、此卡不受某類效果影響、只要某張卡存在就適用。

句型線索:`〜限り`、`〜する場合`(狀態條件而非事件)、`〜につき`、`〜できない`(施加於對手或雙方的持續限制)、`〜アップする`/`〜ダウンする`。

**這些線索無種類效果也照用**,只憑句型會整族誤標——判到不發動的效果一律先過 §5.5 的四條分界。

官方例句:

- **深海的戰士 / 深海の戦士**(24128274)
  卡文:`「海」がフィールド上に存在する限り、このカードは魔法の効果を受けない。`
  明示:`■「深海の戦士」の効果は永続効果です。`
- **野蠻人2號 / バーバリアン２号**(40453765)
  卡文:`①：自分フィールドの「バーバリアン１号」１体につき、このカードの攻撃力は５００アップする。`
  明示:`■『①』のモンスター効果は永続効果です。`
- **千眼納祭 / サウザンド・アイズ・サクリファイス**(63519819)
  卡文:`①：このカードがモンスターゾーンに存在する限り、このカード以外のフィールドのモンスターは攻撃できず、表示形式の変更もできない。`
  明示:`■モンスターゾーンで適用する永続効果です。`
- **森之住人 沃登 / 森の住人 ウダン**(42883273)
  卡文:`フィールド上の表側表示の植物族モンスター１体につき、このカードの攻撃力は１００ポイントアップする。`
  明示:`■「森の住人 ウダン」の効果は永続効果です。`

### 2.4 誘發即時效果(2速)

會形成連鎖、且**速度為 2**:可以在對手回合發動,也可以連鎖其他效果發動。

句型線索:`自分・相手ターンに`、`相手ターンでも発動できる`、`〜された時に発動できる`且該時點在對手回合(被攻擊的傷害計算時、被效果對象時)、手牌就能發動的怪獸效果。

官方例句:

- **栗子球 / クリボー**(40640057)
  卡文:`①：相手モンスターの攻撃で自分が戦闘ダメージを受けるダメージ計算時に、このカードを手札から捨てて発動できる。…`
  明示:`■手札で発動できる誘発即時効果です。`
- **雷魔神-桑卡 / 雷魔神－サンガ**(25955164)
  卡文:`①：…このカードが攻撃されたダメージ計算時に、攻撃モンスター１体を対象として発動できる。その攻撃モンスターの攻撃力を０にする。`
  明示:`■モンスターゾーンで発動できる誘発即時効果です。`
- **奧雷卡爾克斯的魔封劍 / オレイカルコスの魔封剣**(847217)
  明示:`■このカードの②の効果が適用されたモンスターがモンスターゾーンで発動できる誘発即時効果です。`

### 2.5 誘發效果(1速)

會形成連鎖、速度為 1、且**有觸發事件**:某件事發生「之後/當時」才能發動,不能拿來連鎖對手的效果。

句型線索:`〜した場合に発動`、`〜した時に発動`、`〜送られた場合`、`リバース：`、`自分エンドフェイズに発動する`(固定時點的強制發動)。

官方例句:

- **邪惡寄生蠕蟲 / 邪悪なるワーム・ビースト**(6285791)
  卡文:`①：自分エンドフェイズに発動する。フィールドの表側表示のこのカードを持ち主の手札に戻す。`
  明示:`■モンスターゾーンで発動する誘発効果です。(必ず発動する効果です。)`
- **三眼怪 / クリッター**(26202165)
  卡文:`①：このカードがフィールドから墓地へ送られた場合に発動する。デッキから攻撃力１５００以下のモンスター１体を手札に加える。…`
  明示:`■墓地で発動する誘発効果です。`
- **壺魔人 / 壺魔人**(55763552)
  卡文:`リバース：フィールド上に表側表示で存在する「ドラゴン族・封印の壺」を破壊する。…`
  明示:`■「壺魔人」のモンスター効果は、フィールドで発動する誘発効果です。`

### 2.6 啟動效果

會形成連鎖、速度為 1、**沒有觸發事件**:在自己的主要階段由自己主動發動。多半帶有代價(捨棄手牌、解放怪獸、除外墓地卡、取除超量素材)。

句型線索:`自分メインフェイズに発動できる`、`１ターンに１度、〜して発動できる`(前面沒有事件子句)、`〜を除外して発動できる`。

官方例句:

- **時間魔術師 / 時の魔術師**(71625222)
  卡文:`①：１ターンに１度、自分メインフェイズに発動できる。コイントスを１回行い…`
  明示:`■モンスターゾーンで発動できる起動効果です。`
- **飛箭龜 / カタパルト・タートル**(95727991)
  卡文:`１ターンに１度、自分フィールド上のモンスター１体をリリースして発動できる。…`
  明示:`■「カタパルト･タートル」のモンスター効果は、フィールドで発動する起動効果です。`
- **黑暗武裝龍 / ダーク・アームド・ドラゴン**(65192027)
  卡文:`①：自分の墓地から闇属性モンスター１体を除外し、フィールドのカード１枚を対象として発動できる。そのカードを破壊する。`
  明示:`【①の効果について】■モンスターゾーンで発動できる起動効果です。`

## 3. 無種類效果與效果外文本的差別

兩者都不形成連鎖,很容易混。差別在**它到底是不是效果**:

| | 是效果嗎 | 官方用語 | 例 |
|---|---|---|---|
| **無種類效果** | 是,只是不屬於其他四類 | `いずれにも分類されない効果です` | `①：自分の墓地にモンスターが存在しない場合、このカードは手札から特殊召喚できる`(守護者 艾爾朵絲) |
| **效果外文本** | 不是,連效果都不算 | `効果として扱いません` | `このカードは通常召喚できない`(黑暗武裝龍) |

實務上會撞在一起的是**特殊召喚程序**:同樣是「怎麼把這張卡叫出來」,官方兩種都判過。判別依據只有一條——**看官方怎麼寫**:

- 寫在召喚條件那一段、官方說「効果として扱いません」(黑暗武裝龍、大飛蛾)→ 效果外文本。
- 寫成一個編號效果、官方說「いずれにも分類されない効果です」(守護者 艾爾朵絲 ①)→ 無種類效果。

沒有官方明示時,以位置為準:**第一個效果編號之前的段落是效果外文本**;寫成編號效果的特殊召喚程序是無種類效果。

## 4. 必發/選發

**只有「誘發即時效果(2速)」與「誘發效果(1速)」兩類寫值。** 啟動效果本就由玩家主動開啟,永續效果、無種類效果、效果外文本則不發動——這四類一律留空,不要填「必發」。

三層,由高到低:

1. **官方明示** —— 補足情報寫「必ず発動」→ **必發**(官方寫過「必ず発動する効果です」「必ず発動します」「必ず発動し、〜」三種,都算)。
   - 邪惡寄生蠕蟲(6285791):`■モンスターゾーンで発動する誘発効果です。(必ず発動する効果です。)`
   - 壺魔人(55763552):`■「壺魔人」自身がリバースした場合に必ず発動する効果です。`
   - 闇晦之城(62121):`■このカードがリバースした場合に必ず発動する効果です。`
2. **日文句型規則** —— 找出這個效果句的**發動子句**,看它的結尾:
   - 以「できる/できます」結尾 → **選發**(`〜に発動できる。`)
   - 否則 → **必發**(`〜に発動する。`、`リバース：`)
3. **找不到發動子句** → 留空待判,不強行推定。舊式無編號卡文在依語意拆開之前也算這一類——那一團的第一句常是素材指定或召喚條件,不是發動子句。

### 發動子句怎麼抓(掃描邊界)

發動子句是效果句裡描述「什麼時候、付什麼代價、能不能發動」的那一段,**到第一個句號為止**:

- `①：このカードが墓地へ送られた場合に発動できる。デッキから…手札に加える。`
  → 發動子句 = `①：このカードが墓地へ送られた場合に発動できる。` → 以できる結尾 → **選發**
- `①：自分エンドフェイズに発動する。フィールドの…手札に戻す。`
  → 發動子句 = 第一句 → 不以できる結尾 → **必發**

**「…時,可以」完成式事件的邊界**是最容易咬錯的地方。舊式卡文常把發動時點與處理寫在同一句,或把「できる」放在處理的動詞上:

- `１ターンに１度、手札を１枚捨てる事ができる。その後カードを１枚ドローする。`
  ——「できる」在第一句、屬於發動子句 → 選發。
- `〜した時、相手に１０００ダメージを与える事ができる。`
  ——只有一句,「できる」屬於這一句 → 選發。

四條硬性邊界:

- **不得跨越效果句邊界**。日文官方卡文常整段不換行(`①：…。②：…。`),掃描時必須停在下一個編號之前;咬到下一個效果的「発動できる」會整族誤標。
- **不得把處理段的「できない」當成發動子句的結尾**。`〜は攻撃できない` 是處理內容,不是發動的可否。
- **句尾的括號補述要剝掉再看結尾**。官方把限制寫在發動子句句尾的括號裡,而括號內常自帶句號:`①：通常魔法カードが発動した時に発動できる（同一チェーン上では１度まで）。` 的發動子句是括號之前的部分,結尾是「発動できる」→ **選發**。不剝括號會把它讀成不以できる結尾而誤判必發(實測 130 條)。
- **領起句不是發動子句**。`②：…「天気」効果モンスターは以下の効果を得る。●…` 這種句子既沒有「できる」也沒提到発動,真正的發動寫在後面的 `●` 分項裡;此時**留空待判**,不得推定必發(實測 11 條)。

## 5. 歷史易錯區分

這一節是前一世代實際誤標過的地方。判定時**逐條核對**。

### 5.1 「只要OO在怪獸區域存在」= 永續效果

`このカードがモンスターゾーンに存在する限り〜`、`「海」がフィールドに存在する限り〜` 這種「只要…存在就…」的句型是**持續適用**,判**永續效果**,不要因為它描述了一個條件就當成有觸發事件的誘發效果。

- 千眼納祭(63519819)`①：このカードがモンスターゾーンに存在する限り…` → `■モンスターゾーンで適用する永続効果です。`
- 深海的戰士(24128274)`「海」がフィールド上に存在する限り…` → `■「深海の戦士」の効果は永続効果です。`

**唯一的例外**是「〜として扱う」的規則處理(見 §2.2 的 鳳凰 機亞弗里德):同樣帶「存在する限り」,官方判無種類效果。判別依據是這句話做的事情是**規則上的視為**,而不是在場上適用一個效果。

### 5.2 裝備方向:先確定主語是誰

繁中譯文的兩個方向長得很像,讀反會連「這是誰的效果」都標錯:

| 繁中 | 日文 | 此卡是什麼 |
|---|---|---|
| 裝備**此卡的**怪獸 | `装備モンスター` | 此卡是**裝備卡**,那隻怪獸被它裝備 |
| **此卡裝備的**OO | `このカードが装備している〜` | 此卡是**怪獸**(聯合怪獸等),它去裝備別的東西 |

判定約定:

- 此卡是裝備卡、效果寫「装備モンスターの〜」→ 判**無種類效果**。
- 此卡是怪獸、效果寫「このカードが装備している〜」→ 判**永續效果**。

這條是寫死的約定,因為**官方在這裡通常不給類型**。團結之力(56747793)`①：装備モンスターの攻撃力・守備力は…アップする。` 的官方明示只寫到:

```
■装備されているこのカードが適用するチェーンブロックの作られない効果です。(装備モンスターに適用される効果です。)
```

「チェーンブロックの作られない効果」同時涵蓋永續效果與無種類效果,**不構成官方明示**,不得當作類型依據——遇到這種寫法要走規範走到底,不要當成官方已經回答了。

反過來,官方**確實**指名時就照官方:轉生揭幕鎧甲(68663427)`①：このカードを装備したXモンスターは以下の効果を得る。` 的 ● 子效果,官方寫 `■このカードを装備したエクシーズモンスターがモンスターゾーンで適用する永続効果です。`——那些子效果是**被裝備怪獸**適用的永續效果。

### 5.3 誘發即時(2速)與誘發(1速)只差速度

兩個詞在繁中字面幾乎一樣,務必看清「(2速)」「(1速)」的標註。判別只問一件事:**能不能在對手回合、或連鎖其他效果發動?**

- 能 → 誘發即時效果(2速)
- 不能 → 誘發效果(1速)

問題是「在對手回合會觸發」不等於「能在對手回合發動」——`〜が戦闘で破壊された場合` 這種事件在雙方回合都會發生,它仍然是 1 速。**光看「這件事會不會發生在對手回合」判不出速度**,要看發動時點落在戰鬥流程的哪一格,見 §5.6。

「手牌就能發動的怪獸效果一律 2 速」也**不成立**:`②：自分が戦闘ダメージを受けた時に発動できる。このカードを手札から特殊召喚し〜`(源數之壁 42352091)是從手牌發動,官方判誘發效果(1速)。手牌只決定發動的**場所**,不決定速度。

### 5.4 「…時,可以」完成式事件的發動子句邊界

第三個歷史誤標區在[[必發/選發]]:舊式卡文把發動時點與處理寫在同一句,掃描發動子句時很容易咬過頭——尤其日文官方卡文整段不換行時會咬進**下一個效果句**。判別方式與兩條硬性邊界見 §4「發動子句怎麼抓」。

### 5.5 永續效果與無種類效果的四條分界

不發動的效果落在這兩類之間,而 §1 的步驟 3(「持續適用」vs「一次性程序」)不足以判掉全部——**「〜する限り」「〜できない」這些永續效果的句型線索,無種類效果也照用**。以下四條分界取自官方明示,判到不發動的效果時逐條核對,**任何一條成立就是無種類效果**,四條都不成立才回步驟 3。

**分界一:適用場所超出場上 → 無種類效果。**
永續效果只在場上(或官方指名的區域)適用。同一個「規則上視為」的句子,適用範圍限於怪獸區域是永續效果,範圍及於墓地或手牌就是無種類效果。**視為的是卡名還是種類都一樣,只看範圍**:

| 卡文 | 官方 |
|---|---|
| `このカードはモンスターゾーンに存在する限り、カード名を「海」として扱う。`(亞特蘭提斯的戰將 90098000) | 永續效果 |
| `このカードはモンスターゾーンに存在する限り、通常モンスターとして扱う。`(聖騎士 鮑斯 47120245) | 永續效果 |
| `このカードのカード名は、フィールド・墓地に存在する限り「ブラック・マジシャン」として扱う。`(混沌的魔術師 47963370) | 無種類效果 |
| `このカードのカード名は、墓地に存在する限り「ワイト」として扱う。`(白骨皇子 57473560) | 無種類效果 |
| `このカードはフィールド・墓地に存在する限り、通常モンスターとして扱う。`(巨型植物 53257892) | 無種類效果 |

**分界二:數值由召喚方法決定 → 無種類效果。**
`〈召喚方法〉したこのカードの元々の攻撃力は〜になる` 這種以召喚方法修飾主語的原本數值改寫是規則層級的處理,不是場上適用:

- `①：召喚したこのカードの元々の攻撃力は１０００になる。`(惡之魔娘 莉莉絲 23898021)→ **無種類效果**
- `①：このカードの元々の攻撃力・守備力は、このカードのレベル×３００になる。`(貪婪類星體 50263751)→ **永續效果**(沒有召喚方法修飾)

**分界三:破壞替代的代替手段動用墓地的自己 → 無種類效果。**
`〜が破壊される場合、代わりに〜` 的替代效果預設是永續效果(在場上適用),但代替手段若動用**墓地的**這張卡,它就不是在場上適用:

- `②：自分フィールドの「機塊」モンスターが効果で破壊される場合、代わりにフィールド・墓地のこのカードを除外できる。`(斷路機塊 5846183)→ **無種類效果**
- `③：フィールドのこのカードが戦闘・効果で破壊される場合、代わりにこのカードのX素材を１つ取り除く事ができる。`(剎帝利怒威 香格里拉 73542331)→ **永續效果**

**分界四:效果是賦予給別的怪獸而不是自己適用 → 無種類效果。**
`このカードを素材として召喚したモンスターは以下の効果を得る` 這種句子,賦予的當下此卡已經是素材、不在場上適用任何東西:

- `③：フィールドのこのカードを素材としてX召喚したモンスターは以下の効果を得る。`(古神 克圖格亞 12948099)→ **無種類效果**
- `②：このカードをS素材としてドラゴン族SモンスターをS召喚した場合、そのSモンスターは戦闘では破壊されない。`(輝煌的星之龍 75874514)→ **無種類效果**
- 但**被賦予的 `●` 子效果本身照常判**——那是被賦予的怪獸在場上適用的,多為永續效果(見 §5.2 的轉生揭幕鎧甲)。
- 對照:`①：このカードがモンスターゾーンに存在する限り、ターンプレイヤーは以下の効果を適用する。`(剛鬼 雷霆食人魔 30010480)是**永續效果**——此卡人在場上,分界四不成立。

**分界五:適用期間由「〜召喚に成功したターン」限定 → 無種類效果。**
永續效果的適用期間是「只要條件成立」,沒有回合邊界。不發動的效果若把適用期間綁在**某一次召喚的那個回合**,官方判無種類效果(實測 14/18,其餘為含發動子句的誤判):

- `②：フィールドのP召喚されたモンスターを素材としてこのカードが融合召喚に成功したターン、このカードは相手の効果を受けない。`(符文眼靈擺龍 1516510)→ **無種類效果**
- `①：このカードがX召喚に成功したターン、このカード以外のフィールドのカードの効果は発動できず、無効化される。`(DDD雙曉王 伽梨玉迦 15939229)→ **無種類效果**
- 對照:`②：このカードがモンスターゾーンに存在する限り、〜`沒有回合邊界,是**永續效果**。

還有一族只出現在同名卡限制上,直接記下來:`「〈本卡卡名〉」は自分フィールドに１体(１枚)しか表側表示で存在できない` 官方一律判**無種類效果**(氷剣竜ミラジェイド 44146295、王の影 ロプトル 94183877、星風狼ウォルフライエ 3322931 皆是),不要因為它是一條持續限制就判永續效果。同理 `表側表示のこのカードはフィールドから離れた場合に除外される`(混沌核 3806388)也是無種類效果。

### 5.6 戰鬥流程中的發動時點決定速度

沒有寫「自分・相手ターンに」「相手ターンでも発動できる」的戰鬥相關效果,速度看發動時點落在戰鬥流程的哪一格。這是 §5.3 的細則:

先過兩道前置閘門,兩道都不成立才查表:

- **這是陷阱卡或速攻魔法卡「這張卡本身的發動」嗎?** 是 → **誘發即時效果(2速)**。這兩種卡的發動依規則就是速度 2,不受下表約束:`①：相手モンスターの攻撃宣言時に発動できる。その攻撃を無効にする。`(魅影騎士團 失常磁環 62645025,陷阱)是誘發即時效果,而同一句話寫在怪獸上(拖曳山嫗 21187631)是誘發效果。它們在墓地等處由事件觸發的**其他**效果才照下表判。
- **卡文寫了跨回合許可嗎?** 分兩種,只有前者成立:
  - 獨立的一句 `この効果は相手ターンでも発動できる。` → **誘發即時效果(2速)**(實測 218/218)。
  - 寫在括號裡且**附帶條件**(`（自分の墓地の「テラナイト」モンスターが７種類以上の場合、この効果は相手ターンでも発動できる）`,煉星騎士 多祿某 64414267)→ **不算**,照沒有那句話時的形態判,實測 14/14 全是**啟動效果**。
- **發動時點的「回合」被寫死成對手回合嗎?** 指的是 `相手ターンの〜に発動できる` 這種把回合寫進時點的寫法(不是 `自分・相手ターンに`)。看那個時點是不是固定階段:
  - **不是**固定階段(`相手ターンの直接攻撃宣言時に`、`相手ターンのメインフェイズに`)→ **誘發即時效果(2速)**(實測 3/3)。`①：相手ターンの直接攻撃宣言時に、このカードを手札から捨てて発動できる。その攻撃を無効にする。`(速攻稻草人 18964575)官方明示`■手札で発動できる誘発即時効果です。`
  - **是**固定階段(`相手ターンのエンドフェイズに`)→ 照下表,是**誘發效果(1速)**(實測 5/5)。階段到來是觸發事件,寫成對手回合只是限定哪一邊的階段。

| 發動時點 | 類型 | 例 |
|---|---|---|
| `攻撃宣言時`,且時點的主語是**怪獸**(`相手モンスターの〜攻撃宣言時`) | **誘發效果(1速)**(實測 76/81) | `①：特殊召喚された相手モンスターの攻撃宣言時に、〜発動できる。その攻撃を無効にする。`(幻變騷靈 拖曳山嫗 21187631) |
| `ダメージステップ開始時〜ダメージ計算時`,**選發**,且效果**改變這一次戰鬥的數值或傷害**(攻守變動、戰鬥傷害處理、破壞替代) | **誘發即時效果(2速)** | `②：攻撃表示のこのカードが攻撃表示モンスターと戦闘を行うダメージ計算時に１度、発動できる。その戦闘では〜`(龍狸燈 42596828) |
| 同上但效果是**把怪獸破壞掉**而不是改數值 | **誘發效果(1速)** | `②：このカード以外の自分のモンスターが相手モンスターに攻撃されたダメージ計算前に発動できる。攻撃モンスターとこのカードを破壊する。`(魔鏡導士 念力限界者 65471349,實測 3/3) |
| 同上但**必發**(`〜発動する`) | **誘發效果(1速)** | `②：このカードが相手モンスターと戦闘を行うダメージ計算時に発動する。`(CNo.104 42396591) |
| 同上但效果**與這次戰鬥的數值無關**(例如把自己特殊召喚) | **誘發效果(1速)** | `①：自分の「剣闘獣」モンスターがモンスターと戦闘を行うダメージステップ開始時に発動できる。このカードを手札から特殊召喚する。`(劍鬥獸 維斯帕西亞努斯 88996322,實測 3/3) |
| `ダメージ計算後` / `ダメージステップ終了時` / `戦闘ダメージを受けた時` / `戦闘で破壊された場合` | **誘發效果(1速)** | `②：自分が戦闘ダメージを受けた時に発動できる。`(源數之壁 42352091) |

兩條要點:

- **誘發即時效果一律是選發。** 寫成 `〜発動する` 的必發效果不可能是 2 速,看到必發就可以把誘發即時排除掉。
- **「能不能連鎖對手」才是本質**,上表只是它在戰鬥流程上的投影。連鎖對手發動的效果(`相手が〜を発動した時に発動できる`)一律回 §5.3 判。固定階段的發動(`自分エンドフェイズに発動する`、`相手スタンバイフェイズに発動できる`、`相手バトルフェイズ開始時に発動できる`)是**誘發效果(1速)**——階段到來是觸發事件,不是連鎖能力。

> 「從手牌捨棄發動」不是速度的線索。`②：自分が戦闘ダメージを受けた時に発動できる。このカードを手札から特殊召喚し〜`(源數之壁 42352091)官方明示寫的是`■『②』のモンスター効果は、手札で発動する誘発効果です。`——手牌只決定發動的**場所**,速度看的是上面那三道閘門與這張表。

### 5.7 會發動、卻仍是無種類效果:發動時點橫跨主要階段與戰鬥階段

§2.2 的典型形態是「不形成連鎖」,但那是形態不是定義。官方判過一條**效果自己寫「発動できる」**的無種類效果,理由官方寫在括弧裡:它能在自己的主要階段**與**自己的戰鬥階段發動,四種發動類型沒有一種容得下這個時點——啟動效果只在自己的主要階段,誘發即時效果是 2 速,誘發效果要有觸發事件。

- **栗子巴比倫 / クリバビロン**(70914287)③
  卡文:`③：自分のメインフェイズ及びバトルフェイズに発動できる。このカードを持ち主の手札に戻し、自分の手札・墓地から「クリバー」「クリビー」「クリブー」「クリベー」「クリボー」を１体ずつ選んで攻撃表示で特殊召喚する。`
  明示:`■『③』はフィールドで発動できる効果です。（起動効果・誘発効果・誘発即時効果・永続効果のいずれにも分類されない効果です。自分のメインフェイズまたは自分のバトルフェイズに発動できます。対象を取る効果ではありません。ダメージステップには発動できません。）`

閘門(在 §1 步驟 4 的最前面):效果自己寫「発動できる」、**不**具 §5.6 的 2 速特徵、但發動時點同時涵蓋主要階段與戰鬥階段 → **無種類效果**。

順序不能顛倒:誘發即時效果本來就能在戰鬥階段發動,先判 2 速會把這條閘門變成整族誤標的來源。

**實測只有 1 條,而且不進[[規則層]]。** 官方判無種類效果的效果句裡,卡文出現「発動」的共 9 條,其餘 8 條的「発動」講的都是**別的**效果——拿別的效果的發動當條件(`〜モンスターが効果を発動するために手札を除外する場合、代わりに墓地のこのカードを除外できる`,S-Force 追溯者 53782828)——只有這一條是效果自己說「発動できる」。覆蓋 1 條遠低於規則層的 8 條門檻,所以它只寫在本文件,不登記為規則。

## 6. 官方明示的歸屬陷阱

補足情報會**為了解說而引用其他卡的效果文**。判定歸屬時必須確認引用的是**本卡**。

深海的戰士(24128274)是標準案例。它的補足情報三行:

```
■「深海の戦士」の効果は永続効果です。          ← 指向本卡,本卡只有一個效果句,採用
■「海」がフィールドに存在する間のみ適用される効果です。
■「海」がフィールドゾーンに存在する場合だけでなく、「海神の巫女」の『このカードが
  フィールド上に表側表示で存在する限り、フィールドは「海」になる』効果が適用されて
  いる場合でも、…                              ← 『』裡是「海神の巫女」的卡文,與本卡的
                                                 效果句無關,必須忽略
```

規則:

- 明示句用「」提到的卡名**只有別張卡**時,這一行不產生任何判定。
- 『』引用的效果原文**對不回本卡卡文**時,不猜歸屬。
- 『』引用同時命中**多個**效果段時,視為歧義,不採用。
- 卡名限定(「〈本卡卡名〉」の効果は…)但本卡有**多個**效果句時,由判定者決定歸屬,不整卡套用。
- 一行**只由第一個『』引用決定歸屬**。日文的寫作慣例是主語在前,後面的引用是解說時提到的另一個效果:`■『②』はフィールドで発動する誘発効果です。（『①』の効果を発動したこのカードが…必ず発動する効果です。）` 講的是②,①只是條件。逐一套用會把②的判定複製到①(實測 92 行,無一例外)。

歸屬確定不了時:類型值仍然是官方的,但**歸屬由判定者決定**,並在該票的結果檔記下判斷依據。歸屬與類型是兩件事,不要因為歸屬不確定就丟掉官方的類型。

## 7. 禁用句型

### 「効果ではありません」絕對不可作為判定依據

補足情報有 4,433 處出現「効果ではありません」,**絕大多數是限定否定**,與效果分類無關:

- `(対象を取る効果ではありません。)` —— 說的是不以卡為對象
- `チェーンブロックの作られる効果ではありません。` —— 說的是不形成連鎖,但沒說是永續還是無種類

把它當成「不是效果」會整族誤標數千行。**看到這個句型直接跳過**,回到 §1 的流程自己判。

會形成連鎖與否的資訊仍可作為**輔助線索**(不形成連鎖 → 走步驟 3),但它**不能**單獨決定六類中的哪一類。

### 「効果として扱いません」則可以採用

這是效果外文本的官方明示(見 §2.1,含八種變體)。但若它指向的段落**不在卡文開頭的前言段**,不要自動拆分卡文——列進報告請人工判讀。

**但括弧裡的那一種不算。** 官方會把「不算哪一種效果」的補述寫在句尾括弧,那和「対象を取る効果ではありません」同一類的限定否定:

```
■モンスターゾーンで適用する永続効果です。（モンスター効果として扱われます。罠カードの効果としては扱われません。）
```

這一行講的是永續效果,括弧只是說它不算陷阱卡的效果。**判別方式:明示句要出現在括弧之外才算數。**

## 8. 無編號舊式卡文的拆句原則

沒有①②③編號的舊式卡文,由判定者依語意拆成多個效果句。原則:

1. **每一段必須是原文的連續子字串。** 不改寫、不補字、不調整標點。拆出來的段落串起來可以有缺口(空白與換行),但每一段本身必須能在原文中原封不動找到。
2. **換行是強分隔提示。** 原文有換行的地方優先當切點。
3. **補足情報的「■」條目可作參考。** 官方逐項解說時常常一項對一個效果,但這只是提示——官方也會為同一個效果寫多條解說。
4. **一句一類型。** 拆出來的每一段必須能被判成單一效果類型;如果一段裡明顯有兩種類型(例如前半是誘發效果、後半是持續適用),那就是還該再拆。
5. **前言段照樣先抽出來。** 素材指定/召喚條件/使用次數限制在拆句時就分離為效果外文本,不要混進效果句。
6. 官方在一個效果內用「●」分項描述的子效果,拆成獨立效果句,各自單一類型。

拆完的段落若通不過連續子字串驗證,**不寫入**——列進待審清單。

## 9. 判不出來的時候

留空,並在該票的結果檔記錄:效果句的識別、卡文原文、你考慮過的兩個候選類型、以及卡不住的原因。

**不要**為了讓欄位不空而選一個看起來比較像的。留空的行會被列進待審清單由使用者處理;猜錯的行不會。

若不確定的原因是**這份文件沒講清楚**,那就是這份文件要改——遮蔽測試不通過時,修正對象是這份規範文件,不是重刷分數。
