# 03: 區域選單只列有命中的

**What to build:** 抽屜的來源、目的、所在三欄,玩家選單只列這個動作在這一欄出現過的玩家;區域選單不列動作沒有的區域,目前選的玩家與其他欄下沒有命中的區域灰掉、選不了。見規格「判定」段區域一條與「區域選單與中心詞候選要不要過濾?」。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 抽屜選項的區域欄回玩家清單(含狀態)與每個玩家對應的區域清單(含狀態);不限玩家一律列出
- [ ] 區域隱藏看詞元的框在這一欄有沒有這個區域(任何玩家),玩家隱藏看有沒有這個玩家
- [ ] 區域灰色看(選單上目前選的玩家或不限, 區域)在其他欄成立的框上有沒有;玩家在其他欄下沒有任何區域命中時也灰
- [ ] 已加入的區域項一律列出、可刪;整欄沒有可列的玩家與區域、也沒有已加入的項時不畫這一欄
- [ ] 抽屜的兩個選單照它畫,灰的選項不能選;換玩家時區域選單跟著換
- [ ] 條件模型測試(手寫小框表):玩家與區域的隱藏、依玩家的灰色、已加入的項照列
- [ ] 全套 node 測試通過
