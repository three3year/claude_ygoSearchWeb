# 06 — 回填轉欄

**What to build:** 站主翻「墓地のモンスター１体を選んで特殊召喚する」時,特殊召喚 那列回填 對象=モンスター１体、來源=墓地——選ぶ 不是移動類,區域在它的所在,交給移動類的 特殊召喚 時轉成來源;反過來移動類上游的來源交給非移動類下游時轉成所在。沿用第二版回填的兩種來源(か 群組、選ぶ鏈)與停止條件;下游原文自己有來源或所在時不填。回填欄值域多「所在」。回填接到的區域若下游又有推得的同欄,以回填為準。

**Blocked by:** 04, 05

**Status:** ready-for-agent

- [ ] 回歸例子先補、後修:選んで特殊召喚(所在→來源)、選び…破壊(來源/所在→所在)、加えるか特殊召喚 的群組轉欄、下游有原文來源時不填、回填蓋過推得(選んで捨てる 之類上游有區域時)、對象照舊原字面接過
- [ ] 全語料重跑:與修前比對,差異只落在既有回填框架(1,525)與新增的轉欄;抽查 20 句沒有接錯;決定性重跑相同
- [ ] 拆解頁轉欄的格照回填淡色,照原網址重新發布
