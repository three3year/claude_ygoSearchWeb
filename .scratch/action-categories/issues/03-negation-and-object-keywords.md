# 03 — 否定極性(耐性/限制)與對象關鍵詞

**What to build:** 否定極性的框架走獨立的詞元節點:被動否定與「にならない」(破壊されない、対象にならない)歸耐性那組大類、可能否定(できない)歸限制那組;可能極性視同肯定。葉條件可宣告對象關鍵詞(字面子字串清單),只在該葉宣告時比對:「魔法・罠カードを破壊する」歸 破壊:魔法・罠、「発動を無効にする」歸 無効にする:発動;對不上任何關鍵詞的落該詞元的預設葉。站主在框架類別檔看到「破壊されない」與「破壊する」在不同大類、「破壊できる」與「破壊する」同葉。
