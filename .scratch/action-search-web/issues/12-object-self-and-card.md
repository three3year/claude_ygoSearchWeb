# 12: 被動作的卡:這張卡自己、指定一張卡

**What to build:** 區塊多「被動作的卡」一欄,先做兩種選法:這張卡自己、指定一張卡。玩家可以查「自己不會被破壞的卡」和「哪些卡動得到 ブラック・マジシャン」。

- 「這張卡自己」是新的查詢:只命中物件是此卡的對象線。物件是一個條件式、而這張卡剛好滿足的,不算。查詢判斷多一個鍵;它和指定卡、給條件三者擇一。
- 「指定一張卡」用現有的指定卡查詢,網站這邊用候選卡集合比:指定的卡在這條線的候選卡裡就命中。寫明對象符合的與對任何卡都適用的都在清單裡,不分組。
- 物件代不進去的線不命中。物件判不了的線不命中;它進不進「無法確認」由票 15 負責,兩張票後做的那張要把這個接上。
- 介面:不指定、這張卡自己、指定一張卡三選一。指定卡時輸入卡名,從建議清單選,名字短的排前面。
- 區塊裡要有文字說明「這裡篩的是被動作的卡,不是有這個效果的卡」。
- 做動作的線(不是被動作的卡)不算。

- 規格:需要你決定的「Q19」;實作決策「比對規則」的這張卡自己、「玩家介面」;使用者故事 28、29、31、47;測試決策「接縫一」與標準卡表、「兩邊答案一致」。
- 參考:原型的三種選法與卡名建議。原型量到「龍族、破壞抗性」57 張,限定這張卡自己 40 張;原型的比對是粗略版,這兩個數字只當參考。
