# 07: 效果對應

**What to build:** 動作索引的每一段都對回前端索引的一個效果句。之後「要落在同一個效果」的判斷與標出命中的效果(票 16)都靠它。

- 建置多兩份輸入:效果標記表(提供每個效果句的日文原文,前端索引裡沒有日文)與前端索引(提供效果句的序號)。
- 對法依序:區塊有①②③編號時,對到同一個來源(主文或靈擺效果)裡同編號的效果句;沒有編號時,看段的原文位置落在哪個效果句的日文原文裡;都對不上就留空。
- 內嵌效果裡的段算在它所在的區塊上;引用列算在引用節點所在的效果上。
- 效果句的序號要和前端索引實際的序號一致;對不上時(效果句數不符)建置失敗。
- 建置報告列出留空的段數與卡號。
- 任何一份輸入變了,動作索引要跟著重建。

- 規格:需要你決定的「Q25」;實作決策「效果對應」、「動作索引」最後一條;使用者故事 53;測試決策「接縫二」。
- 統計:有編號的區塊裡的段佔 73.6%(規格〔區塊〕),其餘 26.4% 要靠原文位置。
