# 06 — 子句切分與位置:代價、效果、條件

**What to build:** 一句含多個動作時,拆解頁列出多個框架、依原文順序排,並正確標位置:「…捨てて発動できる。…手札に加える。」得到【代價】捨てる、【效果】加える;「…場合に発動できる」「…時」抽成【條件】框架;「その後、…」後的動作各自成框架。

**Blocked by:** 05

**Status:** resolved

- [x] 子句切分:依句讀與接續(。、て形、し、場合/時)切子句,一子句至多一個述語錨點
- [x] 位置判定:以 発動できる/発動する 為界,發動子句裡的付出=代價、處理段=效果(沿用[[槽位]]既有位置判準),觸發句與發動條件=條件
- [x] 回歸例子通過:代價+效果、條件框架(…場合に発動できる)、その後 連接的多框架、て形並列的兩個動作
- [x] 拆解頁顯示每個框架的位置

## 追記(2026-10-09 實作完成)

- 子句=述語錨點結束處切開(錨點含活用尾/否定/可能/形式名詞後綴與其後的助詞、讀點);
  定語用法(動詞後直接接名詞)不當錨點。
- 發動句=第一個以 発動できる/発動する 收尾(括弧外)的句子;句內:場合/時/際/限り/
  ターン/状態 收尾、対象として、狀態述語(存在/持つ/なる…)、被動形、辭書形 → 條件;
  て形/連用形的付出 → 代價(後面還有條件子句時歸條件);處理段 → 效果,條件子句照樣 條件。
- 発動 本身不成框架(速度註記「相手ターンでも発動できる」同);有直接對象或否定
  (〜を発動できない)才成框架。
- 回歸例子:代價+效果、條件(場合/時)、その後 多框架、て形並列、被動在發動句=條件。
