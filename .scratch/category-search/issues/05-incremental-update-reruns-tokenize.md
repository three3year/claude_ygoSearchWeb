# 05: 差值更新流程加重跑分詞鏈

**What to build:** 站主跑差值更新時,重建網站資料之前會先重跑分詞鏈(分詞 → 框架 → 類別 → 匯出),新卡與勘誤不會讓類別過時、也不會讓索引建置因雜湊對不上而擋住。來源:spec「資料更新」;ADR-0017。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 差值更新的腳本(或它呼叫的步驟)在重建網站資料前執行分詞鏈全鏈與類別匯出;任一步失敗就停下並說明是哪一步。
- [ ] 差值更新的文件(README 的更新步驟)補上這一步與「不重跑時索引建置會因類別過時而失敗」的說明。
- [ ] 既有的差值更新測試照舊通過;若流程是可測的純函式,補一條「步驟順序含分詞鏈」的例子。
- [ ] 實跑一次(或以 --no-write/乾跑)確認順序與耗時,記在本票 Comments。
