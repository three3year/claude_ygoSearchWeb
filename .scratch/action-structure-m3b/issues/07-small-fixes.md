# 07: 小修五項

**What to build:** 里程碑三摘要裁定要改的五個小項,各只動一處閉集、一條判法或一個模板;每項的前後數字在 Comments 分開記:

- **取り除けない**:去除的語尾拿掉「けない」;原本靠它解析出的 3 段回到解析不出(省略的受詞是前一句的計數器,照主語省略規則會記成此卡)。
- **召喚進推得表**:推得表加四列——召喚、通常召喚、上級召喚、反轉召喚 → 場上。原因「表示形式沒有到」的段不會全部解開:另外卡在這輪不收的寫法的(例如前文「自分は通常召喚に加えて１度だけ、」)換成別的原因,照舊解析不出。
- **選択して**:「選択して」而且明寫的出發地含牌組、手牌或額外牌組時記選擇,不記取對象(與既有的「選択し」同一把尺:混寫「手札・墓地」的也算含);明寫的出發地不含這三個區域的照舊。
- **スキヤナー 的模板**:舊式、有讀點的「〜離れた場合、ゲームから除外される」維持照代替記,只修反向檢查模板,寫回時不多寫「代わりに」。
- **異同判不了**:異同原子沒寫比較對象、而且所在物件的數量是恰好一張(數量值 1、比較是等於)時,指定卡代入判不了,那一段列進未解析組;其餘(沒寫數量、兩張以上、「１体以上」「１枚まで」)照舊讀成同群成員之間、單張卡代入一律符合。同一串修飾語裡前面的異同原子寫了比較對象、後面沒寫的,照里程碑三的規則已有比較對象,不在這一條。

- 規格:需要你決定的「其餘細項照預設嗎?」;實作決策「小修」「異同」「查詢判斷」「反向檢查與報告」;使用者故事 23、24、31–35、40。
