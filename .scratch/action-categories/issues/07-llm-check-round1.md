# 07 — LLM 檢驗 round1(依葉分層抽樣)

**What to build:** 樹封頂、全語料貼完後,依葉分層固定種子抽樣——每葉抽 5 個框架(不足 5 全取)、未歸類另抽 50 個——切成 6〜8 份交 LLM 子代理:每份拿原文子句、框架欄位與葉定義,回報錯誤分三類(歸錯葉、該歸未歸、葉定義本身有問題)附理由。錯誤依類型歸納、連同樣本清單存檔,站主能看到第一輪的錯誤率與高頻類型。

**Blocked by:** 05, 06

**Status:** ready-for-agent

- [ ] 抽樣腳本決定性(固定種子、依樹序),樣本清單存檔以便複檢可比。
- [ ] 子代理提示含葉定義(條件欄)與樹的局部(同詞元的其他葉),讓「歸錯葉」能指出該歸哪一葉。
- [ ] 錯誤歸納檔:每筆附卡號、框架、子代理理由、類型;同型錯誤計數。
- [ ] 票 Comments 記樣本量、錯誤數與比例、高頻類型。
