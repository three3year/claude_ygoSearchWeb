# 11 — 未拆句的舊式整團不該當成「單效果卡」套用官方明示

**What to build:** 判斷官方明示歸屬的階梯四、五(卡名限定 + 單效果卡、無歸屬標記 + 單效果卡)問的是「這張卡是不是只有一個[[效果句]]」。舊式無編號卡文在票08 依語意拆開之前**整團只算一個效果句**,於是這兩道階梯會在一個假的前提上開火:整團拿到一個官方類型,而那個類型其實只描述整團裡的其中一段。

發現經過:票07 的遮蔽測試裡 `40160226` 機海龍 蛇頸龍 判錯,使用者查官方 Q&A 後指出卡文其實是兩段:

```
自分フィールド上に海竜族モンスターが存在する場合、このカードはリリースなしで召喚できる。   ← 無種類效果
１ターンに１度、自分フィールド上の水属性モンスター１体をリリースする事で、〜破壊する。      ← 啟動效果
```

官方明示 `■手札から自身を召喚する効果の種別は、〜どれにも分類されない効果となります。` 講的是**第一段**,但整團只有一行,所以無種類效果被套用在包含啟動效果的整團上。

## Comments

要注意的是這 2,044 條現在都是 `source: "official"`,而 `official` 在 ADR-0001 的語意下是「判定一次就算數,永不被重跑覆蓋」。若自癒的推論不成立,這批就是被鎖住的暫定資料,規模不小。

### 結論:不會自癒,而且是三重的不會

追了三條路,每一條都堵死:

1. **拆出來的行不見得對不回舊鍵。** 票08 的拆句若把第一段仍叫 `index: "1"`(那是最自然的編號),`(卡片密碼, section, "1")` 就對得回整團那一行。此時本次算不出 `official`(拆開後不再是單效果卡,階梯四、五本來就不開火),`_merge_clause` 走的是「沿用既有判定」那一支,整團的類型會**原封不動落到第一段上**。`text_hash` 變了所以會標 `needs_review`,但值已經寫進去了。
2. **更根本的是:這些卡根本進不了批次。** 票08 的批次檔取的是「仍為 `kind: null` 的卡」。整團被套上一個官方類型之後 `kind` 就不是 `null` 了,這張卡**永遠不會被抽進判定批次**,也就永遠不會被拆句。連走到第 1 點的機會都沒有。
3. **重跑也清不掉。** 已寫進 `data/tag_cards.json` 的 `official` 行在 `PRESERVED_SOURCES` 裡,即使修好抽取器,預設的重跑合併照樣把舊值沿用回來(實測:改完後照常重跑,報告寫「沿用既有判定 1,145 條」,官方明示條數與修改前一模一樣)。

所以這不只是「某些行的 `kind` 標錯」,而是**一整批舊式卡片被靜靜地排除在拆句流程之外**。修。

### 票面數字的訂正

`index` 為純數字且 `source: "official"` 的 2,044 條裡,只有 **1,146 條**是未拆的舊式整團(`index: "1"`);另外 **898 條**是 `index: "0"` 的前言段,那是效果外文本的官方明示,與本票無關(`'①'.isdigit()` 在 Python 是 `True`,原本的量測把編號效果也一起數進去了)。

1,146 條的階梯分布:卡名限定(階梯四)1,076、無歸屬標記(階梯五)69、`『①』`序號引用(階梯二)1。

「整團含 2 句以上」的 999 條**不是**可用的判準:抽樣看過,多句整團裡有大量是單一效果加上補述(`114932`「〜墓地に送る。〜ダメージを与える。この効果は１ターンに２度まで使用できる。」整團就是一個啟動效果)。反過來單句整團也不保證只有一個效果。整團有幾個效果這件事,在拆句完成之前沒有可靠的判準——這正是要交給判定者的理由,所以採**全面排除**而不是加句數啟發式。這與 `_optional_by_rule` 早就對未拆整團做的事一致(票04:硬掃第一句會把官方明示為必發的 79 條標成選發)。

### 實作

`official.py` 新增 `INDEX_UNNUMBERED`(從 `tagcard.py` 移過來,`tagcard` 改為 import),`apply_to_sole_effect()` 在「唯一的效果句就是未拆整團」時改記 `attribution_deferred` / 理由 `無編號卡文待拆`。`test_tagcard.py` 新增 `TestUnsplitOldStyleAttribution`(5 個測試),並把四個原本借用舊式卡文當 fixture 的既有測試改成有編號卡文或改走階梯二——它們測的都不是階梯四、五本身。

階梯二(`『①』`)**不受影響**:官方自己用『①』指名,那是官方給的歸屬證據,不是我們推論出來的。實測受影響的只有 `23927567` 幸運を告げるフクロウ 一張,它的類型仍由『①』判定,只是同一份補足裡走階梯四的必發明示改列進 `mandatory_deferred`。

### 撞出來的另一個洞:票12

規則層逐條的分母都縮水(R1 2,318→2,317、R6 265→255、R7 535→486、R8 68→64、R9 42→41),其中 **R2(`リバース：` → 誘發效果)從 71 條掉到 1 條**——「リバース：」本來就是舊式卡文的句型,它原本的對照幾乎全是被階梯四、五錯誤套上的類型。撤掉是對的,但 R2 現在印著 `1/1 = 100.0% [PASS]` 照常上工,而規則層只對覆蓋條數設下限、對驗證分母沒有。已開票12 追。
