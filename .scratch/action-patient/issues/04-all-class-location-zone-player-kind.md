# 04: 全部類——發動位置與區域、玩家、卡種比對

**What to build:** 沒有數量的全部類受事者(フィールドのカードを全て破壊する)不再一律當皆非,改成依此卡發動時人在哪判斷會不會包含此卡。做完時:
- 從場上發動的「場上的卡全部破壞」兩種模式都不中。
- 「將墓地的此卡除外發動。場上的卡全部破壞」「此卡被送去墓地的場合。場上的怪獸全部破壞」在「非此卡」中。
- 「對手場上的卡全部破壞」「(怪獸卡的)場上的魔法、陷阱卡全部破壞」在「非此卡」中。

來源:spec「動作對象判定 › 發動位置、全部類比對」「匯出檔格式(卡面參數摘要)」「索引管線」;GLOSSARY「動作對象」。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 發動位置在一句效果句(整個編號效果)內依序取:
  1. 條件或代價寫明的此卡區域:このカードが墓地に存在する場合、手札のこのカードを捨てて、墓地のこのカードを除外して。
  2. 條件位觸發事件裡此卡的去處:墓地へ送られた場合 → 墓地;去處不明的「從場上離開」當不在場上。
  3. 處理中此卡自己移動的起點:このカードを手札から特殊召喚 → 手札。
  4. 都沒有就是場上,此卡在我方。
- [ ] 全部類的區域(所在或來源)含發動位置,而且玩家、卡種(怪獸/魔法/陷阱/卡)對得上此卡時,算會包含此卡,判皆非;對不上就判非此卡。本票先不比種族、屬性等其他條件,沒比的條件一律視為對得上。
- [ ] 受事者寫成區域、沒有數量的(手札を全て捨てる)同樣依此規則判斷。
- [ ] 匯出多讀卡片總表裡此卡的卡面參數;匯出檔 META 記卡面參數摘要,索引建置對不上時失敗,處理方式同原文雜湊。
- [ ] 建置報告列:發動位置各來源(寫明、觸發、自己移動、預設場上)各有多少框架,以及全部類判成皆非與非此卡各多少。
- [ ] 匯出接縫測試(日文例句加合成卡面參數):寫明、觸發去處、自己移動、預設場上各一句;玩家對不上、卡種對不上各一句。
- [ ] 索引接縫測試:卡面參數摘要對不上時建置失敗。
- [ ] effect-tokenize 全套與 script/ 測試通過;本機搜「破壊+非此卡」,記下張數與抽樣觀察。
