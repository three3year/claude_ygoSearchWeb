# 07 — 排序

**What to build:** 結果的順序變得可理解、而且「最高攻擊力的暗屬性怪獸是哪張」答得出來。

預設是**領域序**,沿用 oldProject `cmpCards` 的七層比較:大類 → 靈擺卡排後 →
[[卡片子類型]]序 → 等級/階級/連結值**高到低** → 屬性序 → 種族序 → [[卡片密碼]]升序。
第 3、5、6 層的序**直接取自[[值域正典]]的宣告序**,不另抄一份——oldProject 的
`RACES = VOCAB.race.map(e => e.zh)` 旁註著「與宣告序同一份」,就是這個做法,第三抄因此
不存在(ADR-0008)。

另提供排序選單切換到單鍵排序。

**Blocked by:** 02 — 完整卡片呈現

**Status:** ready-for-agent

- [ ] 預設七層領域序,同類卡聚在一起、高等在前
- [ ] 領域序的比較序取自 `window.VOCAB` 的宣告序,程式裡沒有第二份順序表
- [ ] 排序選單:攻擊力、守備力、等級階級、卡名、[[卡片密碼]],各可升降序
- [ ] 排序切換不重跑搜尋(只重排已有結果),分頁位置歸 1
- [ ] 空值(非怪獸沒有攻擊力、`?`)在數值排序中的位置一致且不會插進數值之間
- [ ] 接縫 3 測試:領域序與各排序鍵的順序正確、升降序對稱、排序穩定
      (相同鍵值的卡順序不隨執行變動)
