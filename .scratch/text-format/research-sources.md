# 研究素材:PSCT 與 OCG 9 期文本格式(2026-08-22 取回)

供 `docs/text_format_guide.md` 撰寫票使用。來源層級標記:**官方** / **社群共識** / **庫內實證**。

## 一、TCG PSCT(官方,2011)

來源:Konami 官方 PSCT 專頁 https://www.yugioh-card.com/en/play/psct/ ,規則分佈於 psct-1 ~ psct-7 七篇。

### Part 1 — 背景(psct-1)

- 舊文本用日常語言,近 5000 張卡中運作微妙不同的卡被迫同措辭,產生歧義。
- 三大目標:precise、easy to read、不能像教科書。
- 目標流程:讀卡 → 邏輯推答案(取代讀卡 → 查裁定)。

### Part 2 — 新詞彙(psct-2)

1. "remove from play" → "banish"。
2. "is removed from the field" → "leaves the field"(移往墓地/手牌/除外;不含回卡組);"remove" 只用於指示物。
3. 穿刺統一 "piercing Battle Damage"。
4. "selected as an attack target" → "targeted for an attack"。
5. Hero → HERO 大寫統一(例外:Hero Kid、HERO'S Bond、Hero Flash!!)。

### Part 3 — 冒號分號核心結構(psct-3)

1. 條件「:」發動「;」結算。
2. 冒號前 = 發動條件/時點。
3. 分號前 = 發動時做的事(cost 與取對象);分號後 = 結算處理。
4. 發動段組連鎖時依序處理,結算段依連鎖逆序處理。
5. 怪獸卡或永續魔陷文本有冒號/分號 = 該效果組連鎖;沒有 = 不進連鎖。
6. 例外:一般魔法/陷阱「發動卡片本身」永遠組連鎖。

### Part 4 — 判讀線索(psct-4)

1. Cost 在發動時支付(分號前的 pay/discard/Tribute/destroy 都是 cost)。
2. 發動條件只在發動時檢查,結算時不再要求成立。
3. 結算文再次用 "target"(that target)= 結算時對象仍須符合;用 "it" 等代詞 = 只需取對象當下符合。
4. "both" 出現 = 須能對所有對象套用,否則不處理。
5. 無冒號分號的敘述 = 永續性質;一卡多段效果依各自標點分別判斷。

### Part 5 — 特殊召喚(psct-5)

1. 特召兩類:效果特召(組連鎖)與內建特召(不組連鎖;Cyber Dragon 型、Xyz/Synchro/接觸融合)。
2. 判別:有「:」或「;」= 效果特召。
3. 內建特召以括號標來源:"(from your hand)"、"(from your Extra Deck)"。
4. "must first be Special Summoned":須先以指定方式完成首次特召。
5. 內建特召可被召喚無效類卡無效;效果特召的召喚本身不能被召喚無效(效果可被無效)。
6. "must first" 召喚被無效後,不能再以 Monster Reborn 等復活。

### Part 6 — TU6 & GENF 實例(psct-6)

1. 「發動卡片」vs「發動效果」之分。
2. 無冒號的敘述不組連鎖。
3. "and" = 同時;"then" = 依序(影響「when…you can」任意誘發時點的錯過與否)。
4. "in the Graveyard" 字樣 = 結算時該卡必須仍在墓地。
5. 永續效果無發動、即時適用、不組連鎖。
6. "those targets" = 結算時仍須成立;"they" = 不再檢查。
7. 無 "both" 時對象缺一仍可對剩餘者結算。

### Part 7 — 2012 連接詞(psct-7)

| 連接詞 | 時序 | 依賴 |
|---|---|---|
| A, then B | 依序 | B 依賴 A;A 不依賴 B |
| A, also B | 同時 | 互不依賴,各自盡量執行 |
| A, and if you do, B | 同時 | B 依賴 A;A 不依賴 B |
| A and B | 同時 | 互相依賴,缺一皆不執行 |

可組合(例 Ignition Beast Volcannon:destroy target, **also** destroy this card, **then** if both destroyed, inflict damage)。

## 二、OCG 9 期新文本格式(2014)

**注意:無官方說明文件**(官方僅規則改訂告知頁)。以下為社群一級整理(遊戯王カードWiki 為主),引用須標「社群共識」。

1. **起始**:2014-03 第 9 期(マスタールール3)起;首個新格式產品 ST14(2014-03-21,官方商品頁 https://www.yugioh-card.com/japan/products/?past=st14 )。→ **本專案三級分類界日採 2014-03-21**。
2. **①②③圈號**:每個獨立效果編號「①:」;帶圈號的段落才是「效果」,無圈號敘述為效果外文本。
3. **分段結構**:圈號前未編號文字 = 召喚條件・效果外文本(特殊召喚限制、誓約、卡名回數制限);靈擺卡分【ペンデュラム効果】/【モンスター効果】各自獨立編號。
4. **「:」**:圈號後接發動條件,結構近似「発動条件:コスト・対象;効果処理」(日文主要用「:」,「;」少用)。
5. **発動する / 発動できる**:強制 / 任意。
6. **時 / 場合**:「時」會錯過時點;「場合」不會。
7. **取對象**:含「…を対象として発動」= 取對象;無此字樣即使有「選ぶ」也不取對象。
8. **一回合一次**:
   - 效果段內「この効果は1ターンに1度しか使用できない」= 該效果每回合一次(同名卡各自計)。
   - 效果外「このカード名の①の効果は1ターンに1度しか使用できない」= 以卡名計;「それぞれ」= 各編號分別計。
   - 「使用」被無效也算用過;「適用」被無效可再用。
   - 「同一チェーン上では1度しか発動できない」= 同一連鎖僅一次。
9. **格式目的**:可從文本直判效果分類(起動/誘發/誘發即時/永續)、取對象與否、cost 與處理之分。
