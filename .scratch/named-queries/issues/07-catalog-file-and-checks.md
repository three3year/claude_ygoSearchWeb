**What to build:** 站主打開新的目錄檔,每個節點直接是述詞字彙:大類(名、可選中類清單、子)、中類、具名查詢(述詞、可選子、可選宣告的大類/中類);詞元節點是帶子的具名查詢,沒有預設葉。一次性編譯器把舊類別樹檔的 233 葉與 101 個詞元節點(含 27 個極性類節點)機械改寫成述詞——葉條件 → 來源/目的/所在的 (玩家, 區域)、關鍵詞 → 受事者中心詞、目的關鍵詞 → 目的中心詞、極性類 耐性 → 否定形 {受身, 不成不受}、限制 → 否定形 {不可能}、詞元節點 → 詞元=X 且 極性 {肯定, 可能}、預設葉刪——寫出新目錄檔,編不出來的列清單(預期 0);舊樹檔凍結、只給過渡期的舊歸葉用。目錄模組:載入、檢查(值域、名字全目錄唯一、宣告的大類/中類存在、中類不與詞元節點同名、每大類至少一個具名查詢、詞元是正規詞元、節點名不含路徑分隔符、用了沒有命名規則的欄)、命名(由述詞機械組出,寫法沿用第二版,否定形集合等於耐性集合寫 (耐性)、等於 {不可能} 寫 (限制));改寫後每個節點名與舊葉名/舊節點名一一對應。「至少命中一張」的檢查在票 08。
