# 02: 候選卡計算加速

**What to build:** 物件條件式的候選卡(卡片總表裡滿足條件式的卡)算得夠快,讓之後「建置時把全部候選卡算好」不會拖垮建置時間。結果一張都不能變。

- 先把卡片總表按屬性、種族、等級、字段等建好索引,多數條件式不必逐張掃。
- 只改算法,不改判法:每個物件在每條對象線上的候選卡,加速前後完全相同。
- 這是重構前的準備工作;攤平(票 03)與索引建置(票 06)都建在它上面。

- 規格:需要你決定的「Q13」;實作決策「建置與門檻」。
- 背景數字(不是驗收數字):照原型的算法逐張掃,全庫約 10 分鐘;卡片結構建置約 23 秒。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 全庫每條對象線的候選卡,加速前後逐一相同;比對方式與結果記在 Comments
- [ ] 既有測試全綠,查詢結果不變
- [ ] 回報全庫算完全部候選卡的時間(加速前、加速後),記在 Comments
- [ ] 回報「卡片結構建置加上全部候選卡」合計能不能落在 2 分鐘內;落不進去就停下來,在 Comments 寫明數字,由站主決定
