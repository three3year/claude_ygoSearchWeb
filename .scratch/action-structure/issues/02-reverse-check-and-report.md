# 02: 反向檢查與報告

**What to build:** 站主能看到全庫的反向檢查報告:每段由卡片結構套句型模板產生的日文,正規化(空白、全半形)後與該段原文範圍是否全等;不等的依原因分類、附卡號。之後每張票的標準卡都靠它驗收。

- 反向檢查是純函式:卡片結構 → 句型模板 → 日文,與原文範圍比對。
- 模板依句型撰寫;沒有模板的句型記「無模板」,算不通過、列進報告。
- 本票只需寫齊特異点の悪魔用到的句型模板。

- [ ] 句型模板有少量固定測試
