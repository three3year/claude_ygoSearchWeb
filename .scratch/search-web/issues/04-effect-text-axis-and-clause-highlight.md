# 04 — 效果文關鍵字與句層命中標亮

**What to build:** 效果文框可用,而且命中的是**哪一個效果**看得見——命中的[[效果句]]整行
標亮、關鍵字本身在行內上色、行首掛 badge。逐句比對是這個站與一般查卡站的分水嶺:
「墓地%手牌」只在同一個效果裡同時出現才算命中,而不是散落在兩個無關的效果。

同時實作**排除素材行**:效果文關鍵字不掃 `role = 素材指定` 的 2,358 行。搜「融合」時,
574 張融合怪獸的素材寫法會把真正的答案淹掉。[[效果標記表]]逐句判過 `role`,所以這件事
做得準,而一般查卡站做不到。這是固定規則,不提供開關。

已知副作用(spec 已記):在效果文框搜「青眼白龍」不會撈到把它寫在素材行的融合怪獸,
但卡名框搜得到本尊。

**Blocked by:** 03 — 搜尋骨架與卡名軸

**Status:** ready-for-agent

- [ ] 效果文框逐[[效果句]]獨立比對,一句之內同時滿足才算命中
- [ ] `%` 萬用字元同卡名框
- [ ] **不掃 `role = 素材指定` 的行**;召喚條件、使用次數限制與其餘[[效果外文本]]照樣掃
- [ ] 命中的[[效果句]]整行標亮,關鍵字本身在行內上色
- [ ] 命中行行首掛 badge 標示命中原因
- [ ] 未命中的效果句維持原樣(標亮只落在真正命中的那幾行)
- [ ] 接縫 3 測試:關鍵字只出現在素材指定行 → 不命中;只出現在召喚條件或使用次數限制行
      → 命中;命中效果句索引指向正確的那一句
