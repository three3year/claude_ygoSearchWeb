# 14: 清單收經引用的卡

**What to build:** 自己沒寫這個動作、但引用的別張卡的效果有寫的卡,也出現在網站的清單裡。

- 前端引擎先算每張卡直接命中的段,再沿動作索引的引用列展開到底,走到走過的卡就停。
- 泛用引用固定關:被引用物件是泛用物件的引用列不展開。
- 被引用卡指定的部分不看查詢的區塊種類,照現有規則。
- 已經直接命中的卡不重複列。
- 清單仍然不分組、不加標記;經引用的卡不影響排序。

- 規格:需要你決定的「Q23」;實作決策「動作索引」的引用列、「前端查詢引擎」;使用者故事 33;測試決策「接縫三」「兩邊答案一致」。
