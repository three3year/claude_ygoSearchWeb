# 02 — 限制·次數其餘句型與取代

**What to build:** 站主在拆解頁看到所有「使用次數」都成了限制·次數框架:前言段「このカード名の①②の効果はそれぞれ１ターンに１度しか使用できない」(對象 ①②、共用=それぞれ)、「…いずれか１つしか使用できない」(共用=いずれか１つ)、「このカード名のカードは１ターンに１枚しか発動できない」(對象=這張卡的發動)、「（同一チェーン上では１度まで）」「デュエル中に１度しか使用できない」(期間=同一連鎖/決鬥)、「（１ターンに１度のみ）」括弧註記,以及沒寫発動但句首寫「１ターンに１度、」的效果(P 區「…発動した効果を無効にできる」、代破「…代わりに…事ができる」、場地魔法「…事ができる」)。這些註記句原本的「できる/効果/否定」「発動/効果/否定」動作框架不再出現。

**Blocked by:** 01

**Status:** resolved

- [x] 次數框架記期間(回合/決鬥/同一連鎖)、次數值、對象(哪幾個效果/這張卡的發動/某召喚方式)、共用方式(それぞれ/いずれか１つ/不適用)
- [x] 前言段的次數框架留在前言段,不複製到各編號效果
- [x] 取代:使用次數註記與卡片發動次數註記句不再出動作框架;受影響的既有回歸例子改期望值、不刪
- [x] 句首「…度、」一律為限制·次數(含非發動句);句中「…度だけ」不在本票(歸 06)
- [x] 每個句型一條回歸例子,修規則前先補會失敗的例子
- [x] 全語料重跑,比對取代前後框架數與覆蓋率,發布拆解頁

## 追記(2026-10-09 實作)

- 規則 `constraints.count_notes`:「X は (それぞれ) 期間に N 度/回/枚 (、いずれか１つ) しか/まで (動作)
  できない/できず/できる」整段吃成限制·次數——對象=は 前的主題原文(含分詞器丟掉的 ①②:原文字面從
  前一個 token 結尾起算);「自分は X を 期間に N 度しか 特殊召喚できない」對象記 X の特殊召喚;
  「このカード名の①の方法による特殊召喚は…しかできない」對象記整個主題;一句多個註記(できず、相連)
  各出一個,「同一チェーン上では発動できない」沒數字記同一連鎖 1 次、承接前一註記的主題與共用方式;
  括弧註記「（同一チェーン上では１度まで）」「（１ターンに１度のみ）」對象 この効果。「期間に N 度、」
  字首規則改在註記規則之後跑、跳過已吃掉的範圍(１ターンに１度、いずれか１つ 不再被當字首)。
- 取代:註記句不再出 使用/発動/特殊召喚/選択 的否定動作框架。效果外文本動作框架 7,467 → 1,809、約束
  框架 5,655;效果句動作框架 47,086 → 47,004、約束 1,300;限制·次數合計 6,955(回合 6,837、決鬥 44、
  同一連鎖 74;それぞれ 2,332、いずれか１つ 278)。覆蓋率效果句 100.00%、效果外 78.72%(+2 句)。
- 既有回歸例子改期望值:test_bare_dekinai_takes_topic_as_action、
  test_bare_number_of_time_phrase_stays_out_of_object(裸數字不進對象改用 まで 可能句驗)。
  test_constraints.py +15 條(TestCountNotes,含 P 區/代破字首、「自分フィールドに１枚しか存在できない」
  不是使用次數的邊界)。
- 沒出次數框架而含「しか…できない」的 23 句都不是使用次數:「S召喚にしか使用できない」(素材用途限制)、
  「〜限り１度しか使用できない」(期間是存在期間)、「効果を１度しか発動できない」(誓約,票 04)。
