# 05: 前提、遊戲狀態與位置繼承

**What to build:** 站主查「墓地 → 手牌」能命中白き森のリゼット的②,查「手牌 → 特殊召喚」能命中它的①——因為「このカードが手札/墓地に存在する」把此卡的出發地交代清楚了;「相手ターンに」也記進結構。

- 前提「X が Y に存在する」(含「〜存在する状態で」)把 X 在該區塊的目前位置設成 Y,後續段的「從」可繼承。
- 條件式新增遊戲狀態原子:回合方(我方、對手)、階段、傷害步驟等;只出現在前提。
- 存在(…);前提裡關於物件的條件併進該物件條件;前提可引用「段X已執行」「本回合發生過(段)」。
- 代價段可有多個出發地(手札・フィールドから)。
