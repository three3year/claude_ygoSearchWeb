# 02: 規則推得的方:場上沒寫方、物件寫了控制方

Status: ready-for-agent

**What to build:** 卡片結構建置多一步「補方」:段與對象線抽完後,對每條對象線的從、到補上卡文沒寫、但照規則推得出的方,方的來源記新值「規則」。這張票先做兩條規則,另兩條在 03、04 接上同一步:

- 從的區域沒寫方、物件的條件式寫了控制方(「自分の墓地の」「相手の表側表示モンスター」;子集、剩餘往上找來源物件)→ 照寫的方。到的區域不用這條。
- 場上系區域沒寫方 → 任一方。

「沒寫方」指區域條目沒有方,不看來源;已經有方的不動。反向檢查不把規則補的方寫回字面;驗證字面與區域一致時,來源是規則的條目只比區域。效果:「破壞 從對手的場上」597 → 約 1,248 張;寫明「自分の墓地の」的卡不會出現在「從對手的墓地」。
