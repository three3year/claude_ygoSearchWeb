# 02: 目錄產生標籤(打通整條路)

**What to build:** 使用者在側欄的具名查詢目錄點一列,結果上方多一張 AND 區的標籤,結果立刻更新;點 − 產生「沒有 X」;× 刪掉;網址貼到新分頁開得起來。這張只做 AND 區與葉路徑,抽屜、欄位對、OR 區、左側條件標籤、手機寬都在後面的票。見規格「條件模型」「目錄導覽」「條件列與抽屜」「網址」段,版面以原型 D 版為準。

新模組「條件模型」(純函式)與「條件列」在這張開始。目錄導覽加進 `acat.js`,舊的 `Acat` 介面、引擎的 `q.act` 與它們的測試留到票 07,舊軸 UI 與舊網址參數這張就拿掉。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
