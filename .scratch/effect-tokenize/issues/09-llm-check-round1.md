# 09 — LLM 檢驗第一輪

**What to build:** 依效果數與卡種分層、固定種子抽 300 張卡(約單效果怪獸 100、多效果 100、魔陷 70、靈擺 30),切成 6–8 份交給 LLM 子代理,每份讀原文與抽出的框架「挑錯」,回報漏抽動作、論元抽錯、位置判錯、極性判錯,每項附理由。產出依錯誤類型歸納的報告,作為 10 號票修規則的輸入。

**Blocked by:** 06、07

**Status:** ready-for-agent

- [ ] 分層抽樣規則與種子固定,300 張樣本清單存檔(複檢沿用同一批)
- [ ] 子代理回報格式統一(卡號、句序、錯誤類型、理由)
- [ ] 錯誤依類型歸納成報告,列各類次數與代表例
- [ ] 子代理數量維持 6–8 個;若改用多代理工作流程編排,先取得站主同意
