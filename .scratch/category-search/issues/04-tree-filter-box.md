# 04: 過濾框

**What to build:** 牌手在動作類別軸頂端的過濾框輸入日文字面(例:墓地),樹只留名稱含它的節點與其祖先,方便在 235 個葉裡找;清空回原狀,過濾不改已選條件。來源:spec「側欄(query)」。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 過濾框比對節點的日文名稱(子字串),只顯示命中節點與其祖先,祖先自動展開;命中的上層節點底下的子節點照常可展開。
- [ ] 清空過濾框時樹回到過濾前的展開狀態;已選節點不因被過濾隱藏而取消,標題已選數不變。
- [ ] 手機寬度可用。
- [ ] 人工驗收(同現有側欄):輸入 墓地、破壊、→手札 各一次確認結果合理。
