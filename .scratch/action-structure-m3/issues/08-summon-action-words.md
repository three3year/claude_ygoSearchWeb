# 08: 召喚動作詞

**What to build:** 單獨的「召喚」有動作詞,「〜に成功した」的條件段解析得出:

- 新增 召喚(上位詞 通常召喚)、上級召喚(アドバンス召喚、生け贄召喚;上位詞 召喚)、反轉召喚(反転召喚;沒有上位詞)、P召喚(P召喚、ペンデュラム召喚;上位詞 特殊召喚)。下位詞展開現行已是傳遞的,只在下位詞表加列。
- リンク/シンクロ/エクシーズ召喚 同義到既有的 L/S/X召喚。
- 「召喚・特殊召喚」「召喚・反転召喚・特殊召喚」等列舉:一段多個動作詞。
- 「このカードが召喚した時」與「召喚に成功した時」記同一個結構,此卡是被召喚的角色;原述語字面各自保留。
- 「墓地からの特殊召喚に成功」的「からの」記成 從;「モンスターの特殊召喚に成功」的「の」是對象線助詞。
- 「この効果で/この方法で特殊召喚に成功した」記原因 效果,指向本卡那一段;「「X」モンスターの効果によって」記原因 效果帶物件(既有)。
- 「召喚」字幹不能讓未解析組比中無關字面。

### 做了什麼

- 同義表:加 召喚(單獨的「召喚」)、上級召喚(アドバンス召喚、生け贄召喚、A召喚)、反轉召喚(反転召喚)、P召喚(P召喚、ペンデュラム召喚);リンク/シンクロ/エクシーズ召喚 收成 L/S/X召喚。下位詞表加 上級召喚 → 召喚 → 通常召喚、P召喚 → 特殊召喚。
- 列舉「召喚・特殊召喚」「召喚・反転召喚・特殊召喚」「召喚・P召喚」「通常召喚・特殊召喚」:一段多個動作詞。語尾不限「に成功した」,「〜した」「〜された」「〜できない」「〜する際」都收。
- 「モンスターの特殊召喚に成功」的「の」記成對象線助詞;「墓地からの特殊召喚に成功」的「からの」記成從(字面「墓地からの」)。
- 原因:
  - 「「X」モンスターの効果で/によって」「「X」と名のついたモンスターの効果によって」「「X」カードの効果で」記 效果帶物件。既有的只收單獨的「X」(「「バスター・モード」の効果で」),這次把物件放寬成以 モンスター/カード 收尾的名詞短語。
  - 「この効果で/この方法で/このカードの①の効果で/このカードの①の方法で 〜召喚に成功した」記 效果,另帶 `segment` 指向做那次召喚的段。
- 未解析組比字面:「召喚」落在別種召喚(特殊召喚、通常召喚、反転召喚、S/X/L/P召喚與片假名全寫)與「召喚条件」「召喚獣」「召喚師」「召喚魔術」「召喚士」「召喚神」「デーモンの召喚」裡不算。
- 順帶:「モンスター１体の召喚を行う」「〜のA召喚を行う」照既有的「X召喚を行う」收;「P召喚できる」「融合召喚できない」的「で」原本會被當成原因「〜召喚で」,整段述語解析不出(改前就有的錯),已修。

### 標「讀法」的決定(規格沒寫死、照既有做法或自己定的,請站主過目)

1. **A召喚 = 上級召喚**。規格只列アドバンス召喚、生け贄召喚;新卡文用字母寫法「A召喚」(全庫約 60 段),照「字母寫法與片假名全寫是同一個詞」收了。票面寫「查「上級召喚」只命中寫アドバンス召喚或生け贄召喚的段」,現在也命中寫 A召喚 的段。
2. **態不相同**。「このカードが召喚した時」態是 主動、「召喚に成功した時」是 被動(態照語尾,既有的「特殊召喚した」413 段也是這樣)。動作詞、對象線(此卡、角色 被召喚、助詞 が)、觸發形相同,查詢不比態,所以查詢結果相同。要兩邊的態也一致的話要另外裁定。
3. **通常召喚的角色跟著改**。對象線角色改成照召喚系的根算(特殊召喚、通常召喚、反轉召喚與下位詞都是 被召喚)。字面寫「通常召喚」的既有 365 段因此從 受事 變成 被召喚;查詢與反向檢查都不看這個差別。
4. **召喚、通常召喚、反轉召喚沒進推得表**。規格沒說,沒加。影響:「このカードは表側表示で召喚できる」這類 22 段因為沒有到,標「表示形式沒有到」。要不要加「召喚 → 場上」請裁定。
5. **列舉的段不查推得表**(既有規則:一段多個動作詞時不推得)。「召喚・特殊召喚に成功した」的線沒有到;單獨的「特殊召喚に成功した」有推得的到 場上。
6. **「この効果で」指哪一段**:寫了編號(このカードの①の…)就在那個編號的區塊找;沒寫就從這一段往前找,同區塊先前的段優先,再往前面的區塊;取最近一個做了那種召喚的段(條件段、極性 不能/不會 的段不算)。找不到(那一段本身解析不出)就整段標「指回的物件找不到」,現有 8 段。
7. **「この効果で特殊召喚に成功した」主語省略時誰被召喚**:記那一段召喚的物件,不一律當此卡(シャドウ・ヴァンパイア 召喚的是別的怪獸)。那一段不是恰好一條線、或還串著別的動作時判不了,標解析不出。
8. **原因 效果帶物件的放寬不只影響召喚**。「このカードが魔法カードの効果で墓地へ送られた場合」「「地縛」カードの効果で破壊された場合」「幻竜族モンスターの効果でのみ特殊召喚できる」這類 74 段也跟著解析出。「戦闘または「X」以外のカードの効果で破壊された」不認(戰鬥與效果的或,現有的格記不了),照舊解析不出。
