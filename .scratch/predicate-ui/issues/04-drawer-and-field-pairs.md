# 04: 抽屜與欄位對網址

**What to build:** 點動作標籤開右側抽屜改欄位,結果立刻更新,改過的標籤寫進網址,貼出去開得起來。使用者可以在同一個查詢裡讓一張標籤要此卡、另一張要非此卡,或把位置改成條件。見規格「條件模型」「條件列與抽屜」「網址」段。手機的底部面板在票 06。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 抽屜:頭是短句與包含/排除切換,接著單張張數、「改自 X」與還原鈕、刪除鈕;欄位分常用與進階,不含詞元;點某個字捲到那一欄,點抽屜外關閉
- [ ] 值從 `VOCAB.frame.domains` 來,玩家選單列出 相對、無 與不限玩家;中心詞自由輸入,候選是中心詞表前 300 個;位置全關視同三個位置都看,明寫三個值
- [ ] 標籤短句跟著欄位變;滑鼠提示顯示具名查詢名或「改自 X」;區域的日文對照涵蓋值域每個區域(測試守)
- [ ] 網址:位置不是預設或欄位改過就寫欄位對 `欄:值~值;欄:值`;區域項 `玩家.區域` 或 `區域`;沒寫 `位置` 是效果、沒寫 `極性` 是不限;欄序與值序固定
- [ ] 轉義:欄名與值逐個 `encodeURIComponent` 再把 `~` 補編成 `%7E`;值含 `: ; , ~ › |` 往返不變
- [ ] 解析:不認得的欄、值域外的值、不在詞元表的詞元安靜忽略,沒有詞元的標籤整張忽略,不認得的欄不會送進引擎;壞百分比編碼不崩
- [ ] 改回原樣回到葉路徑;重新載入後改過的標籤沒有「改自 X」與還原鈕,除非欄位又等於某個具名查詢
- [ ] `Hash` 與條件模型接縫的例子涵蓋以上各條
- [ ] 真瀏覽器桌面走一次:改欄位、還原、包含/排除切換、此卡與非此卡並用、條件位、貼網址到新分頁,console 無錯
- [ ] node 測試全過
