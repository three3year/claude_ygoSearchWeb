# 01: 類別匯出、索引與句尾葉名

**What to build:** 站主開網站時,結果清單每一句標記句尾都列出它的動作類別葉(效果位與代價位,代價位看得出是代價),資料從分詞鏈匯出、入版控,索引建置對過時或對不上的類別吵鬧地失敗。來源:spec「分詞鏈匯出(新)」「索引管線(接縫 1)」「呈現」;ADR-0017。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 分詞鏈在框架類別之後多一步匯出:每句標記句(鍵同效果標記表,● 子效果句是自己的 index)記效果位葉、代價位葉(各自去重、依樹序)與日文原文雜湊,另帶類別樹(節點路徑、樹序、預設葉);寫進資料目錄、入版控。條件位、未歸框架不帶葉,約束框架不在。
- [ ] 框架對標記句:單段效果句整個屬那一句;拆開的效果句依選項 n → index-●n、沒有選項 → 領起句;匯出步驟本身檢查「每個動作框架剛好對到一句」,對不上就失敗。
- [ ] 匯出接縫的回歸例子(合成小資料,真的分詞器):● 子效果句、帶選項但沒拆的 ●、效果外文本、靈擺段落、條件位與未歸、多葉框架、代價位框架、雜湊是那一句的原文。
- [ ] 索引建置讀匯出檔:每句標記句多兩個對齊欄位(效果位葉、代價位葉;沒有就省略);類別樹與涵蓋卡數進 VOCAB;雜湊對不上、匯出有標記表沒有的句、葉不在樹裡三種都建置失敗並在報告列出(接縫 1 測試各一條)。
- [ ] 建置報告加涵蓋卡數、帶葉的句數、各大類句數,索引大小與 gzip 大小照舊列出。
- [ ] 呈現:每句尾列它全部的葉(日文原名),代價位的葉字面可辨;沒有葉的句不多出東西(呈現縫測試)。
- [ ] 分詞鏈決定性重跑兩次匯出檔逐位元組相同;索引兩次建置逐位元組相同;effect-tokenize 全套、script/ Python 與 JS 測試通過。
