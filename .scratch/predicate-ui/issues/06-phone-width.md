# 06: 手機寬

**What to build:** 手機上條件列、抽屜、換區都用得順手,捲結果時條件還看得到,改完條件回得到結果。見規格「條件列與抽屜」段,版面以原型 D 版的手機寬為準。

**Blocked by:** 04, 05

**Status:** ready-for-agent

- [ ] 條件列固定在頂端,超過上限在列內捲動
- [ ] 抽屜在手機是底部面板,點面板外關閉
- [ ] 標籤上有 ⇄ 鈕換區(桌面不顯示)
- [ ] 保留「看結果(N 張)」鈕,收起側欄;篩選鈕顯示條件數;Enter 重查時同時收起側欄
- [ ] 帶條件的網址開起來側欄摺著,條件列看得到全部條件
- [ ] 點左側條件的標籤時展開側欄並跳到那一項
- [ ] 頁面沒有橫向捲動
- [ ] 真瀏覽器手機寬(390 px)走一次:點列、開面板改值、⇄、看結果、貼網址重開,console 無錯
