# 05: 前提、遊戲狀態與位置繼承

**What to build:** 站主查「墓地 → 手牌」能命中白き森のリゼット的②,查「手牌 → 特殊召喚」能命中它的①——因為「このカードが手札/墓地に存在する」把此卡的出發地交代清楚了;「相手ターンに」也記進結構。

- 代價段可有多個出發地(手札・フィールドから)。
