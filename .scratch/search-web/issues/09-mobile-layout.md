# 09 — 手機版面

**What to build:** 在手機上查得動——比賽中或組牌時掏出手機能用。範圍是「能用就好」:
側欄在窄螢幕收成頂部可摺疊區、卡片改單欄、圖片縮小。三到四條 media query。

**不做**的事情要一起講清楚,免得範圍膨脹:不做觸控手勢、不做下拉重整、不做底部固定搜尋列、
不做手機專用的條件全螢幕層。oldProject 整份 `style.css` 只有一條 media query,本站做到
四條就已經比它認真。

**Blocked by:** 05 — 卡片參數軸、06 — 效果類型與必發選發軸

**Status:** ready-for-agent

- [ ] 窄螢幕(720px 以下)側欄收成頂部可摺疊區,預設收起、點一下展開
- [ ] 卡片改單欄,卡圖縮小但仍看得清楚
- [ ] 條件區的按鈕群、範圍輸入框在窄螢幕不溢出、不需要橫向捲動
- [ ] 分頁器在窄螢幕不換行成三四排
- [ ] 桌機版面完全不受影響
- [ ] 以瀏覽器裝置模擬檢查三種寬度(手機直立、手機橫放、平板)
